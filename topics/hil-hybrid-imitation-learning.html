HIL: Hybrid Imitation Learning — 가상 인간 파쿠르 모션 제어

Carnegie Mellon University·NVIDIA·Simon Fraser University 공동 연구 ‘HIL: Hybrid Imitation Learning for Dynamic Athletic Control’. 단 19개 클립·30초 분량의 인터넷 파쿠르 영상으로 가상 인간이 인간다운 동작을 모방하면서도 새로운 장애물에 맞춰 즉흥적으로 동작을 조합하도록 학습시키는 기법.

핵심 내용

해결하는 딜레마

  • 모방 학습(copy): 아름답고 자연스럽지만 학습 데이터 범위를 벗어난 상황에 취약 (brittle)
  • 목표 지향 학습(goal-chasing): 새 장애물에 적응하지만 인간다운 동작을 잃음
  • HIL은 두 접근을 동시에 학습시켜 양쪽 장점을 결합

훈련 구조 — 두 교실 동시 학습

  • 교실 1 (모방): 인간 동작 복사 학습 → 자연스러운 동작 생성, 단 학습 데이터(19클립·30초)에 제한됨
  • 교실 2 (목표): 새 장애물 코스 해결 학습 → 적응력 확보
  • 두 교실 모두 신체·장애물·목적지 정보를 공유 — 핵심 설계 원칙
  • 하나의 AI 컨트롤러가 두 교실에서 동시에 학습

GAN 기반 판별자 학습

  • 판별자(discriminator)가 실제 인간 동작과 AI 동작을 구분하도록 학습
  • AI 캐릭터는 판별자를 속이도록 보상을 받음 → 적대적 학습 (GAN 구조)
  • 손실 함수: min_D -E_{d_M} log(D(s,c)) - E_{d_π} log(1-D(s,c)) + w_gp E_{d_M} ||∇_φ D(φ)||²
    • 첫 항: 실제 인간 동작을 ‘진짜’로 판별
    • 둘째 항: AI 동작을 ‘가짜’로 판별
    • 셋째 항(gradient penalty): 판별자 학습 안정화 정규화

학습 데이터

  • 파쿠르 영상 19개 클립, 총 30초 분량
  • 데이터 수집 파이프라인: 영상 포즈 추정 → 3D 장면 주석 → 시뮬레이션 참조 동작 생성 [Wang et al. 2026]
  • 방향 전환(heading control) 과제에는 Sword and Shield Dataset [Peng et al. 2022] 추가 사용

성능 결과

  • 적응력: 미지의 장애물 배치, 다수(20개) 장애물 연속 코스, 방향 전환 과제까지 일반화
  • 정량 성과: 5개 장애물·σ=0 조건으로 학습 후 20개 장애물·σ=0.03 노이즈 조건에서 40% 과제 완료율
  • 트레이드오프: 이전 기법 대비 추적 오차(tracking error)는 낮지만 성공률에서 일부 손해

남은 한계

  • 긴 장애물 코스에서 성공률 약 40% 수준
