AI로 실제 재미있는 3D 게임 만들기 — Matt Wolfe 실험 기록

Matt Wolfe가 Claude Code(Opus 5)와 Codex(GPT-5.6)를 이용해 전작 ‘The Librarian’(2D)의 후속작 ‘Librarian 2’(3D)를 약 2시간 만에 제작한 실험 기록. AI가 게임 개발을 ‘끝냈다’는 SNS 주장에 반박하기 위해 진행되었으며, 코딩보다 디자인 판단이 진짜 병목임을 실증했다.

핵심 내용

  • 실험 동기: X(트위터)에서 반복되는 ‘바이브코딩 게임 = 게임 개발 종말’ 주장에 반박. Take-Two CEO 인용: “코딩은 게임 개발의 병목이었던 적이 없다”
  • 전작(The Librarian): 도서관 사서 역할 2D 게임. 학생들이 어지른 책을 선반에 정리해 XP 획득, 카오스 게이지 100%면 게임오버. GitHub·플레이 가능 링크로 공개 (44 stars, 18 forks, JS 99.2%)
  • 후속작 목표: 3D 환경·절차적 생성 레벨·파워업·영구 메타 업그레이드·보스 시스템·자연재해(지진·토네이도) 추가
  • Opus 5 초기 빌드: 약 1시간 30분 만에 10,400줄·33개 모듈 생성. 에셋 파일 0개 — 텍스처·머티리얼·사운드·배경음악까지 전부 코드로 절차적 생성. AI가 스스로 게임을 실행·스크린샷·버그 수정·밸런스 조정 수행
  • 모델 이관 방법론: 게임 현재 상태를 마크다운 설계 문서(design.md)로 정리 + GitHub 업로드 → Codex(GPT-5.6)가 문서를 읽고 12개 개선안 제시 (컨텍스트 핸드오프)
  • Codex 최우선 버그 제시: ① 절차적 도달 가능성(reachability) 버그 — Grand Library 시드 87%에서 진입 불가 구역 발생 ② 진행도(progression) 스택 문제 — 여러 업그레이드 효과가 실제 적용되지 않음 ③ 짧은 인터랙티브 튜토리얼 추가
  • 플레이 테스트 결과: 프로듀서 Dave와 실플레이 — 튜토리얼·콤보 시스템·보스(Braden the Bully)·지진·토네이도 시연. 발견된 문제: 토네이도 데미지 너무 느림, 보스 너무 빠름, 소프트락(책이 어느 선반도 받지 않음), 아이들이 멈추지 않고 계속 어지름. 최고 카오스 95%로 게임오버 경험
  • GPT-5.6(Soul Ultra)으로 후처리: 좌클릭 드래그 카메라 회전·창문 채광 개선·난이도 곡선 완화·재난 데미지 강화를 30분 추가 작업으로 개선
  • 잔존 한계: 4개 레벨이 색상 외에는 시각적으로 크게 차별화되지 않음. 콘텐츠 다양성 확보는 AI 자동화 한계 영역
  • 배포 계획: Steam 출시 의사 없음. GitHub·플레이 가능 링크로 무료 공개 예정

모델별 역할 분담 실무 판단

모델강점용도
Claude Code (Opus 5)시각적으로 인상적인 초기 버전 생성, 대량 절차적 콘텐츠초기 빌드, 렌더 파이프라인·프로시저럴 텍스처·레벨 테마
Codex (GPT-5.6)설계 문서 기반 개선안 도출, 세부 버그 분석컨텍스트 핸드오프, 버그 우선순위 제시, 후처리
GPT-5.6 Soul Ultra세부 UX·비주얼 조정카메라·조명·난이도 곡선·재난 데미지 개선

게임 주요 수치 및 기믹

  • 초기 빌드: 코드 10,400줄, 모듈 33개, 에셋 파일 0개
  • 레벨 이름: The Grand Library / Blockbuster Nite(잠김, 12,000 XP 해금) / Groove Merchant Records / Mega Mart Superstore / Old Vault(회색조 차별화)
  • 첫 레벨업 보상 예시: 화재훈련(재해 지속 -15%·강도 -12%), 연체 콤보(20% 빠르게 축적·0.4초 연장), 독서안경(+10% XP)
  • Mega Mart 전용 기믹: 바나나 껍질 미끄러짐, 버섯 먹으면 캐릭터 커짐(SUPERSIZED 파워업)
  • 재난 시스템: 지진(EARTHQUAKE), 토네이도, After-School Rush, 불량학생(Braden the Bully) 보스
  • 플레이 결산 화면 예시: Score 17,650 / 생존 15:00 / 책 처리 568 / 최고 콤보 x71 / 최고 카오스 18% / +23,042 lifetime XP
  • 설정 옵션: 그래픽 품질(Low/Medium/High/Ultra), 마스터 볼륨, 음악, 효과음, 전체 진행 초기화

AI 빌드 워크플로우 상세

Claude Code(Opus 5) 빌드 단계

  1. 원작 분석 (5 commands, 3 files 읽기)
  2. 프로젝트 스캐폴딩·렌더 파이프라인 기초 구축
  3. 프로시저럴 텍스처(textures.js) 생성
  4. 레벨 테마(themes.js) 생성
  5. 아트 수정(선반 깊이·DOF 블러·램프 발광)
  6. 스트레스 테스트 — 60fps·384 draw calls·8분 크래시 없음 확인
  7. 카오스 급상승·오디오 버그(_panFor NaN 오염) 자동 수정

GitHub 백업 → Codex 핸드오프

  • design.md 작성(게임 현황 요약) → GitHub 푸시 → Codex가 문서 읽고 컨텍스트 이어받기
  • Codex가 generator.js(line 397)·game.js(line 242) 등 구체적 버그 위치까지 지목

핵심 주장 — ‘게임 개발은 끝나지 않았다’

  • AI가 생성한 코드는 자체 테스트·스크린샷·버그 수정까지 자동 수행했으나, 밸런싱은 여전히 실제 플레이 피드백 필요
  • 코딩이 아닌 수많은 디자인·밸런스 의사결정이 진짜 핵심 — AAA 스튜디오의 게임 디렉터·크리에이티브 디렉터·디자인 디렉터 역할은 AI가 대체 불가
  • Nick Dobos 트윗(‘모두가 자기 게임을 만들 테니 게임 산업이 죽었다’) 반박: 영화를 보는 것이 만드는 것보다 쉬운 것처럼, 잘 다듬어진 상업 게임을 플레이하려는 수요는 사라지지 않음
  • 개인이 바이브코딩으로 게임을 만드는 것이 상업 게임 구매를 대체하지 않을 것 — ‘재미있는 장난감’ 수준
  • 1년 전 원작 대비 툴 발전 체감: 과거엔 에셋·사운드를 여러 툴로 짜맞췄지만 지금은 한두 개 AI 툴에 프롬프트 몇 개만으로 결과물 생성 가능
