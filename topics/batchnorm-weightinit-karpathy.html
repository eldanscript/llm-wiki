활성화·그래디언트·배치정규화 — Andrej Karpathy makemore Part 3

Andrej Karpathy의 makemore 시리즈 3편. Part 2의 MLP를 기반으로 신경망 학습의 핵심 실무 이슈인 가중치 초기화, tanh 포화 문제, Kaiming 초기화, 배치정규화(BatchNorm)를 깊이 있게 다루고, 활성화·그래디언트·업데이트 비율을 시각화하는 진단 도구를 구축한다 (2022-10-04, 115분 57초).

핵심 내용

1. 초기화 문제: ‘하키스틱’ 손실 곡선

  • 마지막 레이어(logit)가 랜덤으로 초기화되면 첫 스텝에서 모델이 confidently wrong 상태
  • 균등분포 기준 이론적 초기 손실: ln(27) ≈ 3.29
  • 잘못 초기화된 경우 실제 초기 손실: ~27 → 학습 초반 불필요한 ‘하키스틱’ 급강하
  • 해결책: 마지막 레이어 가중치와 bias를 0에 가깝게 초기화 (W2 * 0.01)

2. tanh 포화 문제와 Dead Neuron

  • tanh의 극단값 영역(±1)에서 그래디언트가 소멸(vanishing gradient)
  • 프리액티베이션이 과도하게 크면 히든 유닛이 -1/1 포화 영역에 몰림
  • Dead Neuron: 한 뉴런의 모든 예제가 포화되면 그래디언트가 0 → 영원히 학습 불가
  • 진단: (|h| > 0.99) 불리언 행렬(imshow)로 포화 뉴런 스캔
  • 해결책: 가중치 스케일 축소 (예: 0.2배)

3. Kaiming(He) 초기화

  • 원리: 순전파 분산을 레이어 통과 후에도 보존
  • x@w 행렬곱 시 표준편차가 1→√fan_in으로 팽창 → w / √fan_in으로 정규화
  • 공식: std = gain / √fan_in
    • 선형: gain=1
    • ReLU: gain=√2
    • tanh: gain≈5/3
  • 근거 논문: Kaiming He et al. “Delving Deep into Rectifiers” (arXiv:1502.01852)
    • PReLU 도입, ImageNet top-5 오류율 4.94%로 인간 수준(5.1%) 최초 초과
  • PyTorch: torch.nn.init.kaiming_normal_(tensor, mode='fan_in', nonlinearity='relu')

4. 배치정규화(BatchNorm)

알고리즘 (Ioffe & Szegedy 2015):

1. μ_B = (1/m) Σ x_i            # 미니배치 평균
2. σ²_B = (1/m) Σ (x_i - μ_B)² # 미니배치 분산
3. x̂_i = (x_i - μ_B) / √(σ²_B + ε)  # 정규화
4. y_i = γ x̂_i + β              # 스케일·이동 (학습 파라미터)

효과:

  • 프리액티베이션을 배치 단위로 평균 0·표준편차 1로 정규화
  • 초기화 민감도를 크게 낮춤 (가중치 스케일에 훨씬 덜 민감)
  • 배치 내 예제 간 통계적 결합(jitter) → 부수적 정규화 효과

실전 포인트:

  • BatchNorm 직전 선형 레이어의 bias는 무의미 → bias=False로 설정 (ResNet 공식 코드에서도 확인)
  • 추론 시 단일 예제 처리를 위해 러닝 평균/표준편차 별도 추적 필요
    • bnmean_running, bnstd_running을 momentum 0.001 지수이동평균으로 갱신
  • 배치 결합 문제로 LayerNorm·GroupNorm 등 대안 등장

PyTorch 초기화: bngain = torch.ones(...), bnbias = torch.zeros(...)

6. 진단 시각화 도구

활성화 분포(activation distribution):

  • 레이어별 tanh 출력의 mean, std, 포화 비율(|t|>0.99) 히스토그램
  • 목표: 모든 레이어가 유사한 분포 유지

그래디언트 분포(gradient distribution):

  • 파라미터별 shape, mean, std, grad:data ratio 수치표
  • 마지막 레이어 이상치 탐지

업데이트-대-데이터 비율(update:data ratio):

  • lr × grad.std() / param.std() 로그10 스케일
  • 기준선: -3 → 모든 파라미터가 이 근처에 있어야 이상적
  • plt.plot([0, len(ud)], [-3, -3], 'k') 기준선 표시
  • BatchNorm 포함 후: 모든 파라미터가 -3 근처로 안정적 수렴

7. 핵심 이론 정리

활성화 함수수식gain
Sigmoid1/(1+e^-x)1
tanh(e^x - e^-x)/(e^x + e^-x)5/3
ReLUmax(0, x)√2
Leaky ReLUmax(0.1x, x)—
ELUx if x>0, α(e^x-1) if x≤0—
  • 순수 선형 레이어만 쌓으면 아무리 깊어도 하나의 선형 변환으로 붕괴 → 비선형성 필수
  • update:data ratio: gradient-to-data ratio보다 실제 학습 속도 진단에 더 유용

인사이트

  • BatchNorm은 “초기화 문제를 해결하는 마법”처럼 보이지만, 배치 결합·버그 위험·추론 복잡성을 수반함 → LayerNorm(Transformer에서 표준)으로 이어지는 흐름
  • Kaiming 초기화는 PyTorch nn.Linear 기본값(균등분포 U(-1/√k, 1/√k))보다 이론적으로 우월한 시작점 제공
  • update:data ratio -3 기준선은 실무에서 빠르게 학습 상태를 진단하는 강력한 휴리스틱
  • 이 강의에서 구축한 진단 시각화 패턴은 이후 대규모 모델 학습 모니터링의 원형
