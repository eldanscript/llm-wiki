시뮬레이션이 지배한다: 합성 AI 파이프라인 8단계 (Latent Space AINews, 2026-08-22)

Latent Space AINews가 「10% worse, 100x cheaper, 10000x faster: Why Simulation is taking over」 제목으로 발행한 에세이. 2022년 이후 AI 파이프라인의 각 구성요소가 순차적으로 사람이 만든 것에서 모델이 만든 것으로 교체되어 온 과정을 8단계로 정리한다.

핵심 내용

합성 파이프라인 8단계

단계영역대표 사례
1보상 신호InstructGPT / Constitutional AI
2학습 데이터Textbooks Are All You Need / WRAP / Nemotron-4
3교사 모델Alpaca / Vicuna / Orca / DeepSeek-R1 증류
4커리큘럼Self-Rewarding LM / SPIN

8물리 세계Poolside 피벗 / CZ Biohub virtual cell — 아직 미완
  • 핵심 주장: 합성 데이터가 발전하는 시점은 ‘생성 품질이 좋아질 때’가 아니라 ‘검증 메커니즘이 신뢰할 만해질 때’
  • 마지막 미완 영역: 물리 실험(웻랩) — 합성화가 완전히 이루어지지 않는 유일한 영역

Karpathy autoresearch

  • 코딩 에이전트가 실제 LLM 훈련 셋업을 밤새 700회 실험 → 20개 개선안 채택
  • GPT-2 도달 시간: 2.02시간 → 1.80시간 단축

Generative Agent Simulations of 1,000 People

  • 2시간 인터뷰 기반 디지털 트윈 생성
  • 2주 뒤 본인 재현 정확도의 85% 수준 재현

Ox Alpha 스텔스 모델 논란

  • 정체불명 코딩 에이전트 모델이 DeepSWE 10개 과제에서 80%+ 달성
    • Fable 65%, GPT-5.6 Sol 52%와 비교
  • GLM-5.3/5.4 Vision 파생 모델이라는 추정이 우세
  • Kimmonismus가 벤치마크 결과 최초 공개

DeepSeek-V4-Flash-Vision-Exp 출시

  • 텍스트 성능 유지 + 멀티모달 입력 지원 추가
  • 이미지당 117~384 토큰을 Flash 가격으로 과금
  • 재사용 업로드용 Files API 함께 공개

OpenAI GPT-5.6 Sol 가격 인하 & Codex 성장

  • GPT-5.6 Sol API 가격 3개월간 20%+ 인하
  • Codex 활성 사용자 2,000만 명 돌파 → banked reset 혜택 지급
  • API 키별 사용량 추적·조직 한도 설정 기능 추가

GLM-5.3 성능 향상 메커니즘

  • 새 베이스 모델 아님 → 743B 베이스 동일
  • post-training + 샌드박스 + SAO(세밀한 credit assignment) 강화로 성능 향상

새 벤치마크들의 낮은 점수 (현실적 에이전트 성능 한계)

  • SWE-bench Science: Claude Code + Opus-5도 50% 미만
  • CADBench: 최고 모델 24.6% pass rate
  • AI4AI-Bench: 최고 0.288점

vLLM IsoExec

  • 부동소수점 비결합성으로 인한 RL rollout/training logprob 불일치 해결
  • Qwen3.5-35B-A3B + DAPO 실험: logprob 오차 1.6e-2 → 6.7e-7 (오버헤드 25.3%)

로컬 Qwen3.8-27B 에이전트 실사용 후기 (Reddit)

  • RTX 3090, Q4 양자화로 Playwright를 통해 학교 시스템 접근 성공 — 예상 밖의 에이전트 능력
  • 동시에 지식 회상 능력은 Qwen3.6 대비 퇴보 — 상반된 보고 공존
