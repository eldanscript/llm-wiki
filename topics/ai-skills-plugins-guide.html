AI 코딩 에이전트용 무료 스킬·플러그인 9종 가이드

Matt-Wolfe 채널이 소개한 Claude Code·Codex 등 AI 코딩 에이전트에 무료로 설치 가능한 스킬·플러그인 9종 실전 가이드. (2026-06-24)

1. 스킬 vs 플러그인 개념 정의

구분정의구성
스킬(Skill)SKILL.md 파일에 담긴 재사용 가능한 상세 프롬프트프롬프트 + (선택적) 참조 스크립트·예시·에셋
플러그인(Plugin)스킬·에이전트·훅·MCP 서버·커맨드를 묶은 설치 단위 번들스킬 + 에이전트 + MCP + 커맨드 + 기타 설정
  • 공통 작동 방식: 에이전트가 SKILL.md를 사용자 프롬프트와 함께 동시에 읽어 일관된 반복 행동을 보장
  • 설치 방법: GitHub URL 제공 후 ‘이거 설치해줘’ 한 마디 — Claude Code, Codex, Cursor, VS Code, Microsoft Copilot 등 주요 IDE·에이전트 하네스에서 범용 작동

2. 소개된 스킬·플러그인 9종

2-1. gstack (Garry Tan, Y Combinator CEO 제작)

  • 성격: 대형 번들(플러그인)
  • 구성: 23명의 전문가 역할 + 8개 파워툴, 모두 슬래시 커맨드·마크다운·무료·MIT 라이선스
  • 주요 파워툴:
    • /codex: Codex CLI로 크로스모델 세컨드 오피니언 획득
    • /careful: rm -rf·DROP TABLE 등 위험 명령어 실행 전 경고
    • /freeze: 편집 허용 범위 잠금
  • 리뷰 커맨드: /plan-design-review→/design-review, /plan-eng-review→/review, /autoplan 등 단계별 커맨드 지원

2-2. Stop Slop

  • 성격: 소형 스킬 (GitHub 12k stars)
  • 기능: AI 특유의 문체(AI tells)를 감지·제거해 글을 자연스럽게 다듬음
  • 용도: 에이전트가 생성한 문서·블로그·이메일 등에서 인공적인 AI 문체 탈피

2-3. Graphify

  • 성격: 지식 그래프 생성 스킬
  • 기능: 코드베이스·문서·노트를 쿼리 가능한 지식 그래프로 변환 → 에이전트가 매번 재탐색 없이 그래프를 메모리처럼 조회 → 토큰 절약
  • FutureTools 코드베이스 실행 결과: 824 nodes, 1,748 edges, 49 communities, 108개 파일, ‘God Nodes’ 상위: createAdminClient() 82 edges, Button 26 edges
  • 세컨드브레인 시각화: YouTube creator strategy·creator sustainability·AI agent workflow 등 노드가 색상별 커뮤니티로 클러스터링
  • 비교 포인트: Understand Anything과 달리 에이전트 메모리 레이어(토큰 절약)에 초점

2-4. Understand Anything

  • 성격: 코드베이스 시각화·온보딩 스킬
  • 기능: 코드를 인터랙티브 지식 그래프로 생성 — 신규 개발자 온보딩과 에이전트 탐색 양쪽에 사용 가능
  • 아키텍처 다이어그램: API Routes·Security Boundary → Services & Integrations·Supabase Data Model → Admin Workflows → Public UI 레이어 구조 시각화
  • 비교 포인트: Graphify와 달리 사람(온보딩)이 탐색하는 시각화에 초점

2-5. Last 30 Days

  • 성격: 실시간 인터넷 여론 리서치 스킬
  • 커버 소스: Reddit·X·YouTube·Hacker News·Polymarket·GitHub
  • 기능: 특정 주제의 최근 30일 여론을 근거와 함께 종합, HTML 내보내기 지원
  • Claude Fable 5 리서치 결과 예시:
    • Reddit: 21 threads / 48,949 upvotes / 6,618 comments
    • YouTube: 20 videos / 3,204,002 views
    • Hacker News: 27 stories / 4,256 points / 2,758 comments
    • Polymarket: Claude Fable 5 restored 86%, US government rescind ban 14%

2-6. 프런트엔드 디자인 스킬 (Anthropic 공식)

  • 성격: UI 생성 스킬 (Anthropic 공식 제공)
  • 실험: Taste 스킬과 4가지 조합(미사용/디자인 단독/Taste 단독/동시) 비교 테스트

2-7. Taste (Leon 제작)

  • 성격: UI 품질 향상 스킬 (GitHub 5만 stars)
  • 기능: 에이전트가 생성하는 UI의 디자인 취향·품질 기준을 끌어올림
  • 실험 결과: 동일 프롬프트에서 Taste + 디자인 스킬 동시 사용 시 가장 우수한 결과 평가

2-8. Remotion

  • 성격: 텍스트→애니메이션 생성 스킬
  • 기능: 텍스트 프롬프트로 애프터이펙트풍 애니메이션(문자메시지·로고 리빌·주가 차트) 생성
  • 데모: NVDA 5년 주가 애니메이션 — 2021-06-23~2026-06-23, +356% 수익률, Yahoo Finance 데이터

2-9. Hyperframes (HeyGen 제작)

  • 성격: 텍스트→애니메이션 생성 스킬 (Remotion 대안)
  • 평가: 발표자 주관 테스트에서 대체로 Remotion보다 우수한 결과물 생성

3. 주요 인사이트

  • 스킬은 보편 자산: Claude Code, Codex, Cursor, VS Code, Copilot 등 주요 에이전트 하네스에서 동일하게 작동
  • Graphify vs Understand Anything: 둘 다 지식 그래프를 생성하지만 목적이 다름 — 전자는 에이전트 메모리(토큰 절약), 후자는 사람 온보딩(탐색)
  • 커뮤니티 자산화: 사용자들이 발견한 최적 프롬프트를 SKILL.md로 공개해 누구나 복제 가능한 방식이 에코시스템 핵심
  • Matt-Pocock-Skills-Workflow와의 연관: 스킬/플러그인 개념은 Matt Pocock의 mattpocock/skills 저장소와 동일한 패러다임. gstack은 그 대표적 대형 번들 사례
