LLM 입문 강연 — Andrej Karpathy 2023

Andrej Karpathy가 2023년 11월 발표한 약 1시간 분량의 LLM 입문 강연. LLM의 구조, 훈련 파이프라인, 미래 발전 방향, 보안 취약점을 체계적으로 설명한다. 유튜브 누적 조회수 수백만 회를 기록한 입문 자료의 정석.

핵심 내용

  • LLM = 2개 파일: 파라미터 파일(Llama-2-70b 기준 140GB, float16) + 실행 코드(run.c, ~500줄). 인터넷 없이 MacBook에서 실행 가능한 자기완결 패키지
  • 훈련 2단계 구조:
    • Stage 1 프리트레이닝: ~10TB 텍스트, GPU 6,000개, 12일, ~$200만. 연 단위 반복
    • Stage 2 파인튜닝: ~10만 건 고품질 Q&A, 훨씬 저렴, 주 단위 반복. 결과물이 어시스턴트 모델
  • 다음 단어 예측 = 세계 지식 압축: 정확히 예측하려면 Ruth Handler의 이름·생몰년 등 실제 지식을 파라미터에 내재화해야 함 → LLM은 인터넷의 손실 압축
  • RLHF: 생성보다 비교가 쉬운 인간 노동 특성 활용. 후보 답변 중 더 나은 것을 고르는 비교 라벨로 모델 추가 개선 (3단계 파인튜닝)
  • 스케일링 법칙: 파라미터 수(N)와 학습 데이터량(D) 두 변수만으로 다음 단어 예측 정확도 예측 가능. 알고리즘 개선 없이 규모 확대만으로 성능 향상
  • LLM OS 비유: LLM = 커널 프로세스, 컨텍스트 윈도우 = RAM, 계산기·Python 인터프리터 = 도구, 브라우저 = 네트워크 I/O. 챗봇이 아닌 운영체제 패러다임
  • 시스템1 한계: 현재 LLM은 즉각 반응하는 시스템1만 보유. 시간을 들인 시스템2 추론, 자기개선, 커스터마이징이 미래 과제
  • 보안 위협 3종: 탈옥(jailbreak, 적대적 노이즈 판다 이미지로 83%/78% 복종률 조작), 프롬프트 인젝션, 데이터 포이즈닝/백도어(James Bond 트리거 슬리퍼 에이전트)

인사이트

  • LLM을 “챗봇”으로 보지 않고 운영체제 커널로 보는 프레임은 이후 Agentic AI 담론의 원형이 됨
  • 시스템1/시스템2 구분은 2025년 이후 o1·DeepSeek-R1 같은 추론 모델(Thinking Model) 의 등장으로 현실화
  • 백도어 공격 논의는 2026년 LLM-Backdoor-Detection (LexisNexis Diff-SAE 연구)로 이어짐
  • 스케일링 법칙과 도구 연동 예측은 GPT-4·Claude 3.5 시대에 그대로 실현됨
