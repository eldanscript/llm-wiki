TypeScript 고급 패턴 6가지 — Total TypeScript 팁 모음

Matt Pocock의 Total TypeScript 강좌 기념 컴필레이션. 난이도 순으로 정리된 실전 TypeScript 트릭 6가지.

1. 키 옵셔널 vs 값 옵셔널 (Key-Optional vs Value-Optional)

가장 중요한 구분 — LLM이 가장 자주 틀리는 패턴

  • LLM은 새 속성 추가 시 습관적으로 ?(키 옵셔널)를 붙임 → 내부 함수 체인에서 값이 조용히 누락될 수 있음
  • OpenTelemetry trace ID 예시: 키 옵셔널이면 doThing({}) 호출 시 traceId 누락 → 프로덕션에서 조용한 정보 유실
  • 규칙: 공개 API 표면 → 키 옵셔널 / 내부 함수(값이 체인을 타고 전달돼야 함) → 값 옵셔널

2. Pick/Omit vs Exclude/Extract — 유틸리티 타입 구분

유틸리티대상동작
Pick<T, K>객체 타입지정한 키만 포함한 새 객체 타입
Omit<T, K>객체 타입지정한 키를 제외한 새 객체 타입
Extract<T, U>유니언 타입유니언에서 U에 할당 가능한 멤버만 추출
Exclude<T, U>유니언 타입유니언에서 U에 할당 가능한 멤버를 제거
  • 자리를 바꿔 쓰면 에러 없이 never나 엉뚱한 결과 → 디버깅이 어려운 조용한 버그

3. Prettify — 교차 타입 평탄화 헬퍼

  • TypeScript에 기본 내장되지 않은 커뮤니티 유틸리티 타입
  • 복잡한 교차 타입(intersection)을 IDE hover 시 깔끔한 단일 객체 형태로 표시
  • & {} 가 핵심: 빈 객체 교차로 타입을 강제 평탄화
  • 실제 타입은 동일, 표시 방식만 변경 → 디버깅·문서화에 유용

4. 루즈 오토컴플리트 (Loose Autocomplete)

  • 유니언 리터럴에 | string을 그냥 추가하면 string으로 collapse → 자동완성 소멸
  • (string & {}) 형태로 감싸면 collapse가 지연되어 자동완성 유지 + 임의 문자열 허용 동시 달성
  • React, Vercel AI SDK 등 여러 라이브러리에서 실제 사용 중인 패턴

5. 매핑 타입 (Mapped Types)

  • [K in keyof T]: 객체의 각 키를 순회
  • as: 키 리매핑 — 템플릿 리터럴·Capitalize 결합 가능
  • 읽기전용 제거(-readonly), 옵셔널 제거(-?) 등 수정자 제어

6. 즉시 인덱싱된 매핑 타입 (IIMT — Immediately Indexed Mapped Type)

  • 매핑 타입 뒤에 [keyof T]를 붙여 값들만 모아 유니언으로 변환
  • { type: K } & Actions[K]로 판별자(discriminant)를 각 멤버에 자동 주입
  • Matt Pocock이 2022년 2월에 처음 공개한 팁 — TypeScript에 애정을 갖게 된 계기라고 언급
  • 키드 오브젝트 → 판별 유니언 변환의 표준 패턴으로 자리잡음
