Tencent Octop — 자가호스팅 멀티 에이전트 AI 어시스턴트

텐센트 클라우드가 MIT 라이선스로 공개한 자가호스팅 AI 어시스턴트로, Expert(특화 에이전트)·Knowledge Base(문서 검색)·Teams(멀티 에이전트 협업)·ACP(외부 코딩 에이전트 연동)·Automation(예약 작업) 기능을 단일 대시보드에 통합한 플랫폼이다.

핵심 내용

  • 포지셔닝: OpenAI Dots·Meta Muse 같은 상시 에이전트 플랫폼의 자가호스팅 오픈소스 대안. GitHub TencentCloud/Octop, 6.6k stars, MIT 라이선스, 현재 v1.0.2b5
  • 설치 방법: macOS/Linux curl -fsSL .../install.sh | bash, Windows PowerShell irm .../install.ps1 | iex. 이후 octop run 실행 시 포트 8088에서 Uvicorn 서버 구동, 일회성 초기 비밀번호 ~/octop-login.txt에 저장
  • Expert 구조: 각 Expert는 독립 워크스페이스·모델 설정·프롬프트 파일 5종(AGENTS.md·SOUL.md·IDENTITY.md·USER.md·TOOLS.md)을 가짐. 역할 분리(작성 Expert + 검토 Expert)로 품질 검증 파이프라인 구현 가능
  • Knowledge Base(지식베이스): 별도 임베딩 모델(BAAI/bge-small-en-v1.5, 로컬 ONNX)로 문서 벡터화. 채팅 모델과 완전 분리되며, 온라인 임베딩 서비스 사용 시 문서 내용이 해당 서비스로 전송되고 추가 비용 발생
  • Agent Teams(베타): 코디네이터 1명 + 멤버 최소 2명 구조. 멤버는 Running 상태여야 작업 수신 가능. 코디네이터 응답 중단 시에도 이미 넘어간 멤버 작업은 계속 진행되므로, 앱 재시작 전 멤버 작업 완료 여부 확인 필수
  • ACP(Agent Client Protocol) 연동: OpenCode·Claude Code·Codex·CodeBuddy·Kimi Code·Pi 등 외부 코딩 에이전트를 Expert에 연결 가능. 단, 동일 머신에 해당 도구가 사전 설치·설정되어 있어야 하며, 연동이 해당 도구의 모델 사용 비용을 면제하지 않음
  • Automation(예약 작업): cron 스케줄 + Text(고정 메시지) 또는 Agent(매번 모델이 실제 실행) 두 가지 모드. octop service start로 백그라운드 상시 구동 필요, 프로세스 종료 시 예약 작업도 중단
  • 주요 검증 사례: TaskBoard 2.4 가짜 릴리스 노트(디바이스 동기화 지원·내일 출시 허위 주장) 삽입 후, Reviewer Expert가 원본 문서와 대조해 오류를 실제로 잡아냄
  • 비용 구조: 앱 자체는 무료이나 연결 모델(클라우드 API 또는 로컬 하드웨어) 비용은 별도. Expert 수 증가 시 모델 호출 비용 비례 증가. 발표자 권장: Expert 1개·모델 1개·작은 문서 1개로 시작해 검증 후 확장

한계 및 주의사항

  • Agent Teams는 베타 상태로 안정성 제약 존재
  • 채팅의 완료 메시지와 실제 파일 생성 결과가 다를 수 있어 직접 확인 필요
