gcloud 핵심 명령어 치트시트 (GCP CE 준비용)

GCP Customer Engineer 업무(고객 미팅 데모·PoC·문제 진단)에서 자주 쓰이는 gcloud CLI 명령어를 카테고리별로 정리한 레퍼런스. SDK 586.0.0(core 2026.09.20) 기준. 전체 GA 명령 5,769개 중 약 121개(~2%)를 선별.

선별 기준

  • 한 워크플로를 처음부터 끝까지 실행하는 최소 세트 (생성→조회→접속·호출→정리)
  • 다른 명령의 전제가 되는 공통 기반 (로그인·API 활성화·권한 부여)
  • 문제 원인 탐색에 쓰는 진단 명령 (로그·정책 진단·연결 테스트)
  • CE 업무 우선 서비스: Vertex AI·Cloud Run·GKE·BigQuery·IAM

전역 플래그 (모든 명령에 사용 가능)

플래그하는 일
--project이 명령만 다른 프로젝트에 대해 실행
--account이 명령만 다른 로그인 계정으로 실행
--format출력 형식: json, yaml, table(...), value(...)
--flatten리스트 필드를 행 여러 개로 펼침 (--filter와 함께 사용)
--quiet, -q확인 질문을 모두 기본값으로 넘김 (삭제 명령에 주의)
--impersonate-service-account서비스 계정 권한으로 실행 (키 파일 불필요)
--filter, --limit, --sort-bylist 계열 명령에서만 사용 가능

시작·설정·인증

명령어하는 일예시
gcloud init로그인·프로젝트·기본 리전 대화식 설정gcloud init
gcloud auth login사용자 계정으로 gcloud 로그인gcloud auth login --no-launch-browser
gcloud auth application-default login코드·라이브러리용 ADC 자격증명 생성gcloud auth application-default login
gcloud auth print-access-tokenREST 호출용 액세스 토큰 출력curl -H "Authorization: Bearer $(gcloud auth print-access-token)" URL
gcloud auth print-identity-token인증된 Cloud Run 호출용 ID 토큰 출력curl -H "Authorization: Bearer $(gcloud auth print-identity-token)" URL
gcloud auth activate-service-account키 파일로 서비스 계정 로그인 (CI용)gcloud auth activate-service-account --key-file=KEY.json
gcloud auth configure-dockerdocker가 Artifact Registry 인증에 gcloud 사용gcloud auth configure-docker us-central1-docker.pkg.dev
gcloud auth list로그인된 계정 및 활성 계정 확인gcloud auth list
gcloud auth revoke계정 자격증명 삭제 (로그아웃)gcloud auth revoke EMAIL
gcloud config list활성 설정 확인gcloud config list
gcloud config set기본 프로젝트·리전 지정gcloud config set project PROJECT_ID
gcloud config get속성 값 출력gcloud config get project
gcloud config configurations create이름 붙인 설정 세트 생성gcloud config configurations create customer-a
gcloud config configurations list설정 세트 목록gcloud config configurations list
gcloud config configurations activate설정 세트 전환gcloud config configurations activate customer-a
gcloud components installkubectl 등 부가 구성요소 설치gcloud components install kubectl gke-gcloud-auth-plugin
gcloud version설치된 gcloud 버전gcloud version
gcloud info설치 경로·설정·로그 위치 진단gcloud info
gcloud projects list접근 가능한 프로젝트 목록gcloud projects list --format="table(projectId,name)"
gcloud projects describe프로젝트 메타데이터gcloud projects describe PROJECT_ID

팁: gcloud auth login(gcloud CLI용)과 gcloud auth application-default login(코드·라이브러리용) ADC는 저장 위치가 다름. gcloud auth login --update-adc로 한 번에 갱신 가능.

IAM·조직 정책

명령어하는 일예시
gcloud iam service-accounts create서비스 계정 생성gcloud iam service-accounts create SA_NAME --display-name="Demo SA"
gcloud iam service-accounts list서비스 계정 목록gcloud iam service-accounts list
gcloud iam service-accounts add-iam-policy-binding서비스 계정 자체에 권한 부여gcloud iam service-accounts add-iam-policy-binding SA_EMAIL --member="user:EMAIL" --role="roles/iam.serviceAccountTokenCreator"
gcloud iam service-accounts keys create키 파일 발급 (최후 수단)gcloud iam service-accounts keys create KEY.json --iam-account=SA_EMAIL
gcloud projects add-iam-policy-binding프로젝트 수준 역할 부여gcloud projects add-iam-policy-binding PROJECT_ID --member="serviceAccount:SA_EMAIL" --role="roles/run.invoker"
gcloud projects get-iam-policy프로젝트 IAM 정책 조회gcloud projects get-iam-policy PROJECT_ID --flatten="bindings[].members" --filter="bindings.members:user:EMAIL" --format="table(bindings.role)"
gcloud iam roles describe역할이 포함하는 권한 목록gcloud iam roles describe roles/aiplatform.user
gcloud policy-troubleshoot iam권한 부여·거부 이유 추적gcloud policy-troubleshoot iam RESOURCE --principal-email=EMAIL --permission=PERMISSION
gcloud org-policies list조직 정책 제약 확인 (PoC 막힐 때 먼저 확인)gcloud org-policies list --project=PROJECT_ID

팁: 키 파일 없이 서비스 계정 권한 테스트 시 --impersonate-service-account=SA_EMAIL 전역 플래그 사용. 호출자에게 roles/iam.serviceAccountTokenCreator 필요.

BigQuery (bq CLI)

bq는 gcloud와 별개 CLI이지만 함께 사용하는 GCP 핵심 도구.

명령어하는 일예시
bq ls데이터셋 목록bq ls --project_id=PROJECT_ID
bq mk데이터셋 또는 테이블 생성bq mk --dataset PROJECT_ID:DATASET_NAME
bq querySQL 쿼리 실행bq query --use_legacy_sql=false 'SELECT COUNT(*) FROM project.dataset.table'
bq load파일에서 테이블로 데이터 로드bq load --source_format=CSV DATASET.TABLE gs://BUCKET/file.csv schema.json
bq extract테이블을 Cloud Storage로 내보내기bq extract DATASET.TABLE gs://BUCKET/export-*.csv
bq show테이블·데이터셋·Job 상세bq show --format=prettyjson DATASET.TABLE
bq rm테이블 또는 데이터셋 삭제bq rm -f DATASET.TABLE
bq cp테이블 복사bq cp SOURCE.TABLE DEST.TABLE
bq jobs list최근 Job 목록bq jobs list --max_results=10
