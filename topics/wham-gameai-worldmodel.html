WHAM: 게임 플레이 영상으로 게임을 만드는 AI

Microsoft Research(Kanervisto et al. 2025)의 WHAM(World and Human Action Model) — 인간 게임 플레이 영상을 학습해 새로운 상황에서 다음 프레임을 예측·생성하는 세계 모델. Nature 게재. (Two Minute Papers, 2025-03-03)

핵심 내용

  • WHAM 정의: 게임 플레이 영상을 시퀀스로 학습한 후, 컨트롤러 입력이 주어지면 다음 화면 프레임을 예측·생성하는 ‘게임 세계 모델’. 사실상 게임을 실시간으로 합성함
  • 아키텍처: Causal Transformer가 관측(o_t)과 컨트롤러 액션(a_t)을 번갈아 토큰화해 처리. VQGAN 인코더/디코더(reconstruction + perceptual loss)로 픽셀 복원. 관측 토큰 vocabulary z_t ∈ {1,…,16384}^540, 액션 토큰 a_t ∈ {16385,…,16452}
  • 학습 진행에 따른 품질 변화: 초기 학습 → 다른 장면으로 이탈 / 중간 학습 → 같은 맵·점프 동작 재현 / 완전 학습 → 점프 vs. 비행 구분, 파워셀 상호작용 정확히 재현
  • 다양성(Diversity): 동일 시작 지점에서 Left / Centre / Right 세 방향으로 각 3개씩(3×3 그리드) 다양한 시퀀스 생성 가능
  • 지속성(Persistency): 새 오브젝트·캐릭터를 장면에 추가하면 AI가 그 자리에 유지하고 상호작용 가능하게 만듦. 단일 프로모션 이미지 한 장으로 게임을 ‘살아 움직이게’ 할 잠재력
  • 주요 활용처: 완성 게임 대체재가 아닌, ① 빠른 프로토타이핑, ② 기존 게임의 ‘what-if’ 실험(장애물 추가 시 게임이 깨지는가 등). 27명 게임 제작자 사용자 연구에서 반복 수정(iterative tweaking)의 중요성 확인
  • 바텀업 vs. 탑다운 대비: WHAM의 ‘탑다운(영상 학습→새 영상 생성)’ 방식과 달리, Claude 3.7·Grok 3 같은 LLM이 코드를 처음부터 작성하는 ‘바텀업’ 방식도 존재 (Claude의 Self-Aware Snake 게임, Grok 3의 멀티플레이어 비행 시뮬레이터 사례)
  • 기술 전망: AI 영상 생성 기술이 Google Phenaki → Veo2 수준으로 빠르게 발전한 선례를 근거로, 현재 저해상도 게임 생성도 1년 이내 고해상도화 예측. ‘완전히 새로운 게임 창작’은 수년간 미지수

아키텍처 세부

  • 입력 표현: 관측 o_t는 VQGAN으로 이산 토큰 인덱스(vocabulary 16,384개)로 압축. 액션 a_t는 68개 컨트롤러 액션을 별도 vocabulary로 토큰화
  • VQGAN 학습: reconstruction loss + perceptual loss 결합. 인코더·디코더는 WHAM Causal Transformer와 분리 학습
  • Demonstrator UI: 컨트롤러 입력 패널·프레임 타임라인·In/Out/Reps/Temp 슬라이더·Predict 버튼으로 구성된 인터페이스로 실시간 프로토타이핑 가능
