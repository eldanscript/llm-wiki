JCode — Rust 기반 초경량 AI 코딩 에이전트 하네스

Rust로 작성된 MIT 라이선스 오픈소스 AI 코딩 에이전트 하네스. GitHub 11,000+ 스타. 초저 리소스 사용량·시맨틱 메모리·스웜 모드가 주요 차별점.

핵심 내용

리소스 효율

지표JCode경쟁 도구
베이스라인 메모리~28MB140~400MB
부팅 시간14msJCode 대비 27~245배 느림
세션당 추가 메모리~10MB76~300MB+

시맨틱 메모리 시스템

  • 벡터 임베딩 + 시맨틱 검색으로 이전 세션 맥락 자동 보존
  • Passive retrieval: 에이전트 도구 호출 없이 관련 메모리 자동 삽입
  • Active memory tool: 수동 검색·저장
  • 백그라운드 자동 통합(consolidation) + 오래된 정보 걸러내기(staleness checking) → 코드베이스 이해도 점진적 향상

스웜 모드

  • 여러 에이전트가 동일 저장소에서 동시 작업
  • 파일 충돌 자동 감지 및 에이전트 알림
  • 에이전트 간 메시지 교환 가능
  • 기존의 git worktree + tmux 수동 구성 대체

내장 기능

  • 브라우저 자동화: Firefox 백엔드·페이지 스냅샷·클릭·입력·스크린샷·JS 실행(별도 MCP 서버·확장 불필요)
  • Self-dev 모드: 에이전트가 자기 소스코드 수정·재빌드·무중단 재적용
  • 타 하네스 세션 재개: Claude Code·Codex·OpenCode 세션 --resume으로 계속 가능
  • 터미널 내 Mermaid 렌더링: 자체 라이브러리(표준 대비 ~1,800배 빠름 주장)

지원 프로바이더

Claude·OpenAI·Gemini·GitHub Copilot·Azure·OpenRouter·DeepSeek·OpenAI 호환 엔드포인트·Ollama·LM Studio
