바이브 코딩 35가지 핵심 개념 완전 가이드 (Riley Brown)

Riley Brown이 vibecode.dev에서 TaskGPT 앱을 실제로 구축하며 바이브 코딩에 필요한 35개 핵심 용어를 하나씩 설명하는 43분 튜토리얼 (2026-01-27). 모든 플랫폼(Lovable, vibecode.dev, Replit, Claude Code)에 공통 적용 가능.

핵심 용어 체계

기본 구조

용어정의
PromptAI 코딩 에이전트에게 무엇을 만들지 전달하는 자연어 설명. 첫 프롬프트가 가장 중요
Front-end사용자가 보는 버튼·텍스트·이미지·폼 등 시각적 요소 전체
Back-end서버 로직, 인증, DB 연산, API 호출 등 사용자에게 보이지 않는 서버 측 처리
Database앱 데이터를 영구 저장하는 구조화된 저장소 (enable 버튼 하나로 인증과 동시 추가)
Authentication사용자 신원 확인 메커니즘. vibecode.dev에서는 이메일 OTP 방식 기본 제공

API 계층

용어정의
API앱이 외부 서비스와 데이터를 주고받는 인터페이스
Third-party API외부 서비스(GPT-5.2, Gemini 3 Pro 등) API. 백엔드에 API 키 저장
Webhook외부 서비스가 특정 URL로 데이터를 보내 앱을 실시간 트리거하는 방식

에이전트·자동화

용어정의
AgentAI 모델이 툴을 루프 안에서 사용하는 것. 일반 챗봇과 달리 자율적·반복적 툴 호출
Agent Skills에이전트에 부여하는 외부 액션 능력 (예: Slack 웹훅 연동)
Queue (Q)프롬프트를 순차 예약해 에이전트가 순서대로 처리하도록 하는 기능

개발·운영

용어정의
Error앱이 예상대로 동작하지 않는 상태
Debugging오류의 원인을 찾아 수정하는 과정
Logs앱 실행 중 발생한 이벤트 기록
SchemaDB의 테이블·필드·관계 구조 정의
Seed Data실제 데이터 없이 디자인 프로토타입을 위한 가짜 테스트 데이터
Deployment앱을 인터넷에 공개하는 과정
Hosting배포된 앱이 실제로 실행되는 서버 인프라
Domain앱의 공개 URL 주소
SaaS구독 기반 클라우드 소프트웨어 서비스

Claude Agent SDK 활용

  • 일반 챗봇 모델(GPT-5.2, Gemini 3 Pro)과 달리 웹서치 같은 툴을 자율적으로 반복 호출
  • vibecode.dev 기본 에이전트: Claude Opus 4.5
  • 에이전트 모드 전환 시 비용 증가에 주의 (누적 비용 실시간 표시: 758 904 범위)

Tasks DB 스키마 예시

task 테이블
- id
- title
- userId
- createdAt
- updatedAt

SignalLite + TaskGPT Webhook 연동 사례

  • SignalLite: 음성 메모 모바일 앱 (iPhone 프레임 UI, 파형 애니메이션)
  • 음성 메모 → Webhook → TaskGPT에 실시간 태스크 자동 생성
  • 외부 앱 → 특정 URL → 실시간 트리거 구조

핵심 조언

  • SaaS로 바로 수익화하려 하지 말고 개인 도구/팀 내부 도구부터 제작·검증 후 유료화 고려
  • 첫 프롬프트에 디자인 레퍼런스 이미지 첨부로 원하는 UI 방향 지정 가능
  • AI가 인증·백엔드부터 만들면 토큰 소모가 크므로 단순한 프롬프트로 시작 후 점진적 기능 추가 권장
  • database enable 버튼 하나로 인증과 데이터베이스가 동시에 앱에 추가됨
