Eval Tools with FastHTML — 주석 앱 직접 구축

Isaac Flath가 AnkiHub 실제 상용 의료 플래시카드 평가 사례를 토대로, FastHTML 파이썬 웹 프레임워크로 데이터 주석(annotation) 앱을 직접 만드는 방법을 시연한 강연. Hamel Husain의 ‘Build Your Own Eval Tools’ 시리즈 일환.

핵심 내용

  • 자체 주석 앱 구축이 최고 레버리지 — AI 프로젝트에서 데이터 주석 앱을 직접 만드는 것이 가장 높은 레버리지를 가진 작업 중 하나
  • AnkiHub 도메인 난제 — 쿼리 길이가 단어50페이지로 가변적이고, 결과는 12문장 의료 플래시카드이며 전문 용어 정밀 매칭 필요 → 기성 검색 도구 plug-and-play 불가
  • FastHTML 특징 — HTML 태그를 파이썬 함수로 1:1 감싼 저추상화 프레임워크. Streamlit·Gradio보다 유연하며 커스텀 CSS/JS 파일 불필요
  • HTMX 부분 업데이트 패턴 — 버튼 클릭·입력 변경 시 페이지 전체가 아닌 대상 DOM 요소만 서버가 다시 렌더링해 교체(hx_post, hx_target)
  • 평가 워크플로우 — 2명의 주석자가 독립 평가 후 불일치 시 각자 근거를 남기고 최종 조정(finalize); 주석자는 의대생 도메인 전문가
  • Phoenix 연동 — 완료된 주석 데이터를 관리자 대시보드의 ‘Push to Phoenix’ 버튼으로 Phoenix(트레이스·데이터셋 저장소)에 이관
  • AI 코딩 조언 — 완전 수작업도 100% 바이브코딩도 지양; FastHTML처럼 AI가 덜 익숙한 프레임워크는 cursor rules로 충분한 컨텍스트 제공 필요
  • 빠른 반복 철학 — 완벽한 설계보다 단순한 버전을 빠르게 내놓고 실제 주석 과정에서 드러나는 문제(예: 쿼리 자체의 타당성 평가 누락)를 고치는 방식 권장

도구 스택

  • FastHTML — 파이썬 웹 프레임워크
  • MonsterUI — FastHTML UI 컴포넌트 라이브러리 (TableFromDicts, ButtonT 등)
  • HTMX — 부분 DOM 업데이트
  • fastlite — SQLite 경량 ORM
  • Phoenix — 트레이스·주석·데이터셋 저장소
  • Cursor Rules — AI 코딩 시 FastHTML 컨텍스트 제공용 룰 파일
