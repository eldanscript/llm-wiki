Gemini / Enterprise Agent 고객 사례 모음 (GCP CE 준비용)

Google Cloud 공식 블로그·발표에서 다룬 Gemini / AI Studio / Enterprise Agent(Agent Builder, Vertex AI Agent Engine, Agentspace/Gemini Enterprise, Customer Engagement Suite 등) 관련 실제 고객 사례 정리. GCP Customer Engineer 제안·데모 준비용.

사례 1 — Schroders: 다중 에이전트 금융 리서치 어시스턴트

출처: Google Cloud Blog, 2025-06-26
고객: 글로벌 액티브 투자관리사
문제: 신규 기업 분석에 수일 소요, 20~30개 심층 분석 + 20개 모니터링 기업을 담당하는 애널리스트의 데이터 수집 시간 과부하

GCP 스택:

  • Vertex AI Agent Builder + Gemini 모델 + LangGraph(오케스트레이션)
  • Vertex AI Search(내부 문서 그라운딩) + Google Search API(실시간 공개 정보) + BigQuery(NL→SQL) + Firestore(에이전트 설정·대화 이력)
  • 향후 ADK·A2A 프로토콜 전환 계획

아키텍처: Router Agent → 전문화 에이전트(R&D·Financial Data·Market Intelligence 등) 라우팅. Porter’s 5 Forces 분석 = 부모 에이전트가 5개 자식 에이전트 병렬/순차 실행 후 취합.

개발 단계: Phase 1 Native Function Calling → Phase 2 LangGraph(순환 워크플로·human-in-the-loop 체크포인트·부모-자식 구조)

성과: 신규 기업 분석 소요 시간 「수일 → 수분」 단축 (정성적 표현, 정확한 % 미공개)

CE 활용: 금융·자산운용·리서치 조직 고객. 「도구는 에이전트당 3~4개로 제한」, 「결정론적 계산과 비결정론적 요약을 그래프로 분리」 설계 가이드로 활용 가능

사례 2 — Customer Engagement Suite: TTEC / loveholidays / YouTube

출처: Google Cloud Blog, 2025-03-13
제품: Customer Engagement Suite (Conversational Agents + Agent Assist + Call Summarization + Conversational Insights + CCaaS)

성과 수치:

회사지표성과
TTEC고객 상호작용 자동화율최대 40%
TTEC에스컬레이션 감소40%
TTEC평균 처리 시간(AHT) 감소11%
TTEC신입 상담원 성과 향상18%
TTEC통화 후 업무 시간 감소30초~4분

loveholidays연간 운영비 절감£3M ($3.8M)

YouTube대기열 이탈 감소75%

CE 활용: BPO(TTEC)·이커머스/여행(loveholidays)·빅테크 내부(YouTube) 3개 유형 혼합. loveholidays £3.8M 연간 절감은 CFO/COO용 슬라이드 소재

사례 3 — Comcast: Xfinity Assistant를 ADK·Agent Runtime으로 재구축

출처: Google Cloud Blog, 2026-04-23 (Gemini Enterprise Agent Platform 발표)
고객: Comcast
문제: 스크립트 기반 자동화에서 대화형 생성형 AI로 전환, 개인화 트러블슈팅 제공 목표

GCP 스택: Agent Development Kit(ADK) + Agent Runtime(Gemini Enterprise Agent Platform 실행 계층) + Gemini 기반

성과: 디지털 완결률(digital containment) 증대. Rick Rioboli(CTO): “Agent Runtime이 획기적인 가속기였다”

CE 활용: 레거시 스크립트 챗봇 → ADK 기반 대화형 에이전트 전환 스토리. 통신·미디어·유틸리티 고객 대상 “당신이 지금 가진 것(스크립트)에서 우리가 제안하는 것(ADK+Agent Runtime)으로” 구도 데모 설계

사례 4 — Payhawk: Memory Bank로 지출 처리 시간 50% 단축

출처: Google Cloud Blog, 2026-04-23
고객: Payhawk(기업용 지출·경비 관리 플랫폼)
문제: 상태 비저장(stateless) 에이전트로 사용자가 매번 같은 맥락 반복 입력

GCP 스택: Gemini Enterprise Agent Platform Memory Bank — Financial Controller Agent가 과거 지출 습관·맥락을 장기 기억

성과: 비용 제출(expense submission) 소요 시간 50% 단축 (공개 수치)

CE 활용: “에이전트가 기억을 갖는다”는 Memory Bank 가치를 한 줄 수치로 설명. 반복 업무(경비 처리·티켓 재문의·정기 리포트)가 많은 백오피스 고객 대상 “매번 처음부터 설명하지 않아도 되는 에이전트” 각도 데모 설계. Gurunavi(Memory Bank로 만족도 30%+ 향상)와 묶어 패턴 제시

사례 5 — Color Health: Virtual Cancer Clinic으로 유방암 검진 접근성 확대

출처: Google Cloud 프레스룸 2025-10-16 + Google Cloud Blog 2026-04-23
고객: Color Health(원격의료 스타트업)
문제: 미국 검진 대상 여성 20~30% 미검진, 검진 로지스틱스(적격성 확인·예약·후속 조치)의 번거로움이 원인

GCP 스택: “Color Assistant” — Gemini 2.5 계열 모델 + ADK(복잡한 다단계 작업) + Vertex AI Agent Engine(보안·성능 배포)

동작 흐름: 대화로 검진 적격성 수집 → 임상의 검토 트리거 → 전국 50개 주 진료 예약 조정 → 초음파·MRI 추가 지시 → 임상의가 결과 전달 및 후속 조치 조율. 에이전트 역할 = 의료 판단이 아닌 로지스틱스 자동화

성과: 2025년 말까지 수만 명 추가 검진 연결 목표 (진행 중, 수치 미공개)

CE 활용: 헬스케어·금융처럼 “AI가 결정을 내리면 안 되는” 고객에게 Agent Engine 역할을 “판단이 아닌 연결”로 포지셔닝. 「검진 미충족률 20~30%」처럼 문제 규모 수치 제시 후 에이전트를 해법으로 연결하는 스토리 구성 템플릿

사례 6 — Highmark Health: Sidekick AI로 연구 프로토콜·사내 검색 자동화

출처: Becker’s Hospital Review (2026-04) + Google Cloud Next 2026 Wrap Up (2026-04-25)
고객: Highmark Health(피츠버그 소재 헬스케어 기업, Allegheny Health Network 포함)

성과: $28M 가치 창출 (공개 수치). 연구 프로토콜 작성 자동화 + 사내 검색 개선.

CE 활용: 헬스케어 고객 대상 정량적 ROI($28M) 제시 사례. 대규모 조직의 내부 지식 검색 + 절차 자동화 조합 패턴
