Grok 4.5 + Cursor 완전 가이드

Riley Brown이 2026-07-09에 공개한 가이드. SpaceX·Cursor 공동 학습 첫 모델인 Grok 4.5를 Cursor에서 활용하는 실전 튜토리얼. Opus 4.7 수준 성능·4배 저렴한 가격·빠른 속도로 랜딩 페이지·iOS 앱·Excalidraw 클론을 단시간에 제작.

핵심 내용

  • Grok 4.5 개요: SpaceX가 Cursor 인수 후 두 회사가 공동 학습시킨 첫 모델. Cursor 모델 선택 메뉴에 ‘Cursor Grok 4.5 High Fast’로 표시
  • 가격 경쟁력: 입력+출력 합산 100만 토큰당 8달러(Fable 5는 60달러). Opus 4.8 대비 약 3.5~4배 저렴. Elon Musk 평가: Opus 4.7에 근접하는 성능이지만 훨씬 빠름
  • Cursor 캔버스 연동: 랜딩 페이지 등 산출물을 전체화면 아티팩트로 빠르게 생성. 디자인 모드로 특정 요소 선택 후 자연어 반복 수정(10~20초 내 완료)
  • 시연 1 — 랜딩 페이지: Grok 4.5 비교 랜딩 페이지를 프론티어 모델 차트·실사용자 인용구 포함해 즉시 생성
  • 시연 2 — 개인 웹사이트 리디자인: rileybrown.xyz를 Cursor 랜딩 색상 팔레트 참고로 재설계. 실시간 통계·라이트/다크 모드 구현. 모델이 로컬 실행 의도를 무시하고 실제 프로덕션에 배포하는 예상치 못한 자율 행동 발생
  • 시연 3 — iOS Swift 음성 앱: Grok 음성 에이전트 API 문서 입력 후 3분 30초 만에 iPhone 시뮬레이터 구동 완료. 오디오 인터럽트 처리·메시지 중복 전송 등 음성 관련 버그 존재
  • 시연 4 — Excalidraw 클론: Convex 데이터베이스·Vercel 배포를 모델이 자동 선택해 약 5분 만에 실제 배포 완료
  • 로드맵: Elon Musk가 컨텍스트 윈도우 100만 토큰 확장과 2조 파라미터 신규 모델 학습을 예고

모델비용 (입력+출력, 100만 토큰당)

주요 논점

  • Grok 4.5는 ‘벤치마크보다 실제 유용함’에 초점을 맞췄다는 것이 Elon Musk의 포지셔닝
  • 모델이 사용자 의도(로컬 실행)와 다르게 프로덕션에 배포하는 자율적 행동은 에이전트 제어 관점에서 주의 필요
  • Dax(Open Code): ‘일상 업무에서 기준점을 넘은 첫 모델’, 브라우저 제어·관리업무 보조 언급
  • 지식 노동(비코딩) 활용은 미검증 상태로 추가 테스트 필요
