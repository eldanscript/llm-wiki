Google AI Studio Build 갤러리 리뷰 (2026-09-06)

Google AI Studio의 Build 갤러리(Featured 탭)에 있는 예제 앱을 카테고리별로 정리한 실사용 리뷰. 전부 “Remix” 가능 — 원클릭 복제 후 API 키만 넣으면 즉시 실행되는 앱들.

핵심 내용

  • 카테고리 구성: Gemini 3.7 Flash·Managed Agents API·Nano Banana 2 Lite·Gemini 3.1 Pro·Lyria 3.5 음악 생성·Veo 영상 생성·이미지 생성(Gemini 3 Image Pro)·3D 게임 등 8+ 카테고리
  • Managed Agents API 핵심 앱 2종: AI Data Analyst(CSV 업로드 → 자율 분석), Financial Research Agent / TICKR(SEC 공시 자율 분석, agent.yaml 5줄 선언)
  • InfoGenius: Gemini 3 Pro Image 기반 인포그래픽 자동 생성. AUDIENCE(초등전문가)·AESTHETIC(미니멀사이버펑크)·LANGUAGE 드롭다운 = 프롬프트 주입 문자열 매핑 구조. PAID APP(과금 API 키 필요)
  • Lyria 3.5: 음악 생성 3종(Lyria Studio·Lyria Rhythm·영상 배경음악 자동 생성)
  • Veo: 텍스트 → 영상(Type Motion·Veo Studio)
  • GCP CE 활용 포인트: AI Data Analyst(고객 CSV 라이브 데모)·Financial Research Agent(5줄 YAML 에이전트 선언 시연)·InfoGenius(프롬프트 엔지니어링 드롭다운 패턴 교육)·Function Call Kitchen(tool calling 비개발자 교육)

세부 분석: AI Data Analyst

  • URL: https://aistudio.google.com/apps/bundled/ai-data-analyst
  • 기술 스택: Managed Agents API + Antigravity
  • UI 흐름: CSV 업로드(1MB 이하 드래그앤드롭, 이상은 GCS URI) → 자연어 질문 입력 → Analyze 버튼 → 자율 분석
  • 내장 예시 프롬프트 3종: 핵심 트렌드 요약 / 가치 기준 상위 세그먼트 / 이상치 탐지
  • GCP CE 활용: 고객 CSV 즉석 업로드 라이브 데모 → Remix 후 로고·질문 예시 교체로 커스텀 데모화 가능

세부 분석: Financial Research Agent (TICKR)

  • URL: https://aistudio.google.com/apps/bundled/tickr
  • UI 흐름: 티커 심볼 단일 입력 → Analyze → SEC 공시 자동 수집·분석
  • 커버 문서: Form 10-K/10-Q, Form 8-K, Forms 3/4/5 & 13F
  • agent.yaml 핵심 (5줄 선언 전체):
  • 포인트: base_agent: antigravity-preview-05-2026로 에이전트 로직 내장, tools에 google_search 하나. environment.sources: []에 GCS 등 고객 문서 저장소 연결 확장 가능
  • 프런트엔드: React (src/App.tsx), server/·run_logs/ 디렉터리 분리

세부 분석: InfoGenius

  • URL: https://aistudio.google.com/apps/bundled/info_genius
  • 브랜드명: InfoGenius Vision — Visual Knowledge Engine
  • ⚠ PAID APP: Gemini 3 Pro 계열 사용 → 과금 설정된 API 키 필요
  • 기술 스택: @google/genai SDK 직접 호출(Managed Agents API 미사용)
  • 드롭다운 = 프롬프트 문자열 매핑 패턴:
    • AUDIENCE: Elementary / High School / College / Expert → 각각 스타일 지침 문자열
    • AESTHETIC: Minimalist(바우하우스) / Futuristic(사이버펑크 HUD) 등 → 스타일 지침 문자열
  • 파이프라인: Google 검색 그라운딩 리서치 → 16:9 인포그래픽 이미지 생성 2단계
  • GCP CE 활용: 드롭다운 몇 개 변경만으로 완전히 다른 결과물 시연 → 프롬프트 엔지니어링 교육 데모로 적합. 단, 사전 결제 설정 API 키 필요

확인 안 된 것

  • “All apps” 탭(Featured 외 전체 목록) 미확인
  • 각 앱의 실제 소스 코드·프롬프트 전체 구조 미확인(Remix 후 직접 열어봐야 함)
  • InfoGenius researchTopicForPrompt 함수 내 systemPrompt 원문·googleSearch 툴 선언부 미확인
