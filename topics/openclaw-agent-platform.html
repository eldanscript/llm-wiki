OpenClaw 에이전트 플랫폼 종합 분석 (Riley Brown 2026-02~03)

Riley Brown이 2026년 2~3월에 집중적으로 다룬 OpenClaw(구 Clawdbot) AI 에이전트 플랫폼의 설치·스킬 구성·Blender MCP 연동·모션 그래픽 생성·멀티 에이전트 팀 구성까지 4편 종합.

OpenClaw란?

  • openclaw.ai에서 curl 스크립트 한 줄로 로컬 컴퓨터(Mac Mini 등)에 설치하는 상주형 AI 에이전트
  • 6대 핵심 기능: Runs on Your Machine / Any Chat App / Persistent Memory / Browser Control / Full System Access / Skills & Plugins
  • 텔레그램·WhatsApp·Discord·Slack 게이트웨이 지원. 텔레그램이 설정 용이성·슬래시 명령어·전용 앱화 측면에서 최우선 추천
  • Manus·Perplexity Computer(태스크마다 클라우드 컴퓨터를 스폰하는 ‘사령부’형)와 달리 한 대의 컴퓨터에 상주하며 메모리+스킬+게이트웨이를 통합 운용
  • 워크스페이스 핵심 파일: agents.md, identity.md, soul.md, memory, mission.md, tools.md

핵심 스킬 7종 (2026-02-16 에피소드)

#스킬설명
1NotionAPI 키 발급→통합 연결→DB 접근 권한 설정. 잘못된 동작 시 자연어로 정정하면 tools.md에 자동 기록
2TypefullyGemini API로 고성과 캡션 분석 → 트위터 초안 자동 예약
3Linear읽기 전용 권한으로 작업 현황 요약·콘텐츠 캘린더 생성(쓰기 권한은 리스크 이유로 지양)
4Transcript ExtractorSupaData API로 YouTube·TikTok·Instagram 등 모든 플랫폼 영상 자막 추출. 특정 크리에이터 스타일 학습 후 재생성
5NanoBanana Pro Thumbnail얼굴 합성 썸네일 무드보드 자동 생성
6Google Image대본 문서에 관련 이미지 자동 삽입
7Take the Wheel에이전트가 주도해 핵심 질문 하나씩 던지며 롱폼 대본 완성(발표자가 가장 선호하는 스킬)

운영 원칙: 스킬이 30개까지 늘어나면 컨텍스트 오염·페르소나 혼재로 신뢰성 저하. 에이전트당 7~10개 좁은 목표 스킬이 최적.

Blender MCP 연동 (2026-02-17 에피소드)

  • 설치 흐름: Blender 다운로드 → Edit > Preferences > Blender MCP 애드온 활성화 → N키 사이드 패널 → 포트 9876으로 MCP 서버 연결
  • 자연어 지시만으로 3D 장면 생성(들판·나무·산·동물), 머티리얼 색상 변경, 텍스트 교체
  • 인터넷에서 구매한 .blend 파일 불러와 레이어별 머티리얼(M4001, M4024) 선택 수정 가능
  • 시각적 피드백: 에이전트가 스크린샷을 텔레그램으로 전송 → 원격 작업 확인 가능
  • 완성 모델 GLB 내보내기 → 랜딩 페이지 생성 → Vercel 자동 배포(openclaw-computer.vercel.app)
  • 코딩·Blender 지식 없이 전 과정을 대화만으로 완결한 엔드투엔드 파이프라인 실증

모션 그래픽 영상 생성 스킬 (2026-02-25 에피소드)

전체 파이프라인

아이디어 입력
  → Firecrawl API로 브랜드 자산·컬러 스크래핑
  → Remotion으로 씬 생성 (localhost:3001 실시간 프리뷰)
  → 씬 배치 및 전환 생성
  → ElevenLabs 오디오 생성 스킬로 BGM 10곡·효과음 3종 생성
  → H.264 렌더링
  → 공유 가능한 비디오 링크 출력

주요 기술 세부

  • Firecrawl API: 대상 웹사이트에서 브랜드 컬러 코드·로고 자동 추출 (Perplexity 예시: 다크 100e12, 라이트 fcfcf9)
  • Remotion: 오픈소스 프로그래매틱 비디오 툴. 타임라인·씬 편집 UI 포함
  • ElevenLabs Audio Generator SKILL.md: generate.sh <output_dir> <music|sfx> "<prompt>" [duration_seconds 0.5~30] [prompt_influence 0~1]
  • 동시 생성 5개 제한으로 배치 처리 필요
  • 스킬은 superskills.vibecode.run에서 무료 공개 (OpenClaw·Claude Code 모두 지원)

전문화 에이전트 팀 아키텍처 (2026-03-02 에피소드)

좁은 목표(Narrow Intent) 에이전트의 5가지 장점

  1. 복제·리믹스 용이: YouTube 에이전트 → TikTok·Substack 에이전트로 쉽게 파생
  2. 팀 공유 용이: 스킬·통합이 적어 설명과 인계가 간단
  3. 이해하기 쉬움: 담당 역할이 명확해 비전문가도 파악 가능
  4. 평가가 pass/fail로 명확: 목표가 좁을수록 성공 기준이 구체적
  5. 자율 루프 가능: 크론잡 기반 단순 루프로 무인 자동화 달성

핵심 설계 원칙

  • Intent-driven: Emmett Shear 인용 — “Prompts are so late 2025. We’re giving models intents now.”
  • 에이전트당 스킬 7~10개: 초과 시 어떤 스킬을 써야 할지 몰라 비효율(카오스) 발생
  • 저널 에이전트: Notion 공유 저널로 다른 모든 에이전트에 컨텍스트 제공하는 허브 역할
  • 향후 과제: 클라우드에서 수백 개 에이전트 운영, 에이전트 간 메모리 공유

텔레그램 슬래시 명령어 전체

/new, /reset, /compact [instructions], /stop, /think <level>, /model <id>, /verbose on|off, /status, /whoami, /context, /skill <name> [input]

SupaData API 스펙

  • Base URL: https://api.supadata.ai/v1
  • Auth: x-api-key: YOUR_KEY
  • Main endpoint: GET /transcript?url=VIDEO_URL
  • 지원 플랫폼: YouTube, TikTok, Instagram, Facebook, X/Twitter, video files
  • 부가 기능: 자동 자막 생성(mode=auto), 배치 처리, 번역, Metadata(제목·작성자·engagement)
