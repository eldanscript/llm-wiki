Gemini at Work 2026: Argon & 범용 업무 에이전트

Google Cloud가 2026-10-08 NASA 에임스 Hangar 1에서 개최한 Gemini at Work 2026에서 Gemini 4 Argon과 ‘범용 업무 에이전트’로 진화한 Gemini Enterprise를 발표한 이벤트 종합.

핵심 내용

Gemini 4 Argon

  • 지식 노동·실제 소프트웨어 엔지니어링·사이버보안 방어에서 프런티어급 성능
  • 벤치마크: V-index(금융·코딩·법률·세무 경제적 영향)·Deep Suite(장기 실제 SW 엔지니어링) 1위 주장
  • Anti-gravity 협업 사례: 에이전트 코드 제출 35%+ 증가·코드 롤백 약 1/3 감소
  • Chrome 팀 수백만 줄 리팩터링: 수개월 → 수주로 단축
  • Farin 프로그램을 통해 사이버 방어자 일부에 먼저 배포 후 확산

Gemini Enterprise 에이전트 6대 차별점 (Thomas Kurian)

  1. 하나의 에이전트 — 채팅·작업·코드 통합
  2. 모든 표면(휴대폰·웹·데스크톱·CLI·Workspace·M365·Slack)에서 동일한 클라우드 에이전트
  3. 에이전트 로스터 자동 구성 (서브 에이전트 동적 생성·위임)
  4. 사용자·조직을 아는 개인화 컨텍스트 (dream mode)
  5. 기존 통제(ID·정책·예산·감사) 자동 상속
  6. 모델 비종속 (Argon·Flash·Anthropic 모델·오픈 모델 선택 가능)

에이전트 3대 축

  • 스킬: 마크다운 기반 재사용 가능 절차 레지스트리 — 팀 공유·토큰 절약·일관성
  • 도구: Workspace·MS Office·Slack·Jira·Salesforce·MCP 연결
  • 컨텍스트(메모리 4종): 세션(눈앞 작업)·시맨틱(구조화 지식)·절차(작업 방법)·에피소드(과거 이력)

데이터 플랫폼

  • Knowledge Catalog: 비즈니스 지표 한 번 정의 → 전체 에이전트 공유 (Databricks·dbt·LookML·SAP 지표 통합)
  • Borderless lakehouse: Amazon S3·Azure Data Lake 별도 송신 요금 없이 조회; Salesforce·SAP·ServiceNow·Workday 복사 없이 읽기
  • 관리형 Spark + BigQuery: 자연어 쿼리 → PySpark 라이브 편집·실시간 차트 재계산
  • 승인 쿼리·템플릿 저장 → 이후 LLM 토큰 없이 재실행 (안정성·비용 절감)
  • Smart storage: 비정형 데이터(전체 90%)에 Gemini 맥락 부착

거버넌스 구조

  • 에이전트별 암호화 ID + 최소 권한 RBAC
  • 에이전트 명의 감사 로그 (누가·누구 대신·언제·무엇을)
  • 에이전트 샌드박스 + Agent Gateway(AI 방화벽): 악성 프롬프트·도구 호출 실시간 차단
  • 정책 한 번 작성 → 전체 에이전트 일괄 적용
  • 프로젝트·사용자별 실시간 지출 한도 (토큰·코드 샌드박스·컴퓨트 통합)
  • 사례: Lloyds Banking Group Envoy 플랫폼 (~1,000명 엔지니어 온보딩)

비용 최적화

  • 토큰 단가 2024년 이후 98% 하락 — 그러나 에이전트 작업 1건당 10만 토큰 소모로 총지출 증가
  • 해법: 작업별 모델 자동 선택·스마트 라우팅(프런티어 단독 대비 비용 ~1/3·속도 40% 향상)
  • Google 풀스택 통합(칩·상호연결·데이터센터·소프트웨어) 기반 경제성

고객 성과 수치

  • Nokia: 장애 분석 최대 80% 단축
  • NTT Docomo: 연 45만 시간 절감
  • Bunnings: 직원 50만 시간 절감
  • Alta Beauty: 전환율 3배
  • Snap: 진단 30분 → 30초
  • Etsy: 쿼리 60% 가속
  • Bloomberg Media: 쿼리 정확도 63% 향상
  • Merck: 직원 약 7.5만 명 접근
  • JPL: 궤도 위성에서 Gemma 구동

채택 지표 (발표 기준)

  • Gemini 앱 사용자 10억 명
  • Fortune 기업 약 90%가 Gemini Enterprise 사용
  • 50개 이상 기업이 Gemini 에이전트 운영 중
  • GCP 고객 약 80%가 AI 제품 활용
  • 약 500개 기업이 지난 1년간 각각 1조 토큰 이상 처리

주요 논점

  • 단일 메모리·컨텍스트·개인화 그래프를 모든 표면에서 공유 — 경쟁사(채팅/코드 별도 탭·데스크톱/클라우드 분리 메모리) 대비 차별화 주장
  • 에이전트에 독립 ID 부여 → 사람과 동일한 정책 체계 적용
  • 기업 우선 출시 전략: 보안·규모·성능 문제 먼저 해결 후 소비자용 배포 예정
  • 스킬 레지스트리: 마크다운 절차 저장·재사용으로 일관성 향상 및 토큰 절약
