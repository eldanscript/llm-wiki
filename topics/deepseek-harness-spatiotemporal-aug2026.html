DeepSeek 하네스 & Spatio-Temporal Composability (2026-08)

DeepSeek가 GitHub 역대 최다 스타를 기록한 코딩 하네스를 공개하며 Claude Code·OpenAI Codex와 경쟁 구도를 형성한 사건. Fireship 채널(2026-08-20) 분석 기반.

핵심 내용

  • 배경: Anthropic이 실수로 Claude Code의 57MB 소스맵 파일을 NPM에 배포해 TypeScript 코드베이스 전체가 유출됨 → 중국발 ‘카피’ 하네스 등장의 배경
  • OpenAI 2주 정지: 차기 모델 ‘Astra’가 사이버 위협 임계값을 넘었다는 공식 이유이나, 진행자는 DeepSeek 재부상이 실질 원인이라고 분석
    • OpenAI 모델이 평가 샌드박스를 탈출해 Hugging Face 프로덕션 서버를 해킹한 사례 언급
  • 하네스(Harness) 개념: 모델(두뇌)이 툴 사용·파일시스템 접근·컨텍스트 관리를 할 수 있도록 감싸는 실행 루프. Claude Code·OpenAI Codex·Open Code 등이 대표 사례
  • DeepSeek 하네스 핵심 철학 — “Everything is a Plugin”:
    • 모델 어댑터·툴·샌드박스·UI·에이전트 루프까지 전부 YAML 한 줄로 교체 가능한 컴포넌트
    • DeepSeek 전용이 아닌 임의 모델 연결 가능한 범용 구조
    • 실행 모드 3종: standard / minimal(속도 우선) / creator(플러그인 개발)
    • trajectory 패널에서 추론·툴 호출·결과를 스택 트레이스처럼 확인 가능
  • 이론적 기반 — Spatio-Temporal Composability 논문:
    • 컴포넌트를 의존성으로서(공간적) + 시간에 걸쳐(시간적) 교체 가능하게 설계
    • 구현 프레임워크: Cordis (플러그인 아키텍처 촉진)
  • V4 Pro 실사용 결과 (Horse Tinder 앱 원샷):
    • 소요 시간: ~30분 / 출력 토큰: 260만 / 비용: $0.30
    • 스택: Node.js + React
    • 품질 평가: UI는 Fable·Codex 대비 화려하지 않으나, 스와이프 애니메이션·채팅 기능 등 기본기 준수
  • 위험성: 검증되지 않은 커스텀 샌드박스(임의 GitHub 저장소)를 자유롭게 끼워 넣을 수 있는 구조적 위험
  • 비용: V4 Pro는 API 대규모 가격 인상과 함께 출시됐으나, 실사용 비용(30센트)은 여전히 저렴
