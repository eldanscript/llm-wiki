GCP 선행 학습된 모델 제품군

Google Cloud의 「AI 및 ML」 영역 중 「선행 학습된 모델」 그룹에 속하는 4개 제품 종합. 모델을 직접 학습시키지 않고 바로 호출해 쓰는 REST API 계열이다. Vertex AI나 AutoML과 달리 커스텀 학습이 없다.

제품 목록

제품분석 대상핵심 특징
GCP-CloudNaturalLanguage텍스트감정·항목·구문·분류·안전 속성 6개 메서드
GCP-CloudVisionAPI정지 이미지11개 기능, 동기(16개 이하)·비동기(2000개) 처리 분기
GCP-VideoIntelligenceAI동영상(시간축)9개 기능, 저장·스트리밍·실시간 3갈래 API
Timeseries Insights API시계열(추정)문서 404 — 확인 불가

공통 설계 원칙

  • REST JSON 인터페이스: 모든 제품이 HTTP JSON 요청/응답 구조를 사용한다.
  • 언어 자동 감지: Natural Language API는 언어 미지정 시 자동 감지를 수행한다.
  • 비동기 처리(LRO): Vision API와 Video Intelligence API 모두 대량 처리 시 장기 실행 작업(Long-Running Operation)을 반환한다.
  • 제한된 액세스 기능 분리: 유명인 인식 등 민감한 기능은 별도 「제한된 액세스」로 운영한다.

Cloud Natural Language API 핵심

  • 메서드 6개: analyzeSentiment, analyzeEntities, analyzeEntitySentiment, analyzeSyntax, classifyText, moderateText
  • annotateText: 한 번 호출로 감정+항목 분석 동시 수행
  • 요청 형식: document.type(HTML/PLAIN_TEXT) + content 또는 gcsContentUri + encodingType(필수)
  • classifyText 모델: V2(최신·두 버전 카테고리 지원) / V1(20토큰 이상 텍스트 필수)
  • moderateText 카테고리: 유해·혐오·폭력·성적콘텐츠·모욕·욕설·사망/피해·총기·공공안전·건강·종교·불법약물·전쟁 13개 — 안전 — 콘텐츠 필터의 Gemini 4개보다 훨씬 세분화
  • analyzeSyntax: 형태론(어간·어근·접두사·접미사) + 종속성 트리 반환

Cloud Vision API 핵심

  • 기능 11개: 텍스트 감지(TEXT_DETECTION) / 문서 텍스트 감지(DOCUMENT_TEXT_DETECTION) / 랜드마크 / 로고 / 라벨 / 이미지 속성 / 객체 현지화 / 자르기 힌트 / 웹 항목 및 페이지 / 세이프서치 / 얼굴 인식
  • TEXT_DETECTION vs DOCUMENT_TEXT_DETECTION: 전자는 간판 등 희소 텍스트 최적화, 후자는 문서 스캔·필기 입력 최적화
  • 세이프서치·얼굴 감정 일치 가능성 6단계: UNKNOWN → VERY_UNLIKELY → UNLIKELY → POSSIBLE → LIKELY → VERY_LIKELY
  • OCR 계층 구조: TextAnnotation → 페이지 → 블록 → 단락 → 단어 → 기호
  • 동기(온라인): images:annotate / files:annotate — 이미지 16개 이하, 파일 5페이지 이하
  • 비동기(오프라인): images:asyncBatchAnnotate / files:asyncBatchAnnotate — 요청당 2,000개 이하, 파일당 2,000페이지 이하, 최대 20MB
  • 무료 등급: 월 최대 1,000건 기능 요청
  • 특정 개인 얼굴 인식 불가: 유명인 인식은 별도 「제한된 액세스」
  • 맞춤설정 객체 감지는 이 API 아님: Vertex AI AutoML Image로 이동

Video Intelligence AI 핵심

  • 기능 9개: 유해성 콘텐츠 감지 / 얼굴 인식 / 라벨 인식 / 로고 인식 / 객체 추적 / 사람 감지 / 장면 변화 감지 / 음성 텍스트 변환 / 텍스트 감지
  • API 3갈래:
    • 저장된 동영상 주석(videos:annotate): LRO 방식, GA
    • 동영상 스트리밍: 베타
    • 실시간 동영상 스트리밍: 베타
  • 동영상 청크 크기: 10MB 미만 권장
  • 라벨 인식: 초당 1프레임 샘플링, 프레임 수준 분석
  • 얼굴 인식 계단식 스위치: includeBoundingBoxes=True 후에야 includeAttributes=True 활성화 가능
  • 음성 텍스트 변환 모델: default / video 두 종
  • 비지원 형식 우회: ffmpeg + 명명된 파이프로 0.2fps PNG 디코딩 가능 여부 확인 후 스트리밍 가능
  • 스트리밍 기능은 전부 베타: GA 이전 약관 적용, 지원 제한 가능

Timeseries Insights API 현황

  • 문서 링크 404 (2026-08-18 확인): https://docs.cloud.google.com/timeseries-insights/docs
  • GCP 문서 홈 내비게이션과 AI 및 ML 개요 페이지 양쪽에 항목은 존재하나 링크가 죽어 있음
  • 이름 외 공식 확인 가능한 정보 없음 — 추측으로 채우지 않음
  • 시계열 이상 감지 대안: BigQuery ML, Vertex AI
