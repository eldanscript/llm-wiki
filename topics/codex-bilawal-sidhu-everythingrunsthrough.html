Everything Runs Through Codex Now — Bilawal Sidhu 인터뷰 분석

Riley Brown 채널에 출연한 Bilawal Sidhu(Google PM 출신, God’s Eye View 창업자)가 OpenClaw에서 Codex로의 전환 이유, 공간 컴퓨팅·영상 생성 최신 기법, 멀티에이전트 협업 툴 전망을 공유한 63분 심층 인터뷰(2026-08-16).

OpenClaw → Codex 전환 배경

  • 4~5개월 전: 맥북프로 M1 Max 로컬 상주 OpenClaw 기반 멀티에이전트 세팅(WhatsApp·텔레그램 라우팅, 캐릭터별 페르소나 에이전트) 운용
  • 현재: ChatGPT 앱 통합 Codex로 완전 전환
  • 전환 이유: Chrome 확장 없이 로그인된 Notion·Google Docs·YouTube Studio를 인앱 브라우저로 직접 조작하는 ‘공유 캔버스’ 협업 경험이 핵심
  • OpenClaw 열풍의 부작용: 대시보드·세컨드브레인 구축에 매몰되는 과잉 엔지니어링. 그러나 그 핵심 가치(사용자 삶 전체 연결·통제)는 Anthropic·OpenAI·Cursor·Google이 제품화하는 방향으로 수렴 중

Codex 4대 강점

  1. 프런티어 에이전트 대화 — 멀티태스킹 고성능 추론
  2. 플러그인 연동 — 서드파티 서비스 통합
  3. 자동화(구 크론잡) — 예약 실행, 반복 작업 처리
  4. 인앱 브라우저 — 로그인 상태 유지한 채 Notion·YouTube Studio 직접 조작

모델 역할 분담

  • Codex(GPT 기반): 리서치, 실행, 자동화 작업
  • Claude Fable: 문서 작성, 디자인 감각이 필요한 작업
  • GPT-5.6(Sol)은 글쓰기 실력이 상대적으로 약하다고 평가
  • 모델 라우팅(경량 vs 기가브레인 모델 자동 전환)은 아직 미성숙 — Cerebras 칩 기반 초고속 추론이 다음 이정표

콘텐츠 제작 파이프라인

  • 코딩, 3.js 시각화 설명 영상, YouTube 애널리틱스 분석, 편집 지시서 작성 전 과정에 에이전트 활용
  • Codex 인앱 브라우저가 Notion API를 직접 호출해 문서를 수정하는 장면 실연(2분 14초 작업 로그)
  • 영상 편집은 여전히 사람이 담당 — Descript·Frame.io 러프컷 + Notion 편집 가이드라인 관리
  • ‘무편집(un-editing)’ 트렌드: Mr. Beast식 과잉 리텐션 편집 대신 담백한 대화형 롱폼 콘텐츠가 오히려 인기
  • 롱폼 유튜브 바이럴이 틱톡·X 바이럴보다 강력한 이유: 10분 이상 시청한 팬층이 만드는 깊은 댓글·피드백 루프

God’s Eye View 프로젝트

  • 이전 명칭 ‘WorldView’ → 현재 ‘God’s Eye View(Gods Eye)’
  • OpenClaw로 바이브코딩된 2백만 뷰 바이럴 프로젝트
  • CCTV·위성·AIS 등 OSINT 데이터를 4D 지구본에 시각화
  • GitHub 저장소: bilawalsidhu/gods-eye-view (‘A spy satellite simulator in your browser, except the data is real’, 677 stars·47 forks)
  • Commercial/Military Flights, GPS Jamming, Maritime Traffic 등 레이어 토글 + 타임라인 스크러버 UI
  • 현재 정식 스타트업으로 발전 중

공간 컴퓨팅 & 영상 생성 최신 기법

3D 재구성 파이프라인

  • 라이다·센서 없이 순수 픽셀(CCTV·위성 등)만으로 3D 재구성: Video A/B → Audio Sync·Joint Solve(2D→3D 마스크)·Gaussian Splat → Path → 방송·God’s Eye 리플레이·라이브 브라우저 뷰어 출력

카메라 경로 기반 영상 생성

  • Omni, Seedance 등 비디오 생성 모델의 공간 추론 능력 급성장
  • 이미지 위에 그린 경로만으로 1인칭 드론 POV 영상 생성 가능
  • 실증 사례: 오스틴 항공샷 위 빨간 선 스케치 → Omni 드론 POV, 호그와트 성 카메라 경로 바이럴
  • 물리적 정확성이 필요한 시각물(파동·궤적)은 3.js 코딩 모델로, 생성형 비디오 모델은 스타일화·부정확 가능성 있어 용도 구분 필요

Spatial RAG

  • Street View 파노라마를 조건으로 사용해 장거리 궤적에서도 사실적 일관성을 유지하는 월드모델 생성 기법
  • Current(초록)·Retrieved Reference(파랑)·Lookahead Sink(주황) 노드 구조
  • 지리좌표·카메라 액션·텍스트 프롬프트로 인근 스트리트뷰 이미지 검색·조건화 → 생성물을 실제 위치·외관에 고정

멀티에이전트 협업 툴 전망

Buzz

  • Codex·Claude Code·Cursor(Grok) 등 서로 다른 에이전트를 한 채널에서 협업
  • 시스템 프롬프트 설계로 대화가 무한정 길어지는 레이스 컨디션 방지
  • ‘개인 에이전트 시대’에서 ‘팀 에이전트 시대’로의 전환을 상징

Claude Tag & OpenAI 워크스페이스 에이전트

  • Claude Tag: 팀 전체가 공유하는 에이전트
  • OpenAI 워크스페이스 에이전트(Slack 연동): 회사 전체 ‘팀 에이전트’ 전환 대표 사례

콘텐츠·비즈니스 전략 인사이트

  • UGC 광고에서 AI 생성 콘텐츠 이미 만연하지만 기업들은 법무팀 지침으로 공개 인정 기피
  • 콘텐츠와 API·레시피를 공개(Substack)해 ‘소프트웨어가 아닌 무브먼트를 소유’하는 전략이 장기적으로 더 강력(Alex Hormozi 비유)
  • 궁극 지향: ‘다시는 앱에 들어가지 않아도 되는’ 챗봇 중심 워크플로우, AI 네이티브 개인·비즈니스로의 전환
  • Google Earth 규모 데이터 활용 ‘거대한 비디오게임/영화 시뮬레이터’가 향후 가능할 것이라는 전망
