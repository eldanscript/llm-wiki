연속 학습 시대의 8가지 예측

Dwarkesh Patel의 2026-08-07 비디오 에세이. 진짜 의미의 연속 학습(continual learning)이 실현될 때 AI 산업의 여러 축이 어떻게 달라지는지 8가지 예측으로 제시한다.

왜 연속 학습이 필요한가

색소폰 학생 비유:

학생들이 메모만 주고받으며 색소폰을 배우려 한다면, 어떤 텍스트 시퀀스도 다음 학생이 처음부터 연주를 완벽히 해내게 만들 수 없다. 어느 시점에는 실제 경험이 뇌에 축적되어야 한다.

  • 현재 AI: 세션 간 마크다운 메모만 남김 → 실제 숙련도 축적 불가
  • 연속 학습: 배포 중 경험이 가중치로 직접 통합됨

8가지 예측

1. AI 규제 패러다임의 붕괴

  • 현재 규제 전제: 훈련 완료 → 배포 전 안전 검사 → 배포
  • 연속 학습 시: 훈련과 배포의 경계가 사라짐 → 배포 전 검사 개념 무의미
  • 대안: 월간/분기별 위험 점검(risk inspection)
  • 현재 규제 체계를 지금 고착화하는 것은 위험 — 1년 내에도 기술이 근본적으로 바뀔 수 있음

2. 정렬 연구의 패러다임 전환

  • 현재 초점: 고정된 가중치의 배포 중 행동 관리
  • 새 초점: 지속적으로 갱신되는 가중치가 탈옥·배신 인격·백도어에 저항하게 만드는 방법
  • 사용자 간 학습 통합 시: 악의적 사용자의 백도어 주입 방지 문제
  • 인간 정렬 문제와 유사: 아이들이 스스로 학습하면서도 핵심 가치를 유지하게 하는 방법

3. AI 마인드 다양성 증가

  • 현재: 5개 미만의 주요 AI 마인드, 비슷한 데이터로 학습 → 서로 유사(mode collapse)
  • 연속 학습 후: 인스턴스별 경험 차이 → 다양성 급증
  • 모놀리식 AI 싱글톤의 위험을 줄이는 긍정적 결과 기대

4. AI 경쟁에서 선두 가속

  • 배포 = 훈련이 되면 선두 모델이 더 많은 사용자·복잡한 작업 → 더 많은 피드백 → 더 똑똑해지는 되먹임 구조
  • 현재의 ‘4개월 추격’ 패턴이 붕괴할 수 있음

5. 더 빠른 스마트 모델 배포 압박

  • Anthropic 사례: Mythos를 2월부터 내부 사용, 6월에야 공개 → 4개월 격차
  • 연속 학습 시대: 이 격차 유지 불가능
    • 더 나쁜 모델을 먼저 배포한 경쟁자도 실세계 경험으로 따라잡기 때문
  • 내부 모델과 공개 모델 간 격차를 최소화하는 방향으로 압박

6. AI 랩의 강력한 해자(Moat) 형성

  • 현재 AI 랩의 해자 부재 → 연속 학습이 해자 창출
  • 클라우드 제공업체 유사 구조: 조직에 축적된 컨텍스트를 가진 모델 교체 시 높은 전환 비용
  • Dario가 Dwarkesh 팟캐스트에서 클라우드 사업자 비유로 설명
  • 당근과 채찍: 세션 학습 허용 고객에게 보조금, 거부 고객에게 하위 모델 제공

7. 배치 효율성과 대규모 조직 우위

  • 개인화 가중치 서빙: 배치 크기 ~1 → 두 자릿수 이상 비효율
  • DeepSeek v3 기준: 최적 배치는 2400개 이상 동시 시퀀스 필요
  • 결론: 대규모 조직이 가중치 포크를 서빙하는 것이 경제적으로 훨씬 유리
  • 개인 맞춤형 AI보다 팀/조직 단위 AI가 현실적

8. (추가 예측 - 정렬 실천)

  • 현재 정렬 연구가 ‘연속 갱신 가중치의 자기 주도 학습’에 대한 준비가 부족
  • 이 문제는 사실상 인간 정렬 문제(human alignment problem)와 동형

현재 유일한 연속 학습 성공 사례

  • Cursor Tab 모델: 하루 4억 건 요청, ‘에딧 수용 여부’ 동일 objective로 online-learn
  • 한계: 사용자별 차이 학습 단계에는 미도달
