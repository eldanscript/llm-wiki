Eval Tools With Notebooks (Marimo)

Vincent Warmerdam(Marimo)이 제시한 ‘Look at Your Data’ 원칙 기반의 반응형 노트북 이밸 도구 제작 방법론. Marimo의 DAG 기반 반응형 실행과 anywidget 표준을 결합해 데이터 탐색·라벨링·주석 워크플로를 직접 구축한다.

핵심 내용

  • ‘Look vs Stare’ 원칙 — 데이터를 단순히 응시(stare)하는 것이 아니라 5분 이상 진지하게 들여다보는(look) 습관이 이밸의 가장 강력한 토대. chickweight 데이터셋 예시에서 인터랙티브 차트로만 드러나는 조기 폐사 병아리 이상치 사례로 실증
  • Marimo 반응형 노트북 — 셀 순서가 아닌 변수 의존성 DAG로 실행 순서를 결정. 불필요한 재계산 스킵, 완전 반응형 실행, UI 위젯·AI 어시스턴트·주석 도구까지 동일 철학으로 관통
  • Marimo 제약과 트레이드오프 — in-place 변수 업데이트 및 동일 변수 다중 선언 금지(전역 상태를 명시적으로 만들어야 DAG 구성 가능). 출력(시각화)은 기본적으로 저장 안 됨(HTML/ipynb export로 별도 저장)
  • Python 파일로 저장 — .py 파일로 저장해 git diff 깔끔, PEP 723 인라인 의존성으로 self-contained 실행, CLI 앱(typer/click)화 가능, uv sandbox 실행 지원
  • UMAP + Altair 반응형 탐색 — UMAP 임베딩 산점도에 텍스트 쿼리로 색을 입히고 Altair selection 위젯을 결합해 배송지연·클럽카드 등 특정 클러스터를 반응형으로 탐색
  • anywidget 표준 — Jupyter/Colab/VS Code/Marimo 전반에서 동작하는 크로스 플랫폼 위젯 규격. traitlets로 JS-Python 값 양방향 동기화(value = traitlets.Int(0).tag(sync=True))
  • molabel 라이브러리 — 발표자가 직접 만든 커스텀 라벨링 위젯. yes/no/skip 이진 선택 패턴, 음성 입력·게임패드 지원, 렌더 함수(HTML 반환)만 사용자 정의하면 나머지(진행바·버튼·노트·단축키)는 위젯 제공
  • AI Assist 커스텀 규칙 — Marimo 내장 AI 어시스턴트에 ‘prefer polars over pandas’, ‘make charts using altair’ 같은 Custom Rules를 프롬프트에 자동 삽입. 모델은 claude-sonnet-4-2 설정 가능
  • 반응형 도구의 진짜 가치 — 도구 자체보다 상상력(imagination)을 넓혀 새로운 워크플로(주석, 실시간 차트 업데이트, LLM 챗 연동)를 쉽게 실험하게 해주는 데 있음
