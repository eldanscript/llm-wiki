Vertex AI Studio → Agent Studio

Google Cloud 콘솔 안에서 프롬프트를 설계·테스트·관리하는 화면이다. 코드를 작성하기 전에 모델과 프롬프트를 눈으로 확인하고 실험하는 자리.

이름 변경 이력

  • 원래 이름: Vertex AI Studio (Vertex AI 하위 생성형 AI 도구)
  • 현재 이름: Agent Studio (Gemini Enterprise Agent Platform 하위)
  • 좌측 nav에는 아직 ‘Vertex AI Studio’로 표시되지만, 링크를 누르면 Agent Studio 문서로 이동
  • 문서 내부에서 Vertex AI Studio라는 용어는 더 이상 사용되지 않음

핵심 내용

  • 지원 모델 3갈래: Google Gemini 대규모 언어 모델 / 파트너 모델(Anthropic Claude 등) / 개방형 모델(Meta Llama 등)
  • 파트너·개방형 모델은 Agent Platform에서 서비스형 모델(MaaS) 로 제공되는 것만 사용 가능, 최초 사용 시 제공업체별 서비스 약관 동의 필요
  • 코드 내보내기: 프롬프트 확정 후 ‘코드’ 버튼으로 언어별 코드 생성, Colab Enterprise 노트북 바로 열기 가능
  • 프롬프트 갤러리: 태스크별(요약·코드 등) 미리 설계된 샘플 프롬프트가 모델·파라미터까지 세팅된 채 제공
  • 시스템 요청 사항(system instruction): 프롬프트와 별개로 모델 응답 방식을 사전 지정하는 필드
  • 기본 모델: gemini-3.1-pro-preview (화면에서 변경 가능, 모델 이름은 자주 변경됨)
  • 프로덕션 호출 용도가 아닌 실험·프로토타이핑 전용 콘솔 UI

문서 구조 (6개 페이지)

페이지설명
개요Agent Studio가 무엇인지
Agent Studio 기능화면에서 할 수 있는 기능 목록
시작하기헤딩만 존재
Gemini에 텍스트 프롬프트 보내기빠른 시작 실습 (좌측 nav가 여는 페이지)
프롬프트를 웹 애플리케이션으로 배포만든 프롬프트를 앱으로 내보내기
에이전트 설계프롬프트에서 에이전트로 전환

빠른 시작 실습 2종

  1. 요약 프롬프트 실습: 프롬프트 갤러리 → ‘오디오 요약’ 카드 → 오디오 파일 입력 → 글머리 기호 요약 출력
  2. 코드 생성 프롬프트 실습: ‘주석에서 코드 생성’ 카드 → 시스템 요청 사항 + 미완성 Java 메서드 → 모델이 빈 자리 완성

활용 시나리오

  • 모델 비교: 어떤 모델이 특정 태스크에 적합한지 감을 잡을 때
  • 프롬프트 이터레이션: 문구를 여러 번 고쳐가며 결과 비교
  • 데모 제작: 팀에 보여줄 데모를 코드 없이 신속하게 구성
  • 반대로 프로덕션 API 호출은 이 화면에서 하지 않음 — 콘솔 확정 후 코드로 가져가 API 호출하는 것이 정상 흐름
