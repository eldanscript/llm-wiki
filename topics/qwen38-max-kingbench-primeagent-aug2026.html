AICodeKing 2026-08 에이전트 라운드업: Qwen 3.8 Max·Fable 오케스트레이터·I Have ADHD·Muse Code·Prime Agent

2026년 8월 4~8일 AICodeKing 채널이 집중 게재한 5편의 영상을 통해 드러난 코딩 에이전트 생태계의 주요 흐름: 프론티어 모델 가성비 경쟁 심화·멀티 에이전트 오케스트레이션 실용화·하네스 자체 진화 가속.

1. Qwen 3.8 Max 정식 출시 (2026-08-04)

  • 모델 개요: 알리바바 플래그십. 2.4조 파라미터 스파스 MoE·100만 토큰 컨텍스트·네이티브 멀티모달(텍스트·이미지·비디오·문서)·OpenAI 및 Anthropic API 프로토콜 동시 지원
  • Kingbench 3 결과: 81.25%(2위) — 1위 Fable 5, 3위 Opus 4.8
  • 공식 벤치마크 하이라이트:
    • Terminal Bench 2.1: 86.6 (Opus 4.8·Fable 5의 84.6 상회)
    • Paper Bench: 93.0 (Fable 5 88.8 상회, GPT 5.6 Soul 94.5에 근접)
    • SWE-bench Pro: 67.7 (Opus 4.8 69.2 근접, Fable 5 80에 미달)
    • OSWorld Verified: 86.1 — 컴퓨터 사용 부문 전체 1위
    • Cowork Bench: 74.8 (Opus 4.8·GPT 5.6 Soul 상회)
    • Agent’s Last Exam: 52.4 (GPT 5.6 Soul 53.6과 동률권)
  • 가격: 입력 2⋅출력6·암묵적 캐싱 $0.25 (백만 토큰당) — Opus 4.8 대비 대폭 저렴
  • 특이사항: 10일 자율 개발 궤적 GitHub 공개·비전 기반 연속 피드백 루프 강조·오픈 웨이트(2.4조 + Qwen 3.8 27B) 다음 주 공개 예고

2. Fable 5 오케스트레이터 + 저가 팀 분업 (Tracer 데스크톱, 2026-08-05)

  • 핵심 아이디어: 비싼 프론티어 모델(Fable 5)은 계획·위임·리뷰에만 사용, 반복·구현 작업은 저가 모델(Codex·GLM 5.2·Kimi K2.7·Qwen)에 위임 → 프리미엄 토큰 사용 약 1/4로 절감
  • Tracer 데스크톱: 무료 오픈소스, 기존 구독(Claude·ChatGPT 등) 활용, 에이전트 간 직접 통신(child agent 생성·지시·결과 수신)
  • 실전 시연: 영화 트래커 앱 통계 페이지 추가
    • Codex: 데이터 집계 로직 (가장 까다로운 부분)
    • GLM 5.2: UI 컴포넌트
    • Kimi K2.7: 테스트
    • Qwen: 문서·정리
    • Fable 5: 저장소 분석·계획·병렬 위임·diff 리뷰
  • 마스터 프롬프트 핵심: “구현 코드를 직접 작성하지 말라” 명시 필수 — 없으면 Fable이 직접 코딩해버림
  • 주의사항: 저가 무료 엔드포인트 데이터 정책 차이 확인 필요, 최종 Git diff 사람이 직접 검토 권장

3. I Have ADHD 스킬 — Claude Code 응답 간소화 (2026-08-06)

  • 개요: GitHub 16,000 스타 오픈소스 Claude Code 플러그인(MIT 라이선스). 단일 skill.md 파일 구성
  • 설치: claude plugin install ihaveadhd@ihaveadhd → /ihaveadhd 활성화
  • 10대 규칙 핵심:
    1. 행동 우선(실행 명령·파일·라인 번호 먼저)
    2. 단계는 번호+단일 행동
    3. 모든 응답 마지막은 2분 내 실행 가능한 다음 행동 1개
    4. 곁가지 제안 억제
    5. 매 턴 진행 상황 재진술 (“5단계 중 3단계 완료”)
    6. 구체적 시간 추정치
    7. 오류 담담하게 원인+수정
    8. 목록 최대 5개
    9. 서론·요약·형식적 인사 생략
    10. (예외) 설명 요청·파괴적 작업·모호한 요청 시 기존 방식 유지
  • 다국어 번역 지원: 한국어·일본어·중국어·포르투갈어 포함

4. Meta Muse Spark 1.2 + Muse Code (2026-08-07)

  • Muse Spark 1.2: 코딩 특화 업데이트. Muse Code와 공동 학습(co-trained)하여 둘 조합 시 최적 성능. 자기개선 루프(모델이 스스로 도전적 환경 생성) 훈련 방식
  • Muse Code 특징: 비동기 백그라운드 에이전트(세션 내내 유지)·로컬 이벤트 로그(재현·재시작 안전)·번들 스킬(/plan·/grill·/goal)·macOS+Linux beta
  • Kingbench 3 결과: 61점/80점(76.25%, 5위) — 전작 1.1 대비 +16포인트. 프론트엔드·SVG 강점, 백엔드·복잡 로직 약점
  • 가격: 표준 요금제 + 데이터 공유 시 대폭 할인 요금제 2종, $20 무료 크레딧
  • TestSprite 피드백 게이트: 오픈소스(Apache 2.0) 검증 CLI — 실배포 앱을 실사용자처럼 조작·실패 시 스크린샷 반환 → 에이전트 루프의 핵심 “No” 신호 역할
    • 교훈: 에이전트가 자체 mock 테스트 전부 통과해도 실제 배포 앱 체크아웃 버튼이 죽어있던 사례

5. Prime Agent — RLM·Continual Harness (Prime Intellect, 2026-08-08)

  • 개요: Prime Intellect 오픈소스 MIT 코딩·연구 에이전트. RLM(recursive language model) 독자 아키텍처
  • RLM 핵심: 지속형 IPython 커널로 컨텍스트를 Python 변수처럼, 도구·서브에이전트를 함수처럼 다룸 → 토큰 소모 절감 주장
    • 파일 전체 컨텍스트 로드 대신 Python 코드로 필요 부분만 추출
    • 서브에이전트는 완전한 Prime Agent 인스턴스·결과만 반환값으로 전달 → 부모 컨텍스트 오염 없음
  • Continual Harness: 시스템 프롬프트·스킬·메모리·서브에이전트 스펙을 에이전트가 CRUD 가능한 durable state로 저장. /refine으로 작업 궤적 검토→하네스 개선 반영. 기본 시스템 프롬프트 불변·변경 스냅샷 롤백 가능
  • 스킬 시스템: Markdown이 아닌 실행 가능한 Python 패키지. 내장 스킬 생성기로 프로젝트별/개인별 패키징
  • 장기 자율 실행: /goal·/heartbeat·autonomous 모드(턴·토큰·시간 예산+품질 게이트). 데몬 기반 세션(SSH 끊겨도 백그라운드 유지). 에이전트 간 직접 메시지
  • ARC-AGI 3 결과(자체 발표): Claude Opus 5 기반 95.5%(best-at-1) — 인간 전문가 기준선 95.4% 초과. best-at-3: 99.97%
  • 호환성: ChatGPT Plus/Pro·Claude Pro/Max·GitHub Copilot 구독 로그인·20개+ API 제공사·완전 로컬(Ollama·LM Studio·vLLM). macOS/Linux curl 설치
  • 주의: 보안 샌드박스 아님, 벤치마크 수치는 자체 발표분 독립 검증 필요

에이전트 생태계 시사점 (2026-08 종합)

  • 가성비 전선 이동: Qwen 3.8 Max가 Opus 4.8 수준 성능을 1/5 이하 비용으로 제공 → 단순 구현 작업 대체 가속
  • 오케스트레이션 실용화: Tracer 무료 오픈소스로 프론티어+저가 조합 누구나 접근 가능
  • 하네스 자체 진화: Prime Agent continual harness처럼 에이전트가 자신의 하네스를 직접 개선하는 방향으로 진화 중
  • 피드백 게이트 중요성: 에이전트 루프의 품질은 모델 성능보다 “No라고 말할 수 있는 검증자”에 달려있음 (TestSprite 사례)
  • 컴퓨터 사용: Qwen 3.8 Max OSWorld 86.1로 화면 조작 에이전트 최선 선택지 부상
