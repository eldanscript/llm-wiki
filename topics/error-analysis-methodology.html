에러 분석 방법론 — AI 엔지니어링 최고 ROI 기법

Hamel Husain과 Shreya Shankar(UC Berkeley PhD)가 체계화한 AI 제품 평가의 핵심 기법. 데이터를 직접 들여다보는 구조화된 프로세스로, 프레임워크·툴 선택보다 데이터 직접 검수가 항상 우선임을 강조.

핵심 내용

  • 데이터 직접 검수 = 최고 ROI — Greg Brockman의 트윗 인용: “manual inspection of data is the highest value to prestige ratio of any activity in machine learning”. Hamel은 이를 AI 제품 개발 전체에서 최고 ROI 활동으로 확장
  • 에러 분석 5단계 프로세스:
    1. 자유 형식 주석(Open Coding): 출력물을 보고 바이브(vibe) 그대로 자유롭게 주석 작성. 카테고리 미리 정하지 말 것
    2. 카테고리화(Axial Coding): 자유 형식 노트를 LLM 또는 수동으로 그룹화
    3. 피벗 테이블 구성: 출력×카테고리 매트릭스로 오류 빈도 정량화
    4. 파이프라인 개선: 발견된 카테고리 기반으로 프롬프트·시스템 수정
    5. 반복: 처음부터 다시 — 영구적 루프
  • 커스텀 데이터 뷰어의 우위 — Excel·Label Studio 같은 범용 툴보다 도메인 특화 커스텀 annotation 앱이 훨씬 빠른 판단 지원. AI 코딩 도구로 몇 분 안에 제작 가능
  • LLM 판사 사용 순서 — LLM을 judge로 먼저 쓰면 사람이 LLM 판단에 앵커링되어 자신만의 바이브를 포착 못함. 반드시 사람이 먼저 최소 10~20개 이상 데이터를 직접 읽어야 함
  • 범용 지표의 무용성 — helpfulness score, conciseness score, toxicity score 등 범용 지표는 대체로 쓸모없고 방향을 흐림. 에러 분석에서 도출한 구체적 카테고리 기반 지표가 실질적
  • Whack-a-Mole 안티패턴 — 프롬프트 엔지니어링으로 문제를 하나씩 땜질하는 방식은 진전 측정 불가능. 에러 분석으로 전체 지형을 파악한 뒤 우선순위에 따라 개선
  • 평가 기준의 드리프트 — 초기에 싫어했던 패턴이 맥락에 따라 나중에 긍정적으로 재평가될 수 있음. 지속적 재검토 필요
  • 충분한 샘플 수 — 고정 숫자가 아니라 “더 이상 새로운 실패 유형이 안 보일 때까지”. 실무 기준으로 20~30개를 시작점으로 제시

실패 유형 예시 (AI 리크루터 이메일 사례)

  • 잘못된 수신자/발신자 역할 전도 (지원자가 보내야 할 이메일을 기업이 받는 것처럼 씀)
  • 이력서에 없는 스킬을 지어내는 환각(hallucination)
  • 과도하게 상투적인 문구 (‘impressed by your experience’ 등)
  • 지나친 장황함, 같은 내용 반복

실제 적용 사례: Nurture Boss

  • Jacob Carter(Nurture Boss 창업자) — 아파트 임대 산업 AI 가상 임대 어시스턴트 사례
  • 채널: 음성·이메일·문자 (OpenAI 기반)
  • 에러 분석 성과: 직접 제작한 LLM Grader 대화 뷰어로 수천 건 대화 검수 → 오류 카테고리 자동 집계
    • Tour Scheduling Errors: 8건
    • Rescheduling Errors: 4건
    • Should Trigger Handoff: 4건
    • Inability to Follow Up: 3건
    • Markdown Usage in Text: 2건
  • 날짜 처리 문제 — Braintrust 플레이그라운드에서 테스트 케이스 반복 개선 → 성공률 33% → 100%
  • 인사이트: 대화 직접 읽기가 제품 로드맵·사용자 오해 패턴·AI 반복 응답 패턴 파악에 결정적 기여

도구 스택

  • 커스텀 annotation 앱: Python Shiny, Flask+HTML, Marimo 등으로 직접 제작
  • 자동 카테고리화: LLM을 활용해 자유 형식 노트를 그룹화
  • eval 자동화: Braintrust 등으로 유닛 테스트 구축
  • 데이터셋: 실제 사용자 로그, WANDS(Wayfair), Kaggle 이력서 데이터셋 등
