Codex + Remotion으로 모션 그래픽 제작하기 (Riley Brown)

OpenAI Codex(GPT-5.4 기반 슈퍼앱)에 내장된 Remotion 플러그인을 이용해 프롬프트만으로 모션 그래픽 런칭 영상을 제작하는 방법. 7~8개의 프롬프트만으로 완성된 실전 시연 포함.

Remotion이란?

  • 코드 기반 모션 그래픽 툴: React/TypeScript로 영상을 프로그래밍하는 프레임워크
  • AI와의 시너지: AI가 코드를 대신 작성해주므로 After Effects 대비 진입장벽이 낮음
  • Codex 내장 플러그인: Codex 왼쪽 채팅창에서 프롬프트 → 오른쪽 사이드 패널에서 실시간 렌더링 확인
  • 실증 사례: Anthropic이 기능 런칭마다 Remotion 영상을 매일 하나씩 만들어 한 달간 3억 뷰 이상 기록

Codex vs Claude Code 차이점

항목CodexClaude Code
코드/협업 통합단일 인터페이스 통합코드(code)·협업(co-work) 분리
플러그인 생태계Remotion·Figma·Gmail 등 내장별도 MCP 설정 필요
결과물 표시사이드 패널 실시간 미리보기터미널 기반

프로젝트 설정 단계

  1. Codex에서 새 프로젝트 생성 (Desktop 폴더 내 ‘Remotion project’ 폴더 지정)
  2. Plugins → Remotion 설치
  3. 프로젝트 폴더에 PNG 에셋(로고 등) 드래그 앤 드롭
  4. 첫 프롬프트로 기본 영상 생성

효과적인 프롬프트 기법

  • 타임스탬프 지정: 프레임 단위(30fps)로 특정 지점을 ‘4:17’ 형태로 짚어 정교한 수정 지시
  • 스크린샷+주석 첨부: 이미지를 대화에 첨부해 ‘어떤 라인을 말하는지’ 모호함 제거
  • Steering(Cmd+Enter): 진행 중인 세션에 즉시 지시 반영 vs 새 프롬프트 큐잉 구분 활용
  • 브랜드 에셋 컴포지션: 로고·그라디언트·Lissajous figure를 별도 컴포지션으로 관리해 여러 영상에서 재사용

실전 워크플로 예시

  1. 기본 Hello World 영상 생성
  2. 로고·PNG 에셋 삽입
  3. 텍스트 전환 애니메이션(백스페이스 효과) 추가
  4. 로고 이탈 애니메이션 설정
  5. suno.ai로 배경음악 생성 → 프로젝트 폴더에 드래그 → 볼륨 지정
  6. 소셜미디어 아이콘·통계 증가 씬 추가
  7. H.264 코덱으로 렌더링 → 트위터 업로드 가능 파일 완성

브랜드 에셋 구성 요소

  • 다크그레이 그라디언트 배경
  • 블루 그라디언트
  • 레드/블루/그레이/그린 Lissajous figure
  • iPhone 목업
  • 재사용 가능한 배경 세트로 영상 간 일관성 유지

렌더링 설정

  • 코덱: H.264
  • 프레임레이트: 30fps
  • 완성 파일은 트위터, YouTube 등 소셜미디어 바로 업로드 가능
