Bird: Block의 오픈소스 통합 코딩 에이전트 프런트엔드

Jack Dorsey의 회사 Block(Square·Cash App·Goose 제작사)이 내부 팀에서 사용하던 데스크톱 AI 에이전트 통합 앱 Bird를 오픈소스(Apache 2.0)로 공개. AICodeKing 채널(2026-08-19) 리뷰 분석.

핵심 내용

  • Bird 정의: 여러 AI 코딩 에이전트를 하나의 데스크톱 앱에서 통합 운용하는 프런트엔드. 여러 CLI 도구를 터미널마다 따로 켜는 대신 하니스·모델 선택→작업 실행을 단일 인터페이스에서 처리
  • 지원 하니스 6종: Claude Code·Codex·Copilot·Amp·Cursor Agent·Goose
  • ACP(Agent Client Protocol): Bird와 각 하니스를 연결하는 공통 프로토콜. ACP를 구현한 에이전트는 모두 Bird에 플러그인 가능
  • 완전 무료·오픈소스: Apache 2.0 라이선스. Block에 별도 비용 없음, 기존 구독/API 키만 지참
  • 3D 캐릭터 UI: 에이전트를 캔버스 위에서 돌아다니는 이색적인 3D 캐릭터(크롬 큐브·스타프루트·압정 등)로 표현. 아날로그 시계 위젯 등 배치 가능한 오픈 캔버스 홈 화면
  • 설치 러프엣지: Claude Code 설치 시 ‘설정 오류’ 발생·원인 미안내(신생 앱). Codex는 정상 설치 (내부적으로 Codex ACP 어댑터를 Bird 앱 데이터로 받아오는 방식 확인)
