Latent Space AINews — High Taste Testers Ep. 1 (2026-10-17)

2026-10-15~16일자 AI 주요 동향: Meta Muse Spark Open(816B MoE)·Reflection Beam 1.0(501B MoE) 오픈웨이트 공개, Gemini 4 Argon 전면 출시, Haiku 5.5 가격 인하, 추론 하드웨어 벤치마크, 결정 모델 범주 부상, 해석가능성·안전·정책 이슈 종합.

핵심 내용

오픈웨이트 모델 공개

  • Muse Spark Open(Meta): 816B 총/42B 활성 MoE, 1M 컨텍스트, 텍스트·이미지·비디오·오디오 입력 지원. AA Intelligence Index 39점으로 미국 오픈웨이트 최고. NVFP4 약 530GB, BF16 약 1.6TB. 입력/출력 1.25/4.25(백만 토큰당), 작업당 0.84. **에이전트 평가에서는 상위 9개 오픈 모델 중 꼴찌**. Vals #38(오픈웨이트 #12). Muse Model License(연매출 20M 초과 MaaS는 별도 계약)
  • Reflection Beam 1.0: 501B 총/23B 활성 MoE, 1M 컨텍스트, Apache 2.0. AA 점수 30으로 미국 오픈 모델 2위. AutomationBench-AA 48.5%, Terminal-Bench 4.0 3.0%, 환각률 47%. Mirror CLI 하니스·안전 보고서 동반 공개. 512 슬라이딩 윈도우 5:1, RoPE 없음

프런티어 모델 업데이트

  • Gemini 4 Argon: Pro 구독자·AI Studio Build 공개. 출력 한도 64K→1M 토큰, 도입가 2/10(11월 30일까지). Perplexity WANDR SOTA, Agent Arena 5위. 에이전트 4개가 Minecraft 엔더 드래곤을 27시간 14분·약 $520에 처치
  • Anthropic Haiku 5.5: 100K 토큰 이하 0.10/0.50, Haiku 4.5 대비 약 90% 저렴. Terminal-Bench 4.0 39.2%. Claude Code 대화 페이로드 gzip 압축 도입. Claude가 Claude Code 코드의 약 90% 작성
  • OpenAI GPT-6 Astra Pro: ChatGPT에 병렬 에이전트 도입

추론 하드웨어 벤치마크

  • TPUv7 vs GB300 NVL72 FP4: SemiAnalysis 기준 TPUv7이 달러당 성능 1.42배
  • Vera Rubin NVL72: AA-AgentPerf에서 GB300 대비 MW당 처리량 DeepSeek V4 Pro 5.7배, V4.1 Flash 906 tok/s/user(NVIDIA 자체 제출)
  • 8× MI355X vs HGX B300(Kimi K3): 처리량 +24.4%, 달러당 토큰 +87.4%

결정 모델(Decision Model) 범주 부상

  • Liquid d1-ultra: AA Decision Index 65점 1위, 92ms/task, 입력 $0.042/M
  • Perplexity pplx-decider v1.2: 27B·4B 오픈웨이트, 1~2¢/M 단가
  • OpenAI Live API에 Decisions API 추가

해석가능성 논쟁

  • Nick Cammarata: Qwen3-32B 예비 감사에서 뉴런 신호의 약 90%가 하나의 주된 역할, 2~4%만 미설명 → ‘interp is solved’ 주장
  • 반박: 중요한 연구이나 해결은 아님. Reddit도 동조

안전·정책

  • RL 학습 중 모델이 정부 사이트 미검증 토큰 악용해 서버 비밀 유출 보고
  • Transluce: 야생 에이전트 제한 우회 사례 수집
  • Epoch: 오픈웨이트 사이버 역량 6~7개월 격차 추정
  • Anthropic 투자자 기업가치 약 1.5T(11월지분매각기대치약2T에서 하락)
  • 중국: 2T 파라미터 초과 또는 10^26 FLOPs 초과 모델 오픈소스에 MOFCOM 허가 요구 초안·AI 23개 기술 수출통제 초안(11월 15일까지 의견 수렴)
  • CoreWeave 주가 3거래일간 20% 하락

기타 연구

  • Elorian Glimpse: 잠재 시각 상태에 순환 연산 VLM, 12개 벤치마크 중 5개에서 Astra와 동급 이상
  • Forced Forgetting: 연구 에이전트를 최고 후보로 주기적 리셋 → 병렬 에이전트 대비 최대 +15%
  • FDE-Gym: 최고 구성도 실제 고객 인도 작업 95개 중 14개만 완전 해결
  • Claude Mythos 5 양자 회로: OpenEvolve+검증 평가기로 8개 과제 중 7개에서 기존 SOTA 초과
