GTC Taipei 2026 키노트 기술 용어집

개요

젠슨 황 NVIDIA CEO의 GTC Taipei 2026 (2026-06-01) 기조연설에서 등장한 핵심 기술 용어 정리. 각 용어마다 정의 → 비유/코드 → 키노트 맥락 → FuriosaAI 경쟁 관점 순으로 구성. AI 에이전트 시대를 위한 Vera Rubin 플랫폼, RTX Spark, Physical AI가 3대 주제.

1. 에이전트 컴퓨팅

AI 에이전트 (AI Agent)

정의

LLM을 두뇌로 삼아 관찰(Observe) → 추론(Reason) → 계획(Plan) → 행동(Act) 루프를 돌며, 외부 도구를 호출해 실제 작업을 끝까지 수행하는 자율 소프트웨어. 단발성 질의응답을 넘어 스프레드시트·브라우저·DB 엔진 등을 직접 조작한다.

비유 & 코드

질문에 답만 하는 ‘챗봇’이 신입 상담원이라면, 에이전트는 도구 사용 권한과 업무 위임을 받은 ‘대리’. 목표를 주면 스스로 단계를 쪼개 처리한다.

키노트 맥락

황은 “지난 6개월 사이 모델이 도구와 결합하며 컴퓨팅 산업이 에이전트 시대로 전환됐고, 이 패러다임이 클라우드·PC·로봇 어디서나 동일하게 적용된다”고 선언했다.

FuriosaAI Insight

에이전트는 짧은 추론(prefill)과 잦은 도구 호출이 반복돼 저지연·고빈도 추론 부하를 만든다. 대량 배치 학습보다 ‘추론 효율(토큰/와트)‘이 경제성을 좌우 — NPU의 전력효율 내러티브가 정확히 겨냥하는 워크로드.

관련 태그: agentic-ai react observe-reason-act

에이전트 4요소 (Model · Harness · Tools · Runtime)

정의

키노트가 제시한 에이전트의 4대 분해 요소.

  • 모델: 사고하는 LLM
  • 하네스(Harness): 모델을 도구·데이터에 연결·조율하는 골격
  • 도구·기술(Tools/Skills): 실제 실행 능력
  • 런타임(Runtime): 보안·실행 환경

이들이 데이터센터 곳곳에 흩어져 실행되는 ‘궁극의 분산 컴퓨팅 패턴’을 이룬다.

비유

오케스트라에 비유하면 — 모델은 작곡가(의도), 하네스는 지휘자(조율), 도구는 연주자(실행), 런타임은 공연장과 안전 규정(환경·보안).

키노트 맥락

황은 ‘LLM이 운영체제처럼 모든 것을 연결하고 사고한다’고 표현했으며, 이 4요소가 분산 실행되는 점이 Vera Rubin 같은 분산 시스템이 필요한 이유라고 설명했다.

FuriosaAI Insight

하네스·런타임·도구 실행은 CPU/DPU 영역, 모델 사고는 가속기 영역으로 워크로드가 분해(disaggregate) 된다. 이질적 컴퓨팅 조합이 표준이 되면 특정 가속기 벤더 종속도가 낮아져 NPU 진입 여지가 생긴다.

관련 태그: disaggregation harness runtime

하네스 (Harness)

정의

모델(LLM)을 실제 도구·데이터·다른 에이전트와 묶어 작업이 흐르도록 만드는 ‘골격/배선’ 계층. 모델 자체가 아니라 모델을 둘러싼 오케스트레이션 로직이다. 키노트에서는 Vera CPU의 ‘Vera Compute’와 RTX Spark의 ‘Hermes’ 하네스가 예시로 등장.

비유

우주복(하네스)이 우주인(모델)을 산소·통신·이동 장치(도구)에 연결해 실제로 임무를 수행하게 하는 것과 같다. 우주인 혼자로는 진공에서 아무것도 못 한다.

키노트 맥락

RTX Spark의 건축 설계 에이전트가 ‘Open Shell + Hermes 하네스’로 클라우드 모델과 연동해 주택 설계를 수행하는 사례로 소개됐다.

관련 태그: orchestration hermes

오픈 셸 (Open Shell)

정의

에이전트를 감싸 **정책(policy)·프라이버시·권한(permission)·신원(identity)**을 강제하는 보안 런타임. NVIDIA가 오픈소스로 공개해 전 세계 표준 채택을 노리는 ‘에이전트용 보안 쉘’이다.

비유

OS의 사용자 권한 시스템(sudo, sandbox)을 에이전트에게 입힌 것. 에이전트가 무엇을 만지고 무엇을 못 만지는지를 결정하는 ‘출입 통제소’.

키노트 맥락

황은 모든 기업이 에이전트를 내부 운영하며 자체 OS가 필요해질 것이라며, Open Shell을 에이전트 보호 런타임으로 제시했다.

FuriosaAI Insight

보안 런타임이 오픈소스·표준화되면 하드웨어 추상화가 진전돼, 특정 가속기에 묶이지 않는 멀티-실리콘 배포가 쉬워진다 — 클라우드 어그노스틱 전략과 결이 맞음.

관련 태그: security opensource policy

MCP 서버 (Model Context Protocol Server)

정의

에이전트(클라이언트)가 외부 앱·데이터·도구에 표준 방식으로 접근하도록 노출하는 인터페이스. 앱이 ‘MCP 서버’를 띄우면, 어떤 에이전트든 동일 규약으로 그 앱의 기능을 호출할 수 있다.

비유 & 코드

앱마다 다른 케이블 대신 **‘USB-C 포트’**를 단 것. 에이전트는 케이블 하나로 어떤 도구든 꽂아 쓸 수 있다.

키노트 맥락

Adobe가 Photoshop·Premiere를 RTX Spark에서 2배 빠르게 재설계하면서, 에이전트 친화적 MCP 서버를 통해 노트북에서 에이전트와 상호작용하게 했다고 소개됐다.

관련 태그: mcp interoperability adobe

단기·장기 기억 (Short / Long-term Memory)

정의

에이전트가 작업 맥락(단기 — KV Cache·컨텍스트 윈도우)과 누적 지식(장기 — 벡터DB·파일)을 관리하는 메모리 체계. 황은 이 메모리 요구가 ‘스토리지 시스템에 혁명을 일으킨다’고 했다.

비유

단기 기억 = 책상 위에 펼쳐둔 작업 서류, 장기 기억 = 캐비닛에 보관한 파일. 에이전트는 작업 중 둘 사이를 끊임없이 오간다.

키노트 맥락

에이전트가 방대한 컨텍스트와 기억을 관리해야 하므로, 초고속 스토리지(Vera BlueField)와 빠른 메모리 접근이 핵심 설계 목표로 등장.

FuriosaAI Insight

장기 컨텍스트·KV Cache 폭증은 메모리 대역폭과 용량을 추론 병목으로 만든다. HBM 용량/대역폭과 메모리 계층 설계가 추론 가속기 경쟁의 핵심 전장.

관련 태그: kv-cache vectordb context

NVIDIA 에이전트 툴킷 (Agent Toolkit)

정의

엔터프라이즈가 자체 에이전트를 만들도록 모델·하네스·도구/기술·런타임을 묶어 제공하는 NVIDIA의 패키지. Cadence가 칩 설계 에이전트를 구축한 것처럼, 기업이 자사 워크플로에 에이전트를 이식하게 한다.

비유

에이전트판 ‘레고 스타터 키트’ — 부품(4요소)과 조립 설명서를 함께 줘서, 기업이 자기 공장에 맞는 로봇 팔을 직접 조립하게 한다.

키노트 맥락

황이 ‘AI 참여를 위한 최대 성장 기회’로 강조한 소프트웨어 사업 축. 황은 소프트웨어 기업의 종말이 아니라 더 많은 도구 활용 기회라고 주장.

관련 태그: enterprise-ai sdk cadence

2. 모델 · 알고리즘

트랜스포머 (Transformer)

정의

2017년 ‘Attention Is All You Need’에서 제안된 신경망 아키텍처. 셀프 어텐션으로 시퀀스 내 토큰 간 관계를 병렬 계산해, 현대 LLM과 거의 모든 생성 AI의 기반이 됐다.

비유

문장을 읽을 때 각 단어가 다른 모든 단어를 **‘동시에 곁눈질’**하며 누가 중요한지 가중치를 매기는 방식. RNN의 순차 처리와 달리 한 번에 전체를 본다.

키노트 맥락

Cosmos 3는 ‘새로운 트랜스포머 하이브리드 아키텍처’, Nemotron 3 Ultra는 ‘SSM+MoE 하이브리드’로 소개돼, 순수 트랜스포머를 넘어선 변종이 트렌드임을 시사.

관련 태그: self-attention foundation-model

전문가 혼합 (Mixture of Experts, MoE)

정의

하나의 거대 모델 대신 여러 ‘전문가(expert)’ 서브네트워크를 두고, **라우터(gating)**가 토큰마다 일부 전문가만 활성화하는 구조. 전체 파라미터는 크지만 추론 시 실제 연산량(active params)은 작아 효율적이다.

비유 & 코드

종합병원에서 환자를 전체 의사가 보는 게 아니라, 접수처(라우터)가 증상에 맞는 2~3명 전문의에게만 보내는 것. 병원 규모는 크되 진료 비용은 절약.

키노트 맥락

Nemotron 3 Ultra가 SSM과 MoE의 하이브리드로 **‘5배 빠르고 30% 저렴’**하다고 발표됐다. MoE는 추론 비용 절감의 핵심 기법.

FuriosaAI Insight

MoE는 활성 파라미터가 적은 대신 메모리 용량 부담·전문가 라우팅 트래픽이 크다. 메모리 대역폭과 인터커넥트가 병목 — 가속기별 강·약점이 갈리는 지점.

관련 태그: moe sparse active-params

상태공간 모델 (State Space Model, SSM)

정의

Mamba 등으로 대표되는 시퀀스 모델 계열. 트랜스포머 어텐션이 시퀀스 길이에 제곱(O(n²))으로 비싸지는 반면, SSM은 **선형(O(n))**에 가깝게 긴 시퀀스를 처리해 장문 컨텍스트·추론에 유리하다.

비유

트랜스포머가 매 단어마다 ‘지금까지 모든 단어’를 다시 훑는다면, SSM은 **요약 상태(state)**를 들고 다니며 새 단어로 갱신만 한다. 회의록을 매번 처음부터 읽지 않고 누적 요약만 업데이트하는 식.

키노트 맥락

Nemotron 3 Ultra의 SSM+MoE 하이브리드 아키텍처로 등장. 장문·고속 추론을 노린 차세대 설계 흐름.

FuriosaAI Insight

SSM의 선형 스케일링은 어텐션 대비 연산 패턴이 달라, 어텐션에 최적화된 하드웨어와 효율 프로파일이 갈린다. 아키텍처 다변화는 **‘유연한 가속기’**에 유리한 환경.

관련 태그: ssm mamba long-context

네모트론 3 울트라 (Nemotron 3 Ultra)

정의

NVIDIA가 공개하는 오픈 모델 패밀리의 차세대 플래그십. 5배 빠르고, 30% 저렴하며, 완전 오픈소스. SSM + MoE 하이브리드로 최상위 오픈 모델과 견준다. 기업이 이를 기반으로 자체 에이전트를 구축한다.

비유

NVIDIA가 배포하는 ‘에이전트 엔진 블록’ — 완성차(기업 에이전트)를 만들 때 누구나 가져다 튜닝할 수 있는 고성능 오픈 베이스.

키노트 맥락

Cadence 칩 설계 에이전트(Codex Agent)의 기반 모델로 활용됐고, 황은 후속 Nemotron 4도 개발 중이라 밝혔다.

FuriosaAI Insight

오픈 가중치 모델은 가속기 종속을 낮춘다 — 동일 모델을 NVIDIA·AMD·NPU 어디서든 돌릴 수 있어, 추론 가속기 경쟁이 ‘모델 호환성’에서 **‘효율/TCO’**로 이동.

관련 태그: open-model nemotron ssm moe

코덱스 에이전트 (Codex Agent)

정의

Nemotron 기반의 코드·설계 특화 에이전트. Cadence 칩 설계 에이전트의 **‘오케스트레이터’**로 등장해, RTL 생성·테스트벤치 구성·회귀 테스트·디버깅 등 전문가 하위 에이전트들을 호출·조율한다.

비유

수석 엔지니어 한 명이 여러 전문 하청팀(하위 에이전트)에 작업을 분배·취합하는 ‘PM 에이전트’.

키노트 맥락

이 칩 설계 에이전트가 수백 건 시뮬레이션으로 설계 결함을 찾아, 수 주 걸리던 검증을 수 시간으로 — ‘40배 가까이’ 단축했다고 발표.

FuriosaAI Insight

EDA(칩 설계 자동화)는 FuriosaAI 같은 팹리스에도 직접 영향. 설계·검증 가속은 NPU 자체 개발 속도와도 연결되는 도구 사슬.

관련 태그: eda cadence sub-agents rtl

코스모스 3 (Cosmos 3 — World Foundation Model)

정의

물리적 AI의 최전선 모델. 새 트랜스포머 하이브리드로 픽셀·행동(action)·소리·언어 스트림을 통합한다. 물리 세계를 관찰·이해하고, 이미지에서 물리 정보를 추출하며, 텍스트/비디오로부터 비디오를 합성한다. 시뮬레이터로서 폐쇄 루프 정책 훈련·평가에 쓰이며 Omniverse의 기반.

비유

로봇을 위한 ‘물리 직관을 가진 상상력 엔진’. 사람이 공이 굴러갈 방향을 직감하듯, 미래 프레임을 예측해 로봇의 지각·계획·행동 생성을 돕는다.

키노트 맥락

물리적 AI의 최대 난제인 **‘데이터 부족’**을 합성 데이터·시뮬레이션으로 해결하는 핵심 도구로 제시. 개발자가 자기 모델로 강화할 수 있는 오픈 시스템.

관련 태그: world-model omniverse synthetic-data physical-ai

알파마요 2 (Alpamayo 2)

정의

NVIDIA가 발표한 자율주행차용 오픈 모델. 차량이 주변을 이해하고 보행자·차량에 반응하며 복잡한 교통을 안전 주행하는 추론 능력을 갖춘 ‘세계 최초의 추론형 자율주행 모델’로 소개.

비유

기존 자율주행이 **‘학습된 반사신경’**이라면, 알파마요 2는 **‘왜 저 차가 끼어들지?’**를 추론하는 운전자에 가깝다.

키노트 맥락

전 세계 완성차의 약 80%가 NVIDIA Hyperion을 사용하며, 알파마요는 Halos OS + Hyperion 런타임으로 배포돼 모빌리티 서비스의 97%와 연결될 것이라 발표.

3. 베라 루빈 · 하드웨어

베라 루빈 (Vera Rubin Platform)

정의

에이전트 AI 시대를 위한 NVIDIA의 멀티랙 포드 스케일 슈퍼컴퓨터. GPU · NVLink 72 · Vera CPU · 고속 스토리지 · Doka SW 스택 · 보안 프로세서를 통합한 엔드투엔드 시스템. 전작 Grace Blackwell이 ‘추론’을 위한 것이었다면, 베라 루빈은 **‘에이전트 실행’**을 위해 완전 양산 중.

비유

단일 서버가 ‘강력한 PC 한 대’라면, 베라 루빈은 여러 랙을 NVLink로 묶어 마치 **‘거대한 단일 컴퓨터’**처럼 동작하는 슈퍼컴퓨터. 천체물리학자 Vera Rubin에서 명명.

키노트 맥락

황은 NVIDIA가 **‘GPU 회사 → 시스템 회사 → 인프라 회사’**로 진화했다며, 4,000명 엔지니어와 150개 대만 공급망 파트너가 참여한 회사 역사상 가장 야심 찬 프로젝트라 강조.

FuriosaAI Insight

베라 루빈은 ‘랙 전체를 하나로’ 파는 풀스택 수직통합 전략. FuriosaAI의 대척 포지션 = 개방형·구성요소 단위·에이전트 친화적 효율 강조. ‘Gigawatt 슈퍼컴’ 외 시장(엣지·특화 추론)에 기회.

관련 태그: vera-rubin multi-rack-pod end-to-end

그레이스 블랙웰 (Grace Blackwell)

정의

베라 루빈의 직전 세대 플랫폼. Grace(Arm 기반 CPU)와 Blackwell(GPU)을 결합한 AI 추론용 슈퍼칩/시스템. 베라 루빈은 이를 ‘에이전트 실행’으로 확장한 후속작이다.

키노트 맥락

황은 ‘베라 루빈은 추론을 위한 그레이스 블랙웰을 넘어선다’며 세대 전환을 명확히 했다.

관련 태그: grace blackwell predecessor

베라 CPU (Vera CPU)

정의

기존 CPU가 ‘인간 사용자’용이었다면, 베라 CPU는 AI 에이전트 전용으로 처음부터 새로 설계한 CPU. 나노초 단위로 동작하는 에이전트의 도구 호출·DB 접근에 최소 지연으로 응답한다. 랙 내에서 GPU 오케스트레이션 · KV Cache 관리 · 소프트웨어 처리를 담당하는 ‘지휘자’.

비유

GPU가 거대한 **‘연산 공장’**이라면 CPU는 공장에 부품을 제때 나르는 ‘물류 지휘자’. 지휘가 느리면 비싼 공장(GPU)이 놀게 된다 — 그 병목을 없애는 CPU.

키노트 맥락

황은 베라 CPU를 ‘회사 역사상 가장 성공적인 제품 출시’로 표현.

  • 단일 스레드 성능 세계 최고
  • SQL 실행 속도 3배 향상
  • 실시간 스트림 처리 6배 향상

FuriosaAI Insight

에이전트 시대엔 **‘CPU ↔ 가속기 조율’**이 GPU 활용률(=경제성)을 좌우. 가속기만 빨라도 오케스트레이션이 느리면 무의미 — 호스트-가속기 인터페이스 설계가 NPU 시스템 통합의 핵심 과제.

관련 태그: vera-cpu agent-native olympus-core orchestration

올림푸스 코어 (Olympus Core)

정의

Vera CPU에 탑재된 NVIDIA의 커스텀 CPU 코어. 세계 최고 수준의 IPC (클럭당 명령어)와 단일 스레드 성능을 목표로 설계됐으며, 확장 가능한 일관성(coherence) 아키텍처와 결합해 AI 팩토리 성능을 끌어올린다.

비유

엔진으로 치면 ‘실린더당 출력(IPC)을 극한으로 끌어올린 고회전 코어’. 같은 rpm(클럭)에서 더 많은 일을 한다.

관련 태그: olympus-core custom-core coherence

IPC (Instructions Per Cycle)

정의

CPU가 클럭 1사이클당 실행하는 명령어 수. 높을수록 같은 클럭에서 더 많은 일을 처리해 저지연·고단일스레드 성능을 낸다. 에이전트의 순차적 도구 호출처럼 병렬화하기 어려운 작업에서 특히 중요.

비유

같은 시간(클럭) 동안 한 번에 처리하는 손동작 수. 손이 빠를수록(IPC↑) 동일 박자에서 더 많은 일을 끝낸다.

키노트 맥락

Vera CPU의 핵심 자랑거리. 에이전트가 ‘기다리는 모든 순간’이 손해이므로 IPC·저지연을 최우선 설계 목표로 삼았다.

관련 태그: ipc single-thread latency

칩렛 (Chiplet)

정의

하나의 큰 단일 다이(monolithic) 대신, 작은 기능 블록(칩렛)들을 패키지 안에서 고속 인터커넥트로 묶어 하나의 칩처럼 동작시키는 설계. 수율·비용·확장성에 유리하다. 베라 CPU는 ‘칩렛 경계 없이’ 모든 코어가 초고속 통신한다고 강조.

비유

한 덩어리 대형 케이크(모놀리식)를 굽다 실패하면 전체를 버리지만, 작은 컵케이크(칩렛)를 모아 조립하면 불량 하나만 버리면 된다 — 수율과 비용에 유리.

FuriosaAI Insight

칩렛은 팹리스의 비용·수율 전략 핵심. NPU 역시 칩렛/패키징 전략으로 대형 가속기와 비용 경쟁 가능. AMD MI300(칩렛 다수)·하이퍼스케일러 커스텀 실리콘과의 비교 포인트.

관련 태그: chiplet packaging yield die-to-die

HBM (High Bandwidth Memory)

정의

DRAM 다이를 수직 적층하고 가속기 옆에 바짝 붙여(2.5D) 초고대역폭을 내는 메모리. AI 가속기의 성능·용량을 좌우하는 핵심 부품. 키노트는 SK하이닉스·삼성·마이크론의 HBM 사용을 언급.

비유

연산 공장(GPU) 바로 옆에 **‘초고속 컨베이어 창고’**를 여러 층으로 쌓아 올린 것. 멀리서 자재(데이터)를 받지 않아 대기 시간이 짧다.

키노트 맥락

베라 루빈은 TSMC 3나노 7개 신규 칩 + HBM을 CoWoS 패키징으로 통합. HBM 공급망(메모리 3사)이 AI HW의 병목이자 핵심 자산.

FuriosaAI Insight

추론 워크로드는 흔히 ‘메모리 바운드(memory-bound)’ — HBM 용량/대역폭이 토큰 처리량을 직접 결정. NPU의 메모리 서브시스템 설계와 HBM 확보 능력이 경쟁력의 본질.

관련 태그: hbm memory-bound sk-hynix samsung micron

CoWoS / 첨단 패키징 (Advanced Packaging)

정의

로직 다이와 HBM을 실리콘 인터포저 위에 함께 올려 초고대역폭으로 연결하는 첨단 패키징(TSMC CoWoS 계열). 키노트의 **‘Kowarz 패키징’**은 베라 루빈 칩 통합에 쓰인 첨단 패키징을 가리킨다.

비유

여러 부품을 긴 전선으로 잇는 대신, 한 기판(인터포저) 위에 **‘초근접 배선’**으로 올려 신호 지연·손실을 최소화하는 정밀 조립.

FuriosaAI Insight

첨단 패키징 용량(CoWoS)은 업계 전체의 공급 병목. 확보 경쟁이 곧 출하량 경쟁 — 팹리스에게 TSMC 패키징 캐파 확보는 전략 변수.

관련 태그: cowos tsmc interposer 2_5d

통합 대역폭 (6 TB/s · PCIe Gen6 · LPDDR5X)

정의

Vera CPU의 시스템 대역폭 사양.

  • 6 TB/s 시스템 대역폭
  • PCIe Gen 6 인터페이스
  • LPDDR5X 메모리

CPU 내부 및 CPU ↔ 스토리지 ↔ GPU 간 데이터 이동을 극대화한다.

비유

고속도로 차선 수(대역폭)를 대폭 늘려, 공장·창고·항만(GPU·메모리·스토리지) 사이 물류 정체를 없앤 것.

관련 태그: bandwidth pcie6 lpddr5x

기밀 컴퓨팅 (Confidential Computing)

정의

데이터가 메모리에서 **‘사용 중(in-use)‘**일 때조차 하드웨어 기반 신뢰 실행 환경(TEE)으로 암호화·격리해 보호하는 기술. 베라 루빈은 AI 모델 보안을 위해 이를 준수한다.

비유

전송 중(자물쇠 든 택배)·저장 중(금고) 보호는 흔하지만, 기밀 컴퓨팅은 **‘내용물을 꺼내 작업하는 순간조차 방탄 작업실 안’**에서만 다루는 것.

FuriosaAI Insight

멀티테넌트 추론·엔터프라이즈 배포에서 TEE는 필수 체크리스트. NPU도 추론 가속기로서 기밀 컴퓨팅 지원 여부가 엔터프라이즈 영업의 관문이 된다.

관련 태그: tee confidential-computing security

액체 냉각 · 버스바 · 매니폴드

정의

고밀도 랙의 열을 물로 식히는 냉각 체계. 베라 루빈은 케이블·호스·팬을 없앤 설계로 조립을 2시간 → 5분으로 단축했고, 고효율 매니폴드 액체 냉각 버스바는 5,000암페어 이상 전류를 전달한다.

비유

공랭(선풍기)으로는 한계인 거대 열을, 자동차 라디에이터처럼 액체로 흡열·순환시켜 식히는 것. 버스바는 가는 전선 다발 대신 굵은 ‘전력 고속도로’.

FuriosaAI Insight

전력밀도·냉각은 AI 팩토리 TCO의 숨은 절반. 와트당 토큰이 좋은 가속기는 냉각·전력 인프라 부담까지 줄여 총비용에서 복리 효과 — NPU 효율 내러티브의 확장 논거.

관련 태그: liquid-cooling busbar 5000a serviceability

4. AI 팩토리 · 인프라

AI 팩토리 (AI Factory)

정의

데이터센터를 **‘토큰을 생산하는 공장’**으로 재정의한 개념. 입력은 전력·데이터, 출력은 토큰(지능). 칩·랙·네트워크·전력·냉각이 한 몸으로 설계돼야 하며, 기가와트급 전력과 수천억 달러 자본이 들어가므로 ‘처음부터 완벽 가동’이 필수.

비유

반도체 팹이 웨이퍼를 찍어내듯, AI 팩토리는 전기를 넣어 **‘토큰(=지능 단위)‘**을 찍어낸다. 가동률 1%가 곧 수익 수억 달러.

키노트 맥락

황의 핵심 메시지: “컴퓨팅은 곧 수익이며, 와트당 성능이 수익을 결정한다.” 고객은 컴퓨터가 아니라 AI 팩토리를 산다.

FuriosaAI Insight

‘토큰/와트 = 수익’이라는 황의 프레임은 역설적으로 NPU의 가장 강력한 무기. 동일 전력예산에서 추론 토큰을 더 많이 뽑으면 그게 곧 경제성 — 효율 우위를 TCO 언어로 번역하는 핵심 논거.

관련 태그: ai-factory token-factory capex gigawatt

DSX (Data center Scale Infrastructure)

정의

AI 팩토리 구축을 위한 NVIDIA의 청사진(blueprint). 칩·랙·네트워크·전력·냉각 등 모든 계층을 함께 설계하게 한다. 소규모 기업도 세계적 AI 클라우드를 짓도록 지원하며 CoreWeave·Mebius·Nscale·Neighborhood Cloud 등과 협력.

DSX 3대 구성요소

구성역할
DSX SIMOmniverse로 공장 레이아웃·전력·냉각·네트워크 사전 시뮬레이션
DSX OS인프라 운영·모니터링·수리
DSX Max LPs전력 예산 내 GPU 최대 배포 → 연 수십억 달러 추가 수익

비유

AI 팩토리판 ‘턴키 시공 설계도+감리’ — 부지(전력)부터 생산라인(GPU)까지 한 번에 설계·검증·운영하게 해주는 종합 패키지.

FuriosaAI Insight

DSX는 사실상 ‘NVIDIA 표준 공장’ 강제 — 강력한 락인(lock-in). 클라우드 어그노스틱·개방형 인프라를 원하는 고객에게는 멀티-실리콘 설계 여지가 차별화 포인트.

관련 태그: dsx blueprint coreweave lock-in

토큰/와트 · 와트당 성능 (Tokens per Watt · Perf/Watt)

정의

AI 팩토리 경제성의 핵심 지표. 같은 전력(와트)으로 얼마나 많은 토큰을 생성하느냐가 수익을 결정한다.

황: “잘못된 아키텍처는 저렴한 칩이라도 무의미하며, 와트당 토큰 생성량과 시스템 신뢰성이 중요하다.”

비유 & 코드

연비(km/L)처럼, AI 팩토리의 ‘토큰연비(token/W)’. 차값(칩값)이 싸도 연비가 나쁘면 총비용은 더 든다.

FuriosaAI Insight

FuriosaAI의 1번 셀링 포인트. 칩 단가 비교가 아니라 ‘워크로드별 토큰/와트와 TCO’로 토론을 옮기는 것이 NPU 영업의 정석. NVIDIA 스스로 이 지표를 표준화해 준 셈.

관련 태그: tco tokens-per-watt perf-per-watt economics

전력 평활화 · 그리드 연동 (Power Smoothing · Grid-interactive)

정의

AI 워크로드의 급격한 전력 변동(스파이크)을 완충·평활화하고, 전력망 신호를 실시간으로 읽어 공장 소비를 동적 조정하는 기술. AI 팩토리를 전력망의 **‘탄력적 자산(flexible asset)‘**으로 만든다.

비유

가정용 ESS(에너지저장장치)처럼, 전기가 쌀 때 모으고 비쌀 때 줄이며 전력망과 **‘협상’**하는 스마트 미터의 거대 버전.

관련 태그: ess demand-response power-spike

5. 네트워킹 · 인터커넥트

NVLink 72 / NVLink 스위치

정의

NVIDIA의 GPU 간 초고속 직결 인터커넥트. NVLink 72는 한 도메인에 72개 GPU를 묶어 마치 하나의 거대 GPU처럼 메모리·연산을 공유하게 한다. NVLink 스위치는 이 토폴로지를 구성하는 교환 장치로, 베라 루빈에서는 **교체 가능(serviceable)**하게 설계.

비유

PCIe가 **‘도시 간 일반도로’**라면 NVLink는 ‘GPU 전용 초고속 자기부상 직결선’. 72개 GPU가 옆 사무실처럼 데이터를 주고받는다.

키노트 맥락

Grok MLP의 초저지연 추론을 베라 루빈+NVLink 72로 처리량 확장하는 사례로 등장. 대규모 모델 분산 학습/추론의 통신 병목을 푸는 핵심.

FuriosaAI Insight

NVLink는 NVIDIA 락인의 핵심 해자(moat). 다중 가속기 스케일아웃에서 표준 이더넷(UEC)·오픈 인터커넥트를 쓰는 진영(NPU 포함)이 어떻게 통신 효율을 좁히느냐가 경쟁의 본질.

관련 태그: nvlink scale-up interconnect moat

스펙트럼-X 이더넷 (Spectrum-X Ethernet)

정의

AI 데이터센터의 스케일아웃(랙↔랙, 클러스터 전체)을 위한 NVIDIA의 이더넷 플랫폼. 표준 이더넷에 혼잡 제어·RDMA 최적화를 더해 AI 트래픽에 맞춘 고성능·저손실 네트워킹을 제공.

비유

NVLink가 건물 내부 엘리베이터(스케일업)라면, Spectrum-X는 건물 간을 잇는 ‘전용 고속철도망(스케일아웃)’. AI 트래픽 전용 다이어로 정체를 줄인다.

키노트 맥락

황은 NVLink 스위치와 Spectrum-X Ethernet **포토닉스(photonics)**를 들어 NVIDIA가 ‘세계 최고의 네트워킹 회사’가 됐다고 선언.

FuriosaAI Insight

네트워킹까지 NVIDIA가 장악하면 인프라 락인이 심화. 클라우드 어그노스틱 진영은 표준 이더넷(RoCEv2/UEC)으로 동등 성능을 노린다 — NPU 클러스터의 네트워크 전략과 직결.

관련 태그: spectrum-x scale-out rdma rocev2

실리콘 포토닉스 (Silicon Photonics / Co-packaged Optics)

정의

전기 신호 대신 빛으로 데이터를 전송하는 광학 인터커넥트를, 스위치 칩에 광엔진을 직접 붙여(co-packaged) 구현하는 기술. 구리 전송의 거리·전력 한계를 넘어 대규모·저전력 네트워킹을 가능케 한다.

비유

구리선(전기)이 **‘전령이 직접 뛰어 전달’**이라면, 포토닉스는 ‘광속 신호탑’. 멀리 보내도 손실·전력이 적다.

FuriosaAI Insight

광 인터커넥트는 대규모 스케일아웃의 전력 절감 열쇠. 가속기 자체 효율 + 광 네트워킹이 결합돼야 팩토리 단위 TCO가 완성 — 시스템 레벨 경쟁이 됨을 시사.

관련 태그: cpo optical silicon-photonics

베라 블루필드 (Vera BlueField — DPU)

정의

베라 루빈의 DPU(Data Processing Unit) 계열. 네트워킹·스토리지·보안 오프로드를 전담해, 에이전트의 빠른 메모리/스토리지 접근 요구를 충족한다. 키노트에서 ‘가장 빠른 스토리지 서버/시스템’으로 소개.

비유

CPU·GPU가 본업(사고·연산)에 집중하도록, 통신·보안·스토리지 잡무를 전담하는 ‘전문 비서(DPU)’. 본업 효율이 올라간다.

FuriosaAI Insight

DPU 기반 오프로드는 멀티테넌트·보안·스토리지 가속의 표준 추세. NPU 시스템도 DPU/스마트NIC와의 통합 설계로 호스트 부담을 줄여야 경쟁 가능.

관련 태그: dpu bluefield offload smartnic

6. 개인 컴퓨팅 (RTX Spark)

RTX Spark

정의

NVIDIA·Microsoft가 **‘40년 만에 PC를 재구상’**한 개인용 AI 플랫폼. 로컬/클라우드 에이전트가 안전하고 지속적으로 작업하는 개인 AI 샌드박스.

주요 사양:

  • 6,144 CUDA 코어
  • 1 PetaFLOP AI 성능
  • MediaTek 공동설계 20코어 Grace CPU
  • 128GB 통합 메모리
  • TSMC 3나노 · 700억 트랜지스터

비유

스마트폰이 ‘전화’의 의미를 바꿨듯, RTX Spark는 ‘개인용 컴퓨터’의 의미를 바꾸려는 시도 — 집집마다 두는 ‘개인 AI 슈퍼컴’.

키노트 맥락

100% Windows · 100% CUDA · 100% NVIDIA Tensor Core 호환. 24/7 무료로 에이전트를 돌리고 집 전체와 연결되는 개인 비서로 제시. Adobe Photoshop·Premiere가 RTX Spark에서 2배 빠르게 동작.

FuriosaAI Insight

엣지·온디바이스 추론 시장의 신호탄. 개인/엣지 영역은 전력·발열 제약이 극심해 효율 가속기에 유리한 무대 — 데이터센터 밖 NPU 기회 영역.

관련 태그: rtx-spark edge-ai windows on-device

N1X 칩

정의

RTX Spark급 PC를 구동하는 NVIDIA 신규 SoC. **‘33년 기술의 집약’**으로, 디지털 생물학·지진 처리·천체물리·유전체학·AI·컴퓨터그래픽 등 모든 CUDA 애플리케이션을 PC에서 실행 가능하게 한다.

비유

데이터센터급 CUDA 생태계를 통째로 **‘책상 위 한 칩’**에 이식한 것. 슈퍼컴에서만 돌던 워크로드를 개인이 돌린다.

키노트 맥락

CUDA 생태계의 ‘하방 확장’ — 동일 코드가 슈퍼컴부터 PC까지 돌아가는 호환성이 NVIDIA의 가장 큰 해자임을 보여주는 사례.

관련 태그: n1x soc cuda-everywhere

DGX-4 (데스크톱 AI 슈퍼컴퓨터)

정의

Windows 호환 데스크톱 AI 슈퍼컴퓨터. 768GB 메모리 · 20 PetaFLOP 성능으로, 개발자가 수조 개 파라미터 모델을 데스크톱에서 실행하게 한다.

비유

예전엔 데이터센터를 빌려야 돌리던 초대형 모델을, **책상 밑 한 박스(워크스테이션)**에서 돌리는 ‘개인 슈퍼컴’.

관련 태그: dgx4 768gb 20-pflops workstation

CUDA 코어 / 텐서 코어 (CUDA Core · Tensor Core)

정의

  • CUDA 코어: 범용 병렬 연산(FP32 등)을 처리하는 GPU의 기본 연산 유닛
  • 텐서 코어: 딥러닝의 핵심인 **행렬곱-누산(MMA)**을 저정밀(FP16/FP8/FP4 등)로 초고속 처리하는 전용 유닛. AI 성능 대부분이 여기서 나온다.

비유 & 코드

CUDA 코어가 **‘만능 일꾼’**이라면, 텐서 코어는 ‘행렬곱만 미친 듯이 빠른 전문 기계’. AI는 결국 거대한 행렬곱이라 전용 유닛이 압도적.

FuriosaAI Insight

NPU의 핵심 경쟁축. 텐서 코어 vs NPU의 연산 어레이/데이터플로 — 동일 행렬곱을 누가 더 적은 전력·데이터 이동으로 처리하느냐가 토큰/와트를 가른다.

관련 태그: tensor-core mma fp8 fp4 systolic-array

통합 메모리 (Unified Memory)

정의

CPU와 GPU(가속기)가 별도 메모리를 복사해 옮기지 않고 하나의 메모리 주소공간을 공유하는 구조. 데이터 복사 오버헤드를 없애 대형 모델을 메모리에 통째로 올리기 쉽다. RTX Spark는 128GB 통합 메모리.

비유

두 사람이 각자 사본을 들고 일하다 매번 맞추는 대신, **‘하나의 공용 화이트보드’**를 같이 보는 것. 복사·동기화 비용이 사라진다.

FuriosaAI Insight

메모리 복사 제거는 에이전트의 잦은 도구 호출·KV Cache 이동에서 큰 이득. NPU의 메모리 모델(통합 vs 분리)이 추론 효율과 SW 복잡도를 동시에 좌우.

관련 태그: unified-memory 128gb zero-copy

7. 물리적 AI · 로봇

물리적 AI (Physical AI)

정의

디지털 공간을 넘어 물리 세계에서 지각·추론·행동하는 AI (로봇·자율주행·드론 등). 황은 생성형 AI를 ‘디지털 로봇’에 비유하며, 추론·계획·행동·도구 사용이 물리 영역으로 확장된다고 봤다.

비유

챗봇이 **‘글로 답하는 뇌’**라면, 물리적 AI는 ‘몸을 가진 뇌’. 답이 텍스트가 아니라 ‘실제 동작’으로 나온다.

키노트 맥락

최대 난제는 데이터. 언어모델은 인터넷의 인간 데이터를 쓰지만, 로봇은 ‘로봇 관점의 데이터’를 직접 생성해야 한다 → Cosmos 3 · Omniverse · 합성데이터가 해법.

FuriosaAI Insight

엣지 로보틱스는 전력·발열·실시간성 제약이 극심한 영역. 저전력 추론 가속기의 핵심 무대 — 데이터센터 밖에서 NPU가 강점을 펼칠 시장.

관련 태그: physical-ai embodied-ai robotics edge

Sim-to-Real · 폐쇄 루프 학습

정의

  • Sim-to-Real: 시뮬레이션에서 학습한 정책(policy)을 실제 로봇으로 옮기는 것
  • 폐쇄 루프(Closed-loop): 정책이 환경에 행동 → 결과 관찰 → 정책 갱신을 반복하는 학습 방식

시뮬레이터(Cosmos 3 · Omniverse)에서 안전·저비용으로 무한 반복한다.

비유

파일럿이 실제 추락 위험 없이 **‘플라이트 시뮬레이터’**에서 수만 번 연습한 뒤 실기에 투입되는 것. 현실의 시행착오 비용을 시뮬로 대체.

관련 태그: sim-to-real closed-loop rl policy

원격조작 · 합성데이터 (Teleoperation · Synthetic Data)

정의

  • 원격조작(Teleoperation): 사람이 로봇을 원격 조종해 시연(demonstration) 데이터를 수집 (모방학습 재료)
  • 합성데이터: Omniverse · Cosmos 3로 가상 환경에서 라벨링된 데이터를 대량 생성해 실제 데이터 부족을 메움

비유

원격조작 = 운전 강사가 직접 핸들을 잡아 시범(시연 수집), 합성데이터 = 게임 엔진으로 무한히 만든 ‘가상 도로주행 영상’.

FuriosaAI Insight

합성데이터·시뮬 학습은 막대한 연산을 소모(학습)하지만, 실배포 추론은 엣지에서 효율적으로 돌아야 함. 학습/추론 분리 구도가 NPU 추론 포지션을 강화.

관련 태그: teleoperation synthetic-data imitation-learning

아이작 그루트 (Isaac GR00T)

정의

NVIDIA의 휴머노이드 로봇 풀스택 플랫폼. 데이터 생성 · 시뮬레이션 · 런타임(OS 포함)을 제공하고, 25 DoF(손 31) · 6피트 · 150파운드 휴머노이드 레퍼런스 디자인과 Thor 프로세서를 포함한다. 연구실 → 공장까지 로봇 연구 전 단계를 지원하는 모듈형 개방형 플랫폼.

비유

로봇판 ‘안드로이드 OS + 레퍼런스폰’. NVIDIA가 표준 스택과 기준 하드웨어를 깔아두면, 연구자·제조사는 그 위에 자기 로봇을 올린다.

키노트 맥락

클라우드·PC·자율주행·로봇이 **‘동일한 패턴(모델·하네스·도구·런타임)‘**을 공유한다는 황의 통합 비전의 물리적 구현체.

관련 태그: isaac-gr00t humanoid thor reference-design

자유도 (Degrees of Freedom, DoF)

정의

로봇이 독립적으로 움직일 수 있는 관절·축의 수. 높을수록 인간에 가까운 정교한 동작이 가능하지만 제어·학습은 복잡해진다. Isaac GR00T: 몸체 25 DoF, 손 31 DoF.

비유

인형의 ‘꺾이는 관절 수’. 관절이 많을수록 다양한 포즈가 가능하지만, 그만큼 조종(제어)이 어렵다.

관련 태그: dof kinematics dexterity

토르 프로세서 (Thor Processor)

정의

휴머노이드·자율주행을 위한 NVIDIA의 차세대 엣지 AI 프로세서. Isaac GR00T 로봇과 자율주행 차량에서 전체 SW 스택을 실시간 구동한다. 데이터센터의 추론 능력을 ‘몸’ 안으로 가져온 엣지 추론 칩.

비유

로봇의 ‘척수+소뇌’ — 클라우드(대뇌)와 연결되되, 즉각 반응이 필요한 실시간 추론은 몸 안에서 직접 처리.

FuriosaAI Insight

Thor는 엣지 추론 SoC의 직접 경쟁 카테고리. 전력예산이 극도로 제한된 로봇/차량에서 토큰·추론/와트 효율이 그대로 항속거리·발열로 직결. NPU 가치가 가장 또렷한 전장.

관련 태그: thor edge-soc realtime autonomy

제트슨 · 아이작 ROS (Jetson · Isaac ROS)

정의

  • Jetson: NVIDIA의 임베디드 엣지 AI 모듈(저전력 GPU SoC)
  • Isaac ROS: ROS2 위에서 GPU 가속 지각·내비게이션 패키지를 제공하는 미들웨어

Isaac GR00T로 개발한 로봇을 실제 기기에 배포하는 단계의 핵심.

비유

Jetson = 로봇에 심는 ‘소형 두뇌 보드’, Isaac ROS = 그 위에서 도는 ‘GPU 가속 운영 미들웨어’.

FuriosaAI Insight

ROS2는 벤더 중립 표준이지만 ‘Isaac ROS’는 NVIDIA 가속 종속을 유도. NPU 진영은 표준 ROS2 백엔드 지원으로 클라우드/엣지 어그노스틱 배포를 보장하는 게 차별화.

관련 태그: jetson ros2 isaac-ros deployment

하이페리온 · 할로스 (Hyperion · Halos OS)

정의

  • Hyperion: NVIDIA의 자율주행 차량 레퍼런스 센서·컴퓨트 플랫폼 (전 세계 완성차 약 80% 채택)
  • Halos: 그 위에서 도는 자율주행 안전 운영체제

Alpamayo 2 모델이 이 위에 배포돼 모빌리티 서비스의 **97%**와 연결될 전망.

비유

Hyperion = 자율주행차의 ‘표준 차대+센서 키트’, Halos = ‘안전 인증 운영체제’, 알파마요 = ‘AI 운전자’.

관련 태그: hyperion halos av 80percent-oem

8. 소프트웨어 · 생태계

CUDA

정의

20년 전 NVIDIA가 만든 GPU 범용 병렬 컴퓨팅 아키텍처/플랫폼. 가속 컴퓨팅을 위한 **‘단일 아키텍처’**로, 수천 가지 컴퓨팅 방식을 재편했다. 방대한 라이브러리·개발자·코드 자산이 NVIDIA의 최대 해자.

비유

가속 컴퓨팅의 ‘공용 언어이자 운영체제’. 한번 CUDA로 코드를 짜두면 세대가 바뀌어도 계속 돌아가, 떠나기 어렵게(lock-in) 만든다.

키노트 맥락

황은 ‘CUDA 생태계가 긴 수명과 낮은 TCO를 제공’한다며, 유연한 아키텍처 + 풍부한 생태계가 시스템 수명을 결정한다고 주장.

FuriosaAI Insight

CUDA 락인은 모든 AI 가속기 도전자의 1차 장벽. NPU는 표준 프레임워크(PyTorch/JAX) 백엔드·컴파일러로 ‘코드 이식 비용’을 낮추고, 추론 효율·TCO로 전환 인센티브를 만들어야 한다.

관련 태그: cuda moat ecosystem lock-in

CUDA-X 라이브러리 (CUDA-X Libraries)

정의

CUDA 위에 쌓인 도메인별 가속 라이브러리 묶음 (선형대수·신경망·데이터·통신·과학계산 등). 키노트는 이를 **‘에이전트가 인간보다 더 잘 쓰는 도구’**로 재해석 — 에이전트가 호출하는 검증된 가속 함수 모음.

비유 & 코드

에이전트의 ‘전동 공구 세트’. 맨손(범용 코드)으로 깎는 대신, 검증된 고속 라이브러리를 골라 쓴다.

관련 태그: cuda-x cudf culitho cublas acceleration

cuLitho · EDA 가속

정의

cuLitho: 반도체 노광 공정의 계산집약적 단계(컴퓨테이셔널 리소그래피)를 GPU로 가속하는 CUDA-X 라이브러리. 넓게는 칩 설계 자동화(EDA)를 AI·가속 컴퓨팅으로 단축하는 흐름. 키노트의 Cadence 칩 설계 에이전트가 대표 사례.

비유

마스크 패턴 보정(OPC)을 손으로 며칠 계산하던 것을, GPU가 몇 시간에 끝내는 ‘리소그래피 계산 가속기’.

FuriosaAI Insight

EDA·리소 가속은 팹리스(FuriosaAI 포함)의 자체 칩 개발 속도와 직결. 설계 도구 사슬의 가속이 차세대 NPU의 출시 주기를 단축하는 내부 레버리지.

관련 태그: culitho eda opc semiconductor

오픈 모델 전략 (Open Model Strategy)

정의

Nemotron 3 Ultra(언어) · Cosmos 3(월드) · Alpamayo 2(자율주행) · Open Shell(런타임)을 오픈 공개해, 개발자·기업이 자유롭게 기반으로 삼고 NVIDIA 하드웨어·생태계로 끌어들이는 전략. “모델은 열고, 인프라로 돈을 번다.”

비유

무료 앱(오픈 모델)을 뿌려 사용자를 모으고, 그들이 돌릴 **‘스토어·서버(인프라)‘**에서 수익을 내는 플랫폼 전략.

FuriosaAI Insight

오픈 모델 확산은 가속기 종속을 낮춰 NPU에 유리. 동일 오픈 모델을 **‘더 효율적으로 추론’**하는 능력이 곧 차별화. 모델은 공통재, 경쟁은 실리콘 효율로 이동.

관련 태그: open-weights platform lock-in-via-infra

Omniverse (옴니버스)

정의

NVIDIA의 물리 기반 3D 시뮬레이션 플랫폼. AI 팩토리 레이아웃·냉각·전력을 사전 시뮬레이션(DSX SIM)하고, 로봇 학습을 위한 합성 데이터 생성과 폐쇄 루프 훈련(Sim-to-Real)의 기반이 된다. Cosmos 3의 기반 플랫폼.

비유

현실 공장·로봇을 짓기 전에 **‘디지털 트윈(digital twin)‘**으로 완전히 실험해보는 가상 환경. 실패 비용이 사실상 0.
