Chapter 01 — 들어가며

📖 원본: https://wikidocs.net/book/19736

01-1. 목적과 대상 독자

AI 자동화 파이프라인 구축에 관심 있는 분. 사전 지식은 터미널 기본 명령어(ls, cd, mkdir) 수준이면 충분합니다.

01-2. Remote-Control 팀 에이전트란

CLAUDE.md는 에이전트의 **직무기술서(JD)**입니다.

사람(오케스트레이터)
    ├── TMUX pane 1 → Claude Code (CLAUDE.md: "백엔드 개발자")
    ├── TMUX pane 2 → Claude Code (CLAUDE.md: "프론트엔드 개발자")
    └── TMUX pane 3 → Claude Code (CLAUDE.md: "코드 리뷰어")

01-3. 전체 아키텍처 — 3레이어

레이어구성역할
Layer 3모바일 앱 / Remote-Control API지휘 인터페이스
Layer 2TMUX 세션 (로컬 머신)에이전트 팀 실행
Layer 1GitHub · DB · Slack · 파일시스템외부 도구 연동

01-4. 최소 사양

항목최소권장
OSUbuntu 22.04 / WSL2 / macOSUbuntu 24.04
RAM8GB16GB+
Claude 요금제Pro ($20/월)Max ($100/월) 이상

Chapter 07 — 팀 운영 전략

📖 원본: https://wikidocs.net/347784

Triple Crown 5단계 파이프라인

Phase도구핵심 명령
1. 전략 수립gstack/cso → /autoplan
2. 구조화GSD/gsd:new-project → /gsd:plan-phase
3. 구현GSD + Superpowers/gsd:execute-phase + TDD 스킬
4. 검증GSD + gstack/gsd:validate → /review → /qa
5. 완료gstack + GSD/ship → /gsd:complete-milestone

적용 기준

규모권장예시
소 (1h 이내)도구 없이오타 수정
중 (반나절)gstack만버그 수정
대 (1~3일)gstack + Superpowers새 API 모듈
특대 (1주+)Triple Crown 전체신규 서비스

Chapter 09 — 트러블슈팅

📖 원본: https://wikidocs.net/347786

인증 오류 빠른 해결

오류 증상원인해결
세션 목록 비어있음Claude Code 미실행claude --remote-control 재시작
인증 실패토큰 만료claude auth login
Full-scope login requiredAPI 키 방식 로그인Google/이메일 재로그인

TMUX 4단계 복구

장애진단해결
SSH 끊김tmux lstmux attach -t team
Claude 종료파인 출력 확인claude 재실행
파인 소실파인 개수 확인split-window + 재설정
세션 소실tmux ls 없음./setup-team.sh

빠른 오류 참조

오류 메시지해결
command not found: claudePATH 재설정
Context window full/compact 또는 새 세션
Rate limit exceeded잠시 대기 또는 플랜 업그레이드
Session expiredclaude --rc "세션명" 재시작
