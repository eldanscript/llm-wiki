Obsidian Wiki Knowledge Agent — Claude Code 실행 지침서

이 문서의 용도: Claude Code가 읽고 Phase 1~3 전체를 무감독으로 실행하기 위한 단일 지침 파일입니다.
실행 전제: obsidian-wiki 리포 클론 완료, .env에 OBSIDIAN_VAULT_PATH 설정 완료.

에이전트 행동 원칙

  • 확인 없이 진행: 각 단계를 스스로 판단하여 실행한다. 사용자 승인 대기 없음.
  • 실패 시 자력 복구: 오류 발생 시 대안 접근법 시도 후 .done/errors.log에 기록하고 다음 단계로 진행.
  • 단계 완료 신호: 각 Phase 완료 시 .done/phase{N}-{timestamp}.log 파일 생성.
  • 금지 행위: vault 외부 파일 삭제 / git push / secrets 파일 접근 / 네트워크 외부 요청.

Phase 1 — 초기 구축 (wiki-setup + 첫 ingest)

1-1. Vault 디렉터리 구조 초기화

.env에서 OBSIDIAN_VAULT_PATH 값을 읽고, 해당 경로에 아래 폴더 구조를 생성한다. 이미 존재하는 폴더는 건드리지 않는다.

$OBSIDIAN_VAULT_PATH/
├── concepts/        # 아이디어, 이론, 정신 모델
├── entities/        # 사람, 조직, 도구, 기술
├── skills/          # 방법론, 절차, How-to
├── references/      # 논문, 문서, 외부 자료 요약
├── projects/        # 프로젝트별 지식
├── decisions/       # 결정 기록 (ADR 패턴)
├── _raw/            # 미처리 캡처 스테이징 영역
├── _reports/        # 자동 점검 보고서
├── _archives/       # wiki-rebuild 시 스냅샷
└── .done/           # 단계 완료 로그

1-2. Claude 대화 기록 Ingest

~/.claude/ 경로에서 다음 파일 유형을 탐색한다:

  • *.jsonl — 대화 세션
  • MEMORY.md, memory.md — 장기 메모리
  • projects/*/CLAUDE.md — 프로젝트별 컨텍스트

각 소스에서 다음을 추출한다:

  • 개념(concepts): 반복 등장하는 기술 개념, 패턴, 원칙
  • 결정(decisions): “~하기로 했다”, “~를 선택했다” 형태의 결정 기록
  • 엔티티(entities): 언급된 도구, 서비스, 사람, 프레임워크
  • 스킬(skills): 해결한 문제의 접근법, 재사용 가능한 방법론

Delta 처리: .manifest.json에 이미 기록된 파일은 수정 시각(mtime)이 변경된 경우만 재처리한다.
