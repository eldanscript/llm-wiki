검색 연산자

  • file: 파일 이름 검색
  • path: 특정 파일 경로에서 검색
  • content: 파일 내용에서 검색
  • match: 대소문자 구분
  • tag: 특정 태그 포함 노트 검색
  • line: 같은 라인에서 키워드 포함 노트 검색
  • block: 같은 블락에서 키워드 포함 노트 검색
  • section: 같은 섹션에서 키워드 포함 노트 검색
  • task: 태스크 리스트에서 검색
줄 바꿈 없으면 같은 라인
enter 두 번 입력으로 빈 공간 발생하면 블록 구분
같은 제목 마크다운 아래에 있다면 같은 섹션

Claude Skill 연동 - 반복 작업 최적화

Obsidian에 주간 브리핑 스킬 생성

이 프로젝트에서 다음 skill을 만들어 줘. skill 이름은 briefing 이야.
이 스킬은 최근 2주간의 노트를 통해서 내게 브리핑을 하는 스킬이야.
다음 노트를 확인할 것
- 최근 14일간 생성 및 수정된 노트
- 최근 14일간 일간, 주간 노트
그리고 다음을 말해줘.
- 노트 활동 요약 및 현재 주요 관심사
- 미완성 작업
- 유사한 주제의 노트인데 연결이 안 된 노트가 있다면 연결 제안
생성된 노트는 옵시디언 CLI를 이용해 해당 파일을 열어 줘.

다른 Skill 활용

obsidian-skills

영구 보관 노트 작성 스킬 생성

다음 skill을 만들어줘.
스킬 이름: permanent-note
스킬 설명
1. 제텔카스테의 permanent note를 만들기 위한 스킬
2. 해당 스킬은 사용자로부터 메모를 입력받음
3. 0.Slip-box 폴더에 노트를 생성함
4. 메모로부터 그렇게 길지 않게 짧게 한 문장으로 요약해서 노트 제목으로 정함
5. 생성한 노트의 본문 형식은 다음과 같음
# 원문
사용자가 입력한 메모를 오타나 비문만 수정한 채로 작성
# AI 생성
추가적으로 네가 보충하거나 추천하고 싶은 내용을 같이 작성해줘
# 연관된 노트
이 노트랑 연관있는 노트를 markdown list로 달아줘. 어떤 맥락에서 연관 있을지도 같이 적어봐. 찾을 땐 qmd MCP 쓰면 좋을 거야
작성 완료 시에는 obsidian CLI를 통해 생성한 노트를 열어줘
