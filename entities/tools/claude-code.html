Claude Code

Anthropicのターミナルベース AI コーディング CLI。Raingent エージェント生態系の核実行単位として、自律的ワークフロー、Extended Thinking、Agent Skills、MCP 統合、CLAUDE.md プロジェクトメモリ管理を実装。

核心機能

1. ターミナル・ネイティブ設計

  • IDE 非依存性：エディタ・作業環境の制約なし
  • Terminal Native 実装で初期設計段階から CLI 中心
  • 複雑な環境構築不要、シェルスクリプトと同일ワークフロー

2. エージェント自律実行フロー

  • 計画 → 実行 → 検証 を自動循環
  • 3つのモード：Normal (Edit)、Auto-Accept、Plan Mode
    • Normal : ファイル修正・コマンド実行時に毎回承認要求
    • Auto-Accept : 自動承認モード
    • Plan Mode : 読み取り専用で分析後プラン立案、実行選択可能 (複雑なリファクタリング・アーキテクチャ検査・学習用)

3. Extended Thinking モード

  • Claude Coder に推論時間を追加割当
  • Advanced Thinking : 作業複雑度に応じて推論深度を動的決定
  • [Option + T] キーで有効化トグル設定

4. プロジェクトメモリ体系

CLAUDE.md（プロジェクト・ローカルメモリ）

  • 3 層スコープ管理：

    1. Project Memory Scope : [project]/CLAUDE.md, [project]/.claude/CLAUDE.md
    2. User Memory Scope : ~/.claude/CLAUDE.md（全プロジェクト共通）
    3. Project Local : [project]/CLAUDE.local.md（個人プロジェクト別）

  • 構成項目：

    • プロジェクト概要：目的・主要機能
    • 技術スタック：言語・フレームワーク・ライブラリ
    • 核心コマンド：ビルド/テスト/リント、開発サーバ実行
    • ディレクトリ構造：主要フォルダ役割・コード配置規則
    • コーディング規則：naming convention、style guide
    • 禁止事項と例外規則：ファイル修正/削除、Git/DB 操作、ライブラリバージョンアップ等

  • 長大化対策：

    • @import で別ファイル分離参照
    • .claude/rules/ ディレクトリで特定ファイル/ディレクトリ自動有効化
    • Glob パターン対応

AGENTS.md（エージェント標準文書）

  • エージェント向け README
  • プロジェクト効果的作業のための専用コンテキスト・指針提供
  • オープン標準：Google、OpenAI、Factory、Sourcegraph、Cursor 等（2025年7月正式化）
  • CLAUDE.md から参照推奨（AGENTS.md を原本、CLAUDE.md で参照）

5. Agent Skill システム

  • モジュール化知識・指針パッケージ でモデル能力拡張
  • SKILL.md ファイル + 支援ファイル（スクリプト、テンプレート）で構成
  • 対話文脈自動分析で必要 Skill を自動読込
  • @mention で即座ロード可能

Skill Front Matter メタデータ

公式 Skill マーケットプレイス

  • Anthropic 公式 Skills リポジトリ
  • skill.sh : Vercel 運営、ワンコマンドインストール
  • awesome-claude-skills : Composio 運営、カテゴリ分類・品質検証・外部アプリ連携
  • SkillsMP : 分散 GitHub Agent Skills の一元検索

6. クラウドコード要須コマンド

コマンド役割
/initCLAUDE.md 生成、プロジェクト構造解析、技術スタック把握、conventions 作成
/compactコンテキスト圧縮
/contextセッション状態可視化（トークン使用量、要素別状態）
/memoryCLAUDE.md メモリファイル編集
/rewindコード変更取消
/rename [name]セッション名変更（/resume で検索）
/resume [session]前セッション ID/名で再開
/skills利用可能 Skill 確認
/pluginPlugin マーケットプレイス管理

頻出ショートカット

  • Ctrl + L : ターミナル画面クリア
  • Ctrl + R : コマンド履歴検索
  • [Shift + Tab] : モード切替
  • [Option + T] : Extended Thinking 有効化

7. プロンプト内特殊文法

  • @src : ファイル入力
  • ! : Bash コマンド実行
  • # : メモリ記録

8. Hook システム（ワークフロー自動化）

  • 特定イベント発生時に決定論的な制御を追加
  • 事象で自動実行スクリプト : 特定時点で必ず実行を保証
  • Pre/PostToolUse、PermissionRequest、UserPromptSubmit、Notification イベント対応

9. 拡張性アーキテクチャ

  • Hook : イベント駆動スクリプト自動実行
  • MCP (Model Context Protocol) : 外部ツール連携
  • Plugin : チーム固有ワークロード パッケージ・共有

13. コーディング規則 CLAUDE.md テンプレート

ネーミングコンベンション例

- React コンポーネント : PascalCase
- ユーティリティ : camelCase
- テスト : *.test.ts
- 変数 : camelCase
- 定数 : UPPER_SNAKE_CASE
- 型/インターフェース : PascalCase
- Boolean : is/has/can 接頭辞

禁止パターン

- any 型使用
- プロダクション console.log 残存
- インラインスタイル (Tailwind 活用)
- require() (ES module 強制)
- 相対パス '../../../' 3段超 (パスエイリアス使用)

推奨パターン

- async/await (Promise chain 回避)
- 並列処理可能なら Promise.all
- Component 構造 : imports → types → constants → helpers → component → export
- テスト : Arrange-Act-Assert パターン
- エラーメッセージ : ユーザ表示 vs ロギング分離
