Finance Agent

Python 기반 개인 자산 모니터링·자동 분석 에이전트. 주식, ETF, 퇴직연금 등을 통합 관리하며 일일 Telegram 알림, 주간 이메일 리포트, REST API 대시보드를 제공합니다.

핵심 기능

  • 자동 가격 수집: yfinance + KIS API로 실시간 주식·ETF·환율 수집
  • 포트폴리오 계산: 평가액·수익률·22억 달성률 자동 계산
  • AI 전략 분석: Gemini 2.5 Flash로 주간 포트폴리오 전략 분석
  • 멀티 채널 보고: Telegram (일일), Gmail (주간), REST API (실시간)
  • React 대시보드: FastAPI + React SPA로 웹 기반 포트폴리오 시각화
  • KIS 자동 동기화: 한투 증권 잔고 자동 동기화

AI 전략 분석

Gemini 2.5 Flash 프롬프트 (5섹션)

컨텍스트:

  • 22억 합산 달성률·잔여액·기한
  • 카테고리별 달성률 + 월 필요수익률
  • 배당금 내역 (연간·월별)
  • 종목별 수익률·변동성
  • 퇴직연금 펀드 현황

산출:

  1. 목표 달성 가능성 — 통계·배당 기여도
  2. 리스크 요인 — 집중도·섹터 편중
  3. 장기 전략 — 6개월 이상 리밸런싱
  4. 단기 전략 — 1~3개월 매수 우선순위
  5. 액션 플랜 — 이번 달 3가지 구체적 과제
