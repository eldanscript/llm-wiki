Obsidian REST API 연결 가이드

작성일: 2026-05-24

1. 개요

Obsidian Local REST API 플러그인은 Obsidian 앱에 HTTP REST API 서버를 내장합니다. Claude Code에서 이 API를 통해 Obsidian 앱과 실시간 양방향 소통이 가능합니다.

Claude Code
    ↕ MCP (또는 curl)
Local REST API (localhost:27124)
    ↕
Obsidian 앱 (파일 + UI 제어)

2. 플러그인 설치

  1. Obsidian → 설정(⚙) → 커뮤니티 플러그인
  2. 커뮤니티 플러그인 탐색 클릭
  3. Local REST API 검색 → 설치 → 활성화
  4. 설정 → Local REST API → API Key 복사해 두기

포트 기본값

프로토콜포트
HTTP27123
HTTPS27124

MacBook에서 사용 시 HTTP(27123) 권장 (인증서 설정 불필요)

POST/vault/{path}노트 끝에 내용 추가(append)
DELETE/vault/{path}노트 삭제
GET/vault/파일 목록

활성 노트 (현재 열린 노트)

POST/active/현재 활성 노트에 내용 추가
PATCH/active/현재 활성 노트 부분 수정

6. 실제 워크플로 예제

워크플로 A — 지금 보는 노트로 영구 노트 만들기

1. Obsidian에서 참고 자료 노트 열기
2. Claude Code: "지금 보고 있는 노트로 Slip-box 영구 노트 만들어줘"
3. → get_active_note로 내용 읽기
4. → 핵심 아이디어 추출 후 0.Slip-box에 write_note
5. → open_note로 완성된 노트 Obsidian에서 열기

워크플로 B — 일간 브리핑 자동 열기

1. /briefing daily 스킬 실행
2. → 브리핑 파일 생성 (파일시스템 Write)
3. → open_note로 Obsidian에서 즉시 열기

워크플로 C — 연관 노트 검색 후 링크 추가

1. Claude Code: "이 주제와 연관된 노트 찾아서 링크 추가해줘"
2. → search_notes로 관련 노트 검색
3. → 현재 노트에 [[내부 링크]] append_note로 추가

워크플로 D — 오늘 일간 노트 열기

1. Claude Code: "오늘 일간 노트 열어줘"
2. → 오늘 날짜 파일 없으면 write_note로 생성 + 템플릿 적용
3. → open_note로 Obsidian에서 열기

7. 주의사항

  • Obsidian 앱이 실행 중이어야 API가 동작함
  • API는 앱이 실행 중인 디바이스(localhost)에서만 직접 접근 가능
  • API Key는 ~/.claude.json에 저장됨 — vault에 커밋 금지
  • 인증서는 1년 유효, 만료 시 5-1 단계 재실행 필요
  • MCP 연결 실패 시 확인 순서: ① Obsidian 실행 여부 → ② 인증서 만료 여부 → ③ Claude Code 재시작
