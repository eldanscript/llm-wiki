Claude Code + Obsidian 활용 레시피

Claude Code에서 /briefing 스킬과 Obsidian MCP를 활용한 실전 레시피 모음. 각 레시피는 사용자 입력 → Claude 동작 → 결과 흐름으로 구성됩니다.

사전 확인

Claude Code 세션 시작 시 아래를 확인:

Obsidian MCP 연결 상태 확인해줘

정상이면 obsidian: Connected 응답. 연결 안 되면 → Obsidian REST API 연결 가이드 5-4 단계 참고.

Recipe 1 — 일간 브리핑

1-1. 오늘 브리핑 생성

/briefing

또는

오늘 브리핑 만들어줘

Claude 동작:

  1. find 로 오늘 변경된 .md 파일 목록 수집
  2. 변경 파일 Read → 내용 분석
  3. 5.Periodic Notes/Daily/2026-05-24.md 생성 (또는 기존 파일 끝에 저녁 브리핑 섹션 추가)
  4. mcp__obsidian__open_file 으로 Obsidian에서 즉시 열기

결과: 5.Periodic Notes/Daily/YYYY-MM-DD.md 생성 + Obsidian에서 자동 오픈

1-2. 특정 날짜 브리핑 생성

2026-05-20 브리핑 만들어줘

Claude 동작: 해당 날짜 기준으로 변경 파일 탐색 (-newer 기준일 조정) → 브리핑 생성

1-3. 브리핑 생성 후 Obsidian에서 열기

오늘 브리핑 만들고 Obsidian에서 열어줘

Claude 동작:

Recipe 2 — 기술 동향 브리핑

2-1. 특정 회사 최신 동향 브리핑

Anthropic 최신 동향 브리핑 만들어줘. 최근 5개 아티클 기준으로.

Claude 동작:

  1. mcp__obsidian__search_simple(query="anthropic") 로 관련 노트 검색
  2. 날짜순 정렬 후 최근 5개 Read
  3. 핵심 내용 종합 → 응답 또는 노트 생성

결과 저장 요청 추가:

Anthropic 최신 동향 브리핑 만들고 0.Slip-box에 저장해줘

2-2. 카테고리별 동향 브리핑

최근 모델 릴리즈 동향 전체 브리핑해줘 (openai, anthropic, deepmind, meta-ai 기준)

Claude 동작:

# 각 소스별 model-releases 태그 노트 검색
mcp__obsidian__search_simple(query="모델 릴리즈")
# 또는 태그 기반 경로 직접 탐색
mcp__obsidian__vault_list(path="3.Resources/Tech Report/Anthropic Blog/MOC")

2-3. 특정 기술 주제 심층 브리핑

AI 에이전트 관련 아티클들 모아서 트렌드 분석해줘

온디바이스 AI 관련 내용 vault에서 찾아서 요약해줘

LLM 안전성(alignment, safety) 관련 최근 연구 동향 정리해줘

Claude 동작: mcp__obsidian__search_simple 으로 키워드 검색 → 관련 아티클 Read → 종합 분석

2-4. 결과를 노트로 저장

방금 분석한 내용을 3.Resources/Tech Report/브리핑-AI에이전트-2026-05.md 로 저장해줘

1.Projects 폴더에 있는 프로젝트들 현황 파악하고 브리핑해줘

Recipe 5 — 대화 내용 → Obsidian 노트

5-1. 현재 대화를 Slip-box 영구 노트로 저장

지금까지 대화한 내용을 Slip-box 영구 노트로 저장해줘.
제목은 "Claude Code MCP 연동 실전 경험"으로.

Claude 동작:

5-2. 코드 분석 결과 노트로 저장

방금 분석한 내용을 0.Slip-box/raingent-tech-report-구조.md 로 저장해줘

5-3. 기존 노트에 대화 내용 추가

오늘 대화 내용 중 핵심 인사이트를 0.Slip-box/Claude Code 활용 메모.md 끝에 추가해줘

Claude 동작:

5-4. 회의·미팅 내용 정리 후 저장

아래 회의 내용 정리해서 1.Projects/미팅노트-2026-05-24.md 로 저장해줘:

[회의 내용 붙여넣기]

5-5. 학습 내용 → Zettelkasten 노트

오늘 공부한 "트랜스포머 어텐션 메커니즘" 내용을
Zettelkasten 형식(원문+AI생성+연관노트)으로
0.Slip-box/트랜스포머-어텐션-메커니즘.md 에 저장해줘

Recipe 6 — Obsidian 노트 → Claude 컨텍스트

6-1. 특정 노트 불러와서 질문

0.Slip-box/Claude Code MCP 연동 실전 경험.md 읽고 핵심 내용 설명해줘

Claude 동작:

6-2. 현재 Obsidian에서 열린 노트 기반으로 작업

지금 Obsidian에서 열려 있는 노트 읽고 요약해줘

Claude 동작:

6-3. 관련 노트 검색 후 연결

"멀티 에이전트" 관련 vault 노트 찾아서 현재 작업 컨텍스트에 포함시켜줘

Claude 동작:

6-4. 여러 노트 묶어서 분석

1.Projects 폴더 전체 읽고 현재 진행 중인 프로젝트 우선순위 제안해줘

0.Slip-box 에서 AI 관련 영구 노트 모두 찾아서 지식 맵 그려줘

Recipe 7 — 스마트 노트 변환

7-1. Tech Report 아티클 → 영구 노트

3.Resources/Tech Report/Anthropic Blog/Articles/2026-05-20_Claude-4-출시.md
읽고 핵심 인사이트만 추출해서 0.Slip-box에 영구 노트로 저장해줘

7-2. 현재 열린 아티클 → 영구 노트

지금 Obsidian에서 열린 아티클 읽고 Slip-box 영구 노트로 만들어줘

Claude 동작:

  1. active_file_get_path() → 현재 파일 경로
  2. vault_read() → 내용 분석
  3. 핵심 인사이트 추출
  4. vault_write() → 0.Slip-box/[주제].md 생성
  5. open_file() → Obsidian에서 열기

7-3. 여러 아티클 → 종합 분석 노트

Anthropic 아티클 중 "해석가능성(interpretability)" 관련 것들 모아서
종합 분석 노트를 0.Slip-box/Anthropic-해석가능성-연구-종합.md 로 만들어줘

8-1. 특정 섹션만 수정

0.Slip-box/Claude Code 활용 메모.md 의 "연관된 노트" 섹션에
[[Obsidian REST API 연결 가이드]] 링크 추가해줘

Claude 동작:

8-2. 노트 이동

0.Slip-box/임시메모.md 를 4.Archive/임시메모.md 로 이동해줘

Claude 동작:

8-3. 고아 노트 찾기 (링크 없는 노트)

0.Slip-box 에서 다른 노트와 연결되지 않은 고아 노트 목록 알려줘

Claude 동작: vault_list + 각 파일 vault_read 로 backlinks 배열 확인 → backlinks 없는 노트 목록 반환

8-4. 태그 기반 노트 탐색

anthropic/engineering 태그 달린 노트 최근 10개 보여줘

Claude 동작:

Recipe 9 — 복합 워크플로

9-1. 아침 루틴 (Daily Starter)

아침 루틴 시작해줘:
1. 어제 일간 노트 요약
2. 오늘 미완료 태스크 목록
3. Tech Report 간밤에 추가된 아티클 3줄 요약

9-2. 저녁 루틴 (Daily Closer)

오늘 저녁 정리:
1. 오늘 완료한 태스크 체크
2. 내일로 넘길 항목 정리
3. 오늘 브리핑 저장하고 Obsidian에서 열어줘

9-3. 주간 리뷰

주간 리뷰해줘:
1. 이번 주 완료한 프로젝트 태스크 정리
2. Slip-box에 추가된 영구 노트 목록
3. 주간 브리핑 생성
4. 다음 주 집중할 것 제안

9-4. 기술 트렌드 리포트 생성

이번 주 Tech Report 아티클 기반으로
주요 AI 트렌드 5가지 정리해서
3.Resources/Tech Report/주간트렌드-2026-W21.md 로 저장해줘

MCP 도구 빠른 참조

도구용도예시 대화
vault_read노트 읽기”X.md 읽어줘”
vault_write노트 생성·덮어쓰기”X.md 만들어줘”
vault_append노트 끝에 추가”X.md 끝에 추가해줘”
vault_patch특정 섹션 수정”X.md의 Y섹션 수정해줘”
vault_list폴더 목록”Projects 폴더 파일 목록 보여줘”
vault_move파일 이동”X.md를 Y폴더로 옮겨줘”
vault_delete파일 삭제”X.md 삭제해줘”
search_simple텍스트 검색”vault에서 X 검색해줘”
open_fileObsidian에서 열기”X.md Obsidian에서 열어줘”
active_file_get_path현재 열린 파일”지금 열린 노트 읽어줘”
tag_list태그 목록”어떤 태그 있어?”
periodic_note_get_path주기 노트 경로내부적으로 briefing이 사용
command_executeObsidian 커맨드”Graph view 열어줘”
