Agent Skill

AI 에이전트의 능력을 확장하는 모듈형 지시 단위. SKILL.md 파일로 구성되어 에이전트 대화 맥락에 자동 로드되며, 반복 가능한 워크플로우를 표준화한다.

핵심 내용

  • 구조: SKILL.md + Front Matter (name, description, disable-model-invocation 등)로 구성. 에이전트 호출 시 자동으로 컨텍스트에 로드
  • 토큰 효율: 38개 스킬 전체 설치 시 약 660토큰만 소비 (user-invoked 방식으로 컨텍스트 자동 개입 없음)
  • 마켓플레이스: skill.sh·awesome-claude-skills·SkillsMP·Anthropic 공식 마켓플레이스에서 공유·배포
  • Codex 호환: openai.yaml 사이드카 + allow_implicit_invocation: false로 명시적 호출 강제
  • 스킬 유형: user-invoked(사용자 명시 호출) vs agent-invoked(에이전트 자동 호출)
  • 워크플로우 스킬 vs 에이전트 절충: 스킬은 워크플로우를 구조화하고 에이전트는 실행을 담당 — 역할 분리가 핵심

mattpocock/skills 참조 구현 (2026-07 기준)

  • 메인 플로우 스킬: grill-with-docs → to-spec → to-tickets → implement → code-review
  • 계획 스킬: /wayfinder (대규모 작업 지도 제작), /grill-me (독립 그릴링, 의존관계 그래프 라운드 방식)
  • 프로토타이핑: /prototype (LOGIC.md 경로 vs UI.md 경로 분기)
  • 보조 스킬: /wait-what (장황한 응답 재요청), /wizard (bash 마법사), /to-questionnaire (외부 협의 문서), /writing-for-agents (에이전트용 문서 작성), /research, /tdd
  • 설치: npx skills@latest add mattpocock/skills 또는 Claude Code 공식 플러그인 마켓플레이스
