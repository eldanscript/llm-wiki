LLM Wiki 패턴 (Karpathy)

Andrej Karpathy가 제안한 LLM 기반 지식 관리 아키텍처. LLM이 Raw 소스를 읽어 합성 지식 페이지를 자동 생성·관리하는 패턴.

핵심 개념

  • 3-Layer 분리: Raw Sources(원본 불변) → Wiki(LLM 합성) → Public(배포)
  • LLM의 역할: Raw Source 변화 감지 → 해당 개념·엔티티 페이지 자동 생성·업데이트
  • Append-only Log: 모든 변경을 log.md에 기록하여 감사·추적 가능
  • 크로스 레퍼런싱: Concept ↔ Entity 상호 연결로 지식 네트워크 형성
  • 다중 에이전트 협업: 여러 Agent가 Raw Source를 병렬로 수정 → 자동 Wiki 갱신

구조

Raw Sources (0-5 폴더)

  • Slip-box: 영구 노트
  • Projects: 프로젝트 문서
  • Areas: 주제별 리서치
  • Resources: 참고 자료
  • Archive: 아카이브(Wiki 반영 제외)
  • Periodic Notes: 주기적 기록

Wiki (6 폴더)

  • Concepts/: 추상 개념 (Agentic AI, Multi-Agent 등)
  • Entities/: Companies, Models, Tools, People
  • Projects/: 프로젝트 요약 페이지
  • Topics/: 주제별 합성 페이지 (cross-cutting)
  • index.md: 전체 카탈로그
  • log.md: 작업 이력(append-only)

페이지 형식

콘텐츠 구조

  1. 한 줄 정의 — 무엇인가
  2. 핵심 내용 — 3~7개 bullet point
  3. 관련 노트 — [[링크]] 형식
  4. 출처 — Raw source 경로

운영 Operations

Ingest

  1. Raw source 파일 감지
  2. 새 개념/엔티티 → Wiki 페이지 생성 또는 업데이트
  3. index.md, log.md 자동 갱신

Query

  1. Wiki 페이지 조회로 기존 지식 확인
  2. 새 인사이트 발생 시 Raw Source에 기록
  3. 다음 ingest 사이클에 자동 반영

Lint

  • 고아 페이지 검사
  • 깨진 링크 검사
  • 중복 개념 통합
  • sources 필드 검증
  • 오래된 페이지(6개월+) 갱신

Obsidian 구현

Obsidian-Wiki-System에서 GitHub Actions + Claude API로 이 패턴을 실제 구현하였다.
