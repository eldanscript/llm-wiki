🚀 Claude Code Skills 스타터 팩

🚀 Claude Code Skills 스타터 팩

2026년 6월 06일7 min read

🛠️ 사용 방법

  1. 터미널에서 ~/.claude/skills/ 폴더를 생성합니다.

  2. 아래 원하는 템플릿의 코드를 복사하여 지정된 파일명(.md)으로 저장합니다.

  3. Claude Code를 실행하면 해당 Skill이 자동으로 로드됩니다.

1. 기본 템플릿 (빈 구조)

자신만의 스킬을 만들 때 사용하는 기본 뼈대입니다.

  • 파일명: my-skill.md

2. 인스타 캡션 작성 Skill

톤앤매너를 유지하며 후킹한 인스타그램 캡션을 작성합니다.

  • 파일명: instagram-caption.md

3. 블로그 SEO 글쓰기 Skill

검색 유입과 체류 시간을 동시에 잡는 최적화 블로그 글을 작성합니다.

  • 파일명: blog-seo-writer.md

4. 회의록 정리 Skill

복잡한 회의 내용을 5분 안에 파악 가능한 구조로 요약합니다.

  • 파일명: meeting-notes.md

5. 이메일 답장 Skill

예의 바르고 명확한 비즈니스 이메일 초안을 빠르게 작성합니다.

  • 파일명: email-reply.md
