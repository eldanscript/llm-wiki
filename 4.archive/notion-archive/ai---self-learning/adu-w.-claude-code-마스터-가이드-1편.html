1. Claude Code란 무엇인가?

Claude Code는 Anthropic이 만든 CLI(명령줄 인터페이스) 기반의 AI 개발 에이전트입니다.

일반적인 챗봇과 결정적으로 다른 점은 컴퓨터 파일에 직접 접근하고, 코드를 실행하고, 결과를 검증할 수 있다는 것입니다.

💡 일반 AI와의 차이점

구분일반 챗봇 (ChatGPT 등)Claude Code
파일 접근❌ 불가✅ 직접 읽기/쓰기/삭제
코드 실행❌ 불가✅ 터미널에서 직접 실행
결과 검증❌ 사용자가 직접✅ 스스로 스크린샷 찍어 확인
작업 연속성❌ 매번 복붙 필요✅ 프로젝트 단위로 기억
병렬 작업❌ 불가✅ 서브 에이전트로 동시 처리

🎯 이런 사람에게 필요합니다

  • 코딩을 모르는데 앱을 만들고 싶은 창업자

  • 개발 생산성을 10배 높이고 싶은 개발자

  • 반복 업무를 자동화하고 싶은 비즈니스 운영자

  • AI 도구로 수익을 창출하고 싶은 1인 기업가

2. 기초 설정 — 설치 & 터미널 환경

📺 영상 구간: 00:00:00 – 00:12:00

필수 조건

  • Anthropic Pro 플랜 이상 구독 필요 (무료 플랜 사용 불가)

  • Mac: 기본 터미널 앱 사용

  • Windows: PowerShell 사용

설치 방법

토큰(Token)과 컨텍스트(Context) 이해하기

토큰이란 AI가 텍스트를 처리하는 최소 단위입니다.

대략 영어 단어 1개 = 토큰 1~2개, 한국어는 더 많은 토큰을 소모합니다.

컨텍스트 창은 AI가 한 번에 기억할 수 있는 정보의 양입니다.

Claude Code는 약 20만 토큰을 지원하며, 대화가 길어지면 자동으로 압축합니다.

⚠️ 중요: 세션이 길어질수록 초반 내용을 잊어버릴 수 있습니다.

claude /context로 현재 토큰 사용량을 수시로 확인하세요.

3. IDE 설정 — VS Code & Anti-Gravity

📺 영상 구간: 00:12:00 – 00:24:00

IDE란?

  • *통합 개발 환경(IDE)**은 파일 관리자 + 텍스트 에디터 + AI 채팅창이 합쳐진 도구입니다.

터미널만 쓰는 것보다 파일 구조를 시각적으로 파악하기 훨씬 쉽습니다.

VS Code 설정 방법

  1. VS Code 설치 후 좌측 확장 프로그램 탭 클릭

  2. 검색창에 Claude Code 입력

  3. 반드시 Anthropic 공식 배포 확장만 설치 (검증 마크 확인 필수)

  4. 확장 설치 후 재실행

권한 모드 설정

모드설명추천 상황
Ask (확인 모드)파일 수정 전 매번 승인 요청중요한 프로덕션 코드 작업 시
Edit Automatically (자동 모드)승인 없이 자동으로 파일 수정빠른 프로토타이핑, 새 프로젝트

💡 팁: 프로젝트 성격에 따라 모드를 전환하는 습관을 들이세요.

자동 모드는 빠르지만 실수 발생 시 되돌리기 어려울 수 있습니다.

4. 실전 웹사이트 구축 — 스크린샷 루프 기법

📺 영상 구간: 00:24:00 – 00:54:00

스크린샷 루프란?

AI에게 텍스트로만 설명하는 대신, 실제 디자인 이미지를 보여주고 그대로 구현하게 만드는 기법입니다.

말로 설명하는 것보다 훨씬 빠르고 정확합니다.

작업 흐름: Task → Do → Verify 루프

Important

  1. Task : 디자인 스크린샷 + 요구사항 전달
    ↓

  2. Do : Claude가 HTML/CSS 코드 작성
    ↓

  3. Verify: Claude가 직접 스크린샷 찍어 비교 검증
    ↓

  4. 결과가 다르면 → 1번으로 돌아가 반복

단계별 실전 가이드

Step 1. 디자인 영감 찾기

  • godly.website — 세계 최고 수준의 웹 디자인 모음

  • 마음에 드는 디자인의 전체 스크린샷을 찍어 저장

Step 2. Claude에게 전달하기

Important

이 스크린샷과 똑같은 디자인으로 웹페이지를 만들어줘.
기술 스택: Next.js + Tailwind CSS
텍스트는 내가 따로 알려줄게, 일단 레이아웃과 색상을 최대한 동일하게 맞춰줘.
완성되면 스크린샷 찍어서 원본이랑 비교해줘.

Step 3. 반복 수정

  • 결과물이 90% 이상 일치할 때까지 스크린샷 루프 반복

  • 텍스트, 이미지, 모바일 최적화 순서로 진행

💡 생산성 팁: 타이핑 대신 음성 입력(Voice Transcript)을 활용하세요.

말로 하면 더 자연스럽고 풍부한 지침을 빠르게 전달할 수 있습니다.

5. .claude 디렉토리 & 규칙 설정 심화

📺 영상 구간: 00:54:00 – 01:31:00

핵심 파일 구조

Important

프로젝트 폴더/
├── .claude/ ← 숨겨진 에이전트 설정 폴더
│ ├── rules/ ← 프로젝트 규칙 파일들
│ │ ├── workflow.md ← 작업 흐름 규칙
│ │ ├── tech-defaults.md ← 기술 스택 기본값
│ │ └── design-rules.md ← 디자인 가이드라인
│ ├── skills/ ← 커스텀 스킬 스크립트
│ └── agents/ ← 에이전트 설정
└── CLAUDE.md ← 프로젝트 전체 규칙 (메인)

CLAUDE.md — 에이전트의 “뇌”

CLAUDE.md는 Claude가 세션 시작 시 가장 먼저 읽는 파일입니다.

이 파일에 프로젝트의 규칙, 목표, 기술 스택을 정의하면 매번 설명하지 않아도 됩니다.

좋은 CLAUDE.md 예시:

slash init — 자동 설정 생성

기존 프로젝트에 Claude를 처음 도입할 때 유용합니다.

Claude가 현재 프로젝트 구조를 스스로 분석하여 최적화된 CLAUDE.md를 자동 생성합니다.

글로벌 vs 로컬 설정 구분

구분위치적용 범위
글로벌 설정~/.claude/모든 프로젝트에 적용
로컬 설정프로젝트/.claude/해당 프로젝트에만 적용

⚠️ 주의: CLAUDE.md가 너무 길어지면 오히려 성능이 떨어집니다.

내용이 많아지면 주기적으로 불필요한 내용을 제거(Pruning)하세요.

6. 풀스택 앱 구축 — Plan Mode & Bypass Mode

📺 영상 구간: 01:31:00 – 02:33:00

Plan Mode (계획 모드)

실제 코드를 건드리기 전에 아키텍처와 접근 방식을 먼저 설계하는 단계입니다.

Plan Mode를 써야 하는 이유:

  • 잘못된 방향으로 많은 코드를 짜는 실수 방지

  • 토큰 낭비 감소

  • 큰 그림을 먼저 확인한 뒤 작업 가능

💡 원칙: 1분의 계획이 10분의 코딩 시간을 아낍니다.

Bypass Permissions Mode (자동 승인 모드)

권한 확인 절차 없이 Claude가 자율적으로 파일을 수정합니다.

⚠️ 보안 경고:

  • 중요한 시스템 파일이 있는 폴더에서 절대 사용 금지

  • 새 프로젝트 폴더에서만 사용 권장

  • 실수로 파일이 삭제되어도 복구 어려움

실전 앱 구축 기술 스택 예시

이 챕터에서 실제로 구축한 앱:

├── 인증: Supabase Auth

7. MCP와 커스텀 스킬 — 능력 확장

📺 영상 구간: 02:33:00 – 03:11:00

MCP(Model Context Protocol)란?

Claude와 외부 앱을 연결하는 표준 프로토콜입니다.

마치 스마트폰에 앱을 설치하듯, Claude에게 새로운 능력을 추가할 수 있습니다.

연동 가능한 도구들:

  • Chrome DevTools (브라우저 제어)

  • Gmail / Google Calendar

  • Slack / Notion

  • GitHub

  • Figma 등

MCP 설정 방법

MCP의 단점 → 스킬(Skill)로 해결

MCP는 강력하지만 토큰 소모량이 매우 큽니다.

MCP 도구 설명만으로 전체 컨텍스트의 10%를 넘으면 성능이 급격히 저하됩니다.

해결책: 자주 쓰는 기능은 Skill(로컬 스크립트)로 변환

Important

MCP (외부 연결, 토큰 많이 씀)
↓ 자주 쓰는 기능 추출
Skill (로컬 스크립트, 토큰 절약)

스킬 실전 예시

예시 1: Gmail 자동 분류 스킬

  • 수백 개의 이메일을 카테고리별로 자동 라벨링

  • MCP로 하면 느리고 비용이 많이 들지만, 스킬화하면 87초 만에 완료

예시 2: 잠재 고객 리스트 수집 스킬

  • 특정 조건의 잠재 고객 1,000명을 1분 만에 수집

  • 스크립트 한 번 만들어두면 계속 재활용 가능

💡 핵심 원칙: MCP로 먼저 테스트하고, 반복 사용하면 스킬로 변환하세요.

8. Subagent & Agent Teams — 병렬 처리

📺 영상 구간: 03:11:00 – 04:02:00

Subagent(서브 에이전트)란?

메인 에이전트로부터 특정 작업을 위임받아 독립적으로 실행되는 하위 AI 에이전트입니다.

순차 처리 vs 병렬 처리

Important

[순차 처리] — 기존 방식
작업A (3분) → 작업B (3분) → 작업C (3분) = 총 9분

[병렬 처리] — Subagent 방식
작업A (3분)
작업B (3분) → 동시 실행 = 총 3분
작업C (3분)

실전 예시: 1,000개 이메일 분류

  • 순차: 30분 소요

  • 10개 서브에이전트 병렬: 3분 완료

Agent Teams — 에이전트 협업

서로 다른 역할을 가진 에이전트들이 협력하여 복잡한 문제를 해결하는 방식입니다.

보안 취약점 탐색 예시:

Important

공격팀 에이전트 방어팀 에이전트
↓ ↓
취약점 공격 시도 ←→ 방어 및 패치
↓
최종 보안 리포트 생성

코드 리뷰 예시:

Important

개발 에이전트 → 코드 작성
↓
리뷰 에이전트 → 코드 검토
↓
테스트 에이전트 → 자동 테스트 실행
↓
최종 결과물

⚠️ 비용 주의:

Agent Teams는 일반 작업 대비 최대 7배 토큰을 소모합니다.

작업 완료 후 반드시 모든 에이전트를 종료하세요.

12. 웹 앱 제작 5단계 체크리스트

프로젝트 시작 전 이 체크리스트를 따라가세요.

✅ Step 1. 준비 단계

  • godly.website 등에서 디자인 레퍼런스 스크린샷 저장

  • 기술 스택 결정 (Next.js / React / HTML 등)

  • 필요한 외부 서비스 계정 생성 (Supabase, Stripe 등)

✅ Step 2. 초기화

  • 프로젝트 폴더 생성

  • 터미널에서 claude /init 실행

  • 생성된 CLAUDE.md 검토 및 커스터마이징

  • 기술 스택, 디자인 원칙, 금지 사항 추가

✅ Step 3. 설계 (Plan Mode)

  • claude /plan 으로 Plan Mode 진입

  • 전체 기능 요구사항 입력

  • Claude가 제시한 아키텍처 검토

  • 계획 승인 후 다음 단계 진행

✅ Step 4. 구축 (Build Phase)

  • 스크린샷 루프로 UI 구현

  • Task-Do-Verify 루프 반복

  • 주요 기능 구현 완료 후 /context 로 토큰 확인

  • 필요 시 새 세션으로 전환

✅ Step 5. 검증 & 배포

  • 전체 기능 테스트 완료

  • Modal 또는 Netlify/Vercel로 배포

  • 배포 URL 정상 작동 확인

  • 모니터링 설정 (에러, 트래픽 등)
