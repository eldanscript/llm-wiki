Answers Reference

  • 위키 한글 IPA - https://ko.wiktionary.org/wiki/위키낱말사전:국제_음성_기호

  • 한국어 IPA 변환기 - http://pronunciation.cs.pusan.ac.kr/

  • First-Pass IPA Generator - https://tophonetics.com

  • Dictionary - https://www.dictionary.com/

  • IPA Voice Reader -http://ipa-reader.xyz

  • IPA English Docs -https://en.wikipedia.org/wiki/Help:IPA/English

  • Custom Vocab Docs -https://docs.aws.amazon.com/transcribe/latest/dg/how-vocabulary.html#char-english

  1. Start with the First-Pass Generator - you may get good IPA from here immediately, and it can handle multiple words at once. However, it
    will not help with some words, certainly not with brands, and generally not with non-English words

  2. If that didn’t work then I go to the Dictionary, which often struggles on plurals, but seemed surprisingly good at place names - very handy when I had to do French Canadian cities in a Vocab. Also, it often gives you multiple versions of the pronunciation, and you can
    choose the one that better-matches your target region/accent

  3. If all else fails, Wikipedia often - but not always - gives IPA for places. After that you have no choice but use the IPA English Docs in
    Wikipedia to build up the phrase yourself

  4. Next, I take whatever IPA I’ve found into the IPA Voice Reader to see if it sounds good - usually it’s good, but you can tweak it with the IPA English Docs

QnA

  • AWS IPA는 부족한 부분이 있음 → Wiki page 에서 제공하는 것

  • 결정화딤성불량 → 중간 ㅎ 을 표시할 때 AWS는 h를 사용

    • 30개 중 18개 오류 → 30개 중 9개 오류로 성능 향상

  • 단어수가 많아 지면 작업에 시간이 오래 걸리고 학습 성능이 나올지 의문

  • Error 확인이 어려움

  • 한국어 학습 시 blank로 처리 해야 하는지 띄어쓰기로 해야 하는지

    • IPA : 띄어쓰기

    • SoundLike : 영어 hyphen 지원, 한국어는 hyphen 지원 안됨

  • Data 정제 과정에 대한 Tool은 지원 되는지?

    • Guide는 있지만 서비스팀이 제공하는 tool은 없음 → mapping을 할수 있는 코드 개발이 필요할 수 있음

  • 오답률 인식이 크게 높아지지 않음 (IPA 및 SoundLike 동일)

    • 한국어는 IPA를 사용하여야 함 → 개선이 없다면 방법은 없는 상황

  • 단어에 대해서 끊거나 붙이거나 차이는 없음

    • 중복으로 여러개 단어를 해도 상관 없음

  • 중복으로 구성하면 인식률 향상이 있을지?

    • IPA가 성능이 좋음

    • IPA가 없다면 SoundLike로 구성

  • IPA 매칭 되지 않는 영어 단어는 어떻게 처리?

    • 1 대1 로 matching 되는게 대부분임 → matching 되지 않는 것은 수동으로 찾아서 구성 필요

  • 한국어 CharacterSet에 대해 Syllabus가 코드가 되어 있는데 (한글 Syllabus) 사용할 수 있는 방법이 있는지?

    • 한국 Syllabus 지원에 대한 계획은 있는지? → 기능 개선 항목으로 등록 하겠음

  • 영준님 작업 내용

  • 이후 계획

    • 1차 PoC 목표 : 제품 컨셉에 대한 확인 → 오류에 대해 매뉴얼 입력 등으로 개선 확인 → LGD와 함께 논의 (차주)

      • Transcribe + Translate

      • FrontEnd는 이후 LGD에서 구축

    • 2차 PoC 목표 : Display 내부에서 시험

    • 3차 목표 : 상품화 검토

      • 2만개 단어에 대한 학습 필요

  • 내년 Show 출품에 대한 대비

    • IPA와 SoundLike에 대한 matching 자동화 작업은 예상 하지 못함

    • 75% 정도는 mapping → 초정, 종성에 대해서 확인 mapping → 최종 수동 검사 필요

  • BD에 escalation이 되어 있는데 SA level에서는 PFR 밖에 없음

  • 영어는 custom language model이 지원되고 있음 → ML training이 지원 되어 있음

  • custom vocabulary mode에서는 ML training 지원 안됨

  • 인식 오류에 대해서는 AWS의 지원이 필요 : 현재 30% 수준
