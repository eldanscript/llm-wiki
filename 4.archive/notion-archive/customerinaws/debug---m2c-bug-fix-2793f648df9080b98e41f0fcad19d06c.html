Output Encryption KMS Key Form Restriction for Amazon Transcribe

Hello,

We are making a change to Amazon Transcribe, which may require your attention.

Amazon Transcribe provides you the ability to specify OutputEncryptionKMSKeyId as a request parameter in the StartCallAnalyticsJob, StartMedicalScribeJob, StartMedicalTranscriptionJob, and StartTranscriptionJob APIs. You can then use transcribe:OutputEncryptionKMSKeyId [1] as a condition key in your IAM permission policies, which will filter access based on the KMS key included in the API request. Currently, this KMS key can be provided in the form of a KMS key ID, KMS key ARN, KMS alias ID, or KMS alias ARN [2].

Beginning October 2, 2025, we recommend making the following modifications:

  • Change IAM permission policies when using transcribe:OutputEncryptionKMSKeyId as a condition key to follow key ARN format: arn::kms:::key/ [3]

  • Change OutputEncryptionKMSKeyId API request parameter to follow key ARN format: arn::kms:::key/ [4] [5] [6] [7]

If you have not made the modifications, API requests made after December 31, 2025 with OutputEncryptionKMSKeyID parameter using any other form besides KMS key ARN may result in a ValidationError.

If you have additional questions or concerns, please contact AWS Support [8].
