SageMaker Neo

Optimization Model - Compilation

  • 학습된 DL model을 load하여 graph structure로 재 건축 → model에 정의된 operator를 primitive operator로 정의 → computational graph 생성 → 다양한 graph 최적화 기술 적용

  • Hardware 맞춤(dependent) 최적화의 경우 optimized graph 만으로는 가능하지 않음 → Computational graph를 IR (Intermediate Representation, 중간 표현)으로 변환 (Hardware 맞춤 최적화) → Memory allocation, 병렬화, 실행 순서 조정 등을 수행

Compiler

  • Apache TVM : ML Compiler Framework for CPU and GPU

  • TensorRT : NVIDIA GPU (NVIDIA GPU 상에서의 추론 속도를 수배 ~ 수십배 까지 향상시켜 딥러닝 서비스를 개선하는데 도움을 줄 수 있는 모델 최적화 엔진)

  • Treelite : XGBoost
