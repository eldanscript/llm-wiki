Needs

  • 고객 서비스 애플리케이션에서 더 강력하고 매력적인 대화형 AI 환경을 구축

  • 더 직관적이고 정확한 응답 결과를 통해 직원 생산성을 향상

  • 데이터에 대한 응답을 제한하여 모델 환각 (hallucinations, 잘못된 진술)을 완화하고 최종 사용자의 콘텐츠 액세스 권한에 따라 응답 결과를 필터링

GenAI 응답을 사내 데이터로 제한

  • 검색 증강 생성(RAG; Retrieval Augmented Generation)이라는 기법을 사용

  1. 기업 지식 기반 또는 콘텐츠에서 사용자의 요청과 가장 관련성이 높은 정보를 검색

  2. 사용자의 요청과 함께 컨텍스트로 묶어 프롬프트로 표시

  3. LLM으로 전송하여 GenAI 응답 결과를 얻음

→ LLM에는 입력 프롬프트의 최대 단어 수에 대한 제한이 있으므로 기업 내 수천 또는 수백만 개의 문서 중에서 올바른 구문을 선택하는 것이 LLM의 정확도에 직접적인 영향을 미침

Why Kendra?

  • 효과적인 RAG를 설계할 때 콘텐츠 검색은 LLM이 엔터프라이즈 콘텐츠에서 가장 관련성이 높고 간결한 컨텍스트를 수신하여 정확한 응답을 생성할 수 있도록 하는 중요한 단계

  • 정확도 높은 검색 기능으로 가장 관련성이 높은 콘텐츠와 문서를 소싱하여 RAG 페이로드의 품질을 극대화

  • 14개 도메인에 대해 사전 훈련되고 ML 전문 지식이 필요하지 않은 고편의성의 딥러닝 검색 모델을 제공

    → 단어 임베딩, 문서 청킹, 그리고 일반적으로 RAG 구현에 필요한 기타 하위 수준의 복잡성을 처리할 필요가 없음

  • RAG 유스케이스를 위해 설계된 검색(Retrieve) API를 제공

    • 각각 최대 200개의 토큰 단어로 구성된 의미적으로 연관성이 높은 구절을 관련성 순으로 최대 100개까지 검색

    • 사전 구축된 데이터 소스 커넥터 제공 : S3, SharePoint, Confluence, 웹사이트

    • 일반적인 문서 형식 지원 : HTML, Word, PowerPoint, PDF, Excel 및 일반 텍스트 파일

    • 액세스 제어 목록(ACL; Access Control List)을 지원하는 커넥터를 제공 → 최종 사용자 권한이 허용하는 문서만을 기준으로 응답을 필터링

    • AWS IAM, IAM Identity Center (SSO) 통합 제공

Notice

  • Character limit in query text (Kendra) : 1000

  • Limit increase : https://us-east-1.console.aws.amazon.com/servicequotas/home/services/kendra/quotas/L-7107C1BC

RAG using SageMaker KNN

Hands-On

  • https://sagemaker-examples.readthedocs.io/en/latest/introduction_to_amazon_algorithms/jumpstart-foundation-models/question_answering_retrieval_augmented_generation/question_answering_jumpstart_knn.html

Operation

  • LLM from SageMaker JumpStart : GPT-J-6B → embedding vector 생성

  • SageMaker KNN : Embedding vector indexing + KNN search endpoint 생성

  • 사용자 질의에 대해 K개의 인접 문서 응답

RAG using OpenSearch and Lambda

https://aws.amazon.com/ko/blogs/machine-learning/build-a-powerful-question-answering-bot-with-amazon-sagemaker-amazon-opensearch-service-streamlit-and-langchain/

Operation

  • Python Streamlit : 사용자 질의 응답을 위한 웹 app 생성 → API Gateway

    • Using Streamlit in SageMaker : https://aws.amazon.com/blogs/machine-learning/build-streamlit-apps-in-amazon-sagemaker-studio/

  • 질의에 대한 REST API endpoint (API Gateway) → Lambda invoke

  • Lambda invoke SageMaker : 사용자 질의를 embedding 화

  • Lambda invoke OpenSearch : 사용자 질의와 관련된 유사 document 서치

  • Lambda는 embedding과 OpenSearch 결과를 사용하여 prompt 생성

  • Prompt에 대한 LLM 응답 결과 reply
