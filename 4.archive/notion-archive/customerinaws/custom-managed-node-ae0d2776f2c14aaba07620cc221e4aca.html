Custom AMI를 이용한 EKS managed node 생성 과정

1. Custom AMI 생성

  • Reference git project : https://github.com/aws-samples/amazon-eks-custom-amis

  • Support OS : Amazon Linux, Ubuntu 18.04/20.04, RedHat Enterprise Linux 7/8, CentOS 7/8, Windows 18.09/20.04

  • Install Package & Configuration : https://github.com/aws-samples/amazon-eks-custom-amis/tree/main/scripts

    • Shared

      • Docker, EKS (kubelet, aws-iam-authenticator, cni-plugin)

      • bootstrap script : worker node 실행 시 실행할 /etc/eks/bootstrap.sh 생성

    • OS Dependency

      • OS별 추가 package 및 configuration

2. Launch Template 생성

  • Worker node 생성 시 필요한 EC2 instance에 대한 구성 정보 생성

  • API Server를 위한 Security Group 설정

  • UserData에 customizing 항목 추가

    • bootscript.sh 추가 : Cluster Name, Kubernetes용 추가 tag

2. EC2 Launch Template 생성

Cluster 생성 template 사용

  • cluster 구성 yaml에 managedNodeGroups field 구성

    • Custom AMI ID

  • EKS cluster를 생성하며 필요한 security group 자동 생성

    • Remote 작업을 위한 SSH port allow

    • EKS cluster security group의 ingress allow

  • UserData에 bootstrap script 추가

    • cluster name, node group name, custom ami를 지정
  • NodeGroup 및 Node 생성 확인

Launch Tempate 수동 구성

  • Reference Blog : https://aws.amazon.com/blogs/containers/introducing-launch-template-and-custom-ami-support-in-amazon-eks-managed-node-groups/

  • 사전 설정 항목

    • Security Group 생성

      • Node에 access할 수 있도록 SSH port를 allow, SSH 접속에 사용할 key-pair 생성

      • Cluster의 Security Group의 ingress port를 allow

    • UserData 생성

      • bootstrap의 script 추가 설정

  • UserData 생성

    • UserData 구성 : user-data.txt

    • bootstrap에 cluster name, node group name, custom ami를 지정 한다

  • UserData를 base64로 encoding
  • Encodede UserData

  • Launch Template 생성

    • JSON file 생성 : config_custom_rhel_ami_eks.json

  • AWS CLI로 Launch Template 생성

    • SSH 접속에 사용할 key-pair name 지정

    • Launch Template JSON file

💡

“LaunchTemplateData”, must be one of: KernelId, EbsOptimized, IamInstanceProfile, BlockDeviceMappings, NetworkInterfaces, ImageId, InstanceType, KeyName, Monitoring, Placement, RamDiskId, DisableApiTermination, InstanceInitiatedShutdownBehavior, UserData, TagSpecifications, ElasticGpuSpecifications, ElasticInferenceAccelerators, SecurityGroupIds, SecurityGroups, InstanceMarketOptions, CreditSpecification, CpuOptions, CapacityReservationSpecification, LicenseSpecifications, HibernationOptions, MetadataOptions, EnclaveOptions

    • 생성된 Launch Template ID 사용
