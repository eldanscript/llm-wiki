S3 Log Analysis

Athena 소개

  • Athena는 Standard SQL을 사용하여 S3에 저장된 데이터를 분석하는 interactive query 서비리스 서비스 입니다.

  • Athena는 비정형, 반정형, 정형 데이터 모두 분석 가능하며, 지원되는 데이터 포맷은 CSV, JSON, Colum형 데이터 (Apache Parquet 혹은 Apache ORC) 입니다.

  • Athena는 Ad-hoc query를 지원하여 모든 데이터를 Athena에 load 하지 않고 처리할 수 있습니다.

  • AWS의 Glue를 사용하여 S3의 메타데이터를 수집하고 (Catalog 생성) 이를 활용하여 Athena에서 query하고 table을 생성할 수 있습니다.

  • Athena의 전반적인 기능 학습을 위한 sample : github 링크

Athena query 구문 구성

  • S3에 수집된 Log들에 대해 Error Case별 개수 count 등의 query를 수행

    • S3 Log에 대한 Athena query : 실습 lab 링크

    • S3에 저장한 Apache Log query : 구현 예시 링크

  • Athen query 구문들에 대한 예제

    • AWS Service Log에 대한 Athena query 구성 예 : AWS Blog 링크

  • S3 data query with AWS Glue and Amazon Athena

    • Athena로 S3 data를 query하고 분석하기 위해서는 S3 data 파악 및 메타데이터 분석이 필요한데 이것을 Glue로 진행합니다.

    • 위의 S3 Log 분석 실습 과정에서는 Log 구조를 파악하고 있기 때문에 Glue를 사용하지 않고 바로 Athena query를 진행하였습니다.

    • Athena와 Glue를 사용한 S3 Data 분석 예 : AWS Blog 링크, 한국어 번역 링크

  • Query 결과에 대해 다른 서비스로 전달

    • Query 결과를 새로운 Table로 생성하여 S3에 저장 (CTAS - CREATE TABLE AS SELECT) : 기능 안내 링크

    • Query 결과를 CSV, TXT 파일로 S3에 저장 : 기능 안내 링크

    • 시각화를 위해 Amazon QuickSight와 연동
