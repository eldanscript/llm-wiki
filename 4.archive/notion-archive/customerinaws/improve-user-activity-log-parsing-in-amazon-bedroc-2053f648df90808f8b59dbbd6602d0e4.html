Amazon Bedrock - Customizing Knowledge Base with Metadata

https://docs.aws.amazon.com/bedrock/latest/userguide/kb-metadata.html

CSV file 처리

  • Knowledge Base에게 CSV 내의 각 열을 처리하는 방법에 대한 힌트를 제공

  • CSV 파일은 한 번에 한 행씩 구문 분석되고 콘텐츠 필드는 청킹 전략과 벡터 임베딩이 적용되어 청크로 분할 됩니다.

  • 콘텐츠 필드는 한개만 사용되어야 합니다.

  • 메타데이터로 지정한 필드는 콘텐츠 필드의 청크와 연결된 문자열 값으로 처리됩니다.

CSV file 요구 사항

  • CSV가 RFC4180 형식이며 UTF-8로 인코딩되어 있습니다.

  • CSV의 첫 번째 행에 헤더 정보가 포함되어 있습니다.

  • metadata.json 파일에 제공된 메타데이터 필드가 CSV에 열로 표시됩니다.

  • 다음 형식으로 **fileName.csv.metadata.json 파일을 제공**
