Install Android Studio

  • Download Android Studio : https://developer.android.com/studio

  • Latest version @2022.10.1 : Dolphin 2021.3.1

Install Android SDK

  • Android Studio → Preference

  • Appearance & Behavior → System Settings → Android SDK

  • Click Edit and Install SDK : /Users/rainny/Library/Android/sdk

  • Download SDK component and Finish

  • Install Android 11.0 (R) SDK for APK

  • Install Android SDK Tools

    • NDK, SDK CLI Tools, CMake

    • Emulator, SDK Platform Tools

    • Intel x86 Emulator Accelerator : optional with CPU architecture

  • Apply and Done

Create Virtual Device

  • Open Virtual Device Manager & Create Virtual Device

  • Select Hardware : Pixel 5 or anything

  • Select API 30 : Android 11.0

  • Select ARM Images : Android 11.0 AOSP

  • Download selected ARM Images

  • Check Configuration & Finish

  • Use Emulator with Device Manager

  • Play AVD

Run Virtual Devices

  • Open Android Studio → More Actions → Virtual Device Manager

Create Token Exchange Role Alias

  • GreengrassV2TokenExchangeRole : https://docs.aws.amazon.com/greengrass/v2/developerguide/device-service-role.html

    • Greengrass core devices use an IAM service role, called the token exchange role, to authorize calls to AWS services. The device uses the AWS IoT credentials provider to get temporary AWS credentials for this role, which allows the device to interact with AWS IoT, send logs to Amazon CloudWatch Logs, and download custom component artifacts from Amazon S3

    • Use an AWS IoT role alias to configure the token exchange role for Greengrass core devices. Role aliases enable you to change the token exchange role for a device but keep the device configuration the same

    • AWS policy GreengrassV2TokenExchangeRoleAccess and Trust relationship credentials.iot.amazonaws.com

  • Create Greengrass resource access policy : service-role-trust-policy.json (https://catalog.us-east-1.prod.workshops.aws/workshops/446304b7-b946-4c40-b78f-08bf0025d8f6/en-US/5-greengrass-pre-requisites/iam-roles#a.-create-the-role-trust-policy)

  • Attach Token Exchange Role

  • Add Permission for access to AWS resource : device-role-access-policy.json

    • Different access permission with Nucleus version 2.5, 2.4, others (https://docs.aws.amazon.com/greengrass/v2/developerguide/device-service-role.html)
  • Create Resource access policy : AndroidGreengrassV2TokenExchangeRoleAccess
  • Attach resource access policy to Token Exchange Role

  • Create Role Alias

    • A Role Alias is an object in AWS IoT Core that is used by the IoT Core Credential Provider to obtain STS (Security Token Service) short-lived credentials to access AWS services.

    • The use of a role alias eliminates the need to hardcode credentials, such as Access Keys and Secret Access Keys on IoT devices

  • Get Role Alias
