Source Data Update Automation

S3 Data Sync

Q) S3에 Sync한 document가 변경이 발생했을 때 삭제 후 재 업로드 하여 업데이트를 하고 있습니다. 다른 방법이 있는지?

A) S3에 변경되는 파일 삭제 하지 않고 그대로 업데이트 하시고 KB에서 Sync 하시면 반영이 됩니다.

  • KB의 Embedding vector 는 증분 방식으로 생성이 되기 때문에 기존에 embedding 생성 시점 이후 변경 및 삭제, 추가 된 내용에 대해서만 생성이 됩니다.

  • 데이터 동기화 안내 링크

  • S3 오브젝트업데이트 시 S3 bucket에 versioning 기능을 enable 하시면 업데이트 되더라도 이전 파일로 돌아가거나 다른 관리 작업을 할 수 있습니다. 이것도 필요하시면 활성화 하시고 파일 이력도 S3에서 관리 하시면서 사용하셔도 좋습니다.

FAQ Type

  • Q&A를 추가하는 기능은 있지만 하나씩 넣어야 하고, 추가할 때 마다 개발 document로 처리되어 비효율적입니다. 근데 CSV를 그냥 올리면 전체를 붙여서 chunk로 나누어서 인덱싱 하기 때문에, FAQ 스타일의 문서를 원하는 형태로 인덱싱 할 수가 없습니다.

  • 따라서, csv 문서를 업로드 할 때 question, answer (대소문자 구별) 라는 column을 넣은 경우 question 값으로 embedding vector를 뽑아서 인덱싱하고, answer 값을 LLM에 넣을 context로 사용하도록 하였습니다.

  • 관련코드 : https://github.com/sungeuns/ultimate-rag/blob/main/lib/shared/file-import-batch-job/main.py#L69
