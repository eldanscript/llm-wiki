Issue Support - OBD Data Mismatch

OBDII Spec

Terminology

  • DTC (Diagnostic Trouble Code) : defined by SAE (Society of Automotive Engineers, 미국 자동차 기술자 협회)

  • OBD (On-Board Diagnostic)

  • SAE J1979 : defines the five OBDII signalling protocol

  • DLC (Data Length Code)

  • PID (Parameter ID)

FleetWise Standard

  • OBDII J1979DA_202104

  • ISO 15765

ISO 15765 Messaging Format

ID

  • Request Message : 0x7E0 ~ 0x7E7

  • Reply Message : 0x7E8 ~ 0x7EF

  • Broadcast Message : 0x7DF

Decode LG CAN Message

Request

  • CAN_ID : 0x7E0 (Request message)

  • DLC : 8 bytes

  • DATA 0 : 0x07 (0000 0111)

    • Bit 7~4 : 0000 (Single Frame)

    • Bit 3~0 : 0111 (Single Frame Data Length)

  • DATA 1 : 0x01

    • Service or Mode : Show Current Data

  • DATA 2 : 0x6B

    • PID : Exhaust gas recirculation temperature (return 5 bytes)

  • DATA 3 : 0x6C

    • PID : Commanded throttle actuator control

  • DATA 4 : 0x6D

    • PID : Fuel pressure control system

  • DATA 5 : 0x6E

    • PID : Injection pressure control system

  • DATA 6 : 0x6F

    • PID : Turbocharger compressor inlet pressure

  • DATA 7 : 0x70

    • PID : Boost pressure control

Response

  • CAN_ID : 0x7E8 (Reply message)

  • DLC : 8 bytes

  • DATA 0 : 0x10 (0001 0000)

    • Number of Additional Bytes :

  • DATA 1 : 0x19

  • DATA 2 : 0x41

    • 0x40 + Request service (0x01) : Show Current Data

  • DATA 3/4 : 0x6B

    • PID : Exhaust gas recirculation temperature

    • Return Value : 0x00

  • DATA 5/6 : 0x6C

    • PID : Commanded throttle actuator control

    • Return Value : 0x00

  • DATA 7/8 : 0x6D

    • PID : Fuel pressure control system

    • Return Value : 0x00

  • DATA 5 : 0x6E

    • PID : Injection pressure control system

  • DATA 6 : 0x6F

    • PID : Turbocharger compressor inlet pressure

  • DATA 7 : 0x70

    • PID : Boost pressure control
