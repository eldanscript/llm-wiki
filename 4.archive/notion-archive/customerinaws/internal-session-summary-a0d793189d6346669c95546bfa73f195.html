Transcribe + GenAI Bootcamp Broadcast

  • https://broadcast.amazon.com/videos/1224215/

  • 요약

    이 스크립트는 Amazon Transcribe 서비스와 제너레이티브 AI 모델을 활용하여 오디오/비디오 콘텐츠를 텍스트로 전사하고 전사된 텍스트를 정제하여 대규모 언어 모델 학습에 활용하는 워크샵을 소개하고 있습니다. 주요 내용은 다음과 같습니다.

    1. Amazon Transcribe 서비스 소개 및 주요 기능 설명

    2. 오디오 파일을 배치 및 스트리밍 방식으로 전사하는 실습

    3. 전사된 텍스트를 정제하고 불필요한 내용을 제거하는 실습 (Anthropic 모델 활용)

    4. 정제된 텍스트를 벡터 임베딩하여 Amazon Bedrock 지식베이스에 업로드하는 실습

    5. 업로드된 지식베이스를 활용하여 대규모 언어 모델 추론 및 질의응답 실습

    6. 전체 프로세스를 통해 오디오/비디오 콘텐츠를 정제하여 대규모 언어 모델 학습에 활용하는 방법 소개

    워크샵에서는 Python SDK와 AWS 콘솔을 활용하여 각 단계를 실습하며, 최종적으로 오디오/비디오 콘텐츠를 대규모 언어 모델 학습에 적합한 형태로 가공하는 전체 파이프라인을 경험할 수 있습니다.

  • 세부 내용

    전사된 텍스트를 정제하고 불필요한 내용을 제거하는 실습 부분은 다음과 같습니다.

    1. 전사된 텍스트를 한 줄에 하나의 문장으로 재구성합니다. 이는 후속 정제 작업을 용이하게 하기 위함입니다.

    2. Anthropic의 Claude 모델을 활용하여 재구성된 텍스트에서 불필요한 부분을 제거합니다. 제거 대상은 다음과 같습니다.

      • 인사말, 연사 소개 등의 맥락과 무관한 내용

      • 개인정보보호(PII) 관련 내용

      • 혐오 발언, 성차별/인종차별적 내용

      • 광고, 구독/좋아요 요청 등의 내용

    3. Claude 모델에 특정 프롬프트를 입력하여 위 내용들을 제거하도록 지시합니다.

    4. 제거된 문장은 제거 사유를 안에 명시하여 정제 결과를 쉽게 확인할 수 있게 합니다.

    5. 정제된 텍스트와 원본 텍스트를 비교하여 정제 수준을 검증할 수 있습니다.

    이 실습을 통해 전사된 텍스트에서 불필요하거나 부적절한 내용을 제거하고, 대규모 언어모델 학습에 적합한 고품질의 데이터를 생성할 수 있습니다. 또한 프롬프트 엔지니어링을 경험해볼 수 있는 기회가 됩니다.
