Create Slack Chatbot App

Slack App Page

https://api.slack.com/quickstart

Slack App Quick Guide

  1. 다음 링크를 통해 Slack App 생성 페이지로 이동합니다.

    https://api.slack.com/apps

  2. From scratch를 선택하여 app 생성을 시작합니다.

  3. App Name을 지정하고 Bot을 설치할 Slack Workspace를 지정하고 ‘Create App’ 버튼을 클릭합니다.

  4. App이 생성되면 다음과 같은 App 설정 화면이 표시 됩니다.

  5. ‘OAuth & Permissions; 메뉴로 이동하여 OAuth token의 권한을 설정 합니다.

  6. OAuth token Scope에서 App의 권한을 설정합니다. 다음의 권한을 부여합니다. - im:read, im:write, chat:write

  7. ‘Install App’ 메뉴로 이동하여 선택한 Workspace에 App을 설치 합니다.

  8. 설치가 완료되면 App의 OAuth Token 값이 표시 됩니다. Copy 버튼을 클릭하여 OAuth Token 값을 저장해 둡니다. OAuth Token은 AWS API Gateway에서 Slack App의 AWS Cloud 접근을 인증할 때 사용됩니다.

Slack platform tokens

https://api.slack.com/concepts/token-types

  • Bot Token

    • Ascribe to a granular permission model to request only the scopes you need.

    • Individual workspaces and are used for performing specific actions and automations within those workspaces

  • App-level Token

    • App-level tokens are for use with Slack apps but only with specific APIs, which are related to the app across all organizations where the app is installed.

    • Provide a way for your app to interact with Slack’s APIs at a broader organizational level, rather than being limited to individual workspace interactions.
