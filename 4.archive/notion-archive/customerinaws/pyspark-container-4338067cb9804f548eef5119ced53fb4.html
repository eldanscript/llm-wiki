Why PySpark Container

💡

Amazon SageMaker Processing Container

Release Blog

💡

PySpark Container는 사전 구축된 **빅 데이터 처리 컨테이너**로 **완전 관리형의 Spark 환경을 제공**하여 데이터 처리 및 피쳐 엔지니어링 워크로드를 위한 Amazon SageMaker Processing에 사용할 수 있다

  • Apache Spark as a pre-built data processing container

  • Amazon SageMaker Processing에 이 container를 사용하여 data processing 및 feature engineering workload에 활용

  • Full-manged Spark environment

Apache Spark

💡

Spark 정리 Blog

  • 대규모 데이터 처리를 위한 통합 분석 엔진 or 통합 플랫폼 (**Unified analytics engine for large-scale data processing**)

  • Cluster 환경에서 데이터를 병렬로 처리하는 Library 집합 → **분산 클러스터 컴퓨팅 프레임워크**

  • MapReduce 형태의 cluster computing은 disk에서 데이터를 읽고 Map을 통해 흩어져 있는 데이터를 Key-Value 형태로 연관성 있는 데이터끼리 묶은 후 Reduce를 하여 중복된 데이터를 제거하여 원하는 데이터로 가공한 후 다시 disk에 저장한다.

  • MapReduce의 disk i/o 성능 한계를 향상 시키기 위해 In-memory 연산을 사용하는 Spark가 등장 : 100x 향상 (Hadoop vs Spark vs Hive)

  • 다양한 데이터 분석 작업에 대해 동일한 연산 엔진과 일관성 있는 API로 수행할 수 있도록 설계 → 빅 데이터 분석 업무의 표준

  • 통합에 중점을 두어 기능의 범위를 컴퓨팅 엔진에 제한 → 저장소의 데이터 연산만 수행하며 저장소 역할은 수행하지 않음

    • 지원 저장소 : MS Azure, Amazon S3, Apache Hadoop, Apache Cassandra, Apache Kafka

Which benefit of using container

  • Spark 처리 작업을 대규모로 손쉽게 실행

  • Amazon SageMaker의 보안 및 규정 준수 기능을 갖춘 infra 이점 활용 - 확장 및 on-demand
