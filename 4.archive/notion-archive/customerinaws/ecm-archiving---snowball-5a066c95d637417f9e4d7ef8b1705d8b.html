ECM Archiving - SnowBall

InnoTek meeting - 2022.8.2

Attendee

  • InnoTek : 신희진 선임, 왕재민 선임

  • CNS : 장성규 책임, 주은희 책임, 문형진 선임

Network

  • 파주, 구미와 AWS간 DX 구성 검토 중

    • BGP가 지원되는 10Gbps 인터페이스가 2개 이상 포함된 장비

  • 내부 적으로 3개월 소요

Archiving Plan

  • 구미를 먼저 진행 : 내부 IBM 저가 저장소의 3PB를 10월 까지 진행

Data Sync Agent 구성

  • On-prem 서버에 VMWare, KVM, Hyper-V 설치 필요

  • VM에서 Storage mount 하여 사용 : Shared Storage 구성

  • GPFS에서 SMB 서비스 가능 하여 Shared Storage 구성 가능 할 것으로 보임

DataSync QnA

  • 병렬 session 구성은 file 구조나 크기에 맞춰 자동으로 조정

SnowBall 구성

  • 고객이 대용량 Snowball Migration Plan 작성 필요 → 콘솔 접속하여 진행 (https://us-east-1.console.aws.amazon.com/snowfamily/home?region=us-east-1#/)

  • SnowBall 기기 확보를 위한 예약 작업 → 실제 Order후 1주 정도 소요

  • SnowBall 에서 zero day 세팅을 하면 S3 Standard로 저장 되지만 바로 Glacier로 가기 때문에 S3 Standard 비용은 발생 하지 않음 (12시 기준으로 넘어 가기 때문에 낮에 저장할 경우 비용이 미미하게 발생 할 수 있음) : GDA로

PoC 진행

  • 별도 리눅스 서버에 KVM 설치 하여 구성 진행

Storage Special SA meeting - 2022.8.1

Attendee

  • Storage Specialist SA : Kim Yongki

  • Storage Specialist : Lee Kwangjae

2021 진행 내용

  • 3대의 스노우볼을 동시에 진행하는 경우 최적의 성능이 나옴

  • 210TB (80TB * 3대) 수행에 7일 정도 소요

IBM GPFS 제한

  • 작년 SnowBall로 데이터 이전 진행했을 때 대역폭에 한계가 있었음

  • GPFS의 최대 성능은 500MBps로 예상 되고 있음

준비

  • Migration plan update 후 reserve를 하고 동시에 주문 진행
