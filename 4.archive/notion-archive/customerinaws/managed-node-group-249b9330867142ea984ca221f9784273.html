Create EC2 Launch Template

💡

관리형 노드 그룹은 항상 Amazon EC2 Auto Scaling 그룹 시작 템플릿을 사용하여 배포됩니다. 관리형 노드 그룹을 생성할 때 사용할 고유한 시작 템플릿을 지정하지 않으면 Amazon EKS API가 계정에 기본값을 사용하여 시작 템플릿을 생성합니다

[

시작 템플릿 지원

관리형 노드 그룹은 항상 Amazon EC2 Auto Scaling 그룹 시작 템플릿을 사용하여 배포됩니다. 관리형 노드 그룹을 생성할 때 사용할 고유한 시작 템플릿을 지정하지 않으면 Amazon EKS API가 계정에 기본값을 사용하여 시작 템플릿을 생성합니다. 자체 시작 템플릿과 해당 템플릿에서 관리형 노드 그룹을 생성하면 기본 시작 템플릿에서 제공하는 것보다 관리형 노드를 배포할 때 더 높은 수준의 유연성과 사용자 지정을 제공할 수 있다는 이점이 있습니다.

https://docs.aws.amazon.com/ko_kr/eks/latest/userguide/launch-templates.html

](https://docs.aws.amazon.com/ko_kr/eks/latest/userguide/launch-templates.html)

[

Amazon Elastic Kubernetes Service (EKS) now supports EC2 Launch Templates and custom AMIs for managed node groups.
