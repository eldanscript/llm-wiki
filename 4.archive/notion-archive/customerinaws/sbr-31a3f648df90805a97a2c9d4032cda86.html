1. Amazon EKS Adoption and Operations

배경 및 컨텍스트

아카이브에서 확인된 내용에 따르면, HYBE는 EKS 기반으로 다양한 워크로드를 운영 중이며, AWS 팀과 지속적으로 EKS 관련 교육 및 기술 지원을 진행해 왔습니다.[1][2]

주요 활동 내역:

  • 2023년 7월: SM엔터테인먼트 대상 Amazon EKS Immersion Day 진행 (이종우 SA 주도). 세션 자료 공유 및 후속 리소스 링크 제공 [3]

  • 2025년 2월: HYBE DevOps팀 요청으로 re:Invent 2024 EKS/컨테이너 신규 피처 업데이트 교육 세션 기획 및 진행. 주요 토픽: EKS Auto Mode 등 신규 기능, Container & Computing / Network & Security, Storage & Database 세션으로 구성 (이종우 SA, 박헌민 TAM 발표) [4][5]

  • 2025년 4월: “2025 Modern Application Day: Amazon EKS 구축부터 운영까지” 이벤트 (4월 23-24일) 안내. 신규 EKS 기능, EKS 콘솔, SCAD 업데이트, VPC Lattice 기능 포함

  • 2024년 11월: HYBE 대상 EKS Observability 구성 관련 블로그 공유 — Amazon EKS에서 관리형 서비스를 활용하여 Spring Boot 애플리케이션 관찰 가능성(Observability) 구성하기 [6]

EKS 핵심 기술 내용 (아카이브 자료 기반):

  • 네트워킹: Prefix Delegation, Custom Networking, Security Group for Pods, VPC CNI 설정

  • 오토스케일링: Cluster Autoscaler, Karpenter (Group-less auto scaling), HPA, VPA, KEDA

  • GitOps/자동화: Flux, Argo CD를 활용한 GitOps 기반 CD 파이프라인

  • 보안: IRSA (IAM Role for Service Account), Pod Security Standards, Sealed Secrets

  • 스토리지: Amazon EBS (StatefulSet), Amazon EFS (Persistent Network Storage)

  • DevOps: Terraform/CDK for IaC, Helm/CDK8s for Deployment Descriptor, Jenkins + ArgoCD (GitOps) [1][2]

2. AWS Identity and Access Management (IAM) Best Practices

배경 및 컨텍스트

아카이브에서 확인된 내용에 따르면, HYBE 및 산하 계열사 전반에 걸쳐 IAM Identity Center(SSO) 기반의 중앙화된 계정 접근 관리가 이미 구현되어 있습니다.[7][8][9]

주요 활동 내역:

  • 2025년 6월: “AWS Identity Academy” 이벤트 (6월 5일) 안내. 주요 토픽: 신규 IAM 기능, 보안 위협 탐지, Terraform 기반 거버넌스, DevSecOps Secrets 관리

  • Trusted Advisor 점검 결과: hybeim, DRIMAGE 등 주요 계열사 계정에서 IAM SAML 2.0 Identity Provider 설정이 모두 Green(정상) 상태로 확인됨 — IAM Identity Center 기반 SSO 연동 완료 [7][8]

  • IAM Password Policy: hybeim 계열 25개 계정 모두 OK 상태 (강력한 패스워드 정책 적용 완료)

EKS 보안 연계 내용:

  • RBAC + AWS IAM, Pod level IAM role 적용

  • Pod Security Group 활용

  • SSM Parameter Store를 통한 Secrets 관리 [1][2]

5. AWS Service Updates

배경 및 컨텍스트

아카이브에서 확인된 AWS 서비스 업데이트 관련 커뮤니케이션 내역입니다.

주요 서비스 업데이트 내역 (아카이브 기반):

EC2 / Compute:

  • EC2 P5.4xlarge (H100 GPU 1개) 신규 출시 — 기존 P5.48xlarge(H100 8개) 대비 소규모 워크로드에 최적화된 비용 효율적 옵션. Supertone(HYBE 그룹) R&D팀에 공유 및 활용 방안 논의 [13][14]

    • 제공 리전: 미국 동부/서부, 유럽(런던), 아시아 태평양(뭄바이, 시드니, 도쿄), 남아메리카(상파울루)

    • 구매 옵션: On-Demand, Spot, Savings Plan, ML용 Capacity Blocks

  • EC2 C7g, M7g, R7g (Graviton3) 추가 리전 확장 — 서울 리전 포함 [106][113]

  • EC2 R8g (Graviton4, Preview) 발표 — 메모리 최적화 인스턴스 [114]

  • EC2 C8gb (Graviton4): 최대 30% 성능 향상, 150 Gbps EBS 대역폭 (Slack 요약 기반)

Database:

  • Amazon ElastiCache 서비스 업데이트 (elasticache-20240225-arm, elasticache-20240225-intel) — HYBE, hybeim, Weverse Company 계정에 보안 업데이트 적용 권고 [116][117][121]

  • HYBE ElastiCache → Valkey 마이그레이션 검토: Redis에서 Valkey로 무중단 마이그레이션 방법 기술 지원 (박헌민 TAM 답변) [118]

  • ElastiCache Serverless WATCH 명령어 지원 추가 — 고동시성 환경에서 데이터 일관성 및 트랜잭션 안정성 향상 (Slack 요약 기반)

  • Aurora MySQL 3.10 LTS 지원 시작 [108]

  • Graviton3 R7g 데이터베이스 인스턴스 Aurora MySQL/PostgreSQL 추가 리전 확장 (서울 포함) [113][115]

Quantum Computing:

  • AWS Braket: Qiskit 2.0 지원 강화, 네이티브 Sampler/Estimator 프리미티브 및 클라이언트 사이드 컴파일 추가 (Slack 요약 기반)

참고: 아카이브 검색 결과를 바탕으로 각 주제별 상세 내용을 보강했습니다. re:Invent 2025 관련 내용 및 일부 최신 서비스 업데이트(EC2 C8gb, ElastiCache WATCH 명령어, AWS Braket Qiskit 2.0 등)는 아카이브 범위를 벗어나 Slack 요약 원문 내용을 그대로 반영했습니다.
