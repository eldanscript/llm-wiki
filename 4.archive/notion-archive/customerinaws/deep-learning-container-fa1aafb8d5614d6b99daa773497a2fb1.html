TensorFlow

💡

end-to-end open source platform for machine learning

  • Google에서 개발 2015년에 open source 공개

  • Python 기반 library → C++, R 언어 지원

Keras

  • Open source Deep Learning library

  • High-level NN APIs for Python

    • TensorFlow, Theano, CNTK 등의 Deep Learning engine 구동 → 직관적이고 사용이 쉬운 API로 제공

  • 비전문가도 쉽게 Deep Learning model을 개발할 수 있도록 하는 것이 목적

Theano

  • 최초 Deep Learning Library 중 하나

  • CPU 및 GPU 수치 계산에 유용

PyTorch

  • Torch

    • Lua 기반 Deep Learning Framework

    • GPU 처리 : C/C++ library 및 CUDA 사용

  • Torch의 Python 구현

  • Deep Neural Network과 Tensor computing이 포함된 python package 형태

Apache MXNet

  • Open source deep learning project

  • AWS에서 Deep Learning engine으로 선택

CNTK

  • MS Computational Network Toolkit

  • Open source deep learning tool

AWS Deep Learning Container Images

  • Avaiable in Amazon ECR

  • Provides optimized environments

    • TensorFlow : 1.15.3, 2.4.1

    • PyTorch : 1.8.0

    • Apache MXNet (for CPU & GPU instances) : 1.8.0

    • Nvidia CUDA (for GPU instances)

    • Intel MKL (Math Kernel Library for CPU instances)
