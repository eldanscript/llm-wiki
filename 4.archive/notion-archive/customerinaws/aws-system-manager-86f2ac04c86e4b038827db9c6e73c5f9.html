Systems Manager 관리 서비스를 통해 소프트웨어 인벤토리를 자동으로 수집하고 OS 패치를 적용하고 관리 작업 및 복잡한 워크플로를 자동화하는 방법에 대해 알아보십시오. 또한 배스천 호스트가 리소스를 관리해야 하는 번거로움을 어떻게 덜어주는지도 확인할 수 있습니다. Run Command, 상태 관리자, 인벤토리, 패치 관리자, 유지 관리 기간, 자동화, 파라미터 스토어, 세션 관리자, OpsCenter, Explorer, Change Calendar, Distributor 등의 기능을 살펴봅니다.

Example Operation

Configuration

  • Central Account : Automation Account

  • Target Account : EC2 instance, On-prem instance

Workflow

  • CloudWatch Event → Lambda function → Call a MAMR (multi-account and multi-region) Automation operation

  • Command document (AWS-RunPatchBaseline)로 managed instances 패치

  • 제공된 스케줄에 따라 CloudWatch Event로 최초 수행 이후 패치 작업과 패치 규정 준수 데이터는 대상 인스턴스에서 사용 가능

    • 스케줄 메커니즘 : EventBridge rule 혹은 System Manager Maintenace Window 사용

  • 패치 작업

    • 빠진 업데이트를 스캔

    • 관리 인스턴스는 patch baseline 승인 규칙에 따라 패치를 스캔

  • 상태 관리자 Association이 생성되어 소프트웨어 인벤토리 데이터를 수집

    • 설치된 애플리케이션, AWS 컴포넌트, 네트워크 구성

  • 인벤토리 데이터 수집이 성공 여부에 따라 규정 준수 데이터 리포트

  • Resource Data Sync는 패치 데이터, 인벤토리 데이터, 규정 준수 데이터를 중앙 집중화된 S3 버킷으로 export

💡

Scan (missing update) → Patch → Gather (Inventory data) → Report (Data Sync)

Patching Process

  1. CloudWatch Event triggers based on schedule.

  2. CloudWatch Event rule initiates the Lambda function to call the Automation API StartAutomationExecution against the targeted accounts and regions.

  3. The Automation workflow is initiated in each target account and region.

  4. The workflow initiates the Run Command document AWS-RunPatchBaseline with the operation specified.

  5. Results from the Run Command task are outputted to the centralized S3 bucket.

  6. Patch Compliance data is reported to Patch Manager.

  7. The Resource Data Sync takes the Patch Compliance data and outputs to the centralized S3 bucket.

Inventory Data Gather

  1. The State Manager Association triggers using the rate of 1 day to gather software inventory data.

  2. The Inventory data is reported to Systems Manager.

  3. The Resource Data Sync takes the Inventory data and outputs to the centralized S3 bucket.
