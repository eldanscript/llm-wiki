Network

Cluster IP (iptables)을 사용할 경우 왜 Network 비용이 더 나오는가?

  • Multi-node 환경에서 사용하게 될 경우 AZ간 traffic 발생

AWS Guide

  • Ingress - LB Controller (ALB) + IP mode 사용 권고

  • NLB에 target group으로 구성 되기 때문에 AZ간 비용 발생 최소

  • Topology Aware Hints 사용하여 특정 AZ내에 traffic이 머물도록 구성이 가능

    • Max skew 등 정의 ; qoj

    • 현재 고객들이 가장 많이 사용하는 방식

    • DreamUs : AZ당 1개 정도로 유지 하여서 topology key로 zone을 설정, affinity 기능으로 사용

DNS

  • CoreDNS의 ndots가 5개 여서 내부에서 recursive 호출이 발생 → 규모가 커지면 성능의 문제가 발생

  • FQDN을 얼마나 사용하는지 확인이 필요 → config 수정하여 최적화한 호출을 만들어 사용

  • CoreDNS는 자동 확장 구성이 안 되어 있어 Cluster 규모가 늘어남에 따라 CoreDNS가 늘어날 수 있도록 구성 필요

  • Node Local DNS

  • Federation 사용하는 경우는 거의 없음 : 여러 개의 region에 걸친 cluster를 단일 cotnrol plane으로 운영 할 경우

  • Gateway Controller 도입이 많아 지는 상황 : L7외에도 Service Mesh 기능을 활용할 수 있어 서비스 간 traffic 관리에 유리

  • Upgrade B/G 방식

    • Load Balancer 보다는 Target Binding을 사용하여 업그레이드
