Quick Start - PyTorch NeuronX for Inference (DLAMI 사용)

Get Started - PyTorch NeuronX

💡

Neuron SDK Guide page에서 안내 하고 있는 PyTorch Neuron 설치와 실행에 대한 시작 가이드 입니다. Trainium및 Inferentia instance에 Neuron SDK를 설치하여 training 및 inference용으로 구성하는 과정을 안내하고 있습니다.

https://awsdocs-neuron.readthedocs-hosted.com/en/latest/frameworks/torch/index.html#pytorch-neuronx-main

  • NeuronX : Trn1, Trn2, Inf1, Inf2 지원

  • Neuron : Inf1 지원

Get Started - PyTorch NeuronX for Inference

💡

Inferentia 2 instance에 PyTorch Framework을 설치하고 예제 코드로 추론을 수행하는 과정을 안내 합니다.

https://awsdocs-neuron.readthedocs-hosted.com/en/latest/frameworks/torch/inference-torch-neuronx.html#inference-torch-neuronx

1. Inferentia Instance Setup

💡

Ubuntu20, Ubuntu22, AL2023, AL2, Rocky Linux9에 PyTorch Neuron 을 설치하는 과정을 안내 합니다.

https://awsdocs-neuron.readthedocs-hosted.com/en/latest/general/setup/torch-neuronx.html#setup-torch-neuronx

1-1) Inferentia 2 instance type 선택

  • Inferentia 2 사양 안내 : https://aws.amazon.com/ec2/instance-types/inf2/

  • Inferentia 2 지원 size : xlarge, 8xlarge, 24xlarge, 48xlarge

  • **Notes ) Amazon SageMaker 사용 시**

    • Amazon SageMaker에서 inferentia 2 를 사용할 경우 필요한 instance 수량에 대해 AWS Console의 Service Quotas 메뉴에서 요청하여햐 합니다. (기본 quota : 0)
      Service Quotas 메뉴에서 AWS services에 Amazon SageMaker를 입력 선택 후 inf2로 검색하면 현재 할당된 수량을 확인할 수 있고 여기서 필요한 type의 instance 수량을 추가 신청 합니다.

1-2) Instance에 사용할 AMI 선택

💡

Instance용 Amazon Machine Image는 Deep Learning용으로 구성된 DLAMI와 기본 OS만 포함하는 AMI를 선택하여 사용하면 됩니다.

DLAMI의 경우 Neuron SDK가 사전 설치되어 빠르게 환경을 구축할 수 있습니다. 기본 AMI를 사용할 경우 Neuron SDK를 별도로 설치, 구성해야 합니다.

Neuron DLAMI

  • 지원되는 AMI 목록 : https://awsdocs-neuron.readthedocs-hosted.com/en/latest/dlami/index.html#neuron-single-framework-dlami

    • Base DLAMI : Neuron driver, EFA, tool 만 설치되는 AMI로 PyTorch, TensorFlow와 같은 Framework는 별도로 설치해야 합니다. 주로 Container 구성 시 base image로 활용 합니다.

    • Single Framework DLAMI : 단일 Framework에 대한 virtual environment가 구성되는 AMI 입니다. 필요한 Framework과 version에 맞는 AMI를 선택하여 사용 합니다.

    • Multi Framework DLAMI : 여러 Framework에 대한 virtual environment가 제공됩니다. (PyTorch, TensorFlow, JAX) 여러개의 Framework 사용이 필요할 경우 사용 합니다.

  • **PyTorch Framework DLAMI**

    • Single Framework DLAMI

      • Ubuntu 22 : **Deep Learning AMI Neuron PyTorch 2.1 (Ubuntu 22.04) 20241027** / ami-049856d28288cce07

      • AL2 : Deep Learning AMI Neuron PyTorch 1.13 (Amazon Linux 2) 20240815 / ami-00981c5074545e272

    • Multi Framework DLAMI

      • Ubuntu 22 : **Deep Learning AMI Neuron (Ubuntu 22.04)** / ami-07ed48febdc2662fa

      • AL 2023 : **Deep Learning AMI Neuron (Amazon Linux 2023)** / ami-080b4a9b6e048125e

  • Neuron Base DLAMI

    • AL2 : Deep Learning Base Neuron AMI (Amazon Linux 2) 20240815

    • Ubuntu 22 : Deep Learning Base Neuron AMI (Ubuntu 22.04) 20241206

Only OS AMI

  • Ubuntu 22, Amazon Linux 2023 AMI 사용

1-3) Instance 생성 - Multi Framework DLAMI 사용

  • EC2 콘솔이나 CLI, API를 사용하여 inf2 instance type에 선택한 AMI를 적용하여 생성 합니다.

  • AMI 선택 : **Deep Learning AMI Neuron PyTorch 2.1 (Ubuntu 22.04) 20241027**

  • EBS 크기는 최소 512GB를 권장하고 있습니다.

2. PyTorch Neuron 활성화 - Multi Framework DLAMI 사용

💡

Ubuntu22에서 Multi-Framework DLAMI를 구성하는 가이드 : https://awsdocs-neuron.readthedocs-hosted.com/en/latest/general/setup/neuron-setup/multiframework/multi-framework-ubuntu22-neuron-dlami.html#setup-ubuntu22-multi-framework-dlami

  • Deep Learning AMI Neuron (Ubuntu 22.04)는 PyTorch 2.5 버전을 지원하고 있습니다. Model 학습이나 추론에 사용되는 virtual environment는 다음과 같습니다.

    1. PyTorch 2.5 Framework 환경

      1. aws_neuronx_venv_pytorch_2_5

    2. 대규모 언어 모델이나 Multi-modal 모델의 학습이나 추론에 특화할 경우 NxD (NeuronX Distributed) virtual environment를 사용합니다.

      1. aws_neuronx_venv_pytorch_2_5_nxd_training (NxD training)

      2. aws_neuronx_venv_pytorch_2_5_nxd_inference (NxD inference)

    3. Transformers 모델의 학습이나 추론에 특화할 경우 다음 virtual environment를 사용합니다.

      1. aws_neuronx_venv_pytorch_2_5_transformers

3. PyTorch Inference model compile 및 deploy

💡

Neuron SDK github repository에서 제공하는 sample code로 모델을 compile하고 inference를 수행하는 과정을 확인 합니다.

PyTorch Neuron Sample Codes

💡

Neuron Sample Code의 github repository 는 다음과 같습니다.

https://github.com/aws-neuron/aws-neuron-samples.git

3-1) Sample Code Download - Neuron SDK Sample repository clone

  • VSCode에서 Neuron SDK의 Github repository를 download 합니다.

  • inf2 instance 내 clone할 폴더 위치를 지정합니다.

3-2) Notebook에서 Sample Code 오픈

💡

Inference에 대한 sample code 들의 내용은 다음에서 확인할 수 있습니다.

https://github.com/aws-neuron/aws-neuron-samples/blob/master/torch-neuronx/README.md#inference

  • Hugging Face의 사전 학습된 Perceiver 모델을 선택합니다.

    https://github.com/aws-neuron/aws-neuron-samples/blob/master/torch-neuronx/inference/hf_pretrained_perceiver_language_inference.ipynb

3-3) Sample code 실행

  • Notebook code를 실행하고 Kernel 선택에서 Existing Jupyter Server를 선택 합니다.

  • 앞 단계에서 Terminal 또는 VSCode의 Remote Explorer에서 구동 시킨 Notebook Server url을 입력 합니다.

  • Kernel을 inf2에 활성화 시킨 aws_neuronx_venv_pytorch_2_5 가상 환경의 kernel로 선택 합니다.

  • Notebook 코드를 실행 하고 결과를 확인 합니다. 코드는 다음의 내용을 포함하고 있습니다.

    • Hugging Face에서 사전 훈련된 Perceiver 언어 모델 로드

    • torch-neuronx를 사용한 모델 컴파일

      • 입력으로 받은 함수 또는 모듈을 실행하여 연산 그래프(graph representation)를 기록

      • 연산 그래프를 Neuron 전용 최적화된 형태로 변환하여 ScriptModule을 생성

      • ScriptModule은 Neuron 하드웨어에서만 실행 가능한 최적화된 모델이며 torch.jit.save()를 통해 저장하고 torch.jit.load()로 로드

    • Inferentia2 에서 추론 실행

      • torch_neuronx.trace()로 생성된 TorchScript 모듈을 파일에서 로드

      • model_neuron 객체에 입력 데이터(inputs)를 전달하면, 모델이 Neuron 하드웨어에서 실행
