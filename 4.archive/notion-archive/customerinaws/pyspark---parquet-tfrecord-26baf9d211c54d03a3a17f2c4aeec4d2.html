  • spark.ContextCleaner (org.apache.spark.ContextCleaner) class

    • ContextCleaner는 driver에서 실행. SparkContext가 시작될 때 작성되고 즉시 시작

    • Acculmulate를 정리

    • context-cleaner-periodic-gc는 JVM 가비지 콜렉터를 요청. 주기적 실행은 ContextCleaner가 시작될 때 시작되고 ContextCleaner가 중지 될 때 중지

  • The BlockManager is basically the main service in Spark that is serving the programming (Scala, Java, Python, etc.) variables and data structures, RDDs (reference notes)

  • user/system defined values, etc. and caching them on the Spark executors

  • How Spark cache RDDs and re-use them in memory to speed up computation, reducing data transferring between the HDFS to the executors

  • Respectively, Spark Driver and Executor will both initialize such BlockManager service like a daemon in their YARN container to serve the purpose of caching data structures, RDD, variables.

  • When a Job is executed, the Driver may try to add a variable value, and indicate the executors to cache it down the path to boost performance, it will be broadcasted to one of the executor that is working on this job and this executor will cache them for further usage when you invoke one of the Resilient Distributed Dataset (RDD) persistence APIs (e.g. persist, cache).

  • Once it is cached on one of the BlockManager service on the executor (either on the Driver or one of the executors), the transient value on the driver and other executors will be removed when the job completes to release the occupied memory so only one or few BlockManager services will have these values cached to a certain of time.

Answers

공유주신 code에서 parquet output이 S3로 전송되지 않은 이유는 parquet file들이 HDFS 상에만 있고 Processing Container의 local file system으로 저장이 되어 있지 않기 때문이었습니다.

local file system으로 저장이 되어야 Processing Container에 mapping 된 S3 output folder로 전송이 됩니다. “file://{local folder name}” 같이 명시적으로 local file system으로 저장하도록 하여야 합니다.

local file system에 저장후 다시 S3로 전송이 되기 때문에 현재 사용하고 계신 것처럼 직접 “s3://” 나 “s3a://“를 사용하는 것이 성능적인 면에서는 이점이 있는데 Processing 작업 구성에 따라 선택하여 적용하시면 될 것 같습니다.

다음 링크에서 S3에 최적화 된 committer에 대한 내용을 확인하실 수 있습니다.
