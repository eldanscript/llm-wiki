RPA System 연동 구성

  1. S3로 Hosting 되는 업무 시스템 페이지 접속

    1. 사내망에서 업무 시스템 접속 : 사내망 NAT IP, 사내망 공인 IP

    2. 원격 환경에서 VPN 연결을 통해 업무 시스템 접속 : 인터넷 망의 불 특정 NAT IP

  2. Web Page내 구성된 기능별 API Gateway URL을 통해 API Gateway access

  3. API Gateway는 Public으로 Open 되어 있기 때문에 IP 기반으로 whitelist 방식의 Blocking

    1. 사내망 NAT IP, 사내망 공인 IP → 허용

    2. 인터넷 망의 불 특정 NAT IP → 차단

Issue 사항

  • 사내망이 아닌 외부 환경에서 VPN으로 접속할 경우 IP를 특정할 수 없기 때문에 API Gateway에서 Blocking

네이버웍스 메신저 연동 구성

네이버웍스 메신저에 LGCNS Singlex ChatBot 등록

  1. 네이버웍스 메시지 Bot에 LGCNS Singlex ChatBot을 등록 : AWS Cloud에 구성한 Relay Server를 사용

    1. 테넌트와 도메인으로 구분

      1. 테넌트

        1. 그룹사 개념

        2. 메시지 Bot은 테넌트 기준으로 등록

      2. 도메인

        1. 개별 기업 개념

        2. 메시지 Bot 사용 가능 범위 지정

    2. 네이버웍스에서 제공하는 메시지 Bot 등록 API를 통해

    3. 등록 API를 통해 Relay Server의 API Gateway URL을 메시지 수신 Callback URL을 전달

메시지 Bot 등록

  • 네이버웍스의 메시지 Bot 등록 API를 통해 진행 → 누가 어디서? (Relay Server?)

    • Bot 등록 Parameter

      • Bot Name, Image, Description, Admin account

      • Bot 사용 가능 도메인 list : 추가 도메인 등록을 위해 필요

      • Bot Event : text, location, sticker, image, file

      • Bot Event 수신 서버 URL (callbackURL)

네이버웍스 메신저를 통해 LGCNS Singex ChatBot간의 메시지 전송

  1. 네이버웍스 메신저에 로그인한 사용자가 메시지 작성

  2. 사용자 메시지는 네이버웍스 Bot을 통해 AWS내 Relay Server로 전달

  3. AWS내 Relay Server는 Lambda를 통해 Singlex Chatbot 으로 메시지 전송

  4. Singlex Chatbot에서 응답 메시지 작성하여 Lambda에 reply

  5. API Gateway를 통해 메시지 Bot으로 메시지 응답
