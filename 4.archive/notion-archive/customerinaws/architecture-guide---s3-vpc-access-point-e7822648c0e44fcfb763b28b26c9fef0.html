VPC endpoint에 custom private DNS name 설정

  • Guide : https://aws.amazon.com/premiumsupport/knowledge-center/vpc-private-dns-name-endpoint-service/?nc1=h_ls

  • Privatee DNS name for endpoint services : https://docs.aws.amazon.com/vpc/latest/privatelink/verify-domains.html

    • vpce-svc-01234567890abcdef.us-east-1.vpce.amazonaws.com

    • **Private DNS is not supported for Amazon S3 interface endpoints** (https://docs.aws.amazon.com/vpc/latest/privatelink/vpce-interface.html)

      • Related re:Post : https://repost.aws/questions/QUeJsY_nepTvmJeBc_iZUPdw/how-do-i-create-a-vpc-endpoint-for-s-3-interface

      • S3 interface endpoint는 private DNS를 지원 하지 않음 → S3 interface는 Interface Endpoint 생성시 만들어지는 public DNS를 사용 하며 이 public DNS는 ENI의 private IP를 해독

      • S3 endpoint 생성 후 Public DNS

        • Regional : vpce-000f58f01fd5b68c5-z5zc2wap.s3.us-east-1.vpce.amazonaws.com

        • Zonal : vpce-000f58f01fd5b68c5-z5zc2wap-us-east-1c.s3.us-east-1.vpce.amazonaws.com

  • Private DNS option은?

    • Private Hosted Zone을 VPC와 연결 (associate)

    • Hosted Zone은 서비스에 대한 기본 DNS name에 대한 record set을 가지고 있으며 VPC내의 network interface에 대한 endpoint IP 주소를 해석한다

    • 이 option을 활성화 하면 기본 DNS name 으로도 endpoint hostname을 통해 사용할 수 있게 된다

Gateway vs Interface

  • https://docs.aws.amazon.com/AmazonS3/latest/userguide/privatelink-interface-endpoints.html

  • Interface endpoint bandwidth limitiation : 10Gbps → Gateway endpoint bandwidth limitation : X

Interface VPC endpoint

  • VPN 혹은 DX를 통해 on-prem application에서 direct access 가능

  • 다른 AWS region의 application이 VPC peering을 통해 direct access 가능

  • Interface endpoint는 Gateway endpoint의 기능을 확장 할 수 있으며 Gateway endpoint와 호환된다. Gateway endpoint가 있는 경우 동일 VPC에 2가지 type의 endpoint를 사용할 수 있음

Gateway VPC endpoint

  • VPC로 부터 S3에 access 하도록 route table에 지정된 gateway

Gateway Endpoint Issue

  • https://docs.aws.amazon.com/vpc/latest/privatelink/vpce-gateway.html#vpc-endpoints-limitations

  • Gateway Endpoint : Create routing of traffic between VPC and other service.

  • Endpoint connections cannot be extended out of a VPC. Resources on the other side of a VPN connection, VPC peering connection, transit gateway, AWS Direct Connect connection, or ClassicLink connection in your VPC cannot use the endpoint to communicate with resources in the endpoint service.
