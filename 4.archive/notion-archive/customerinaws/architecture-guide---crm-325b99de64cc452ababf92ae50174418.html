고도화 Item 검토

현황 Check

  1. 캠페인 내용 세분화

    1. 캠페인 기간 통상 7일간 진행

      1. 종료일 변경 가능

    2. 분석 시스템은

      1. 고객 분석 솔루션 MSTR olap, 캠페인 시스템 Red CRM

      2. 패키지 customizing

    3. 타겟 분류 방식은

      1. 여러 개 타겟 생성 가능 : VIP, 우수 등

      2. 등급은 브랜드별 관리 : 채널은 브랜드 (럭셔리, 오휘, 숨)

      3. 고객에게 SMS 발송

        1. 매체는 DM, 문자 위주 eDM → LMS내 URL 링크 삽입

      4. 캠페인 코드를 생성하여 관리, 진행

      5. 캠페인 코드를 통해 구매 여부 만 확인

        1. 오프라인 매장 방문 시 캠페인 여부 확인이 어려움

      6. 고객 마스터 속성 데이터

        1. 이름, 성별, 생일, 구매 매장, 가입 매장

        2. 피부 타입 → 관리 안됨

        3. 캠페인 활동을 위해 관리하는 데이터는

      7. 본사 CRM 팀에서 대상자 선정 요청 → Campaign 시스템에 upload 하여 진행

        1. 모바일 팩토리 (협력 회사)에서 스크립트를 통해 캠페인 대상자를 선정하여 업로드

    4. 현재 캠페인 관리는

      1. 문자 발송 성공률

      2. DM 발송 성공률

      3. 캠페인 유무에 따른 매출 데이터 비교를 통해

    5. 캠페인 Target 선정 / Channel 선정 / 효과 분석

  2. 온라인 고객 활동 및 장바구니 분석

    1. 개인별 온라인 몰 상품 추천은 적용 하지 않음

      1. 자사몰에서는 추천 기능 적용

      2. 임직원용 가족몰에서 추천 기능 적용

      3. 브랜드몰

    2. 자사몰 보다는 외부 쇼핑몰을 통해 대부분 이루어 지고 있어 이에 대한 분석이 필요

    3. 네이처 컬렉션 몰에서 온,오프라인 데이터 통합

      1. 구현 가능한 데이터는 있으나 구현 되어 있지 않음

    4. 고객사에서 온라인 쇼핑몰을 활성화 하고 싶어 함

    5. 상품 라이프 사이클을 통해 제품 추천

    6. Needs가 있으나 효과성에 대한 입증 필요

  3. VIP 고객 이탈 방지

    1. 브랜드별 VVIP 고객 관리 : 구매 금액, 구매 횟수에 따라 분류

    2. 별도 관리 : 문자 안내, 쿠폰 발행

    3. 라이프 사이클에 맞는 고객 관리는 → 없음

  4. 고객 프로파일 생성

    1. 고객 데이터

    2. VoC 정보, 온라인 데이터 부재 → 네이버 쇼핑몰 데이터 정도

    3. 온라인 구매 데이터는 네이버나 쿠팡에서 받고 있지 않음 → OMS (온라인 주문 정보 보유)에서 관리는 하지만 가져오지 못하고 있음

    4. CDO 산하 데이터 ML 팀에서 진행

      1. 네이버 온라인 고객 경험

      2. AI 기반 감성 품질 예측

      3. 고객 데이터 분석 플랫폼
