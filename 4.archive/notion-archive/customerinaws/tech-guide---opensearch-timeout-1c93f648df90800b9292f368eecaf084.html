추가 확인 사항

  1. AOS 버전 및 mode (provisioned or serverless)

  2. Index 수 및 alias 사용하지 않는 이유 (또는 사용한다면 위 query에서 사용하지 않는 이유)

  3. 위 query의 json format으로 변환된 형태 및 추가로 “profile” : true 로 dev tools에서 실행한 결과 (참조: link)

  4. 동시 search AOS로 전달되는 수 (대략적으로 초당 몇 정도)

  5. dev tools에서 GET _cluster/settings 실행 결과

  6. dev tools에서 GET /_settings 실행 결과

  • 현재 timeout 발생한다고 하셨는데 그 timeout이 opensearch에서 발생하는 것인지 사용중인 환경 (아마도 java 기반의 framework이나 package?) 에서 connection 관리 차원에서 timeout 하고 있는지 확인도 필요
