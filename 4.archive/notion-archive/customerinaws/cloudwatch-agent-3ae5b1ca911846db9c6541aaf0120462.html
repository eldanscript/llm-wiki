Get CloudWatch Agent Docker File

  • CloudWatch Agent Image를 생성을 위한 참고 파일을 Download 합니다.

  • Dockerfile 구성은 다음과 같이 되어 있습니다.

    • debian OS를 기반으로 실행되며

    • container 실행 시 apt update 및 Amazon S3에서 cloudwatch-agent를 download 받아 설치 합니다.

    • cloudwatch agent에 대한 설정을 진행하고

    • container image 실행 시 cloudwatch-agent를 수행하도록 entry point를 설정합니다.

ECR에서 Private Repository 생성

  • ECR 콘솔 메뉴에서 Private Repository를 생성합니다.

Upload CloudWatch Agent Image to ECR

  • ECR에 login 합니다. AWS ID로 login을 진행하게 됩니다.
  • Build된 Image에 tag를 추가 합니다.
  • Tag된 Image를 확인하면 다음과 같습니다.
  • Image file을 ECR로 Upload 합니다.
  • Push가 완료되면 ECR 콘솔에서 Image를 확인할 수 있습니다.
