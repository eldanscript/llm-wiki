Kubernetes Ingress 설명

Ingress 란?

  • Cluster 외부에서 Cluster내의 Service로 HTTP(S) routing 되도록 노출 시키는 리소스

  • Ingress 리소스에 정의되는 Rule에 따라 traffic을 routing 한다

  • Ingress는 arbitrary port나 protocol을 expose 하지 않음

  • HTTP(S) 이외의 서비스를 expose 하기 위해 Service type을 사용

    • Service.type = NodePort

    • Service.Type = LoadBalancer

Ingress configure

  • 외부에서 연결 가능한 URLs

  • SSL/TLS traffic termination

  • Name 기반의 virtual hosting : custom domain 할당 (?)

Ingress Controller

  • Load Balancer와 함께 Ingress 수행

  • 트래픽을 처리하는 데 도움이 되도록 에지 라우터 또는 추가 프런트 엔드를 구성 할 수도 있음

  • Ingress 리소스 생성 만으로는 Ingress 동작을 처리할 수 없으며 Ingress Controller가 있어야 한다
