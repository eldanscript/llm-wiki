FMs available in Amazon Bedrock

AI21labs

Jurassic-2 Ultra

AI21’s most powerful model for complex text generation tasks that require the highest quality output.

Max tokens: 8,192

Languages: English, Spanish, French, German, Portuguese, Italian, and Dutch

Supported use cases: Question answering, summarization, draft generation, advanced information extraction, ideation for tasks requiring intricate reasoning and logic.

Jurassic-2 Mid

AI21’s mid-sized model for advanced text generation tasks that require both quality and affordability.

Max tokens: 8,192

Languages: English, Spanish, French, German, Portuguese, Italian, and Dutch

Supported use cases: Question answering, summarization, draft generation, advanced information extraction, ideation.

Amazon Titan

Amazon Titan Text Premier

Amazon Titan Text Premier is a powerful and advanced model within the Amazon Titan Text family, designed to deliver superior performance across a wide range of enterprise applications. This model
is optimized for integration with Agents and Knowledge Bases for Amazon Bedrock, making it an ideal option for building interactive generative AI applications that can use your APIs and interact with your data.

Max tokens: 32K

Languages: English

Fine-tuning supported: Yes (preview)

Supported use cases: RAG, agents, chat, chain of thought, open-ended text generation, brainstorming, summarization, code generation, table creation, data formatting, paraphrasing, rewriting, extraction, and Q&A.

FMs Benchmarking

Foundation models are evaluated using various benchmarks that test their capabilities across different domains and tasks. Here are descriptions of some of the commonly used benchmarks and metrics:

  1. HellaSwag:

    • Task: Commonsense reasoning.

    • Description: This benchmark evaluates the model’s ability to choose the most plausible continuation of a given situation from multiple choices.

  2. MMLU (Massive Multitask Language Understanding):

    • Task: Multitask language understanding.

    • Description: Tests models on a wide range of subjects from elementary school to professional level across multiple languages and domains.

  3. ARC-C (AI2 Reasoning Challenge - Challenge Set):

    • Task: Question answering.

    • Description: Designed to test a model’s reasoning and knowledge using science questions from elementary and middle school exams.

  4. DROP (Discrete Reasoning Over Paragraphs):

    • Task: Reading comprehension with discrete reasoning.

    • Description: Requires models to answer questions by performing discrete operations (like addition, sorting, or counting) over paragraphs of text.

  5. WinoGrande:

    • Task: Commonsense reasoning.

    • Description: An extension of the Winograd Schema Challenge, it tests models on their ability to resolve pronoun references that require commonsense knowledge.

  6. MATH:

    • Task: Mathematical problem solving.

    • Description: Contains problems from various levels of mathematics, testing the model’s ability to understand and solve math questions.

  7. BIG-bench (Beyond the Imitation Game Benchmark):

    • Task: Multitask benchmark.

    • Description: A diverse set of tasks designed to test the general capabilities of AI models, including language understanding, reasoning, and world knowledge.

  8. HumanEval:

    • Task: Code generation.

    • Description: Tests the model’s ability to generate correct code solutions for given programming problems.

  9. WMT23 (Workshop on Machine Translation 2023):

    • Task: Machine translation.

    • Description: Evaluates the quality of machine translation systems across multiple languages using human and automatic evaluations.

  10. GSM8K (Grade School Math 8K):

    • Task: Mathematical problem solving.

    • Description: A dataset of 8,000 high-quality grade school math problems, designed to test models on arithmetic and basic math problem-solving skills.

  11. GPQA (General-Purpose Question Answering):

    • Task: Question answering.

    • Description: Tests models on a wide variety of question types, aiming to evaluate the model’s general-purpose question-answering ability across various domains.

Each of these benchmarks provides a different perspective on the model’s capabilities, from language understanding and commonsense reasoning to mathematical problem solving and code generation. They are essential for assessing the strengths and weaknesses of foundation models in a comprehensive and systematic manner.

기초 모델(foundation model)은 다양한 분야와 작업에서 그 능력을 평가하기 위해 여러 벤치마크를 사용합니다. 여기 몇 가지 일반적으로 사용되는 벤치마크와 메트릭에 대한 설명이 있습니다:

  1. HellaSwag:

    • 작업: 상식 추론.

    • 설명: 주어진 상황의 가장 그럴듯한 연속성을 여러 선택지 중에서 선택하는 모델의 능력을 평가합니다.

  2. MMLU (Massive Multitask Language Understanding):

    • 작업: 다중 작업 언어 이해.

    • 설명: 초등학교부터 전문 수준까지 다양한 주제와 여러 언어 및 도메인을 대상으로 모델을 테스트합니다.

  3. ARC-C (AI2 Reasoning Challenge - Challenge Set):

    • 작업: 질문 답변.

    • 설명: 초등학교와 중학교 과학 시험 문제를 사용하여 모델의 추론 및 지식을 테스트하도록 설계되었습니다.

  4. DROP (Discrete Reasoning Over Paragraphs):

    • 작업: 단락에 대한 읽기 이해와 이산 추론.

    • 설명: 모델이 단락의 텍스트를 통해 덧셈, 정렬, 셈과 같은 이산 연산을 수행하여 질문에 답변하도록 요구합니다.

  5. WinoGrande:

    • 작업: 상식 추론.

    • 설명: Winograd Schema Challenge의 확장판으로, 상식 지식을 필요로 하는 대명사 참조를 해결하는 모델의 능력을 테스트합니다.

  6. MATH:

    • 작업: 수학 문제 해결.

    • 설명: 다양한 수준의 수학 문제를 포함하며, 모델의 수학적 질문 이해 및 해결 능력을 테스트합니다.

  7. BIG-bench (Beyond the Imitation Game Benchmark):

    • 작업: 다중 작업 벤치마크.

    • 설명: 언어 이해, 추론, 세계 지식을 포함한 AI 모델의 일반적인 능력을 테스트하기 위해 설계된 다양한 작업 세트입니다.

  8. HumanEval:

    • 작업: 코드 생성.

    • 설명: 주어진 프로그래밍 문제에 대한 올바른 코드 솔루션을 생성하는 모델의 능력을 테스트합니다.

  9. WMT23 (Workshop on Machine Translation 2023):

    • 작업: 기계 번역.

    • 설명: 여러 언어에 걸쳐 기계 번역 시스템의 품질을 인간과 자동 평가를 통해 평가합니다.

  10. GSM8K (Grade School Math 8K):

    • 작업: 수학 문제 해결.

    • 설명: 산수와 기본 수학 문제 해결 능력을 테스트하기 위해 설계된 8,000개의 고품질 초등 수학 문제 데이터셋입니다.

  11. GPQA (General-Purpose Question Answering):

    • 작업: 질문 답변.

    • 설명: 다양한 질문 유형에 대해 모델의 범용 질문 답변 능력을 평가합니다.

이러한 벤치마크 각각은 언어 이해 및 상식 추론에서 수학 문제 해결 및 코드 생성에 이르기까지 모델의 능력을 다양한 관점에서 평가합니다. 이는 기초 모델의 강점과 약점을 포괄적이고 체계적으로 평가하는 데 필수적입니다.
