Agentic AI Accelerated Program

HYBE Agentic AI 구축 가속화 Program

Program 개요

본 프로그램은 HYBE가 최대한 고객이 직접 작업하고 AI/ML Specialist SA와 함께 솔루션 구축까지의 방향성 제시와 문제점 해결 가이드를 제공하여 여러 가지 형식의 Agent를 구축하는 방법론을 지향합니다.

목표: Infrastructure Operations 전반에 Agentic AI를 도입하여 CI/CD 장애 분석, 인시던트 대응, 비용 최적화, 프로비저닝 자동화 등을 자동화하는 Production-grade AIOps Platform 구축

Program 구성

Phase 1: Tech Enablement 1차 (SA 주도)

기간: 1일
목표: Agentic AI 기본 개념 이해 및 AWS 도구 활용 방법 습득

세션 구성

  • Agentic AI on AWS 소개 (1.5시간)

    • Agentic AI 개념 및 비즈니스 임팩트

    • AWS Strands Framework 소개

    • Amazon Bedrock AgentCore 개요

    • Multi-Agent 아키텍처 패턴

  • Kiro를 사용한 AI Coding (1.5시간)

    • Amazon Q Developer 활용

    • AI 기반 코드 생성 및 최적화

    • 개발 생산성 향상 방안

  • Hands-On Session (2-3시간)

    • AWS Strands를 활용한 Agent Prototyping

    • 기본 Agent 구축 실습

    • MCP (Model Context Protocol) 서버 연동

참고 자료: AWS Strands GitHub Repository, AgentCore 문서

Phase 2: 고객 Case Brainstorming, 선정, Breakdown (SA 주도)

기간: 1-2주
목표: 고객사의 실제 Use Case 발굴 및 우선순위 선정

주요 활동

  1. Use Case Brainstorming Workshop

    • Infrastructure Operations 팀과 함께 Pain Point 도출

    • AIOps 적용 가능 영역 탐색

    • 6가지 핵심 Use Case 후보 선정

  2. Use Case 우선순위 선정

    • 비즈니스 임팩트 평가

    • 기술적 실현 가능성 검토

    • Phase 1/Phase 2 구현 로드맵 수립

  3. 상세 요구사항 정의

    • 각 Use Case별 입력/출력 정의

    • 연동 시스템 및 API 식별

    • 성공 지표(KPI) 설정

HYBE 사례: CI/CD Failure Analysis (GitLab), Incident Response (Datadog), Cost Optimization (AWS/GCP), Provisioning Automation, Audit & Compliance, Knowledge Q&A

Phase 3: 주요 Agent 선정 및 세부 Spec 생성 (Specialist SA 주도)

기간: 2-3주
목표: Production-ready Architecture 설계 및 기술 스펙 확정

주요 활동

  1. Multi-Layer Architecture 설계

    • User Interface Layer: Web Portal, REST API, Slack 연동

    • Core Orchestration Layer: Planner Agent, Executor Agent, Validator Agent

    • Specialized Agent Layer: 6개 도메인별 Agent

    • Data & Knowledge Layer: GitLab API, Datadog API, AWS Bedrock, CloudWatch

    • Integration & Tool Layer: MCP 서버 (GitLab, Datadog, AWS Cost Explorer)

  2. Use Case별 Technical Design

    • Agent 간 통신 프로토콜 정의

    • LLM 호출 최적화 전략

    • Error Handling 및 Retry Logic

    • State Management 방안

  3. 기술 스택 확정

    • AWS Strands Framework

    • Amazon Bedrock (LLM Orchestration)

    • AgentCore Runtime, Gateway, Identity

    • MCP Server Integration Pattern

Phase 4: 고객 개발 및 정기 체크인 미팅 (고객 주도, Specialist SA Support)

기간: 4-8주
목표: Prototyping 구축 및 검증

개발 단계 (2주 단위 체크인 미팅)

1-2주차: 기본 Agent 개발

  • Agent Framework 구축

  • 첫 번째 Use Case 구현 (예: CI/CD Failure Analysis)

  • 기본 MCP 서버 연동

  • 단위 테스트 및 검증

3-4주차: Multi-Agent Orchestration

  • Core Orchestration Layer 구현

  • Agent 간 통신 구현

  • 두 번째 Use Case 추가 (예: Incident Response)

  • 통합 테스트

5-6주차: 추가 Use Case 확장

  • Cost Optimization Agent 구현

  • Provisioning Automation Agent 구현

  • End-to-End 시나리오 테스트

7-8주차: Prototyping 완성

  • UI/UX 개선

  • 성능 최적화

  • 보안 강화

  • 사용자 피드백 반영

Specialist SA 지원 내역

  • 주 2회 정기 체크인 미팅

  • 기술적 이슈 해결 가이드

  • 코드 리뷰 및 Best Practice 공유

  • Architecture 검증 및 개선 제안

HYBE 사례: 2026년 1월 20일 Full-Day AIOps Workshop 진행, AWS Strands 기반 Hands-on Prototyping 실습

Phase 5: Tech Enablement 2차 (Specialist SA 주도)

기간: 1일
목표: Bedrock AgentCore 심화 이해 및 Production 준비

세션 구성

  • Bedrock AgentCore Deep Dive (2시간)

    • AgentCore Runtime: Serverless 환경, Session Isolation

    • AgentCore Gateway: API/Lambda를 Agent Tool로 변환

    • AgentCore Identity: AWS 서비스 및 3rd-party 도구 보안 연동

    • AgentCore Observability: 모니터링 및 텔레메트리

  • Production Best Practices (1.5시간)

    • Agent 성능 최적화

    • 보안 및 거버넌스

    • 비용 관리 전략

    • 장애 대응 및 복구

  • Hands-On Session (2-3시간)

    • AgentCore를 활용한 Agent 배포

    • Multi-Agent 워크플로우 구성

    • 모니터링 대시보드 구축

Phase 6: AgentCore 구축 진행 (고객, SA, Specialist SA 협업)

기간: 3-4주
목표: Production-ready 시스템 구축

주요 활동

  1. AgentCore 기반 Migration

    • Prototype에서 AgentCore로 전환

    • Runtime 환경 구성

    • Gateway 및 Identity 설정

  2. 통합 및 테스트

    • 실제 운영 환경 연동

    • 부하 테스트 및 성능 검증

    • 보안 감사 및 컴플라이언스 확인

  3. 운영 준비

    • 모니터링 및 알람 설정

    • 운영 매뉴얼 작성

    • 팀 교육 및 지식 이전

Phase 7: Production 적용

기간: 2-4주
목표: 실제 운영 환경 배포 및 안정화

주요 활동

  1. 단계적 배포

    • Canary 배포 전략

    • 점진적 트래픽 증가

    • 실시간 모니터링

  2. 성과 측정

    • CI/CD 장애 분석 자동화율 측정

    • MTTR (Mean Time To Resolution) 감소율 측정

    • 비용 최적화 효과 측정

    • 인프라 프로비저닝 효율성 개선 측정

  3. 지속적 개선

    • 사용자 피드백 수집

    • Agent 성능 튜닝

    • 추가 Use Case 발굴

HYBE 목표 KPI:

  • CI/CD 트러블슈팅 수동 개입 60% 감소

  • 인프라 인시던트 MTTR 40% 감소

  • 자동화된 리소스 최적화를 통한 30% 비용 절감

Program 특징

고객 중심 접근

  • 고객이 직접 개발: 최대한 고객 팀이 직접 구현하여 내재화

  • SA는 가이드 역할: 방향성 제시 및 문제 해결 지원

  • 실무 중심 학습: 실제 Use Case 기반 Hands-on

단계적 역량 강화

  • Phase 1-2: 기본 개념 및 도구 습득

  • Phase 3-4: 실전 개발 경험 축적

  • Phase 5-7: Production 운영 역량 확보

AWS 최신 기술 활용

  • AWS Strands Framework (오픈소스)

  • Amazon Bedrock (LLM)

  • AgentCore (Enterprise-grade Agent Platform)

  • MCP (Model Context Protocol)

성공 사례: HYBE AIOps Workshop

일시: 2026년 1월 20일 (월) 10:00-17:00
장소: HYBE ICN16 Office
참석자: HYBE Infra Operation Team, DevOps Team, SRE Team

Workshop 성과

  • ✅ Production-ready 7-layer Agent Architecture 설계 완료

  • ✅ 6개 AIOps Use Case 정의 및 우선순위 선정

  • ✅ Phase 1 구현 로드맵 수립 (GitLab, Datadog, Provisioning, Cost Management)

  • ✅ AWS Strands 및 AgentCore 기술 교육 완료

  • ✅ MCP Server Integration Pattern 확립

  • ✅ HYBE 팀의 자체 개발 역량 확보

참고 자료

AWS 공식 문서

  • Model Context Protocol (MCP) Specification

내부 참조 링크
