AWS Neuron SDK의 Dynamic Dimension 지원 분석

AWS Neuron SDK 2.21 버전에서 dynamic dimension 관련 컴파일 오류 해결 방법과 최신 개발 현황에 대한 분석입니다.

Neuron SDK의 Dynamic Tensor Shape 지원 현황

AWS Neuron SDK는 현재 버전(2.21 포함)에서도 완전한 dynamic tensor shape을 지원하지 않습니다. 검색 결과에 따르면 “Models with control-flow and dynamic shapes are not supported now. You will need to partition the model using the framework prior to compilation.”이라고 명시되어 있습니다[7]. 즉, 컴파일 시점에 입력 크기가 고정되어야 하며, 다양한 크기의 입력을 처리하기 위해서는 추가적인 기법이 필요합니다.

현재 Neuron SDK는 배치 차원(batch dimension)에 한해서만 dynamic batching을 지원합니다. 이는 컴파일 시 지정한 배치 크기와 다른 배치 크기로 추론을 수행할 수 있게 해주는 제한적인 기능입니다[3].

NeuronCore-v2 아키텍처와 Dynamic Shapes

검색 결과에 따르면 “This feature is supported in NeuronCore-v2 Architecture, the NeuronCore that exists in Trainium, however it is still not implemented by the Neuron Compiler.”라고 언급되어 있습니다[10]. 이는 NeuronCore-v2 아키텍처(Inferentia2 및 Trainium에 포함)가 하드웨어적으로는 dynamic shapes를 지원하지만, Neuron 컴파일러에서는 아직 이 기능이 구현되지 않았음을 의미합니다.

최신 개발 현황

2024년 12월 발표된 Neuron 2.21 릴리스에서는 “NxD Inference”라는 새로운 기능이 추가되었으며, 이는 “PyTorch 기반 라이브러리로 vLLM과 통합되어 대규모 언어 및 다중 모달리티 모델의 배포를 단순화”한다고 설명되어 있습니다[1]. 그러나 이 기능이 완전한 dynamic tensor shape 지원을 포함하는지는 명확히 언급되어 있지 않습니다.

Dynamic Batching의 동작 원리

Dynamic batching은 배치 차원에 한해서만 동적으로 작동하는 기능입니다. 그 원리는 다음과 같습니다:

  1. 모델은 특정 배치 크기(예: 4)로 컴파일됩니다.

  2. dynamic_batch_size=True 옵션을 사용하면 컴파일된 배치 크기보다 더 큰 배치 크기(예: 12)로 입력을 처리할 수 있습니다.

  3. 프레임워크는 큰 배치를 컴파일된 크기의 작은 배치로 자동 분할하여 처리합니다[3].

이 기법은 프레임워크-Neuron 간 오버헤드를 숨기고 더 큰 배치 크기로 분산시켜 달성 가능한 처리량을 증가시킵니다[3]. 하지만 배치 차원 이외의 차원(높이, 너비 등)은 여전히 컴파일 시 고정되어야 합니다.

Dynamic Dimension 문제 해결을 위한 대안

완전한 dynamic tensor shape 지원이 없는 상황에서는 다음과 같은 대안을 고려할 수 있습니다:

1. 패딩(Padding)

가변 크기 입력을 최대 크기에 맞춰 패딩하는 방법입니다. 내부 블로그에서 언급된 것처럼, 임의의 너비나 높이를 가진 이미지를 고정된 크기로 패딩하여 처리할 수 있습니다.

2. 버킷팅(Bucketing)

유사한 크기의 입력을 그룹화(버킷팅)하고 각 그룹에 대해 최적화된 모델을 사용하는 방법입니다[9]. 이 방식은 계산 리소스 활용을 최적화하는 데 도움이 됩니다.

3. 모델 분할 전략

검색 결과[6]에서 언급된 사례를 보면, 모델을 여러 단계(stages)로 분할하여 각 단계에서 다른 차원의 입력을 처리하는 방법이 있습니다. 예를 들어:

Stage 1: [Num Patches, Num Channels, X Dim, Y Dim] -> [Num Patches, Embedding Size]
Stage 2: 첫 번째 단계의 출력을 입력으로 사용

4. DataParallel 활용

torch.neuron.DataParallel을 사용하면 여러 NeuronCore에 모델을 복제하고 데이터를 분산시켜 병렬 추론을 수행할 수 있습니다[11]. 이 기능은 dynamic batching을 포함하여 원래 컴파일되지 않은 배치 크기를 사용할 수 있게 해줍니다.

결론

현재 AWS Neuron SDK 2.21 버전에서는 완전한 dynamic tensor shape을 지원하지 않으며, 배치 차원에 한해서만 dynamic batching을 통한 유연성을 제공합니다. Inferentia2는 하드웨어적으로는 dynamic shapes를 지원하지만, Neuron 컴파일러에서 아직 이 기능이 구현되지 않았습니다. 다양한 크기의 입력을 처리하기 위해서는 패딩, 버킷팅, 모델 분할 등의 대안을 고려해야 합니다. 향후 Neuron SDK 업데이트에서 완전한 dynamic shape 지원이 추가될 가능성이 있으므로 최신 릴리스 정보를 지속적으로 확인하는 것이 좋습니다.

AWS Neuron SDK를 활용한 커스텀 모델 변환 및 검증 가이드

AWS Neuron SDK 개요

AWS Neuron SDK는 AWS Inferentia 및 AWS Trainium 기반 Amazon EC2 인스턴스에서 딥러닝 및 생성형 AI 워크로드를 실행하기 위한 소프트웨어 개발 키트입니다. 이 SDK는 컴파일러, 런타임, 훈련 및 추론 라이브러리, 그리고 모니터링, 프로파일링, 디버깅을 위한 개발자 도구를 포함하고 있습니다[5]. Neuron SDK는 특히 PyTorch, TensorFlow, JAX 등 주요 머신러닝 프레임워크와 기본적으로 통합되어 있어, 모델 변환 과정을 간소화합니다.

커스텀 모델을 AWS Inferentia2와 같은 하드웨어에서 실행하기 위해서는 Neuron SDK를 사용하여 모델을 재컴파일하는 과정이 필요합니다. 이 문서에서는 이 과정을 단계별로 안내하고, 변환이 올바르게 이루어졌는지 검증하는 방법을 제시합니다.

Case Writing

Supertone, a leading player in Voice AI technology, has developed a comprehensive Voice AI solutions, including voice generation, synthesis, and Text-to-Speech (TTS) services, all built upon their foundation model. Supertone’s AI workflow presents an interesting use case for the GPU-to-ASIC transition. While they utilize GPUs for training their foundation model and various fine-tuning processes, they identified a critical need for optimization in their real-time TTS service delivery. The key challenges were achieving optimal processing performance and managing costs effectively as their services scaled. To address these challenges, Supertone will strategically implement Inferentia2 for specific TTS model deployments and serving. (This decision aligns with the broader industry observation that ASICs and GPUs serve complementary roles in the AI infrastructure.) Supertone’s plans to expand ASIC(inferentia2) implementation to other models, following successful performance and cost validation.
