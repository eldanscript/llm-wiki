Lambda 코드 분석

얼굴 인식과 인덱싱 클러스터링 기능 분석

개요

이 프로젝트는 AWS 서비스를 활용한 얼굴 인식, 인덱싱 및 클러스터링 기능을 제공하는 솔루션입니다. 주요 구성 요소는 다음과 같습니다:

  1. 얼굴 인식 (Face Recognition): Amazon Rekognition을 사용하여 이미지에서 얼굴을 감지하고 인식합니다.

  2. 얼굴 인덱싱 (Face Indexing): 감지된 얼굴을 Rekognition Collection에 저장하고 관리합니다.

  3. 얼굴 클러스터링 (Face Clustering): 유사한 얼굴들을 그룹화하여 동일 인물을 식별합니다.

이 솔루션은 여러 Lambda 함수로 구성되어 있으며, 각 함수는 특정 작업을 담당합니다. DynamoDB 테이블(faceindexer)을 사용하여 얼굴 데이터를 저장하고 관리합니다.

Lambda 함수별 분석

1. Face Recognition Lambda

이 Lambda 함수는 이미지에서 얼굴을 감지하고 인식하는 역할을 담당합니다.

주요 기능:

  • 이미지에서 얼굴 감지

  • 유명인 인식 (Celebrity Recognition)

  • 얼굴 특성 분석 (성별, 나이 범위, 감정 등)

  • 감지된 얼굴 정보를 다음 처리 단계로 전달

처리 흐름:

  1. S3에서 이미지 로드

  2. Amazon Rekognition API를 사용하여 얼굴 감지

  3. 감지된 얼굴 정보 추출 및 처리

  4. 결과를 다음 단계(Face Embedding)로 전달

2. Run FaceAPI Lambda

이 Lambda 함수는 Amazon Rekognition API를 직접 호출하여 얼굴 관련 작업을 수행합니다.

주요 기능:

  • Rekognition Collection 관리 (생성, 조회)

  • 이미지에서 얼굴 검색 (SearchFacesByImage)

  • 유명인 인식 (RecognizeCelebrities)

  • 얼굴 인덱싱 (IndexFaces)

권한:

  • S3 버킷 접근 (ListBucket, GetObject, PutObject)

  • Rekognition API 호출 (DescribeCollection, SearchFacesByImage, RecognizeCelebrities, IndexFaces, DeleteFaces)

  • DynamoDB 테이블 접근 (Scan, Query, PutItem, UpdateItem, DeleteItem, BatchGetItem, BatchWriteItem)

3. Run Facenet Lambda

이 Lambda 함수는 딥러닝 기반 얼굴 임베딩(Face Embedding) 생성을 담당합니다. Facenet 모델을 사용하여 얼굴의 특징 벡터를 추출합니다.

주요 기능:

  • 얼굴 이미지에서 임베딩 벡터 생성

  • 얼굴 특징 추출

  • 클러스터링을 위한 데이터 준비

처리 흐름:

  1. 감지된 얼굴 이미지 로드

  2. Facenet 모델을 사용하여 임베딩 벡터 생성

  3. 생성된 임베딩 벡터 저장

  4. 클러스터링 단계로 데이터 전달

4. Update Face Indexer Lambda

이 Lambda 함수는 얼굴 인덱싱 데이터를 관리하고 업데이트하는 역할을 담당합니다.

주요 구성 요소:

  1. prepare-iterators: 얼굴 인덱싱 작업을 위한 반복자(iterator) 준비

    • 대량의 얼굴 데이터를 처리하기 위한 배치 작업 설정

    • 처리할 얼굴 데이터 목록 생성

  2. prepare-face-indexing-iterators: 얼굴 인덱싱을 위한 특화된 반복자 준비

    • Rekognition Collection에 인덱싱할 얼굴 데이터 준비

    • 배치 처리를 위한 데이터 구조화

  3. index-faces-to-collection: 얼굴을 Rekognition Collection에 인덱싱

    • S3에서 얼굴 이미지 로드

    • Rekognition IndexFaces API 호출

    • 인덱싱 결과를 DynamoDB에 저장

  4. face-indexing-iterators-completed: 모든 얼굴 인덱싱 작업 완료 처리

    • 인덱싱 작업 결과 확인 및 요약

    • 오류 처리 및 로깅

  5. import-collection: 기존 Rekognition Collection 가져오기

    • 기존 Collection 정보 로드

    • Collection 메타데이터 처리

  6. update-record: DynamoDB의 얼굴 레코드 업데이트

    • 얼굴 메타데이터 업데이트

    • 인덱싱 상태 관리

5. 얼굴 클러스터링 기능

얼굴 클러스터링은 유사한 얼굴들을 그룹화하여 동일 인물을 식별하는 기능입니다.

주요 구성 요소:

  1. prepare-face-embedding-iterators: 얼굴 임베딩 데이터 준비

    • 클러스터링을 위한 얼굴 임베딩 벡터 수집

    • 배치 처리를 위한 데이터 구조화

  2. cluster-face-embeddings: 얼굴 임베딩 클러스터링 수행

    • 유사한 얼굴 임베딩 벡터 그룹화

    • 클러스터링 알고리즘 적용 (거리 기반 클러스터링)

    • 클러스터 결과를 DynamoDB에 저장

  3. iterator-completed: 클러스터링 작업 완료 처리

    • 클러스터링 결과 확인 및 요약

    • 오류 처리 및 로깅

  4. job-completed: 전체 작업 완료 처리

    • 모든 처리 단계 완료 확인

    • 최종 결과 정리 및 보고

데이터 흐름

  1. 이미지 입력 → 얼굴 감지 (Face Recognition Lambda)

  2. 감지된 얼굴 → 얼굴 임베딩 생성 (Run Facenet Lambda)

  3. 얼굴 임베딩 → 얼굴 인덱싱 (Update Face Indexer Lambda)

  4. 인덱싱된 얼굴 → 얼굴 클러스터링 (Face Recognition Lambda의 클러스터링 컴포넌트)

  5. 클러스터링 결과 → DynamoDB 저장 (Update Face Indexer Lambda)

  • 컨테이너 이미지:

결론

이 솔루션은 AWS의 서버리스 아키텍처를 활용하여 확장 가능한 얼굴 인식 및 클러스터링 시스템을 구현했습니다. Amazon Rekognition의 얼굴 인식 기능과 커스텀 딥러닝 모델(Facenet)을 결합하여 강력한 얼굴 분석 기능을 제공합니다. 각 Lambda 함수는 특정 작업에 특화되어 있으며, 전체 시스템은 이벤트 기반 아키텍처로 구성되어 있습니다.

Facenet 대체 모델 검토

대체 가능한 얼굴 임베딩 모델

Facenet 대신 사용할 수 있는 얼굴 임베딩 생성을 위한 오픈 소스 모델들은 다양합니다. 각 모델은 정확도, 속도, 리소스 요구사항 등에서 차이가 있습니다.

1. ArcFace

  • 장점: Facenet보다 높은 정확도, 특히 대규모 얼굴 인식에서 우수한 성능

  • 특징: 각도 마진 손실 함수를 사용하여 얼굴 특징 간 구분을 최적화

  • 구현체: MXNET, PyTorch, TensorFlow 버전 존재

  • 논문: “ArcFace: Additive Angular Margin Loss for Deep Face Recognition”

2. InsightFace

  • 장점: ArcFace 기반으로 개발되었으며, 종합적인 얼굴 인식 파이프라인 제공

  • 특징: 얼굴 감지, 정렬, 인식, 속성 분석 등 통합 기능 제공

  • 구현체: PyTorch, MXNet 버전 제공

  • GitHub: InsightFace는 활발한 커뮤니티와 지속적인 업데이트 제공

3. VGGFace2

  • 장점: 대규모 데이터셋으로 훈련되어 다양한 포즈와 조명 조건에서 강건함

  • 특징: ResNet 및 SENet 아키텍처 기반 모델 제공

  • 구현체: Keras, TensorFlow, PyTorch 버전 존재

  • 논문: “VGGFace2: A dataset for recognising faces across pose and age”

4. DeepFace

  • 장점: Facebook에서 개발한 모델로 높은 정확도 제공

  • 특징: 다양한 얼굴 처리 기능을 통합한 라이브러리로 제공됨

  • 구현체: TensorFlow 기반 Python 라이브러리

  • GitHub: deepface 라이브러리는 여러 모델(VGG-Face, Facenet, OpenFace 등)을 통합 제공

5. SphereFace

  • 장점: 각도 기반 손실 함수를 사용하여 얼굴 특징 구분 최적화

  • 특징: 초구면(hypersphere) 임베딩 공간에서 얼굴 특징 표현

  • 구현체: Caffe, PyTorch 버전 존재

  • 논문: “SphereFace: Deep Hypersphere Embedding for Face Recognition”

6. CosFace

  • 장점: 코사인 마진 기반 손실 함수로 높은 정확도 제공

  • 특징: 클래스 간 마진을 최대화하는 방식으로 학습

  • 구현체: PyTorch, MXNet 버전 존재

  • 논문: “CosFace: Large Margin Cosine Loss for Deep Face Recognition”

7. MobileFaceNet

  • 장점: 경량화된 모델로 모바일 및 엣지 디바이스에 적합

  • 특징: 적은 파라미터로 높은 성능 제공

  • 구현체: TensorFlow, PyTorch 버전 존재

  • 논문: “MobileFaceNets: Efficient CNNs for Accurate Real-Time Face Verification on Mobile Devices”

8. AdaFace

  • 장점: 최신 모델로 다양한 품질의 이미지에서 강건한 성능

  • 특징: 이미지 품질에 적응적인 마진 기반 손실 함수 사용

  • 구현체: PyTorch 구현체 제공

  • 논문: “AdaFace: Quality Adaptive Margin for Face Recognition”

AWS Lambda 환경에서의 고려사항

AWS Lambda 환경에서 이러한 모델을 적용할 때는 다음 사항을 고려해야 합니다:

  1. 모델 크기: Lambda의 메모리 제한을 고려하여 적절한 크기의 모델 선택

  2. 추론 속도: Lambda의 실행 시간 제한을 고려한 빠른 추론 속도

  3. 정확도와 효율성 균형: 사용 사례에 맞는 정확도와 리소스 효율성의 균형

  4. 프레임워크 호환성: Lambda 컨테이너와 호환되는 프레임워크 선택

MobileFaceNet이나 경량화된 InsightFace 모델은 Lambda 환경에서 좋은 선택이 될 수 있으며, 특히 정확도와 속도의 균형이 필요한 경우에 적합합니다.

Face Collection과의 관계

Amazon Rekognition Face Collection: AWS 네이티브 기능 분석

Face Collection은 Amazon Rekognition의 공식 기능입니다

Face Collection은 Amazon Rekognition에서 공식적으로 지원하는 AWS 네이티브 기능입니다. Amazon Rekognition은 얼굴 정보를 저장하고 관리하기 위한 서버 측 컨테이너인 “Face Collection”을 제공하며, 이는 완전 관리형 서비스로 운영됩니다[1][2]. Face Collection은 개별 얼굴과 사용자(동일 인물의 여러 얼굴)를 모두 저장할 수 있으며, 얼굴의 수학적 표현인 face vector 형태로 데이터를 관리합니다[3].

핵심 API 및 기능 구조

1. Collection 관리 API

Amazon Rekognition은 Face Collection 관리를 위한 완전한 API 세트를 제공합니다[2]:

  • CreateCollection: AWS 리전에 새로운 컬렉션 생성[4][5]

  • ListCollections: 사용 가능한 컬렉션 목록 조회[2]

  • DescribeCollection: 특정 컬렉션의 세부 정보 확인[2]

  • DeleteCollection: 컬렉션 삭제[2]

2. 얼굴 관리 API

컬렉션 내 얼굴 관리를 위한 전용 API들[1][6]:

  • IndexFaces: 이미지에서 얼굴을 감지하고 컬렉션에 추가[1][6]

  • SearchFacesByImage: 입력 이미지로 컬렉션 내 일치하는 얼굴 검색[7]

  • SearchFaces: FaceId를 사용한 얼굴 검색[8]

  • ListFaces: 컬렉션의 얼굴 목록 조회[8]

  • DeleteFaces: 컬렉션에서 얼굴 삭제[2]

얼굴 인덱싱 메커니즘

IndexFaces 작업은 다음과 같은 정보를 유지합니다[1][6]:

  • 다차원 얼굴 특성: 얼굴 분석을 통해 추출된 다차원 정보를 컬렉션에 저장[1]

  • 메타데이터: 경계 상자, 신뢰도 수준, Amazon Rekognition이 할당한 ID(얼굴 ID 및 이미지 ID), 외부 이미지 ID[1][6]

중요한 점은 Amazon Rekognition이 실제 이미지 바이트를 저장하지 않는다는 것입니다[1][6]. 대신 얼굴의 수학적 특징만을 추출하여 벡터 형태로 저장합니다.

Media2Cloud와의 통합

Auto Face Indexer 구현

Media2Cloud는 Amazon Rekognition의 Face Collection 기능을 활용하여 Auto Face Indexer를 구현했습니다[11]. Media2Cloud의 웹 인터페이스에서는 다음과 같은 과정을 통해 Face Collection을 활용합니다[11]:

  1. FaceCollection 탭에서 새로운 컬렉션 생성

  2. 비디오나 이미지에서 얼굴을 찾아 경계 상자 조정

  3. 인물 이름 입력 후 Index Face 버튼으로 컬렉션에 등록

  4. Re-analyze 기능으로 새로 인덱싱된 얼굴을 사용하여 재분석

서버리스 아키텍처 통합

Media2Cloud는 AWS의 서버리스 프레임워크와 완전히 통합되어 있으며, Face Collection 기능도 이 아키텍처 내에서 작동합니다[12]. Lambda 함수, Step Functions, DynamoDB 등과 연계하여 자동화된 얼굴 인식 워크플로우를 구현합니다[12].

권한 및 보안

Face Collection 사용을 위해서는 다음 IAM 권한이 필요합니다[5][10]:

  • rekognition:CreateCollection: 컬렉션 생성

  • rekognition:TagResource: 컬렉션 태깅 (선택사항)

  • AmazonRekognitionFullAccess: 전체 Rekognition 기능 사용[13]

성능 및 제한사항

Amazon Rekognition Face Collection은 다음과 같은 특성을 가집니다[14]:

  • 향상된 성능: 최신 업데이트로 40% 더 많은 얼굴 감지 가능

  • 정확도 개선: 30% 더 정확한 얼굴 매칭 결과 제공

  • 오탐률 감소: 50% 감소된 잘못된 감지율

  • 컬렉션 크기: 단일 컬렉션당 최대 2,000만 개 얼굴 저장 가능

결론

Face Collection은 Amazon Rekognition에서 공식적으로 제공하는 완전 관리형 서비스입니다[1][2][5]. Media2Cloud는 이 네이티브 기능을 활용하여 Auto Face Indexer를 구현했으며, 별도의 커스텀 구현이 아닌 AWS의 표준 API를 사용합니다[11]. 이를 통해 안정성, 확장성, 보안성을 모두 확보하면서도 개발 복잡성을 최소화할 수 있습니다.
