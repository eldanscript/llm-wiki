    Media2Cloud v5 S3 저장소 구조 분석

    개요

    분석 대상: s3://so0050-0a48a6e54829-189427507247-us-west-2-proxy/6afcc483-e5d3-98d8-0ee6-d85efa02f3b6/_TEAM_A/

    Media2Cloud v5에서 처리된 미디어 파일의 완전한 분석 결과물들이 체계적으로 저장된 구조를 분석합니다.

    전체 폴더 구조

    _TEAM_A/
├── audio/                          # 오디오 처리 결과
├── frames-v2/                      # 비디오 프레임 추출 및 분석
├── mediainfo/                      # 미디어 정보
├── metadata/                       # 분석 메타데이터
├── raw/                           # 원본 분석 결과
├── timeseries/                    # 시계열 데이터
├── transcode/                     # 트랜스코딩 결과
└── vtt/                          # VTT 자막 파일

    상세 폴더별 분석

    1. audio/ - 오디오 처리 결과

    audio/0/
├── audio.flac                     # 추출된 원본 오디오 (FLAC)

    주요 특징:

    • 다양한 오디오 포맷 지원 (FLAC, M4A, WAV)

    • AI 기반 오디오 향상 기능

    • 화자 분리 및 임베딩 생성

    • EBU R128 표준 라우드니스 측정

    기술적 특징

    Face Indexing 구현

    • 얼굴 그룹: 4개 클러스터로 분류

    • 임베딩 크기: 6MB (고차원 벡터)

    • 메타데이터: 성별, 나이대, 신뢰도 포함

    • 시계열 추적: 타임스탬프별 얼굴 등장 기록

    비디오 분석 파이프라인

    • 프레임 추출: 60fps 간격 샘플링

    • 샷 감지: 자동 경계 감지

    • 장면 분할: 의미적 장면 구분

    • 유사도 분석: 프레임 간 시각적 유사성

    오디오 처리 파이프라인

    • 다중 포맷: FLAC, M4A, WAV 지원

    • 화자 분리: AI 기반 스피커 구분

    • 음질 향상: 노이즈 제거 및 향상

    • 라우드니스: EBU R128 표준 측정

    이 구조는 Media2Cloud v5의 완전한 미디어 분석 생태계를 보여주며, 각 단계별 결과물이 체계적으로 저장되어 재사용 가능한 형태로 관리됩니다.

    감지된 유명인들:

    • ₩uNo (2명) - 77.15%, 80.11% 매칭 신뢰도

    상세 분석 데이터:

    • 감정 분석: 8가지 감정 (CALM, HAPPY, ANGRY, SURPRISED, DISGUSTED, CONFUSED, SAD, FEAR)

    • 얼굴 랜드마크: 5개 주요 포인트 (양쪽 눈, 코, 입 양쪽 끝)

    • 포즈 분석: Pitch, Roll, Yaw 3축 회전각

    • 품질 평가: 밝기(0100), 선명도(0100)

    • 미소 감지: 신뢰도와 true/false 값

    • 배치 처리: 여러 얼굴을 하나의 이미지로 합성하여 API 효율성 극대화

    • 풍부한 메타데이터: 단순 얼굴 감지를 넘어 감정, 포즈, 품질까지 종합 분석

인식 성능 개선

Rekognition 설정

  • Confidence threshold : 80 → 90

Face Indexer 설정

  1. 임계값 상향 조정

    • 현재: 80% → 개선: 85~90%

    • 즉시 적용 가능, 비용 없음

  2. 품질 필터링 강화

    • 밝기: 30~90 범위로 제한

    • 선명도: 25 이상으로 제한

    • 얼굴 크기: 80x80 픽셀 이상

  3. 포즈 각도 제한

    • Pitch: ±25도 이내

    • Roll: ±20도 이내

    • Yaw: ±30도 이내ㅅ
