NAVI Project 회고 @February 4, 2025

구축 Workflow 정리

  1. Basic QnA 검색 응답 (30% 처리)

    1. 수행 작업 : 명확한 응답이 가능한 질의에 대해서 사전에 Dynamo DB에 등록한 내용을 검색

    2. LLM 입력 : 사용자 질의 요약, Category Dictionary (Cateogry Key : Description)

    3. LLM 출력 : Category Description 유사도로 Matching Cateogry Key

    4. 현 수준

      1. Description의 matching 수준

        1. ‘요청 요약과 키워드 검색가 명확한지’라는 Prompting 문구를 사용하여 매칭 수준 설정

        2. No matching case 응답 하도록 가이드

      2. Mis-matching 발생

        1. 해당 되지 않는 질의에 대해서 No matching case로 적절하게 응답 하고 있음

        2. Matching 되는 답변에 오류는 거의 없음

  2. FAQ 문서 조회 응답 (60% 처리)

    1. 수행 작업 : FAQ 문서에서 유사 질문에 대한 답변 검색

      1. FAQ 문서 : 기존에 질의한 내용들을 Best 답변으로 교정하여 Category 별로 저장한 질의 응답 사례

      2. FAQ 문서는 CSV 형식으로 변환하여 KB 소스 데이터로 등록

      3. FAQ 문서 field (column)

        1. Contents Field : Question

        2. Metadata Field : Category, Title, Answer

    2. KB 조회 입력 : 사용자 질의 string

    3. KB 응답

      1. 매칭되는 Question과 metadata

      2. Metadata의 Answer field를 질의 응답으로 사용

      3. Answer field를 Claude Sonnet을 사용하여 사용자 답변으로 재 정리하여 최종 응답으로 전달

    4. 현 수준

      1. 대체적으로 유사한 질의를 찾아내어 등록된 답변을 제대로 전달하고 있음

      2. 질문의 내용과 매칭 되지는 않는데 유사한 단어가 있는 경우 매칭된 내용으로 답변하는 경우 발생

  3. 사내 HR 문서 조회 응답 (10% 처리)

    1. KB에 저장된 사내 문서들의 내용에서 질의에 대한 응답 내용 검색

    2. 검색된 사내 문서 내용을 Claude Sonnet을 사용하여 사용자 답변으로 재 정리하여 최종 응답으로 전달
