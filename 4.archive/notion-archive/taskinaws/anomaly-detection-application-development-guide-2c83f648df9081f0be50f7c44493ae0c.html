Introduction

  • Kinesis Data Generator나 Prod data를 직접 Kinesis Data Streaming을 입력시킨 후 실시간으로 Application 개발

Run DemoSet

💡

전체 과정은 Anomaly Detection DemoSet Build Guide 문서와 동일합니다. Kinesis Data Analytics Application을 콘솔에서 직접 작업을 하게 됩니다.

1. Create Analytic Application

  • Kinesis 콘솔에서 Data Analytics를 선택한 후 create application을 클릭합니다.

  • Application을 설정합니다.

    • Application name을 입력합니다.

    • Runtime은 SQL을 사용합니다.

    • Create application을 클릭하여 다음 단계로 넘어 갑니다.

2. Connect Streaming Data

  • Data Source를 설정합니다.

  • Kinesis data stream을 선택하면 연결 가능한 Kinesis data stream을 보여 줍니다. 연결할 Input Stream을 선택합니다.

    • Record pre-processing with AWS Lambda

      • Input Stream에 대해 사전 처리가 필요하면 AWS Lambda를 구성하여 사용 합니다.

3. Discover Schema

  • Input Stream을 선택하면 Schema 항목이 활성화 됩니다.

  • Analytic 작업을 위해서 Input Stream에 대한 Schema가 정의되어야 하기 때문에 Discover schema를 실행합니다.

  • Data Input Stream이 정상적으로 입력되고 있으면 다음과 같이 Schema를 생성하여 표시합니다.

    • Schema의 변경이 필요하면 ‘Edit schema’를 선택하여 Column을 삭제하거나 추가, 변경 합니다.

    • Schema가 확정되면 ‘Save and continue’를 선택하여 다음 단계로 넘어갑니다.

4. Go to Real time analysis - SQL edit

  • SQL editor를 사용하여 필요한 Application의 코딩 작업을 할 수 있습니다.

  • Yes, start application - 팝업 메뉴에서 Application을 기본 SQL 코드로 실행하면서 시작할 수 있습니다.

    • 기본 SQL 코드는 Input Stream을 이전 단계에서 생성한 Schema에 맞춰 Data를 Query 하는 것 입니다.

    • Kinesis Input Streaming으로 data가 입력된 timestamp가 추가 됩니다.

5. Add Anomaly Detection code from template

  • 기본 Anomaly Detection code template을 제공하고 있습니다. 이 template을 이용하여 SQL 코드를 시작합니다.

  • Sample Code에서 Analytics를 진행할 column 명을 입력해 줍니다.

6. Run Application and get anomaly score

  • SQL 코딩이 완료되면 ‘Save and run SQL’을 선택하여 Analytics application을 시작합니다.

7. Create Output Stream

  • Application 작업이 완료되면 Destination을 연결 시켜 줍니다.

  • Stack으로 생성한 Anomaly Output Stream을 선택합니다.
