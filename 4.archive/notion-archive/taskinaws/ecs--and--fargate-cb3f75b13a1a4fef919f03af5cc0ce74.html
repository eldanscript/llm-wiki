What is a container

  • Package application’s code, configurations, dependencies into a single object : 애플리케이션 코드, 설정, 의존성을 하나의 오브젝트로 패키징

  • Share an OS installed on the server : 서버에 설치된 OS 환경을 공유

  • Run as resource-isolated process, ensuring quick, reliable and consistent deployment, regradless of environment : 실행 환경과 관계없이 리소스가 격리되어 있는 처리, 빠르고 안정적이며 일관된 배포가 가능하게 됨

What is Docker

  • A containerization platform : 컨테이너 플랫폼이다

  • Package application and dependencies together in the form of container : 컨테니어 형식으로 애플리케이션과 의존성을 패키지 한다

  • Package software into standardized units called containers that have everything needed to run including libraries, system tools, code and runtime : 컨테이너라고 하는 규격화된 단위로 소프트웨어를 패키지 한다. 이 패키지에는 라이브러리, 툴, 코드, 런타임 환경이 포함된다.

Why container

  • Powerful to package and deploy application : 애플리케이션 패키지 생성과 배포를 위한 강력한 방법이다

  • Provide a consistent, portable software environment for application : 일관되고 이식성이 있는 애플리케이션 환경을 제공한다

  • Speed, Workload isolation, Single artifact to test from local to production, avoid drift : (여러 가지 의미에서 - 개발 속도, 배포, 시험) 빠르다, 애플리케이션 별 리소스를 격리할 수 있다, 단일 산출물로 로컬에서 프로덕트까지 시험이 가능하다

    • configuration drift : 예상되지 않은 변경사항, 문서화 되지 않은 스테이징과 프로덕션 환경 간의 차이로 소프트웨어 배포(release)가 중단 되는 것을 말한다

Amazon ECS

  • Allow to run and scale containerized applications on AWS : AWS 환경에서 컨테이너 애플리케이션을 구동하고 확장 할 수 있는 서비스 이다

  • Highly scalable, high-performance container orchestration service : 확장성이 뛰어난 고성능의 컨테이너 오케스트레이션 서비스 이다.

  • Eliminate the need to install and operation your own container orchestration software, manage and scale a cluster of VMs or schedule containers on VMs : 고유한 오케스트레이션 소프트웨어를 설치하고 운영할 필요가 없고, VM에 클러스터를 관리하고 확장할 필요가 없으며, VM에 컨테이너를 스케쥴링할 필요가 없어진다. ECS에서 관리해 준다.

  • Deeply integrated into the rest of AWS ecosystem : AWS 환경과의 강력한 통합을 제공한다

    • AutoScaling

    • Load Balancing

    • IAM

    • Networking

    • Logging

    • Monitoring

Cluster

  • Logical group of tasks or services : 작업 혹은 서비스에 대한 논리적 그룹이다

  • If use EC luanch type, a cluster is a grouping of container instances

  • If use capacity provider, a cluster is a logical grouping of capacity providers

  • Can be a combination of Fargate and EC2 launch type

Task Definition

  • A text file in JSON format : JSON 형식의 테스트 파일로

  • Describes one or more containers ( up to a maximum of ten) that form application : 애플리케이션을 구성하는 단일 혹은 여러개의 컨테이너를 기술하고 있다. (최대 10개 컨테이너)

  • A blueprint for application : 애플리케이션의 청사진 이다

  • Launch type, network port, data volume used with the containers in the task : 작업의 컨테이너에서 사용되는 실행 타입, 네트워크 포트, 데이터 볼륨에 대해 기술한다

Task and scheduling

  • Task is the instantiation of a task definition within a cluster : 클러스터에서 작업 정의서를 개체화(인스턴스화) 한 것이 작업이다

  • Can specify the number of tasks that will run on cluster : 클러스터에서 실행 될 작업 수를 특정할 수 있다

  • Task scheduler is responsible for placing tasks within cluster : 클러스터에서 작업 배치를 책임지는 것이 작업 스케쥴러 이다

    • Define a service that runs and maintains a specified number of tasks simultaneously : 지정된 수의 작업을 동시에 실행 및 유지 관리하는 서비스 정의

Services

  • Allow to run and maintain a specific number of instances of a task definition simultaneously : 지정된 수의 작업 정의의 인스턴스를 동시에 실행 및 유지 관리할 수 있게 한다

  • Optionally run service behind a load balancer : 선택적으로 로드 밸런서 아래에서 서비스를 구동할 수 있다

  • Service scheduler strategies

    • Replica

      • 클러스터에 원하는 작업 수를 배치하고 유지

      • Spread tasks across AZ

      • Can use task placement strategies and constraints

    • Daemon

      • 작업 배치 제약을 모두 충족하는 각 활성 컨테이너 인스턴스에 한 작업씩 정확히 배포

      • No need to specify a desired number of tasks

Fargate

  • Allow to run containers without having to manage servers or clusters : 서버나 클러스터를 관리하지 않고 컨테이너를 운영할 수 있게 한다

  • No longer have to provision, configure, and scale cluster of VM to run containers

Service Discovery

  • Containers are immutable by nature : 컨테이너는 본질적으로 불변입니다 → 정기적으로 이탈(churn)하고 최신 버전의 서비스로 교체할 수 있습니다.

  • Need to register the new and deregister the old/unhealthy services → Need for service discovery : 새로운 버전을 등록하고 오래되고 정상 동작하지 않는 서비스를 정지 시키기 위해 Service Discovery가 필요하다

  • AWS Cloud Map : a cloud resource discovery service

    • Define custom names for application resources

    • Maintain the updated location of dynamically chaning resources

    • Increase application availability : 애플리케이션 가용성을 증가 시킨다

ECS Networking Mode & Load Balancer

awsvpc networking mode

  • Cloud native networking for Amazon ECS containers

  • Allocate an ENI to each running task

  • Providing a dynamic private IP address and internal DNS name

  • Task is allocated its own ENI and a primary private IPv4 address

  • Task and EC2 instances have same networking properties

  • Allowing tasks to run with full networking features on AWS like EC2 instances

Load Balancer

  • Can’t attach more than 5 target groups to a service

  • Tasks using awsvpc : IP target type
