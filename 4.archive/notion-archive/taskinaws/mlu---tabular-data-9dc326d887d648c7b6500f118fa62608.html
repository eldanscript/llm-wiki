ML Lifecycle / Data Analysis / Basic Application

Tabular Data

  • Contain information in a tabular way : data is stored in rows and columns (테이블 형식 - 행과 열에 데이터를 저장하는 방법으로 정보를 가지고 있음)

ML Applications

  • Ranking - Relevant thing (관련된 것)

  • Classification - Categorize an item (분류 하는 것)

  • Clustering - Group or cluster similar thing (유사한 것을 묶는 것)

  • Recommendation - Interested in (관심 있는 것)

  • Regression - Predict a numerical value (숫자로 예측 하는 것)

  • Anomaly Detection - Find uncommon/novel thing (흔하지 않은 것을 찾는 것)

What is Machine Learning?

  • Data Science : multi-disciplinary field that use scientific methods, processes, algorithms and system to extract knowledge and insights from structured and unstructured data

  • ML is teaching a machine to learn how to do a task through algorthms that can **learn from experience** without relying on rules-based programming

  • Provide some code (ML algorithm) and DATA

    • code instruct the machine how to learn and extract the RULES from the DATA & ANSWERS

    • Machine-infered / Machine-Learned RULES → trained ML model

Why ML?

DATA

  • Larger amounts of data, easy to produce, collect and store

COMPUTE

  • Powerful processing units, hardware acceleration, prarallelization

ALGORITHM

  • ML frameworks, libraries, improved and more efficient techniques

ML Lifecycle

ML Terms

Supervised / Unsupervised Learning

Supervised Learning

  • 지도 학습 - Learning from some labeled data

Unsupervised Learning

  • 비지도 학습 - Learning using data without labels (unlabeled data)

No free lunch theorem

  • Variety of ML algorithms to solve the same type of problem

  • Certain algorithms tend to perform better than others with certain types of data

  • No single algorithm outperforma all others on all problem : 모든 문제에서 다른 알고리즘을 능가하는 단일 알고리즘은 없다

  • Choose a few algorithm (data type에 대해 잘 동작하는 것으로 알려진 것들) → Select the best-performing one

  • Narrow down initial choices by dividing ML algorithms into categories based on the task

Supervised Learning - Regression

  • Learn relationships and correlations between input features and a **continuous** output variable → **Predicting the continuous output variable**

  • Algorithms

    • Linear Regression

    • KNN (K-Nearest Neighbor)

    • Decision Trees

    • Neural Network

Supervised Learning - Classification

  • Learn relationships between input features and a output variable with the scope of **separating the data into classes / groups**

  • Regression과의 차이

    • Regression output variable : Numerical and Continuous

    • Classification output variable : Categorical and Discrete

  • Algorithms

    • Logistic Regression

    • SVM (Support Vector Machine)

    • KNN

    • Decision Tree

    • Neural Network

Unsupervised Learning - Clustering

  • Determine how many clusterst to extract → a judgement call (정해진 규칙이나 원칙이 없다)

  • Algorithms

    • K-means Clustering

Model Evaluation

Regression Metrics

  • Error : Differences between the target value (y’s) and the predicted value (y_hat)

  • MSE (Mean Squared Error)

    • penalizes even the smallest errors

    • lead to over-estimation of how bad the model is

  • **RMSE** (Root Mean Squared Error)

    • Widley used for regression

    • Report the errors in the original unit → easier to interpreted the error

  • MAE (Mean Absolute Error)

    • More **robust to outliers**

    • doesn’t penalize the errors as extremely as MSE

  • R Squared (R2)

    • Help compare regression model with a constant average baseline model → tell how much better the regression is vs baseline model

    • R2 = 0 → Same error all over the baseline model

    • R2 = 1 → No errors between teh predicted values and the regression tasks

Classification Metrics (Binary Classification)

  • Confusion Matrix

    • reflecting the fact that the classifier is sometimes confused and make mistakes

    • Extract numerical scores from the CM → Compare and discuss

  • Accuracy (정확도)

    • Sum up the number of times correct prediction and total number of data

    • 1 → Highest accuracy score

    • High Accuracy Paradox

  • Precision (정밀도)

    • Accuracy of the predictived positive outcomes : 참으로 예측한 값의 정확도

    • TP에 집중 → 낮은 Precision은 높은 FP를 의미

    • 예) TP가 낮으면 건강한 사람을 병이 있다고 판단해 불필요한 진단, 치료를 하게 됨

  • Recall (재현률)

    • Model’s ability to predict a positive outcome

    • 예) FN이 높으면 병을 가진 사람을 찾지 못해 진단이나 치료를 받지 못하게 될 것

  • F1 Score

    • Case에 따라 Precision이 중요하거나 (FP를 줄여야 하는 경우 - 불필요한 진단)

    • Recall이 중요할 수 있다 (FN을 줄여야 하는 경우 - 환자를 못 찾는 경우)

    • 두 가지 요소에 대한 균형을 위해 조화 평균 값을 사용 → F1 Score

    • Low F1 → Low one or both of Precision and Recall

    • High F1 → High both of Precision and Recall

Training-Validation and Test Datasets

  • ML training 으로 일부 데이터에 대한 모델을 구축하고 향후 유사한 데이터 세트에 사용하려는 것을 미리 알고 있습니다.

  • Learning의 범위는 보았던 것을 반복하고 잘 배우는 것이 아니라 학습한 것을 보이지 않는 비슷한 데이터로 일반화하는 방법이다.

  • Training 성능/에러 보다는 Test 성능/에러가 중요 → Dataset을 training과 test로 분리

Cross - Validation

  • K-fold CV : Model Train과 Validation을 동일한 dataset을 바탕으로 여러번 (K번) 수행할 수 있는 방법을 제공

Underfitting

  • Poorly on training and validation (test)

  • High bias → lack of fit in certain regions

Overfitting

  • Memorize or imitates training data → fail to generalize on new ‘unseen’ data

  • Model is too complex, pick up noise instead of the patterns of training data

Good Fit

  • Not too simple, not too complex

  • Pick up the underlying relationship rather than the noise in the training data

Exploratory Data Analysis (EDA)

Descriptive Statistics

  • 기술 통계 - 자료를 요약하는 기초 통계로 데이터의 주요 특징을 양적으로 기술하는 것 → head(), summary(), describe()

  • Univariate statistics (단변량 분석)

  • Multivariate statistics (다변량 분석) - 여러개의 feature를 동시에 분석, feature (변수)간 연관성

Univariate Statistics

  • Histogram or Bar Plot

  • one single feature (numerical or categorical)

  • group the data in bins → provide a count of the number of observations in each bin

  • Shape of Histogram → observe the distribution

    • Gaussian, Skewed, Exponential

    • Unimodal (단봉), multimodal (다봉)

  • See possible outliers

  • Identify imbalanced datasets

Multivariate Statistics

  • Correlations - Scatter Plots

  • Correlations Matrix

    • -1 : perfect negative correlations

    • 1 : perfect positive correlations

  • Highly correlated features might degrade performance of some ML modes (linear, logistics regression) → Select one of the correlated features and discard the other

Class Imbalance

  • Common problem in ML (specifically in classification)

  • In a credit card fraud detection problem, very few classes are fraud transaction

  • How address class imbalance problems

    1. Down-sample the dominant class → match the size

    2. Up-sample the rare class → randomly duplicating observations from the rare class, resample with replacement

    3. Data generation / Create Synthetic Sample (Data Augmentation) → close cousin of up-sampling

    4. Sample weights → assigning higher weights to rare class and lower weights to dominant class

Missing Data

  1. Drop rows and/or columns with missing value

    1. Depending on how many values are and how are distributed → Removing those rows, columns from the dataset

    2. Might lead to less training data samples, less features to build model → Lead to overfitting or underfitting

  2. Impute (fill-in) the missing values

    1. Average imputation on missing numerical values

      1. Using Pandas functions: df[‘col’].fillna((df[‘col’].mean())) : replace with the average value in the column

    2. Common point imputation on missing categorical values

      1. Using Pandas functions: df[‘col’].fillna((df[‘col’].mode()))) : Replace with the most common value for that column

    3. Placeholder

      1. Using Pandas functions: df[‘col’].fillna(‘missing’)) : Assign a common value for missing data location

    4. Advanced imputation

      1. Predict missing values from complete samples using ML techniques

      2. AWS Datawig uses NN to predict tabular data mssing values

KNN (K-Nearest Neighbors)

  • Predicts new data points based on K similar records from a dataset

  • Example) Dataset x1, x2 → classify a new data point, represented by the ? character

  • Assume K = 3

  • To find K closest data points, calculate the distance from all data points

  • Get the K closest data points

  • Use the majority class as the result → ? classified as orange

KNN in SKlearn

  • KNeighborsClassifier : Sklearn classifier implementing the KNN vote

    • parameter : n_neighbors, distance metric

KNN - how to choose the ‘K’

  • number of neighbors(K) - hyperparameter need to choose at the time of model building

  • have to find what value of K works best by using a validation set → train different KNN models with different K values

  • Low K (K = 1) : overfitting. predictions are greatly impacted by noise in the data like outliers, mislabeling

  • Large K (K = n) : underfitting. rare class가 항상 다른 class보다 우선하게 된다

  • Rule of thumb (K = sqrt(n)) : Robust to noise. neighborhoods can get too inclusive (포괄적) → 경험상 최적의 값

Curse of dimensionality

  • High dimensional feature space → too many features

  • Computationally expensive : finding the neighbors and storing the entire training data

  • Fast algorithms for finding Nearest Neighbors → reduce the computational load

KNN Pros

  • Simple to understand and easy to implement

  • Useful tool for off-the-bat (즉시) analysis of some dataset before planning to run more complex algorithm

  • Works as easily with multiclass data sets whereas other algorithms are hardcoded for the binary setting

  • Non-parametric nature of KNN gives it an edge in certain settings (특정 설정에서 우위를 제공) where the data may be highly ‘unusal’

KNN Cons

  • One of the obvious drawback (단점) : computationally expensive

  • 매우 빠른 테스트 단계에도 불구하고 (albeit a very fast testing phase) 긴 training 단계를 가지는 더 정교한 Neural Network 과 KNN 사이의 엄격한 이분법 (rigid dichotomy)을 주목

  • Can suffer from skewed calss distribution : if a certain class is very frequent in the training set → tend to dominate the majority voting of the new example

  • The accuracy can be severly degraded with high-dimension data

Feature Scaling

  • Unit difference causes Distance-Based algorithms (KNN…) to not perform optimally → Necessary to rescale features that different units to have same scale/units

  • Example) x1 : age ( 1 ~ 100), x2 : height (1 ~ 10 ft)

    • Unscaled : blue datapoint distance is 5, orange datapoint distance is 2 → classified as orange

    • Scaled : blue datapoint distance is 0.05, orange datapoint distance is 0.2 → classified as blue

  • Sensitive algorithms to features being on different scales

    • Metric-based algorithm : KNN, K-means

    • Gradient descent-based algorithm : Regression, Neural Network

  • Not sensitive on different scales

    • Tree-based algorithm

    • Feature Scaling Method

      • Mean/Variance standardization

      • MinMax scaling

Piepeline in SKlearn

  • SKlearn sequential data transforms with a final estimator

  • Prevent data leakage from test into training

  • Pipeline class allows sticking multiple processes into a single scikit-learn estimator

  • .fit()

    • X_train goes through imputation : missing value를 각 numerical feature의 평균값으로 대체

    • Then, goes through minmax scaling : min, max of numerical value

    • Use transformed X_train to train KNN model

  • .predict()

    • X_test goes through imputation : missing value를 각 averages as learned from X_train 값으로 대체

    • Then, goes through minmax scaling : min, max values as learned per X-train

    • Use transformed X_test to make prediction
