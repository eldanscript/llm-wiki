Interview 진행

2022-7-20

  • 인터뷰어 확인과 단계 안내

  • 인터뷰에서 진행하는 내용에 대해 간략하게 소개

  • STAR 방식 소개

    • FeedBack 포함되면 좋음

    • Action, Result를 강조

  • 인터뷰 진행 순서 안내

  • 인터뷰이 소개

    • SW 및 AIML 엔지니어

    • 자율 주행 솔루션 중 정밀 지도 개발을 위한 도로 위 객체 인식, 추출 알고리즘 개발

    • 여러 도메인 데이터를 통합, 관리를 위한 통합 프로세스 개발과 연구를 진행

  • 간단한 솔루션으로 해결한 복잡한 문제의 경우가 있는지?

    • 멀티 센서 기반의 데이터 포맷 연구에서 라이다와 이미지간 정합 문제

    • 파라미터 매칭 시 진동, 사람 무게 등으로 정합 매칭 문제가 발생 → 딥러닝으로 파라미터 추정할 경우 학습 데이터에 핏하게 되거나 여러 가지 변화를 대응하지 못함 → Lidar의 측정값에 카메라 영상의 색상을 입힌 Colorization을 도입하여 문제를 개선

    • 아이디어 제공 → PM이 판단 → 본인이 proto-typing 시도

    • 발상의 배경 : 기술 블로그를 통해 흑백 영상에 칼라를 포함시킨 내용을 접하게 되어 적용

    • MMS 차량 : 카메라 파라미터, 라이더 위치 좌표를 취득 → 진동으로 카메라 캘리브레이션이 변경, 사람 탑승으로 인해 차량의 높이가 낮아짐

    • 정량화된 결과 : 사람 눈으로 확인할 수 있는 주관적인 지표로 Back-progration 결과에 대해 정량적으로 확인

  • 진행했더 일 중에서 혁신적인 었던 일이 무엇이었는지?

    • MAC : 도로 객체 추출 알고리즘을 진행 → 차선 추출 알고리즘 개발 진행

    • 기존 차선 추출 로직에 딥러닝 이용한 Vision AI 도입 → 정확도에 대한 우려

    • 기존 딥러닝 방식에서 point cloud를 이용한 방식은 정확도가 떨어지고 있어 2D image화 시키게 되면 인식률 향상

    • 세그먼트 방식 보다는 인스턴스 방식의 세그먼트를 도입 : MASK-RCNN 적용 하여 성능 인식률 50~60% 향상

  • 업무 능력 향상을 위해 더 높은 전문 지식 수준을 습득하기 위해 노력한 경우는

    • Multi sensor 기반 3차원 객체 추출에서 기존 렌더링 (Voxel, Point Cloud)에 Texture를 입히는 방식이 많은 컴퓨팅 파워를 필요로 함

    • 렌더링 자체에 딥러닝을 활용하는 Rough 방식의 기술 → 속도에서 50배 이상 향상

  • 직장에서 업무 효율성을 향상 시키기 위해 노력한 내용이 있는지?

    • 팀에 도움이 되는 논문을 요약하고 소개하는 작업을 진행

    • 컨플루언스 도구와 위키 사용

  • 멀티 센서 텍스쳐 영상 데이터를 스티칭 하는 작업에서 문제점이 카메라 진동이나 탑승자의 수에 따라 오차가 많이 발생 버드 아이 뷰로 투영한 영상을 이어 붙이는 작업 진행 → 카메라 이미지 왜곡으로 연결이 매끄럽지 않아 문제가 발생
