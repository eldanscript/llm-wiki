SageMaker JumpStart

Description

  • A powerful feature within the Amazon SageMaker machine learning platform - quickly and easily incorporate cutting-edge machine learning techniques

  • Provides developers with a comprehensive hub of state-of-the-art (SOTA) language, vision, and other modalities’ deep learning models

  • Hundreds of built-in algorithms and pre-trained models from leading model hubs and providers tailored in all the most popular machine learning frameworks like PyTorch, HuggingFace, TensorFlow and more.

  • Over 600 pre-trained models available

  • Comes with a low-code user interface that makes it easy to get started with deep learning, even for those without extensive machine learning expertise

  • Provides solution templates for common use cases, as well as executable example notebooks that demonstrate best practices for machine learning with SageMaker

JumpStart Foundation Model Hub

Description

  • A model hub or zoo for SOTA deep learning models tailored for a wide range of advanced text and image generation use cases

  • Public models

    • stability.ai : Text2Image, Upscaling

    • Alexa : AlexaTM, 20B

    • HuggingFace : Flan T-5 models, DistilGPT2, GPT2, Bloom models

  • Proprietary models (자체 모델)

    • co:here : Cohere generate-med

    • Lighton : Lyra-Fr

    • AI21 labs : Jurassic-1, Grande 17B

  • LLMs excel in standard benchmarks and are capable of solving a wide range of problems such as text-to-image generation, text summarization, abstractive question answering, sentiment analysis, and entity extraction, among others

  • These LLMs excel in standard benchmarks and are capable of solving a wide range of problems such as text-to-image generation, text summarization, abstractive question answering, sentiment analysis, and entity extraction, among others. They come with a user-friendly playground that allows developers to interactively test different flavors of the models and generate outputs with different generation configurations.

  • Access these models via APIs or through SageMaker Studio, and fine-tune or deploy them for your domain-specific use cases with just a few clicks in a no-code fashion, or via APIs

  • High-code execution style - come with all the benefits of SageMaker training and hosting and allow you to create endpoints that are automatically enabled for resiliency, scalability, load balancing, and fault tolerance

  • Tightly integrate with all SageMaker components and AWS services for seamless integration into your existing workflows

Bedrock vs JumpStart

  • Stable Diffusion 2/2.1는 Jumpstart에서 제공하지만, Bedrock은 Stable Diffusion 2.2를 제공합니다. (2.2는 비공개 모델)

  • Anthropic의 Cluade는 Bedrock 에서만 지원

  • Titan의 경우 Fine-tune/filter model을 통해 hallucination 을 억제할 수 있다고 말하는데, S3를 통한 training data set과 prompt외에도 또 다른 수단을 제공하는 것인가요?
