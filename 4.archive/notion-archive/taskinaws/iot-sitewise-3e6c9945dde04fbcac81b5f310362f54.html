AWS IoT SiteWise

💡

Data will only be ingested into SiteWise if your assets’s properties match a data stream.
If you are sending /A/Data/Stream but did not configure an asset property to match that stream data will not be ingested into SiteWise

Data Ingestion

  • Through a SiteWise gateway

    • Retrieves from connected OPC-UA servers

    • Directly by SiteWise PUT API

  • Using AWS IoT Rules

Setup SiteWise Gateway

  • Gateway software exists as an AWS IoT Greengrass Connector

SiteWise Connector

  • collects data from OPC-UA servers and publishes to AWS Cloud

  • can collect, organize, and analyze data from industrial equipment at scale

  • can connect to multiple OPC-UA servers

  • select the data streams you want to upload to the AWS Cloud

  • publish equipment data to relevant asset properties in AWS IoT SiteWise

  • configure assets in AWS IoT SiteWise to apply mathematical and statistical operations that process individual data points

  • analyze data over specified time intervals

  • gain insights about your industrial operation - calculating metrics such as overall equipment effectiveness (OEE)

  • If the Greengrass core loses connection to the internet, this connector caches data until it can successfully connect to the AWS Cloud

  • The connector batches OPC-UA data streams to reduce bandwidth between your Greengrass device and the AWS Cloud

  • Requirements

    • AWS Greengrass Core Software v1.10.2

    • Java 8 Runtime installed on the core device

    • Stream manager enabled on Greengrass group

    • An IAM policy added to the Greengrass Group role that allows the iotsitewise:BatchPutAssetPropertyValue action

Configure a SiteWise gateway

  1. add a SiteWise gateway

  2. add OPC-UA server sources to gateway

Create a SiteWise Gateway

  • Move to SiteWise console → Gateways

  • Create gateway

    • name : sitewise-workshop-Gateway

    • Greengrass group : SiteWiseGroup

  • Gateway is marked as Active gateway and Data stream upload Enabled

Configure the gateway

  • Manage → View details

  • Add Source

  • Config OPC-UA source

    • Name : Node-OPC-UA on localhost

    • Local endpoint : opc.tcp://localhost:26543

  • Config OPC-UA nodes

  • Add source → In sync

  • Check the gateway log

    • /greengrass/ggc/var/log/user/[AWS_REGION/]aws/

    • swCollector.log

    • swPublisher.log

💡

You might see error messages containing Failed to start OPC-UA Connection for Source Node-OPC-UA on localhost. This is a normal behaviour as you have not yet a running OPC-UA server.
