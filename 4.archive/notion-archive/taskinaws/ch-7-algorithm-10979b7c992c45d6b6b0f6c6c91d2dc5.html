Regression

What is Regression (회귀)

  • 회귀란 사전적으로 ‘한바퀴 돌아 제자리로 돌아가다’ → 무엇이 어디로 돌아가는 것인가?

  • 회귀 모델에서 회귀라는 것은 데이터가 평균값으로 돌아가는 것을 의미(?) → 데이터는 존재또는 발현하는 것을 획득하는 것이므로 이동하는 의미로는 부적합

  • 데이터 실측값과 모델의 예측치 사이의 차이, 즉 잔차가 평균으로 돌아가도록 만드는 것을 의미 → 잔차가 0이 되는 것이 아닌 이유는 실제 세계에서는 잡음이 존재하기 때문에 완전히 예측치가 실측치와 일치하지 않으며 전체적 추세로 0으로 수렴하는 것이다

  • 잔차가 독립적이고 동일하게 분산된 랜덤(I.I.D)한 성질을 만족해야 한다

    • 잔차의 분포는 정규 분포여야 한다 → Random

    • 잔차와 독립변수 X 사이에 상관 관계가 없어야 한다. 자기 자신과도 상관 관계가 없어야 한다 → Independant

    • 잔차의 분포가 일정해야 한다 (등분산성) → Identically Distributed

Linear Learner Algorithm

https://docs.aws.amazon.com/sagemaker/latest/dg/linear-learner.html

  • 알고리즘은 linear function을 학습

  • 분류 문제에서는 linear threshold function을 학습

  • x 벡터를 y 라벨의 추정치로 맵핑

Linear Model

  • 지도 학습 알고리즘으로 회귀 (regression), 이진 분류 (binary classification), 다중 분류 (multiclass classification) 문제에 적용된다

  • Model(x,y) : x는 고차원 또는 다차원 (high-dimensional) 벡터이고 y는 숫자값 (numeric label) → 다차원 입력 변수 x들에 대한 예측값 y를 생성해 내는 모델을 의미한다

  • 알고리즘을 사용하기 위해 다른 어떤 number를 만들어내는 number, list of number가 필요

  • 이 number, list of number를 사용하여 특정 값을 예측하거나 그룹화를 위한 기준값 (threshold)을 만들어 낸다 → **regression or classification** 에 사용

Adjusts to Minimize Error → Stochastic Gradient Descent

  • 알고리즘은 직선의 방정식을 가능한 fitting 하게 만들고자 한다 → 모든 학습 데이터 포인트와 예측 직선과의 거리값의 합을 최대한 작게 하기 위한 방법을 찾는다

  • Stochastic Gradient Descent (확률적 경사 하강법)

    • Stochastic : Random으로 표시하기도 하는데 ‘임의’ 보다는 확률 특성을 가진다. 확률변수의 영향 때문에 정확히 예측할 수 없는 사건이나 계를 묘사하기 위해 생겨난 학문을 의미하기도 한다. (Probabilistic + Time)

    • Gradient : 기울기.. 공간에 대한 기울기 → 벡터장에서의 기울기

    • Gradient Descent : Gradient 개념을 최적화 문제에 적용 → Local Minimum을 찾는 방법

  • Local Minimum과 Global Minimum이 있는데 Local Minimum에 빠지지 않도록 주의가 필요

Feature

  • Very Flexible

    • 다른 학습 목표들을 탐색하고 최선을 선택하는 것에 사용 가능

    • 이산 이나 연속 데이터에 대한 추론에 모두 적합

  • Built-in Tuning

    • Hyperparameter 튜닝 내장 → 자동 모델 튜닝 (automatic model tuning) 기능과 다름

    • Linear Learner 모델은 여러가지 모델을 병렬로 학습하여 hyperparameter 튜닝

    • Automatic Model Tuning (Hyperparameter Tuning) 은 주어진 데이터셋에서 hyperparameter의 범위에서 테스트 하는 여러 작업을 실행

    • Automatic Model Tuning을 활성화 하면 Linear Learner Model Tuning은 비 활성화 됨 → Parallel model 수를 1로 설정

  • Good First Chois

    • 데이터와 학습 목표가 충족된다면 첫번째 모델 학습으로 좋은 알고리즘

Use Case

  • 주어진 숫자 입력값을 기반으로 양적 값을 예측 (Predict quantitive value)

  • 이산 이진 분류 문제 (Discrete Binary Classification)

  • 이산 다중 분류 문제 (Discrete Mutliclass Classification)

Factorization Machines Algorithm

https://docs.aws.amazon.com/sagemaker/latest/dg/fact-machines.html

  • Linear Learner 모델은 연속 데이터 입력에 대해 매우 좋음 → 데이터가 손실 된 경우에는 ? (Sparse dataset)

Factorization Machines Algorithm

  • How it works : https://docs.aws.amazon.com/sagemaker/latest/dg/fact-machines-howitworks.html

  • 이진 분류 및 회귀를 위한 지도 학습 모델 → 특정 값을 예측하거나 두 그룹중 하나에 배치하기 위한 기준 (threshold) 설정

  • 다차원의 Sparse 데이터셋의 feature 간의 상호 작용을 획득 → 데이터에 hole이 있을 때 좋은 선택이 된다

  • Binary Classification : score > 0.5 → 1

  • Regression : score is the predicted value

Feature

  • Only Pair-wise feature

    • 한번에 두 쌍의 기능에 대한 관계를 분석하는 경우에 사용 → pairwise interaction

  • CSV is not supported

    • sparse dimension에서 CSV는 좋은 선택지가 아님

    • Float32 tensor들의 recordIO-protobuf 형식을 사용하는 File이나 Pipe mode 학습

  • Doesn’t work for Multiclass Problems

    • 이진 분류나 회귀 모델에 사용 가능

  • Needs LOTS of data

    • 희소성(Sparseness)을 보완하기 위해서는 많은 데이터가 필요

    • 추천하는 입력 특징 공간 (Feature space)의 차원 수는 10K ~ 10M

  • CPUs rock sparse data better

    • GPU 보다는 효율적인 CPU 사용을 추천

  • Don’t perform well on dense data

    • Full 데이터셋이 있다면 다른 알고리즘이 더 성능이 좋음

Use Case

  • High Dimensional Sparse Data Sets

    • 사용자에 대한 정보가 주어진 페이지에서의 광고에 대한 Click-stream data

  • Recommendations

    • 감상한 영화중 일부만 평가하거나 다른 영화를 평가한 경우 어떤 영화를 추천할 것인가?

Clustering

Clustering Algorithm

  • 비슷한 것으로 그룹화 하는 비지도 학습 알고리즘

K-Means Algorithm

  • 데이터 내에서 이산(discrete) 그룹을 찾아내는 비지도 학습 알고리즘

  • 그룹의 멤버들은 가능한 유사하고 다른 그룹의 멤버들과는 가능한 다름

  • 데이터를 점으로 표현할 때 점간의 euclidean distance가 유사성(similarity)를 표현한다

  • 어떠한 속성으로 유사성을 나타낼지 지정하면 알고리즘은 유사한 것들끼리 그룹화

  • 유사성은 구분하는 속성간의 거리를 기반으로 계산

  • K는 제공하는 상수를 의미 → 클러스터 개수

Feature

Tabular Data

  • Row : 클러스터할 관찰 대상

  • Column : 관찰 대상의 속성

Identifying Attribute

  • 데이터셋의 특성 파악을 통해 유사성을 정의하기 위한 속성을 찾아야 함

Modified K-Means

  • SageMaker에서는 웹 규모로 수정된 K-Means 알고리즘을 사용 → 정확도 향상

CPU Instance

  • K-Means 알고리즘은 CPU 인스턴스 사용을 추천

  • GPU 인스턴스 사용 가능하나 1개 GPU만 사용할 수 있음

Training is Still a Thing

  • 데이터는 라벨링 되어 있지 않다 → 지속적으로 학습하여 정확도를 높여야 함

  • 정확도 향상을 위해서는 구분 속성(identifying attribute)이 중요

Number of Features and Clusters

  • 분석을 위한 속성 수와 분류를 원하는 클러스터 수를 지정

Classification

Cluster vs Classification

  • Clustering (군집)은 레이블 되어 있지 않은 데이터와 그룹화 속성을 알고리즘에 전달(tell)하여 여러개로 그룹화 하는 비지도 학습

  • Classification (분류)는 레이블 되어 있는 데이터를 전달하면 알고리즘이 데이터를 여러개로 그룹화 하는 지도 학습

    • 알고리즘에서 데이터의 어떤 속성이 중요한지 파악하고 이것에 따라 데이터를 분류

    • Clustering에서 그룹화를 위한 속성을 어떤 것을 사용해야 할지 결정하기 어려울 때 Classification을 사용할 수 있다

How to choose

  • 알고리즘은 데이터 처리 능력, 데이터 밀집도, 성능에 따라 다른 요구 사항이 있음

  • Classification 알고리즘 대신 Clustering 알고리즘을 사용할 수 있을 만큼 충분히 알고 있다면 Clustering을 사용하면 된다

  • 그렇지 않다면 먼저 가장 중요한 특성을 찾아내기 위해 Classification 혹은 PCA (Principal Component Analysis - 주성분 분석) 알고리즘을 사용한다

  • 중요한 특성을 찾아낸 후 Clustering 알고리즘을 사용하여 추론한다

K-Nearest Neighbor

  • 인덱스 기반의 비 패러미터 방식의 분류 및 회귀 모델

  • 가장 가까운 지점을 기반으로 값 예측 혹은 분류하는 지도 학습 모델

Classification

  • 샘플 지점에서 가장 가까운 K개의 지점들을 쿼리하여 가장 빈번하게 사용되는 레이블을 예측 레이블로 전달

Regression

  • 샘플 지점에서 가장 가까운 K개의 지점들을 쿼리한 후 특성 값들의 평균을 예측 값으로 전달

Feature

Choose the number of ‘neighbor’

  • K 값을 지정한다 → Classifying에 사용할 가장 근접한 값들의 갯수

Lazy algorithm

  • 일반화하기 위해 학습 데이터 포인트를 사용하지 않고 인근에 있는 것을 파악하기 위해 사용

  • lazy 알고리즘은 업데이트를 게으르게 한다는 것으로 (Lazy Propagation) Segment Tree 구조에서 해당 노드를 방문할 때 업데이트를 propagation 하는 방식

Training Data stays in memory

  • KNN은 학습을 하지않고 유사한 샘플들을 결정하기 위해 학습 데이터셋을 사용한다

Use Case

Credit Ratings

  • Credit usage가 알려진 다른 사람들과 공유하는 속성을 기반으로 신용 위험을 기준으로 사람들을 그룹화

Product Recommendations

  • 좋아하는 것을 기반으로 좋아할 수 있는 것들과 유사한 item들을 추천

Beware of bias

  • KNN은 고정 관념을 (sterotyping) 만들 수 있다 → redlining

Image Analysis

  • Another form of classification

Image Classification

  • 이미지 분류 결정

Transfer Learning

  • 처음부터 훈련을 하거나 Transfer Learning (전이 학습)을 이용할 수있는 CNN (Resnet)을 사용

  • Transfer Learning : 모델을 더 좋게 만들기 위해 다른 작업에서 혜택을 얻음 → 학습된 모델을 다른 문제를 풀기 위해 재 활용

    • 이미지 인식 (recognition) 모델을 학습할 때 사용하는 리소스로 대규모 이미지들이 레이블 되어 있는 ImageNet 활용하는 것이 대표적 사례

Object Detection

  • 이미지에서 특정 오브젝트를 감지하고 신뢰도 점수 (confidence score)로 Classification

Semantic Segmentation

  • 개별 픽셀에 대한 저수준 분석 (Low level analysis)

  • 이미지내의 형상을 식별 (identify) → Edge detection

  • 압축되지 않는 PNG format 사용

  • 학습에는 많은 컴퓨팅 파워가 필요하여 GPU 인스턴스에서만 가능

  • 학습된 모델은 비교적 단순한 컴퓨팅 파워에도 배포 가능 하다 → CPU 인스턴스, 자동차, Atom processor를 사용하는 소형 컴퓨터 (Deep Racer 등)에도 배포 가능

  • CityScape Dataset : 도시의 이미지를 캡쳐하여 도시의 많은 요소들을 분류한 데이터베이스를 제공 (전이 학습의 예)

Use Case

Image Metadata Extraction

  • 그림 판매 웹사이트에서 메타데이터 추출을 사용하여 특정 키워드로 이미지를 검색할 수 있도록 함

Computer Vision System

  • 산업 영역에서 부품을 조사하거나 결함을 찾는 등의 작업을 사람이 아닌 머신을 사용하여 수행

Anomaly Detection

Random Cut Forest

  • 비정상적인 데이터 포인트를 탐지하는 비지도 학습 모델

  • 시계열 데이터의 Spike, 주기성의 중단, 분류되지 않는 포인트 등…

  • RCF는 그래프를 그릴 수 없는 경우에 유용

  • N 차원 입력에서 동작 되도록 설계

  • “정상”을 초과하는 데이터 발생을 찾음 → 통상적으로 표준 편차 x 3 범위 (99.7%)

Feature

Givea an Anomaly Score

  • 이상 정도를 표현하는 스코어를 사용 → 높을수록 이상 데이터

Scales Well

  • 특성 수가 증가하거나 데이터셋 크기가 커지거나, 인스턴스 개수가 많아질 경우에도 확장이 잘 됨

Not benefit from GPU

  • 보통 수준의 컴퓨팅 인스턴스 사용 추천 : ml.m4 혹은 ml.m5

Use Case

Quality Control

  • 고품질 스피커 시스템에서 오디오 테스트 패턴을 구동하여 비정상적인 주파수 확인

Fraud Detection

  • 거래가 발생할 때 비정상적인 거래량, 장소, 시간에 대해 감지

IP Insights

  • IPv4 주소를 캡쳐하여 사용 패턴을 학습 : IP 주소와 사용자 ID, 계정등의 관계 분석

  • 온라인에서의 잠재 이상을 표시

Ingest Entity/IP address Pairs

  • 기본 패턴 (Baseline pattern)을 학습하기 위해 historical 데이터 사용

Returns Inference via a Score

  • 기준 대비 이상 정도를 스코어로 전달

Uses a Neural Network

  • Latent Vector (잠재 벡터) Representation을 학습하기 위해 신경망 학습을 사용

GPUs recommended for Training

  • GPU 인스턴스가 추천되지만 대규모 데이터셋의 경우에는 분산 CPU 인스턴스가 비용 효율적일 수 있음

CPUs recommended for Inference

  • 일반 추론 작업에는 GPU 인스턴스까지 필요하지 않음

Use Case

  • Tiered Authentication Model

    • 사용자가 비정상적인 IP 주소로 접속할 경우 two-factor 인증 루틴을 동적으로 실행할 수 있다

  • Fraud Detection

    • 온라인 뱅킹에서 IP 접속 주소가 비정상적이라면 특정 활동만을 허용할 수 있다

Text Analytics

Latent Dirichlet Allocation (LDA)

  • 잠재 디리클레 할당 : https://ratsgo.github.io/from frequency to semantics/2017/06/01/LDA/

  • 문서에 존재하는 주제들에 대한 확률 모형으로 토픽별 단어 분포, 문서별 토픽 분포를 추정 → 연속 확률 분포인 Dirichlet 분포 사용 (베이즈 통계학의 다항 분포에 대한 사전 켤레 - conjugate prior- 확률)

  • 아키텍쳐

Algorithm

  • 일련의 관찰을 별개의 범주 (distinct category)가 혼합된 것으로 설명하는 비지도 학습 알고리즘

  • 텍스트 뭉치에서 사용자가 지정한 수의 주제를 발견하는 것에 일반적으로 사용됨

    • Observation → document

    • Feature → 개별 단어의 발생 빈도

    • Category → 주제 (topic)

  • **유사한 단어의 발생 빈도에 기초하여 문서의 유사도를 찾기 위해 사용**된다

  • 말뭉치에서 주제(Topic)을 추출하는 Topic Modeling 기법으로 사용

Use Case

  • Article Recommendation

    • 과거에 읽거나 평가했던 주제와 유사한 기사를 추천

  • Musical Influence Modeling

    • 시간이 지남에 따라 어떤 음악가가 진정으로 혁신적 이었는지, 그 혁신가의 영향을 받은 음악가를 탐색

Neural Topic Model (NTM)

Algorithm

  • 문서의 말뭉치를 주제(Topic)으로 조직화 하기 위해 사용되는 비지도 학습 알고리즘

  • 단어의 **확률 분포에 기초**한 단어 그룹을 주제로 추 출

Topic Modeling

  • **문서를 분류하거나 정리하기 위해 사용**되는 모델링 기법

  • Topic 유사도를 기준으로 정보를 조회하거나 컨텐츠를 추천하기 위해 사용된다

  • NTM과 LDA는 유사하게 Topic Modeling을 수행할 수 있지만 NTM과 LDA는 별개의 (distinct) 알고리즘 이어서 출력되는 결과는 다를 수 있다

Sequence to Sequence (seq2seq)

  • 일련의 토큰 입력 (text, audio)을 다른 일련의 토큰 (sequence of token) 출력으로 생성하기 위해 사용되는 지도 학습 알고리즘

    • 언어 번역 엔진 → 학습 데이터와 어휘를 제공해야 한다

    • Speech to Text

  • Embedding, Encoding, Decoding layer를 가지는 알고리즘으로 신경망 사용 (RNN or CNN)

  • Embedding layer는 사전 학습된 워드 라이브러리 (word vector)로 초기화 한다.

    • Pre-trained word vector : FastText, Glove

  • GPU 인스턴스만 지원되며 단일 머신에 구성되어야 한다 → 단일 머신에서 여러개의 GPU 사용은 지원

BlazingText

  • Word2Vec을 최적화하여 구현한 텍스트 분류 알고리즘

  • FastText를 기반으로 하여 만들어졌으며 속도화 확장성에서 뛰어난 성능을 보임

    • FastText 학습이 몇일 걸린다면 BlazingText는 몇분에 수행하며 실시간 추론 가능

  • 텍스트 본문에서 단어 간의 문맥적 의미 관계 (contextual semantic relationships)를 결정하는 최적화된 방법

  • Downstream NLP 작업에 유용 → 감정 분석 (sentimental analysis), 명명된 개체 인식 (named entity recognition), 기계 번역 (machine translation)

Feature

  • Single pre-processed text file

    • 파일의 각 라인은 단일 문장으로 되어야 한다

    • 여러개의 텍스트 파일을 학습해야 한다면 한개의 파일로 연결 (concatenate)하고 개별 채널에 업로드 한다

  • Highly Scalable

    • 여러개의 CPU 인스턴스를 지원 하도록 하여 기존 Word2Vec 알고리즘을 개선

    • FastText 문서 분류기는 GPU 가속 기능을 사용할 수 있다

  • 20x Faster than FastText

    • 사전 학습된 FastText 모델을 지원하며 FastText 보다 20배 빠른 학습을 수행

Use Case

  • Sentiment Analysis

    • 소셜 미디어 게시물에서 고객 의견을 평가하여 긍정적이거나 부정적인 정서가 있는지 평가 → Amazon Comprehend

  • Document Classification

    • 대형 문서 컬렉션을 검토하고 문서가 개인 정보 또는 영업 비밀과 같은 중요한 데이터를 포함하는 것으로 분류 되어야 하는지 여부 감지 → Amazon Macie

Object2Vec

  • 고차원 오브젝트에 대해 저차원의 밀집된 임베딩 (low-dimensional dense embeddings)을 학습할 수 있는 일반적인 용도의 신경망 임베딩 알고리즘 (general-purpose neural embedding algorithm)

    • 이 때 원본 임베딩 공간에서의 페어간의 의미 관계는 유지 한다 (preserve the semantics of the relationship between the pair)

    • Object이기 때문에 단어 외에도 제품, 고객, 영화 등 무엇이든 가능하다

  • D 차원 공간에 thing을 매핑하여 서로가 얼마나 비슷한지를 알아낼 수 있는 방법

Feature

  • Pairs of Things

    • 아이템 쌍을 찾고 관계 관점에서 긍정적인지 부정적인지 파악

    • 카테고리 레이블이나 평가,점수 기준의 레이블 가능

  • Feature Engineering

    • 임베딩을 분류 혹은 회귀 등의 지도 학습 작업의 downstream을 위해 사용 가능

  • Training Data Required

    • Object2Vec는 학습을 위해 레이블된 데이터를 필요로 한다

    • Natural clustering에서 레이블 관계를 생성하기 위한 방법이 있음

Use Case

  • Movie Rating Prediction

    • 다른 사람의 영화 등급 평가와의 유사성을 기반으로 영화를 제공 할 가능성이 있는 등급을 예측

  • Document Classification

    • 알려진 장르(역사, 스릴러, 전기 등)와 유사한 장르를 결정

Reinforcement Learning (RL)

  • The Carrot and The Stick (당근과 채찍)

  • Postivie

    • 동기를 부여 할 수 있는 긍정적인 보상을 제공하고 또 다른 긍정적인 보상을 위해 행동을 반복 할 수 있도록 함

  • Negative

    • 불쾌한 경험이나 반응을 제공하여 피험자가 원하지 않는 행동을 반복하지 않도록 동기를 부여

Algorithm

  • 어떤 환경에서 에이전트 활동을 최적화하는 전략 (policy라고도 함)을 습득하기 위한 기술을 학습하는 알고리즘

  • 에이전트가 자동으로 결정하여 (autonomous decision) 문제를 해결해야 하는 경우에 적합

  • 최대의 보상 (the greatest reward)을 얻기 위한 경로를 찾아가는 과정

DeepRacer

Use Case

Autonomous Vehicles

  • 시뮬레이션에서 시행 착오의 반복을 통해 운전 자동차 모델을 학습. 모델이 충분히 좋으면 테스트 트랙에서 실제 차량에서 테스트 할 수 있음

Intelligent HVAC Control

  • RL 모델은 에너지 소비를 최소화 하기 위한 온도 조절 최적화를 위해 장비 효율과 햇빛 패턴과 경로의 영향에 대한 투과율을 학습

Forecasting

  • Past performance is not an indicator of future results

DeepAR

Algorithm

  • RNN을 사용하는 스칼라(1차원) 시계열을 예상하는 알고리즘

  • ARIMA (Autoregressive integrated moving average)와 ETS (Exponential Smoothing) 알고리즘 능가

  • 각 개별 시계열과 반대로 여러개의 시계열을 통해 단일 모델을 학습

  • 여러개의 이전 (historic) 데이터셋을 이용하여 Point-in-time 값과 추정값 (estimated value)를 함께 예측 가능

Cold Start Program

  • Forecasting 모델을 구축하기 위해 사용할 수 있는 이전 데이터가 없거나 부족한 경우 발생

  • 여러 패턴을 결합하여 집계 (aggregate) 예측을 만들 수 있는 모델을 생성 → 더 현실적인 모델

Forecast Type

  • Point Forecast

    • “Number of sneakers sold in a week is X”

  • Probabilistic Forecast

    • “Number of sneakers sold in a week is between X and Y with Z% probability.”

Feature

  • Support for various time series

    • 시계열 데이터는 숫자, 횟수, 간격의 값 (0 ~ 100 사이의 온도 값)

  • More time series is better

    • 가능한 많은 시계열을 가지고 모델을 학습하는 것을 추천

    • 수백개의 관련 시계열

  • Must supply at least 300 observations

    • 예측값이 robust 하기 위해서는 모든 시계열에 걸쳐 최소 300개 이상의 관찰 데이터 필요

  • Must supply some hyperparameters

    • Context Length : 예측값을 만들기 전에 모델이 얻는 time points 갯수

    • Epoch : 학습 데이터를 전달하는 횟수

    • Prediction Length : 모델 학습을 위한 time steps → Forecast horizon (예측 범위) 이라고도 함

    • Time Frequency : 지나가는 (passing in) 시계열 데이터의 세분성 (granularity) → 달, 주일, 시간, 분 등

  • Automatic Evaluation of the model

    • 모델의 정확도를 자동으로 평가하기 위해 backtest를 진행

Use Case

  • Forecasting New Product Performance

    • 다른 제품의 과거 데이터를 통합하여 새로 출시 된 제품의 성능을 예측할 수있는 모델을 생성

  • Predict Labor Needs for Special Events

    • 다른 유통 센터의 노동 이용률을 사용하여 새로운 유통 센터에 필요한 수준을 예측

Ensemble Learning

Algorithm

  • 여러개의 학습 알고리즘과 모델을 함께 사용하여 사용하여 모델의 정확도를 향상

Extreme Gradient Boosting → XGBoost

  • Gradient boosted tree 알고리즘의 오픈 소스 구현 버전

  • 단순하고 약한 모델의 추정값들을 결합

  • 모든 종류의 **회귀, 분류, 랭킹** 문제에 적용 가능

  • 2개의 요구 항목과 35개의 옵션 Hyperparameter를 튜닝

Feature

  • 학습과 추론에 CSV, libsvm 허용

    • 테이블형 (tabluar) 데이터 사용

  • Only trains on CPU and memory bound

  • Recommend lots of memory

    • 성능 최적화를 위해 전체 학습 데이터를 유지하기 위해 충분한 메모리가 필요

  • Spark Integration

    • SageMaker Spark SDK를 사용하여 XGBoost를 직접 호출할 수 있음

Decision Tree Ensembles

  • CART (Classification and Regression Trees)의 집합을 생성

Use Case

Ranking

  • 전자 상거래 웹 사이트에서 검색 결과, 클릭 및 성공적인 구매에 대한 데이터를 활용 한 다음 XGBoost를 사용하여 검색 제품에 대한 관련성 점수를 반환 할 수 있는 모델을 훈련

Fraud Detection

  • XGBooROST가 과거 트랜잭션의 데이터 집합과 사기성이 있는지 여부에 관계없이 입력 트랜잭션 데이터를 트랜잭션이 사기성이 있을 확률에 매핑되는 함수를 학습
