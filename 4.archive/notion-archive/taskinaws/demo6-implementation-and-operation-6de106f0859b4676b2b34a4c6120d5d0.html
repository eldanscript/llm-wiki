Lab Process

Implement Model

  • ufo-implementation-operations-lab

Load dataset onto Notebook instance memory from S3

  • ufo_fullset.csv

Cleaning, transforming and preparing the dataset

  • Convert the reportedTimestamp and eventDate to a datetime data types.

  • Convert the shape and weather to a category data type.

  • Map the physicalEvidence and contact from ‘Y’, ‘N’ to 0, 1.

  • Convert the researchOutcome to a category data type (target attribute)

  • one-hot both the weather attribute and the shape attribute

  • drop the columns that are not important : sighting, firstName, lastName

Create and train our model (Linear Learner)

  • Split data into train, validation and test

  • Create recordIO file

    • RecordIO implements a file format for a **sequence of records** : TFRecord (Tensorflow), RecordIO (MXNet)

    • Packing data together allows continuous reading on the disk

    • RecordIO has a simple way to partition, simplifying distributed setting

  • Get Linear Learner algorithm from ECR
  • Create training job
  • Set Hyperparameters
  • Training Result
  • Model artifacts

Deploying the model into SageMaker hosting

  • Deploy the model into SageMaker hosting onto a single m4 instance
  • Setup code to draw confusion matrix and heatmap
  • Draw confusion matrix

  • Test Result
