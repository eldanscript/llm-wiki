AWS

Q) Can you explain what are the definitions of Region and AZ and what are the differences?
A) Region is a geographically separated area where several data centers are gathered. A data center that is logically separated more than one data center in a region is called AZ. There is more than one AZ in the region.

Q) Can I use DNS services other than Route53?
A) It is okay to use other services. But in terms of management, it has advantages because it is a managed service that manages durability and availability.

Q) Can you clarify the advantages of Route53 a little more?
A) Health check for instnace, providing optimal path for end users

Q) There are cases when Route53 can’t provide IP. How can I do that?
A) I will deliver the part after confirming it more

Q) Is there any reason to recommend RDS MySQL over Aurara?
A) performance

Q) When performing backup, there is a lot of IO in StandBy Instance. Is there any effect on Master at that time? If the operation method of RDS says that the Master has Update, it is synchronously replicated to StandBy, and the load generated on the Mater is reflected in StandBy as it is. Could it be that it could slow down?
A) I will check and answer the IO and throughput currently used.

Q) Can you explain the difference between snapshot backup of RDS and general backup?
A) There are automatic BackUp and Manual DB Snapshot. There are Snapshot and Transaction Log. Snapshot will receive an incremental BackUp.

Q) What is the difference between the Snapshot method used by RDS and the method to read back up from the database itself?
A) Automatic BackUp and DB Snapshot method

Q) What are the advantages of NAT Gateway in terms of reliability and HA?
A) NAT Gateway has the advantage of a managed service. To prepare for a failure, it can be configured in a different AZ and used by changing the routing to another NAT gateway when a failure occurs.

Q) How should the routing table be configured if the routing is changed to another NAT gateway when a failure occurs?
A) Set the basic routing table to be routed internally for Local IP and connect to the internet gateway for others.

Q) Why did you recommend ALB among ELBs?
A) It is recommended as L7 LB. It can be recommended if you consider the service of HTTP2.0.

Q) Does NLB not support HTTP2.0?
A) NLB supports TCP/IP, but it is recommended because ALB is excellent in terms of security.

Q) Have you ever used AWS services?
A) I tried it for the first time during the assessment.

Q) What are the advantages and benefits of AWS services?
A) The use through the console is highly visible and can be used explicitly. Automation was easy because infra was easily built through CloudFormation.

Q) What benefits can a public cloud like AWS provide to customers?
A) In terms of operation, there is excellence in tools, and operational efficiency can be improved through managed services. This allows you to focus on other areas and use them efficiently. You pay for what you use, so you can use it more cost-effectively.

Q) There are times when AWS is said to be expensive. How is it?
A) Since there is a cost to build an infrastructure and a cost to maintain it, there seems to be a cost advantage from a TCO perspective.

Q) What are other advantages besides the TCO perspective?
A) There is an advantage of using as much as you use, and you can further reduce costs by using an RI instance.
