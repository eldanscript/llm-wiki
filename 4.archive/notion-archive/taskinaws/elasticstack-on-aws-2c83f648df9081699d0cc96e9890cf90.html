Kinesis Output Plugin

💡

Kinesis Producer Library (KPL) 사용하여 data records를 Kinesis로 전송하는 ruby용 library. Github Project

  • Logstash 2.x

    • Ruby Library

  • Logstash 5.x

    • github code

  • Install plugin

    • binary : bin/logstash-plugin
  • Configuration pipeline

  • AWS configuration

    • Add Kinesis access permission to user

    • Match Kinesis input stream name

  • Error - User Access type error

  • Change not to use access_key & secret_key
  • Error2 - Cloudwatch metric error

  • Fix

    • EC2에 SSM을 사용하기 위해 instance profile을 등록함

    • logstash가 이 profile을 사용하여 AWS resource를 access

    • instance profile에 필요한 권한을 설정하여 같이 사용

  • Using Kinesis Data Streams ARN

  • Fix

    • AWS account 설정은 S3 access를 통해 획득한 credential 사용
