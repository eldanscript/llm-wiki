Concept

Data Preparation

  • Cleaning, Scrubbing, Sanitizing

  • Process of transforming a dataset using different techniques to prepare it for model training and testing : 모델 훈련과 테스트를 위해 서로 다른 기법들을 사용하여 데이터를 변형하는 프로세스

  • Remove incomplete and incorrectly formatted values

  • Remove irrelevant data

  • Remove duplicate data

  • Change text based values into numeric values

  • Group different attributes together

  • Combine different attributes

  • Take text strings and break them into different tokens

  • Redesign features in general

Categorical Engineering

  • Process of manipulating categorical variables when ML expect numerical values as inputs

  • categorical variable = categorical feature = discrete feature

  • Varieties of categorical variable

    • By Count : Binary vs Multiple

    • By Order : Ordinal vs Nominal

One-hot Encoding

  • Transforms nominal categorial features : 순서가 없는 카테고리형 데이터셋에 적용

  • Creates new binary columns for each observation

  • Adding columns to dataset of 1 and 0

Many Variable Case

  1. One-hot or not ?

    1. 너무 많은 category가 있다면 one-hot encoding이 좋은 선택은 아님

  2. Grouping

    1. Encoding 전에 유사성으로 그룹을 만든다면 전체 카테고리 수를 줄일 수 있음

  3. Mapping Rare Values

    1. 빈도 수 가 낮은 값들은 ‘other(그외)’ 로 맵핑하면 전체 컬럼 수를 줄일 수 있음

Text Feature Engineering

Feature Engineering

  • Transform attributes within data to make them more useful within our model for the problem at hand

  • 데이터 내에서 속성을 변환하여 당면한 문제에 대한 모델에 유용하게 하는 것

  • Handle missing values

  • Replace different values

  • Combine or remove features

  • Shape dataset and get it ready for ML algorithm

Text Feature Engineering

  • Transform text within data so ML algorithms can better analyze

  • Split text into bite size pieces

  • Example - Break and tokenize

    • “123 Main Street, Seattle, WA 98101” →

      • Address : 123 Main Street

      • City : Seattle

      • State : WA

      • Zip : 98101

Bag-of-Words (BOW)

  • Tokenize raw text and create a statistical repesentation of the text

  • Break up text by white space into single words → tokenize

  • 단어 주머니 : 텍스트를 토큰화 하고 출현 빈도를 통계적으로 표현하는 것, 단어 순서와 상관 없이 출현 빈도만 카운트

N-Gram

  • Extension of Bag-of-Words

    • Bag-of-Words는 1 size N-Gram

  • Produce groups of words of n size → n size sliding windows

  • Bag-of-words의 가장 큰 문제점은 단어 순서를 무시한다는 점 → 이 한계 극복을 위해 n개씩 묶은 그룹의 빈도를 카운트 → 단어 출현 순서나 가까운 단어들을 고려하게 됨

  • Unigram, Bigram, Trigram

Orthogonal Sparse Bigram (OSB)

  • Create groups of words that always include the first word

    • Create groups of words of size n

    • Output every pair of words that include the first word

  • Use the some type of delimiter for the white spaces within the token

  • Orthogonal : Two things are independent of each other

  • Sparse : Scattered or thinly distributed (산개해 있거나 얅게 분포)

  • Bigram : 2-gram or two words

  • Break tokens into 2 words → Spreads out or sparse out with underscores (_) or some type of delimiter → 2 words are independent of one another

TF-IDF (Term Frequency - Inverse Domain Frequency)

  • Represent how important a word or words are to a given set of text : 주어진 텍스트에서 하나의 단어나 단어들의 중요도를 표시

  • Providing appropriate weights to terms that common and less common in the text : 텍스트에서 일반적이고 덜 일반적인 용어에 적절한 가중치 부여 → 단순 단어 빈도로 접근하는 게 아니라, 어떤 단어가 한 문서에서 많이 나타나는 동시에 다른 문서에서는 잘 나타나지 않는 것 까지 고려

  • Show the popularity of a word or words in text data : 단어나 단어들의 인기(빈도)를 표시

  • Making common words like ‘the’ or ‘and’ less important : 관사나 접사와 같은 일반어를 덜 중요하게 만듬

  • Term Frequency

    • How frequent does a word appear?

  • Document Frequency

    • Number of documents in which terms occur

  • Inverse

    • Makes common words less meaningful

  • (number of documents, number of unique n-grams) : (2,7)

Cartesian Product Transformation

  • Create a new feature from the combination of two ro more text or categorical values : 2개 이상의 텍스트의 조합이나 카테고리 값에서 새로운 특성을 생성

  • Combining sets of words together : 단어들을 함께 묶는 방법

  • Cartesian : Cartesian Co-ordinate system (데카르트 좌표계, 직교 좌표계) → 데카르트 이름의 라틴어 표기 Renatus Cartesius

  • Product : Multiply

  • Multiply a set of words by another set of words to create a new feature

Numeric Feature Engineering

  • Have trouble handling very, very, very large numbers

  • Better interpreted if grouped together

Feature Scaling

  • Change numeric values are on the same scale → Very, very large number scaled down to smaller number

    • Quicker computation

    • Not worry about skewed results due to such large calculation : 비뚤어진 - 정규분포가 아닌 비대칭 분포

    • Skewness (왜도,비대칭), Kurtosis (첨도)

Normalization (정규화)

  • Scaling = Feature Scaling = Normalization (정규화)

  • Max = 1, min = 0

  • Sample (행)에 대해 적용

  • Problem

    • Outliers can throw off normalization : 이상 데이터로 정규화가 제대로 되지 않을 수 있음

Standardization (표준화)

  • Average = 0 → Scale을 평균 0과 분산 1이 되도록 변환

  • Use Z-score for the remainder value

    • -1 ~ 1 : 68%, -2 ~ 2 : 95%, -3 ~ 3 : 99%, 그 외는 outlier일 확률이 높음

  • Z-score smooth out the value : outlier 값을 부드럽게 함 (영향도를 줄임)

  • Outlier가 문제가 된다면 standardization을 사용

Scaling Features

  • Linear, non-linear regression

  • Clustering

  • Neural Network

Translating Back

  • Can scale back the data to the original representation

Binning

  • Change numeric values into groups or buckets of similar values → Numeric variable to Categorical variable

  • 연속적인 하나의 특성을 Bin(상자)이라고 하는 그룹의 특성으로 변환하는 작업

  • When numeric value doesn’t have a linear role, with prediction or target attribute

  • When increasing or decreasing of a specific numeric value, doesn’t have any correlation with what to find out

  • Ex) Person’s age

Quantile Binning

  • Binning can end up with irregular bins which are not uniform → apply a technique

  • Assign the same number of feature to each bin

  • Quantile : equal parts

  • Binning : grouping

Optimum Number of Bins

  • Depends on the characteristics of the variables and its relationship of the target

Handling Missing Values

Missing Data

  • Represented in many different ways : null, NaN, NA, None, …

  • Why are values missing?

Missing at Random (MAR)

  • The propensity for a data point to be missing isn’t related to the missing data, but it is related to some of the observed data : 누락 될 데이터 포인트의 성향은 누락 된 데이터와 관련이 없지만 관찰 된 데이터 중 일부와 관련이 있습니다.

Missing Completely at Random (MCAR)

  • The fact that a certain value is missing has nothing to do with its hypothetical value and with the values of other vairables : 특정 값이 누락되었다는 사실은 가상 값 및 다른 변수의 값과 아무 관련이 없습니다.

Missing not at Random (MNAR)

  • Two possible reasons are that the missing value depends on the hypothetical value or missing value is dependent on some other variable’s value : 누락 된 값이 가상 값 또는 누락 값에 의존하는 두 가지 가능한 이유는 다른 변수의 값에 따라 다릅니다.

Handle missing values - Data Imputation (데이터 대치)

  • If a large amount of values are missing, using supervised learning algorithm

  • Supervised learning : KNN, fuzzy K means

Feature Selection

  • Selecting the most relevant features from data → Deciding what to keep and what to get rid of

  • Prevent over-complicating the analysis

  • Resolving potential inaccuracies

  • Remove irrelevant features or repeated information

  • An intuitive step humans take to reduce the number of features

Principal Component Analysis (PCA)

  • An supervised learning algorithm

  • Reduce the number of features while still remaining as much informaton as possible

Data Preparation Helper Tools

AWS Glue

Feature

  • Fully managed ETL service

  • Allow to run Python or Scala code on datasets to transform : 데이터셋 변환을 위해 python 또는 scala 코드를 실행할 수 있음

  • Allow to create jobs that transform data and give the ability to run on demand : 데이터를 변환하고 요구에 따라 실행 되도록 잡을 생성할 수 있음

  • Run on some schedule or when another service is triggered : 스케쥴 혹은 다른 서비스 트리거에 의해 실행

  • Transformation process

    • Automatically spins up the necessary resources : 필요한 리소스를 자동으로 가동

    • Do the transformation → Output the data into desired output target

Operation

  1. Set up a crawler

    1. Crawls the dataset, looks at the different data types, determines the schema or the structure of dataset : 데이터셋을 크롤링하고, 다른 데이터 타입들을 파악하고, 데이터셋의 구조 혹은 스키마를 결정함

  2. Create a data catalog

    1. The metadata or the data types and the important information about dataset : 데이터셋의 중요 정보나 데이터 타입, 메타 데이터

    2. The structure of dataset that AWS Glue can use to do data preparation jobs or determine important information about data

  3. Set up jobs and run Python or Scala code to transform data

    1. Apply categorical encoding, numerical feature engineering, text feature engineering

    2. Apply feature selection or any other data preparation technigue

    3. Upload code manually or generate the code and edit it directly within the console

  4. Set up jobs to run on demand, run on schedule, run whenever another AWS service is triggered

Spark Job

  • Fully managed cluster of Apache Spark servers that AWS Glue spins up in the background

  • Allow to run transformation code on

ETL language

  • AWS Glue generate a script, provide a script of own or bran a new script from scratch

  • Select Python → Generate PySpark code

  • Select Spark → Generate PySpark or Scala code

Python shell

Zepplin & Jupyter Notebook

  • Do transformation

  • Allow to do ad-hoc transformations and simple transformation on datasets
