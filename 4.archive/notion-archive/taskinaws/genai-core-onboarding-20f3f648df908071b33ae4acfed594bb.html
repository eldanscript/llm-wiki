Introduction to Amazon Textract

기능

아마존 텍스트랙트는 이미지 또는 PDF 문서와 같은 **비정형 데이터 소스에서 텍스트, 필기, 테이블, 양식 등의 구조화된 데이터를 추출**하는 기계 학습 서비스입니다.

단순한 광학 문자 인식(OCR)을 넘어서, 문서 요소 간의 관계와 구조를 추출할 수 있습니다.

[

Text Detection and Document Analysis Response Objects - Amazon Textract

Use Amazon Textract to detect and analyze text in your documents.

https://docs.aws.amazon.com/textract/latest/dg/how-it-works-document-layout.html

](https://docs.aws.amazon.com/textract/latest/dg/how-it-works-document-layout.html)

  1. Invoice와 영수증: 다양한 레이아웃의 invoice와 영수증에서 공급업체 이름, 청구 번호, 품목 가격, 총액, 결제 조건 등의 데이터를 자동으로 추출할 수 있습니다.

  2. 신분증: 여권, 운전면허증 등에서 생년월일, 발급일, ID 번호, 등급, 제한 사항 등의 키-값 쌍 정보를 추출할 수 있습니다.

  3. 양식과 테이블: 문서의 양식과 테이블 데이터를 키-값 쌍, CSV, TXT 파일 형태로 추출할 수 있습니다.

  4. 쿼리 기능: 문서의 구조나 형식에 관계없이 필요한 데이터만을 지정하여 추출할 수 있습니다.

이를 통해 문서 처리 자동화, ID 확인 서비스 구축, 고객 경험 개선 등의 다양한 활용이 가능합니다.

Object Type

  • Pages

  • Lines and Words of Text

  • Form Data : Key-Value Pairs

  • Tables

  • Selection Elements : Radio Button, Checkbox, Underlined Words, Circled Words, Crossed Out Words

  • Queries

Key Features

  1. 인프라 관리 불필요: 텍스트랙트는 문서 처리와 정보 추출을 위한 인프라를 직접 관리할 필요가 없어 혁신에 집중할 수 있습니다.

  2. ML 모델 학습 불필요: 텍스트랙트는 이미 수백만 개의 문서로 학습된 ML 모델을 제공하므로 별도의 모델 학습이 필요하지 않습니다.

  3. 신뢰도 기반 리뷰: 추출된 정보에 대한 신뢰도 점수를 제공하여 상황에 따라 인간 리뷰를 효과적으로 적용할 수 있습니다. 또한 아마존 A2I와 연계하여 인간 리뷰를 손쉽게 구현할 수 있습니다.

  4. 사용량 기반 과금: 실제 사용한 페이지 수만큼만 과금되므로 비용 효율적입니다. 최소 사용량이나 선결제가 없습니다.

  5. 대규모 자동화: 테이블, 양식 등 다양한 데이터 구조물을 자동으로 추출할 수 있고, AWS Step Functions를 활용해 맞춤형 IDP 파이프라인을 구축할 수 있습니다.

요약하면, 텍스트랙트는 문서 처리 자동화와 효율성 증대를 위한 다양한 이점을 제공합니다.

Pricing

AWS 프리 티어

  • Detect Document Text API: 월 1,000페이지까지 무료

  • Analyze Document API:

    • Forms 또는 Tables 기능 사용 시 월 100페이지까지 무료

    • Queries 기능 사용 시 추가로 월 100페이지까지 무료

  • Analyze Expense API: 월 100페이지까지 무료

  • Analyze ID API: 월 100페이지까지 무료

아마존 텍스트랙트의 정식 가격 정책은 다음과 같습니다:

  • Detect Document Text API: 1,000페이지당 가격이 적용되며, 월 100만 페이지 초과 시 가격이 내려갑니다.

  • Analyze Document API: Forms, Tables, Queries 기능별로 1,000페이지당 가격이 적용되며, 월 100만 페이지 초과 시 가격이 내려갑니다.

  • Analyze Expense API: 1,000페이지당 가격이 적용되며, 월 100만 페이지 초과 시 가격이 내려갑니다.

  • Analyze ID API: 1,000페이지당 가격이 적용되며, 월 10만 페이지 초과 시 가격이 내려갑니다.

최신 가격 정보는 아마존 텍스트랙트 공식 가격표를 참고하시기 바랍니다.

Use Cases

  1. 문서 자동화 처리

    • 문서에서 텍스트, 양식, 테이블 등의 정보를 자동으로 추출하여 데이터화

  2. 지능형 문서 처리 파이프라인(IDP) 구축

    • 텍스트랙트와 함께 아마존 컴프리헨드, 아마존 A2I 등의 서비스를 활용하여 문서 처리 자동화 파이프라인 구축

  3. 다양한 데이터 소스 처리

    • PDF, 이미지, 스캔 문서 등 다양한 형태의 문서에서 정보 추출

  4. 인공지능 기반 문서 처리

    • OCR, 양식 데이터 추출, 테이블 인식 등의 기능을 AI 기반으로 제공

  5. 신뢰도 기반 인간 개입

    • 텍스트랙트의 신뢰도 점수를 활용하여 정확성이 필요한 부분에 인간 검토 적용

이처럼 아마존 텍스트랙트는 문서 자동화, IDP 파이프라인 구축, 데이터 추출 등의 다양한 방식으로 클라우드 솔루션에 활용될 수 있습니다.

텍스트랙트의 주요 기술적 개념으로는 OCR, 양식 추출, 테이블 추출, 쿼리 기반 추출, 인보이스/영수증 처리, 문서 식별, 반환 데이터 유형 등이 있습니다.

이러한 기능들을 통해 사용자는 문서 처리의 자동화와 효율성을 크게 높일 수 있습니다.

아마존 텍스트랙트의 주요 활용 사례는 다음과 같습니다:

  1. 지능형 문서 처리(IDP) 파이프라인 구축

    • 다양한 유형과 형식의 문서에서 정보를 자동으로 추출하여 비즈니스 프로세스 자동화

  2. 자연어 처리(NLP)를 위한 텍스트 추출

    • 문서에서 텍스트와 엔티티를 추출하여 Amazon Comprehend와 연계한 검색 및 텍스트 마이닝 활용

  3. 문서 분류를 위한 텍스트 추출

    • 고객 이메일, 벤더 송장, 고객 통화 녹취록 등 다양한 문서에서 텍스트를 추출하여 Amazon Comprehend 기반 문서 분류 수행

  4. 문서 보관소의 스마트 검색 인덱스 및 규제 준수

    • 텍스트랙트의 자연어 쿼리 기능을 활용하여 문서에서 특정 정보를 빠르게 검색

    • 개인식별정보(PII) 탐지를 위해 Amazon Comprehend와 연계

이처럼 아마존 텍스트랙트는 문서 자동화 처리, 기계 학습 기반 텍스트 추출, 문서 분류와 검색 등 다양한 분야에서 활용될 수 있습니다. 이를 통해 문서 처리 업무의 효율성과 정확성을 크게 개선할 수 있습니다.
