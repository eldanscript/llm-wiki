Model Consumers - Applied AI

  • 고객 특성 - ML Stack을 커스텀화 하지 않으며 AI 제품을 기성품으로 구매하는 것을 선호

  • 사전 학습된 Generative model을 사용하여 고객에게 전반적인 경험을 제공

Model Tuners - Applied AI

  • SaaS business - 서비스를 제공하는 특정 산업 부문에 맞게 조정된 모델을 갖추고 있음

  • 사전 학습된 모델을 맞춤화하여 고객을 위한 제품 및 솔루션을 구축 - 오픈 소스 재 사용 (Stable Diffusion 등)

  • Fine-tuning을 수행 할 ML 엔지니어가 필요

Model Providers - Foundation Models, LLMs

  • 거대 모델을 처음부터 사전 학습 (pre-train) 하고 모델 tuner나 producer 등에게 다운스트림으로 사용

  • 1억개 (100+ million) 이상의 파라미터로 transformer나 diffusion 모델을 학습

  • GTM 까지 많은 자본을 필요로 하며 전 세계에 20개 미만

OpenAI

  • GPT-3 : 175 billion parameters (Generative Pre-trained Transformer)

  • DALL-E : 12 billion parameters

  • CLIP : 400 million parameters (Contrastive Language-Image Pre-Training)

Google

  • T5 : 11 billion parameters (Text-to-text Transfer Transformer)

  • BERT : 340 million parameters (Bidirectional Encoder Representation from Transformers)

  • GShard : 600 million parameters

  • XLNet by CMU (카네기 멜론 대학) : 340 million parameters

Facebook

  • RoBERTa : 355 million parameters

Stability AI

  • Stable Diffusion

BigScience Consortium - LightOn, Hugging Face, …

  • Bloom

Model Infrastructure - Tooling Providers, MLOps, ML Infrastructure

  • Transformer 모델, Pre-trained 모델, 도구 작업을 위한 다양한 도구와 서비스를 제공 하여 커스텀 모델을 구축하고 배포할 수 있게 함

  • 머신 러닝을 보다 쉽고 효율적으로 학습하고 배포하기 위해 다양한 기능을 제공
