Domain 1. Data Engineering

Objectives

  1. Create data repositories for ML

  2. Identify and implement a data-ingestion solution

  3. Identify and implement a data-transformation solution

Domain 1.1: Create data repositories for machine learning

아마존 S3의 다양한 스토리지 클래스를 활용하면 데이터 저장 비용을 절감할 수 있습니다. 각 스토리지 클래스의 차이점을 이미지를 통해 확인해 보세요.

그러나 아마존 S3는 모델 학습을 위한 유일한 저장 솔루션은 아닙니다. 다음과 같은 다른 옵션들도 고려해 볼 수 있습니다:

  1. 아마존 S3와 아마존 SageMaker 통합:

    • 아마존 S3를 활용하여 모델 학습 데이터와 출력을 저장할 수 있습니다.

    • 아마존 S3와 아마존 SageMaker가 통합되어 있습니다.

  2. 아마존 FSx for Lustre:

    • **학습 데이터가 이미 아마존 S3에 있고 여러 번 학습 작업을 실행하려는 경우 고려**해 볼 수 있습니다.

    • FSx for Lustre는 아마존 **S3 데이터에 대한 고속 액세스를 제공**하여 학**습 작업 속도를 높일 수 있습니다**.

  3. 아마존 S3와 아마존 EFS 통합:

    • 학습 데이터가 아마존 Elastic File System (EFS)에 있는 경우 EFS를 사용하는 것이 좋습니다.

    • **EFS를 사용하면 데이터 이동 없이 학습 작업을 직접 시작**할 수 있어 **학습 시작 시간이 빨라집니다**.

각 파일 시스템의 상대적인 데이터 전송 속도는 다음과 같습니다:

  • 아마존 S3: <1.0

  • 아마존 EFS: 1.0

  • 아마존 EBS: 1.29

  • 아마존 FSx: >1.6

이 수치는 참고용이며, 실제 워크로드에 따라 다를 수 있습니다. 작업 특성을 고려하여 적절한 파일 시스템을 선택하는 것이 중요합니다.

Domain 1.2: Identify and implement a data ingestion solution

배치 처리와 스트림 처리는 데이터 수집의 두 가지 유형입니다.

  1. 배치 처리:

    • 배치 처리에서는 데이터 소스로부터 **데이터를 주기적으로 수집하고 그룹화**합니다.

    • 배치 처리는 실시간 또는 근실시간 데이터가 필요하지 않은 경우에 일반적으로 더 쉽고 더 저렴하게 구현할 수 있습니다.

    • A**WS Glue, AWS Database Migration Service (AWS DMS), AWS Step Functions** 등의 서비스를 사용하여 AWS 클라우드로 배치 수집을 할 수 있습니다.

  2. 스트림 처리:

    • 스트림 처리에서는 **데이터가 생성되거나 인식되는 즉시 데이터를 조작하고 로드**합니다.

    • 스트림 처리는 **실시간 예측이나 실시간 분석**과 같은 용도로 사용될 수 있습니다.

    • AWS는 Amazon Kinesis 플랫폼을 사용하여 빠르게 움직이는 데이터를 캡처하고 수집할 것을 권장합니다.

    • Amazon Kinesis는 고객의 특수한 요구 사항에 맞는 맞춤형 스트리밍 데이터 애플리케이션을 구축할 수 있도록 해줍니다.

요약하면, 배치 처리는 주기적인 데이터 수집 및 그룹화를 사용하는 반면, 스트림 처리는 데이터가 생성되는 즉시 데이터를 조작하고 로드하는 방식을 사용합니다. 각각의 접근 방식은 서로 다른 용도와 요구 사항을 충족시킬 수 있습니다.

Domain 1.3: Identify and implement a data transformation solution

원천 데이터는 기계 학습(ML) 모델 학습에 바로 사용할 수 있는 상태가 아닙니다. 원천 데이터에는 다음과 같은 문제들이 존재할 수 있습니다:

  • 중복 데이터

  • 불완전한 데이터

  • 속성 표준화 필요

따라서 **데이터 변환 및 정제 과정이 필요**합니다. 이러한 데이터 변환 작업은 다음과 같은 기술을 활용할 수 있습니다:

  1. **분산 컴퓨팅** 프레임워크:

    • **MapReduce, Apache Spark 등의 프레임워크를 사용하**여 데이터를 처리하고 분산 작업을 관리할 수 있습니다.

    • 이를 통해 대량의 데이터를 효율적으로 처리할 수 있습니다.

  2. Amazon EMR과 Apache Spark:

    • Amazon EMR은 Apache Spark를 관리하는 서비스로, 대용량 데이터 처리에 적합합니다.

    • Amazon EMR은 고성능 컴퓨팅에 최적화된 인스턴스 유형을 지원합니다.

  3. **데이터 파티셔닝**:

    • 기계 학습 애플리케이션에 필요한 데이터셋은 데이터 웨어하우스, 스트리밍 IoT 입력, 또는 중앙 집중식 데이터 레이크에서 가져올 수 있습니다.

    • 이러한 데이터셋은 Amazon S3에 저장할 수 있으며, **Amazon Athena, AWS Glue, Amazon Redshift Spectrum과 같은 ETL 처리 서비스를 사용**하여 사전 처리할 수 있습니다.

  4. 단일 데이터 소스 활용:

    • 고객은 Amazon S3에 단일 데이터 소스를 저장하고, Athena, Amazon Redshift, Amazon QuickSight, Amazon SageMaker와 같은 다양한 AWS 서비스를 활용하여 분석 및 기계 학습 작업을 수행할 수 있습니다.

    • 이를 통해 데이터 복사본 생성을 피할 수 있습니다.

요약하면, 원천 데이터는 기계 학습 모델 학습에 바로 사용할 수 없는 경우가 많으므로, 데이터 변환 및 정제 과정이 필요합니다. 이를 위해 분산 컴퓨팅 기술, Amazon EMR, 데이터 파티셔닝, 그리고 단일 데이터 소스 활용과 같은 기술을 활용할 수 있습니다.
