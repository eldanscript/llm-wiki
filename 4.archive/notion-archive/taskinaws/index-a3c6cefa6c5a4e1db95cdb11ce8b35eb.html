컴퓨터 비전(CV) 시스템을 구축하는 것은 시스템의 목적에 따라 복잡하고 다양할 수 있습니다.

이 사이트는 AWS IoT Greengrass(Greengrass)를 사용하여 엣지에서 실행되는 CV 시스템 개발을 안내하여 도움을 드리고자 합니다.

Greengrass v2는 오픈 소스 시스템으로 엣지 컴퓨팅 장비에서 실행되는 컴포넌트를 오케스트레이션 및 관리 하면서 클라우드 제어 및 다양한 옵션을 통해 다른 로컬 및 클라우드 시스템과 서비스와 통합할 수 있습니다.

Constructing Computer Vision (CV) systems can be complicated and varied based on the objective of the system. This site will help to guide you through the development of a CV system that runs on the Edge using AWS IoT Greengrass (Greengrass). Greengrass v2 is an open source system to orchestrate and manage components running on Edge computing equipment, but under cloud control and with a wide variety of options to integrate with other local and cloud systems and services.

이 사이트와 워크샵 일부, 쿡북 일부는 샘플 애플리케이션을 작성하고 샘플 컴포넌트를 CV 애플리케이션으로 구성하기 위한 참조로 사용할 수 있습니다.

수많은 하드웨어 플랫폼이 Greengrass, Docker, GluonCV, Python 및 여기에 제공 될 다른 빌딩 블록에서 지원됩니다.

특정 목표를 달성하기 위한 플랫폼 및 컴포넌트의 “조합”이 설명 되어 있지만 여러분의 애플리케이션에 가장 적합하도록 이런 블록들의 고유한 조합을 직접 만들어야 합니다.

Part workshop, part Cookbook, this site can be used to build sample applications and as a reference for composing sample components into CV applications. Numerous hardware platforms are supported by Greengrass, Docker, GluonCV, Python, and many of the other building blocks that will be presented here. While there are some described “Combinations” of platform and components to accomplish specific goals, making your own combination of these blocks as best fits your application is possible.

# Services used by this workshp

The services this site explores inlcude:

  • AWS IoT Greengrass v2

  • Amazaon SageMaker and Amazon SageMaker Edge Manager (including Amazon SageMaker Neo)

  • AWS IoT Core

  • Amazon Kinesis Video Streams

  • Amazon S3

These Labs are hands-on activities to explore using AWS Services for Computer Vision at the Edge.

The activities use a mix of AWS Command Line Interface (CLI) and the web based AWS Management Console.

# What you will have after completing this workshop

[조합 (Combination)] (/ Combinations.html) 중 하나 이상을 작업할 경우 AWS IoT Greengrass V2를 사용하여 엣지 컴퓨터 비전 시스템의 참조 구현을 가지게 되어 향후 프로젝트 구축에 사용할 수 있습니다.

위해 빌드 할 수 있는 참조 구현을 갖게됩니다.

EC2 조합을 구축하는 데 약 2시간이 소요될 것으로 예상 됩니다. 다른 조합은 일반적으로 더 오래 걸리지만 하드웨어 플랫폼을 준비하는 데 필요한 시간에 따라 매우 다양합니다.

If you work through one or more of the Combinations, you will have a reference implementation of a Edge Computer Vision system using AWS IoT Greengrass V2 that you can build upon for future projects. You can expect to spend approximately 2 hours building the EC2 Combination. Other Combinations will usually take longer, but are highly variable based on the amount of time needed to prepare the hardware platform.

# Who is this workshop for?

  • Data scientists interested in learning about how to put together Edge Computer Vision systems

  • Controls engineers interested in integrating Computer Vision models into their workload

  • Video Management System makers and users looking to use Computer Vision

  • Smart Building and Connected Space users and product makers interested in applications such as People Counting within a space or other Computer Vision based “synthetic sensors”

# What skills or experience to I need?

This is not an introductory workshop and will not repeat information that is readily available elsewhere, like how to set up an EC2 instance or revise a Greengrass deployment. Rather, the focus of this workshop is on overall system design and composition of components to deliver a CV application. Consult the Spells section for activities in bold italics when needed. This helps keep the text focused on the logic and concept of the activity and keeps common actions collected in one spot for ready reference.

While readers with little prior experience can follow these guides, it is recommended that readers have some experience and familiarity with

  • AWS Services and Cloud development

  • Using the AWS Console to create, modify, and inspect service configuration

  • Using the AWS Command Line Interface (CLI)

  • AWS IoT services (Greengrass V2, Components, Deployments, and MQTT)

  • Linux and edge systems

  • Use of the bash shell, environment variables, and common tools

  • Text editors (such as Vim or IDEs)

  • users, permissions, groups, and administration

  • Software development technologies

  • JavaScript Object Notation (JSON)

  • git source code tools and repositories, including GitHub

  • Python including virtual environments and package management

  • Docker

Some projects will also require embedded linux skills including

  • Yocto and image building

  • Writing and using SD Cards

Data science and Machine Learning Network building skills are not required. However, those with background in these areas can readily expand on the solutions presented here.

# How to get started

  • Start by reviewing the overall Design to understand the framework presented here for CV systems.

  • Work through the Introduction to ensure you are set up and ready to go

  • Acquire or have access to at least one of the Devices

  • Look through the documented Combinations for an application similar to yours and create it

  • Extend the Combination with additional services locally or in the cloud

  • Customize the solution or create your own!

# Costs for this workshop

As the majority of the workload is running at the edge, AWS Cloud costs will generally be minimal. However, actual costs are variable based on

  • number of iterations of S3 upload of artifacts, IoT Core messaging to deploy components

  • Cloud9 or EC2 usage and time (recommended for some projects)

  • Any additional integrations or services the reader may choose to explore
