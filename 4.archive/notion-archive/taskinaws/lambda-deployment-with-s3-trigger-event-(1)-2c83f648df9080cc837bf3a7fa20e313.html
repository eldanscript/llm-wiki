Deployment issue between Lambda and S3 event

  • S3 bucket의 event 알림을 Lambda 함수를 사용하여 처리하는 구성에 대해 CloudFormation을 이용한 배포 시 실패하게 되는 경우가 발생함.

  • S3 event와 Lambda간의 순환 종속성 (Circular dependency) 으로 인해 배포 실패가 발생하게 됨.

Circular dependency 관계

  • 위와 같이 S3 bucket event를 Trigger로 동작하는 Lambda 함수를 CloudFormation으로 deployment 하기 위해

  • Lambda 함수의 생성시 S3 bucket에 접근할 수 있는 permission이 필요하고 이를 위해 S3 bucket의 ARN을 알아야 한다.

  • S3 bucket에서는 event notification 생성을 위해 Lambda 함수의 ARN을 알아야한다.

  • 이 관계로 인해 Lambda 함수와 S3 bucket간에 circular dependency가 발생하게 되고 자동 배포시 S3 event를 Lambda 함수에 수동으로 등록하는 작업을 진행하게 된다.

Solution - Custom resource

  • Circular dependency를 피하기 위해 아래와 같은 순서로 배포를 진행 한다.

    1. S3 bucket을 event notification 구성 없이 생성

    2. Lambda 함수와 S3 bucket access permission 생성

    3. Lambda 함수 ARN을 사용하여 S3 event notification 구성

  • 3번 단계에 대해 CloudFormation의 Custom resource를 적용 하여 자동 배포를 구성 할 수 있습니다.

Custom resource 구현

  • Custom::{CustomResourceTypeName} 형식으로 기술

  • Custom Resource : **ApplyNotification**

    • TestS3Bucket과 TestEventFunction이 생성된 후 ApplyBucketNotificationFunction 을 호출

  • Event Mapping Lambda 함수 : **ApplyBucketNotificationFunction**

    • S3 bucket (S3Bucket)에 Event 처리 Lambda 함수의 ARN (FunctionARN)을 사용하여 Event Trigger (NotificationId) 를 생성

SAM 구현 Code

  • 첨부 파일 중 2.SAM 폴더 내 구성 파일

sam-s3-lambda-notification.zip

  • template.yaml

    • SAM Template file

  • samconfig.toml

    • SAM CLI 매개 변수를 저장하는 project 구성 파일

  • lambda/TestEvent.py

    • S3 Bucket에서 발생하는 CRUD event에 대해 처리 하는 lambda 함수

  • lambda/ApplyBucketNotification.py

    • 생성되는 S3 Bucket의 Trigger Event를 생성하고 TestEvent lambda 함수를 연결 시키는 lambda 함수

  • requirements.txt

    • ApplyBucketNotification.py 에서 사용하는 cfnresponse library 설치

SAM Code 설명

  • SAM Template file : **template.yaml**

  • 각 Resource에 Dependency를 설정하여 순차적 생성 가능하도록 구성

    • DependsOn: S3EventBucket → S3 Bucket이 생성 후 Event Trigger 함수 생성

    • DependsOn: TestEventFunction → Event Trigger 함수 생성 후 Custom Resource lambda 함수 생성

  • Custom Resource 생성

    • Type: Custom::CustomResource

SAM Project 구성 및 Deploy

  • SAM Project 생성

    💡

    SAM Application - Hello World 배포

    • SAM CLI 를 사용하여 기본 HelloWorld project를 생성한 후 첨부 SAM project 파일로 업데이트 합니다. Project 생성 시 Runtime은 python3.8 로 구성 합니다.

  • SAM Project Build & Deploy

    • sam validate

    • sam build

    • sam deploy —guided

  • Deploy 결과 Lambda 함수 콘솔에서 S3 Bucket event가 연결되는 것을 확인할 수 있습니다.

  • Sample Lambda 코드는 S3 Event 내용을 단순 print 합니다. Lambda 함수 콘솔의 Monitor 항목에서 CloudWatch Log를 통해 Event를 확인할 수 있습니다.
