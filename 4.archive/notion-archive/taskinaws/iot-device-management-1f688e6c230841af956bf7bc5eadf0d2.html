Single Device Provisioning

Create Certificate using CSR

  • https://docs.aws.amazon.com/iot/latest/apireference/API_CreateCertificateFromCsr.html

  • Signer CA에게 디바이스의 공개 키를 전달하고 디바이스 인증서 생성을 요청하는 과정

  • Public Key

    • RSA

    • 2048 bit의 ECC (Elliptic Curve Cryptosystems)을 사용

      • NIST P-256, NIST P-384, NIST P-512 curve

    • 지원되는 Signing algorithm : https://docs.aws.amazon.com/iot/latest/developerguide/x509-client-certs.html#x509-cert-algorithms

  • 동일 CSR을 사용해도 고유한 인증서가 생성됨

  • 여러개의 CSR을 동일 directory에 두고 여러개의 인증서 생성을 요청할 수 있음

Private CA

💡

https://docs.aws.amazon.com/iot/latest/developerguide/device-certs-your-own.html

  • Amazon root CA가 아닌 다른 root CA가 sign한 client 인증서를 등록할 수 있음

  • Client 인증서 등록 전에 root CA가 AWS IoT에 등록 되어 있어야 함

Limitation

  • Region당 한개의 account에서 CA 인증서 등록 가능

Creat own CA

Configuration files

  • private CA asset은 S3에 암호화 되어 저장

  • private CA 생성을 위해서는 다음 항목에 대한 지정이 필요

    • OCSP (Online Certificate Status Protocol) config : OCSP responder URL

    • CRL (Certificate Revocation List) : CRL 유효 기간, CRL과 CNAME alias가 있는 S3 bucket

    • CA type

    • Optional idempotency token : 여러개의 CA 생성 방지를 위해 필요. 5분내에 동일 token으로 여러번 요청을 보내면 하나의 요청으로 간주

  • CA config

    • Algorithm 명, Key size 지정

  • Revok config : 취소

    • CRL : certification revocation list

Just in time Provisioning

Condition

  • 디바이스가 AWS IoT Core에 처음 연결될 때 자동으로 등록

  • 사용자 CA를 가져와 자동으로 등록할 수 있어야 함

  • CA에 Provisioning template을 associate 해야 함

  • 디바이스 인증서는 사용자 CA로 발급이 되어야 함

Variable

  • private CA : 등록된 사용자 CA의 arn
  • private CA 인증서 ID : AWS IoT에 등록된 사용자 CA 인증서 ID

Just In Time Registration

Working Flow

  • As input the Lambda function receives amongst others the device certificate id, ca certificate id and device certificates status

  • The common name (CN) from the device certificate is used to create a thing in the device registry

  • An IoT policy named jitr_Policy is created if it doesn’t exist

  • The device certificate is activated

  • The device certificate is attached to the thing name

  • The IoT policy is attached to the device certificate
