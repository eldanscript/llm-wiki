SageMaker Modeling

Mechanical Turk

Amazon Mechanical Turk

  • Provide an interface that we can form out little tasks

  • There’s actual humans on the other side that take those tasks and they complete tht tasks and they get paid a certain amount of money for completing those tasks

Data Format

CSV

  • Most SageMaker algorithms accept

  • The target value should be in the first column with no header

  • metadata Content-Type : text/csv

RecordIO protobuf

  • For optimal performance

  • Tak advantage of Pipe mode

  • Data can be streamed from S3 to the learning instance requiring less EBS space and faster strart-up

Pipe input mode

  • the data is streamed directly to the algorithm container while model training is in progress.

  • training jobs start faster, use significantly less disk space and finish sooner

  • reduce overall cost to train machine learning models

File mode

  • downloads data to the local Amazon Elastic Block Store (EBS) volume prior to starting the training

CreateTrainingJob API

  • High-Level Python library or SDK for Python

  • Specify the training algorithm

  • Supply algorithm-specific hyperparameters

  • Specify the input and output configuration

Hyperparameters

Hyperparmeter

  • Values set before the learning process

Parameter

  • Values derived via the learning process
