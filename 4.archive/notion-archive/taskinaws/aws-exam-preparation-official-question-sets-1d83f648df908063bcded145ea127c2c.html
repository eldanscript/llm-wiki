  • Prediction : 문제 꼼꼼히 보기

  • SageMaker Experiments is able to capture artifacts, parameters, and metrics.

이 문제의 주요 내용은 다음과 같습니다:

  1. 보험 회사가 청구서 컴플라이언스 검토를 자동화하려 함
  • 인력 검토가 비용이 많이 들고 오류가 발생하기 때문
  1. 회사는 SageMaker 내장 알고리즘을 사용하여 ML 모델을 개발하려 함
  • 모델은 각 청구서를 읽고 컴플라이언스 여부를 예측해야 함
  1. 모델 입력으로 사용할 청구서 특징을 추출해야 함
  • 청구서는 영어로 된 복잡한 관련 정보를 포함하고 있음
  1. 요구사항:

  • 청구서에서 특징을 추출할 수 있는 솔루션

  • 추출된 특징을 입력으로 사용하여 지도학습 모델을 학습시킬 수 있어야 함

따라서 이 문제의 핵심은 복잡한 관련 정보가 포함된 텍스트 데이터에서 효과적인 특징을 추출하여 지도학습 모델의 입력으로 사용하는 것입니다.

정답: D. Apply SageMaker Object2Vec to claims in the training set. Send derived feature space as inputs for the downstream supervised task.

이 답변이 정답인 이유는 다음과 같습니다:

  • 이 문제에서는 복잡한 관련 정보가 포함된 문장들로 구성된 보험 청구서를 대상으로 합니다.

  • 단순한 one-hot encoding이나 Word2Vec은 이러한 복잡한 문장 간 관계를 효과적으로 포착하기 어렵습니다.

  • 반면 SageMaker의 Object2Vec 알고리즘은 단어 수준이 아닌 문장/문단 수준의 **임베딩을 생**성할 수 있어, 이 문제의 요구사항을 더 잘 충족할 수 있습니다.

  • **Object2Vec을 통해 추출된 특징들을 입력으로 사용하여 후속 지도학습 모델을 학습**할 수 있습니다.

잘못된 답변들에 대한 이유는 다음과 같습니다:

A. One-hot encoding은 단순한 방법으로 복잡한 문장 관계를 포착하기 어렵습니다.
B. **Word2Vec**은 단어 수준 임베딩이므로 **문장 수준의 복잡한 관계**를 포착하기 어렵습니다.
C. **BlazingText 분류 모드**는 이 문제의 요구사항과 부합하지 않습니다.

종합적으로 SageMaker Object2Vec이 이 문제의 요구사항을 가장 잘 충족할 수 있는 솔루션이라고 볼 수 있습니다.

이 문제에 대한 정답이 B인 이유는 다음과 같습니다:

  1. 모델이 과적합(overfitting)되고 있다는 점:

    • 훈련 데이터에서는 97%의 정확도를 보이지만, 테스트 데이터에서는 75%의 정확도만 보이는 것은 과적합이 발생했음을 나타냅니다.

    • 과적합이 발생하면 모델이 훈련 데이터에만 과도하게 맞춰져 있어 새로운 데이터에 대해서는 일반화 성능이 떨어집니다.

  2. 하이퍼파라미터 튜닝이 필요한 점:

    • 과적합을 해결하기 위해서는 **모델의 하이퍼파라미터를 적절히 조정하여 모델의 복잡도를 낮추는 것**이 중요합니다.

    • 하이퍼파라미터를 조정하여 모델을 재학습하면 훈련 데이터와 테스트 데이터 간 성능 차이를 줄일 수 있습니다.

  3. 데이터 분할에 관한 문제:

    • 데이터 분할 방식이 적절하지 않아 과적합이 발생했을 가능성이 있습니다.

    • 훈련 데이터와 테스트 데이터가 **랜덤하게 분할되지 않았다면 과적합이 일어날 수 있습니다.**

따라서 이 문제에서는 하이퍼파라미터 튜닝을 통해 모델의 과적합을 해결하는 것이 가장 적절한 접근이며, 데이터 분할 방식도 확인해볼 필요가 있습니다. **단순히 데이터 세트 비율을 조정하는 것은 문제를 해결하기에 충분하지 않을 수 있습니다**.

문제 요약:

  • 고객 리뷰에서 인사이트를 자동으로 요약하기 위해 ML 모델을 훈련시켜야 합니다. ML 모델의 출력을 사용하여 제품과 기능을 변경할 우선순위를 결정

  • 어떤 알고리즘을 사용해야 할까요?

정답: C. Amazon SageMaker (seq2seq) 알고리즘

이유:

  • seq2seq(sequence-to-sequence) 알고리즘은 입력 시퀀스를 출력 시퀀스로 변환하는 데 사용되는 감독 학습 알고리즘입니다.

  • 고객 리뷰 텍스트를 요약하는 작업은 입력 텍스트 시퀀스를 출력 요약 텍스트 시퀀스로 변환하는 것이므로, seq2seq 알고리즘이 적합합니다.

  • seq2seq 알고리즘은 일반적으로 텍스트 요약 작업에 널리 사용됩니다.

오답 분석:
A. Amazon SageMaker 선형 학습기 알고리즘

  • **선형 학습기 알고리즘**은 **분류 또는 회귀 작업**에 사용되며, 텍스트 요약에는 적합하지 않습니다.

B. Amazon SageMaker Latent Dirichlet Allocation (LDA) 알고리즘

  • **LDA 알고리즘**은 비지도 학습 알고리즘으로, **텍스트를 그룹화**하는 데 사용됩니다. 텍스트 요약에는 적합하지 않습니다.

D. Amazon SageMaker 의미론적 분할 알고리즘

  • **의미론적 분할 알고리즘**은 이미지 픽셀에 클래스 레이블을 지정하는 **컴퓨터 비전 알고리즘**입니다. 텍스트 요약에는 적합하지 않습니다.

종합하면, 문제 상황에서 가장 적합한 알고리즘은 seq2seq 알고리즘이며, 이유는 입력 텍스트를 출력 요약 텍스트로 변환하는 데 효과적이기 때문입니다.

문제 요약:

  • 회사에 1,000개의 문장이 있고, 긍정, 중립, 부정의 감정이 **분류되어 있다**.

  • 이를 기반으로 감정 분석 모델을 훈련하기 위해 어떤 알고리즘을 선택해야 하는가?

정답: A. Amazon SageMaker k-nearest neighbors (k-NN)

  • k-NN은 분류 및 회귀에 사용되는 인덱스 기반 알고리즘이다.

  • 이 문제는 긍정, 중립, 부정의 **다중 클래스 분류 문제이므로 k-NN이 적합**하다.

  • k-NN은 단어 순서와 관계없이 문장을 분류할 수 있다.

오답 분석:
B. Amazon SageMaker Latent Dirichlet Allocation (LDA)

  • **LDA는 비지도 학습** 알고리즘으로, 이 문제는 레이블된 데이터를 이용한 지도 학습 문제이다.

  • **LDA는 "단어백" 모델**이므로 **단어 순서를 고려하지 않아 감정 분석에 적합하지 않다**.

C. Amazon SageMaker k-means

  • k-means는 군집화 모델로, 분류 문제에 적합하지 않다.

D. Amazon SageMaker Random Cut Forest (RCF)

  • RCF는 주로 이상치 탐지에 사용되는 비지도 학습 모델이다.

  • 이 문제는 분류 문제이므로 RCF는 적절하지 않다.

  1. 정답인 D. Precision:

  • Precision은 true positive / (true positive + false positive)를 나타냅니다.

  • 이 문제에서는 어린이에게 부적절한 콘텐츠가 노출되는 것을 최소화하는 것이 가장 중요한 목표입니다.

  • 따라서 **false positive(부적절한 콘텐츠를 안전한 것으로 잘못 분류)를 최소화하는 것이 중요**하므로, **Precision**이 가장 적합한 평가 지표입니다.

  1. 오답 해설:

  • A. Recall: Recall은 true positive / (true positive + false negative)를 나타내며, false negative(부적절한 콘텐츠를 안전한 것으로 잘못 분류)를 최소화하는 데 초점을 둡니다. 이 문제에서는 false positive 최소화가 더 중요합니다.

  • B. Accuracy: Accuracy는 전체 예측 중 정확한 예측의 비율을 나타내지만, 이 문제에서는 false positive 최소화가 더 중요합니다.

  • C. AUC/ROC: AUC/ROC는 false positive와 false negative 사이의 trade-off를 반영하지만, 이 문제에서는 false positive 최소화가 더 중요합니다.

Recall과 Precision을 쉽게 구분할 수 있는 기준은 다음과 같습니다:

  • **Recall: 실제 positive인 것 중에서 얼마나 많이 잘 찾아내는지**

  • **Precision: 예측한 positive 중에서 실제로 positive인 것이 얼마나 되는지**

문제 요약:

  • 디지털 신문사가 많은 기사와 사람이 작성한 요약문을 가지고 있음

  • 신문사 편집자들은 자동으로 요약문을 생성하는 솔루션을 원함

  • ML 전문가가 요약 생성 프로세스를 자동화해야 함

정답 및 오답 분석:

A. 원 기사에 Neural Topic Model (NTM) 적용하기

  • 오답 이유: **NTM**은 토픽을 생성하지만, **자연어 요약문을 생성하지는 않음**

B. Word2vec 분석 결과 요약 및 게시하기

  • 오답 이유: Word2vec은 텍스트 분류에 사용되며, 요약 생성에는 적합하지 않음

C. 요약문을 이용해 Latent Dirichlet Allocation (LDA) 훈련하기

  • 오답 이유: **LDA는 문서 분류**에 사용되며, 요약 생성에는 적합하지 않음

D. seq2seq 순환 신경망(RNN) 적용하기

  • 정답 이유: seq2seq 알고리즘은 단**어 시퀀스를 인코딩하고 디코딩**할 수 있어 **기사 요약에 적합**함

결론적으로, 정답은 D번 선택지입니다. seq2seq RNN이 기사 요약 생성에 가장 적합한 솔루션이라고 볼 수 있습니다.

이 문제는 데이터 불균형 문제를 가진 프로드 탐지 모델의 정확도를 높이는 방법에 대한 문제입니다.

정답 분석:
C. **합성 소수 과대 표집 기법(SMOTE)을 사용한 과대 표집** - 이 방법은 소수 클래스(사기 사례)에 대한 합성 데이터 포인트를 생성하여 데이터셋의 다양성을 높여 과적합을 줄이고 모델 정확도를 향상시킬 수 있습니다.

오답 분석:
A. **부트스트래핑**을 사용한 과대 표집 - 이 방법은 **기존 소수 클래스 데이터를 복제**하여 불균형을 해결할 수는 있지만, 새로운 데이터 포인트를 추가하지는 않습니다. 따라서 데이터 부족 문제를 해결하지 못합니다.
B. 과소 표집 - 이 방법은 다수 클래스의 데이터를 제거하여 불균형을 해결할 수 있지만, 잠재적으로 유용한 정보를 손실할 수 있습니다.
D. 클래스 가중치 조정 - 이 방법은 모델 학습 시 소수 클래스에 더 높은 가중치를 부여하지만, 데이터 부족 문제를 해결하지는 못합니다.

따라서 이 문제에서 가장 적절한 해결책은 SMOTE를 사용한 과대 표집 기법입니다.
