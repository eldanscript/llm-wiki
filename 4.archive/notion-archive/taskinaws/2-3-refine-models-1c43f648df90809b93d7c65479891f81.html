2.3 Refine Models

Objectives

  1. 모델 평가 지표 정의 및 해석:

    • 모델 편향(bias)과 모델 분산(variance)과 같은 모델 평가 지표를 정의하고 해석할 수 있습니다.

  2. 모델 과적합 및 과소적합 탐지 방법:

    • 모델 과적합과 과소적합을 탐지하는 방법을 설명할 수 있습니다.

  3. 과적합 및 과소적합 방지를 위한 기법:

    • 정규화 기법(regularization)과 특성 선택(feature selection)을 사용하여 모델 과적합 및 과소적합을 방지할 수 있습니다.

  4. 앙상블 학습을 통한 모델 성능 향상:

    • 부스팅(boosting), 배깅(bagging), 스태킹(stacking) 등의 앙상블 기법을 사용하여 여러 모델을 결합하여 모델 성능을 향상시킬 수 있습니다.

  5. 하이퍼파라미터가 모델 성능에 미치는 영향:

    • 하이퍼파라미터가 모델 성능에 어떻게 영향을 미치는지 설명할 수 있습니다.

  6. 하이퍼파라미터 튜닝 기법:

    • 하이퍼파라미터 튜닝을 위한 주요 기법을 정의할 수 있습니다.

  7. 자동화된 하이퍼파라미터 최적화:

    • 자동화된 하이퍼파라미터 최적화를 수행하여 모델 성능을 향상시킬 수 있습니다.

  8. 모델 크기에 영향을 미치는 요인:

    • 모델 크기에 영향을 미치는 주요 요인을 식별할 수 있습니다.

  9. 모델 크기 축소를 위한 반복적 모델 압축:

    • **반복적 모델 압축(iterative model pruning) 기법을 사용하여 모델 크기를 줄일 수 있습니다**.

  10. 사용자 정의 데이터세트를 이용한 사전 학습 모델 fine-tuning:

    • Amazon SageMaker JumpStart와 Amazon Bedrock을 사용하여 사용자 정의 데이터세트로 **사전 학습 모델을 fine-tuning**할 수 있습니다.

  11. 재앙적 망각 방지를 위한 기법:

    • 정규화 기법과 특성 선택을 통해 **재앙적 망각(catastrophic forgetting)을 방지**할 수 있습니다.

  12. Amazon SageMaker Model Registry를 통한 모델 버전 관리:

    • Amazon SageMaker **Model Registry를 사용하여 모델 버전을 관리**함으로써 반복성과 감사 기능을 보장할 수 있습니다.

Evaluating Model Performance

  1. 모델 평가:

    • 모델 학습 시 훈련 데이터셋을 사용하고, 검증 데이터셋으로 모델 성능을 평가한다.

    • 검증 데이터셋에서 모델 성능이 좋다면 마지막으로 테스트 데이터셋으로 평가한다.

  2. 모델 편향과 분산:

    • **모델 편향(bias)**은 입력 **특성과 목표 변수 간 관계를 제대로 학습하지 못하는 것**을 의미한다.

    • **모델 분산(variance)**은 모델이 **훈련 데이터에 과도하게 민감**한 것을 의미한다.

  3. 편향-분산 트레이드오프:

    • 모델이 **편향이 너무 높으면 단순해져 데이터 패턴을 충분히 학습하지 못한다**.

    • 반면 **분산이 너무 높으면 훈련 데이터에 과적합되어 일반화 성능이 떨어진다**.

    • 따라서 적절한 편향과 분산의 균형을 찾는 것이 중요하다.

  4. 편향-분산 트레이드오프 관리:

    • 데이터 전처리 방법과 모델 하이퍼파라미터 조정을 통해 편향과 분산의 균형을 맞출 수 있다.

    • 이를 통해 모델 예측 오류를 최소화할 수 있다.

Model Bias-Variance Trade-off

Model Overfitting and Underfitting

Overfit Model (과적합 모델)

  • 과적합 모델은 훈련 데이터의 노이즈나 고유한 패턴을 너무 잘 학습해 버려 일반화 성능이 낮은 모델

발생 원인

  • Training Dataset Too Small (훈련 데이터 부족)

    • 훈련 데이터가 제한적일 때 모델은 과적합될 가능성이 높음

    • 이는 모델이 데이터의 특정 패턴과 노이즈에 과도하게 맞춰져, 데이터의 근본적인 관계를 학습하지 못하기 때문

    • 반면, 데이터셋 크기가 더 크면 이러한 과적합 문제를 완화할 수 있음

    • 더 많은 대표적인 샘플을 제공함으로써, 모델이 데이터의 일반적인 패턴을 더 잘 강조할 수 있게 됨

    • 즉, **데이터셋 크기를 늘리면 모델의 과적합을 줄일 수 있음**

  • Too Much Irrelevant Data (불필요한 데이터 포함)

    • 훈련 데이터에 많은 **불필요한 특성(feature) 또는 노이즈가 포함**된 경우

    • 모델이 이러한 불필요한 패턴까지 학습하려 할 수 있음

    • 이로 인해 모델이 과적합되어 새로운 데이터에 대한 일반화 성능이 떨어짐

  • Excessive Training Time (과도한 훈련 시간)

    • 동일한 데이터에 대해 지나치게 오랫동안 학습하는 경우

    • 모델이 데이터의 근본적인 패턴을 학습하는 대신 **훈련 예제를 단순히 암기하게 될 수 있음**

    • 이로 인해 모델이 과적합되어 새로운 데이터에 대한 일반화 성능이 저하될 수 있음

  • Overly Complex Architecture (너무 복잡한 모델 구조)

    • 모델의 매개변수(가중치와 편향)가 너무 많은 경우

    • 모델이 **훈련 데이터와 노이즈를 단순히 암기하게 될 수 있음**

    • 이로 인해 모델이 과적합되어 새로운 데이터에 대한 일반화 성능이 저하될 수 있음

과적합 감지

  • 모델 분산(variance)이 높은 것을 통해 과적합을 탐지할 수 있습니다.

  • K-fold 교차 검증을 통해 모델의 일반화 성능과 과적합을 평가할 수 있습니다.

    • 단일 검증 데이터셋의 경우 데이터 분포를 대표하지 못할 위험이 있음

    • K-fold 교차 검증은 이를 해결하기 위해 여러 개의 검증 데이터셋을 생성하여 추가 테스트를 수행함

    • K-fold 교차 검증에서는 동일한 데이터셋을 k개의 부분집합(fold)으로 분할함

    • 각 모델 학습 시마다 다른 fold를 검증 데이터셋으로 사용하고, 나머지 fold를 학습 데이터셋으로 사용함

    • 이 과정을 k번 반복하여 서로 다른 검증 데이터셋으로 모델을 평가함

    • 이를 통해 **모델의 일반화 성능과 과적합 가능성을 보다 강건하게 평가**할 수 있음

Underfit Model (과소적합 모델)

  • 데이터의 복잡한 패턴을 충분히 학습하지 못해 성능이 좋지 않은 모델을 말합니다.

발생 원인

  • Insufficient Data Points (데이터 부족)

    • 훈련 데이터셋이 너무 작거나 충분한 정보를 포함하지 않는 경우

    • 이로 인해 모델이 일반화하기 어려워지고, 입력 특성과 목표 변수 사이의 복잡한 관계를 학습하지 못할 수 있음

    • 즉, 제한된 데이터로 인해 모델 과소적합이 발생할 수 있음

  • Insufficient Training Time (훈련 시간 부족)

    • 모델이 충분한 시간 동안 학습되지 않은 경우

    • 이로 인해 모델이 데이터의 필요한 패턴과 관계를 학습할 기회를 얻지 못함

    • 최적의 솔루션에 수렴하기 전에 **학습 과정이 조기에 중단되면 이러한 문제가 발생**할 수 있음

    • 즉, 부족한 학습 시간으로 인해 모델 과소적합이 발생할 수 있음

  • Simple Model (단순한 모델 구조)

    • 모델의 매개변수(가중치와 편향)가 너무 적은 경우

    • 이 경우 모델이 데이터 내의 비선형적 관계나 복잡한 패턴을 정확하게 포착하기 어려워질 수 있음

    • 즉, 모델 아키텍처가 너무 단순하면 과소적합 문제가 발생할 수 있음

과소적합 탐지

  • 모델 편향(bias)이 높은 것을 통해 과소적합을 탐지

Balanced fit Model (균형 잡힌 모델)

  • 과적합과 과소적합의 균형을 이루어 새로운 데이터에 대해 잘 일반화되는 모델

Model Overfitting and Underfitting Prevention

모델의 과적합을 해결하기 위한 기법

  • **조기 중지(Early Stopping)**

    • 모델이 데이터의 **노이즈까지 학습하기 전에 학습을 중단**하는 기법

    • 검증 데이터셋 **성능이 더 이상 향상되지 않을 때 학습을 중단**

  • **가지치기(Pruning)**

    • 모델에서 **중요도가 낮은 가중치를 제거**하여 과적합을 방지

    • **불필요한 특성과 연결을 제거**하여 모델 복잡도를 낮춤

  • **정규화(Regularization)**

    • 모델의 **가중치 값을 제한하여 과적합을 방지**

      • **Dropout**

        • Dropout은 각 **에폭(epoch) 마다 신경망의 각 층에서 무작위로 일부 뉴런을 0으로 만듭니다.**

        • 이를 통해 신경망이 특정 뉴런에 과도하게 의존하지 않도록 하고, **다양한 방법으로 결과에 도달하도록 강제**합니다.

        • 이러한 방식으로 Dropout은 과적합을 방지하는 데 효과적입니다.

      • **L1**

        • L1 정규화는 특성 자체를 제거하는 것이 아니라, **중요도가 낮은 특성의 가중치를 0으로 밀어냅니다.**

        • 이를 통해 모델을 **희소(sparse) 모델로 만들어 노이즈를 감소**시킬 수 있습니다.

        • 즉, L1 정규화를 통해 중요도가 낮은 특성의 영향을 줄일 수 있어 과적합 방지에 효과적입니다

      • **L2**

        • L2 정규화는 **전체 가중치 값을 작게 만들어 줍니다.**

        • 입력 특성들 간 **상관관계가 높은 경우, L2 정규화는 가중치를 안정화**시켜 줍니다.

        • L2 정규화에서는 **가중치 감소(weight decay) 매개변수를 조정하여 손실 함수의 페널티 항의 영향력을 결정**합니다.

        • 이를 통해 모델이 더 작은 가중치 값을 학습하도록 하여, **보다 부드럽고 일반화된 모델**을 만들 수 있습니다.

  • 데이터 증강(Data Augmentation)

    • 기존 **데이터에 변형을 가하여 데이터셋 다양성**을 높임

    • 모델의 일반화 성능 향상

  • 모델 구조 단순화

    • 복잡한 모델 구조를 단순화하여 과적합을 방지

모델 과소적합을 해결하기 위한 기법

  • 적절한 학습 시간 확보

    • 모델이 충분한 시간 동안 학습하여 최적의 성능에 도달하도록 함

    • 특히 심층 신경망과 같은 **복잡한 기계 학습 모델**은 최적의 솔루션에 수렴하고 데이터의 underlying 패턴을 학습하기 위해 **많은 학습 에폭(epoch)이 필요**합니다.

    • 수렴하기 전에 **학습 과정을 조기에 중단**하면, 모델이 올바른 가중치 값을 설정하고 관련 정보를 충분히 학습하지 못해 **과소적합이 발생**할 수 있습니다.

    • 이를 방지하기 위해서는 학습 과정 중 모델의 성능을 모니터링하는 것이 중요합니다.

    • 별도의 검증 데이터셋을 사용하여 학습이 진행됨에 따라 성능의 변화를 추적해야 합니다.

    • 검증 성능이 안정화되거나 더 이상 향상되지 않을 때까지 학습을 지속하면, 모델이 최적의 솔루션에 수렴했음을 알 수 있습니다.

  • 더 많은 데이터 활용

    • 데이터셋의 크기를 늘리거나 데이터 증강을 통해 과소적합 해결

    • 훈련 데이터셋이 너무 작거나 대표성이 부족한 경우

    • 이로 인해 모델이 올바른 가중치 값과 매개변수 간 관계를 학습하기 어려워질 수 있음

    • 이 문제를 해결하기 위해서는 다음과 같은 방법을 사용할 수 있습니다:

      • 더 많은 데이터를 수집하여 훈련 데이터셋의 크기를 늘리기

      • 데이터 증강 기법을 활용하여 추가적인 합성 데이터 생성하기

  • 모델 유연성 증가

    • 새로운 특성 추가 (Add New Domain Specific Features)

      • 추가적인 관련 특성을 포함하면 모델이 데이터의 중요한 패턴과 관계를 더 잘 포착할 수 있습니다.

      • 문제 도메인에 특화된 추가 특성을 제공하면, 모델이 고려해야 할 차원이 늘어나 보다 세부적인 모델을 만들 수 있습니다.

      • 예를 들어, 길이, 너비, 높이 등의 변수가 있다면, 이 세 변수의 곱인 부피 특성을 새로 만들 수 있습니다.

      • 이처럼 관련 특성을 추가하면 모델의 유연성이 증가하여 과소적합 문제를 해결할 수 있습니다

    • 새로운 특성 조합 (Add Cartesian Products)

      • 카르타지안 곱은 **기존의 특성들을 조합하여 새로운 추가 특성을 만드는 기법**입니다.

      • 예를 들어, 다음과 같은 두 변수가 있다고 가정해 봅시다:

        • 인구 밀도 - 도시, 교외, 시골 값을 가짐

        • 주 - 워싱턴, 오레곤, 캘리포니아 값을 가짐

      • 이 두 변수의 카르타지안 곱을 통해 다음과 같은 새로운 특성을 만들 수 있습니다:

        • urban_Washington, suburban_Washington, rural_Washington

        • urban_Oregon, suburban_Oregon, rural_Oregon

        • urban_California, suburban_California, rural_California

      • 이와 같이 카르타지안 곱을 사용하면 모델의 유연성을 높여 과소적합 문제를 해결할 수 있습니다

    • Change Feature Engineering (특성 처리 기법)

      • 자연어 처리 작업의 경우, n-gram의 크기(연속된 단어의 수)를 증가시키면 더 복잡한 언어 패턴을 포착할 수 있습니다.

      • 예를 들어, 단일 단어(unigram)보다는 2-gram(bigram) 또는 3-gram(trigram)을 사용하면 단어 간의 관계를 더 잘 학습할 수 있습니다.

      • 이와 같이 특성 처리 기법을 조정하여 모델의 유연성을 높일 수 있습니다.

      • 결과적으로 모델이 데이터의 관련 패턴을 보다 잘 학습할 수 있게 되어 과소적합 문제를 해결할 수 있습니다.

    • Decrease Regulation (정규화 기법 약화)

      • 정규화는 매개변수 가중치 설정을 지나치게 제한하여 과소적합을 초래할 수 있습니다.

      • 이를 해결하기 위해서는 정규화 강도를 줄이거나 다른 정규화 기법을 사용하는 등 정규화 정도를 감소시킬 수 있습니다.

      • 이렇게 하면 모델이 데이터의 복잡성을 보다 잘 포착할 수 있게 됩니다.

Model Combination for Improved Performance

Ensembling (앙상블)

  • 여러 개의 기계 학습 모델 예측 또는 출력을 결합하여 더 정확하고 강건한 최종 예측을 만드는 과정

  • 개별 모델의 약점을 보완하여 전체 성능을 향상시키는 데 도움이 되며 주요 앙상블 기법은 Boosting, Bagging, Stacking 이 있습니다.

Boosting

  • **순차적으로 학습된 모델들의 출력을 결합**하여 최종 예측을 생성

  • 개별 모델이 약하거나 편향/분산이 있더라도 다양한 데이터 측면을 포착할 수 있음

    1. 훈련 데이터셋에 대해 모든 데이터 샘플에 **동일한 가중치를 부여**한다.

    2. 훈련 데이터셋을 사용하여 **첫 번째 ML 모델을 학습**한다.

    3. 기본 알고리즘이 각 데이터 샘플에 대한 예측을 수행하고, **전체 모델의 오차를 측정**한다.

    4. **오차가 큰 데이터 샘플에 대한 가중치를 높이고, 모델에 대한 가중치를 결정**한다. 이 가중치는 최종 예측에 미치는 영향력을 결정한다.

    5. **재가중된 데이터셋을 사용하여 새로운 모델을 학습**한다.

    6. 이 과정을 중단 기준(예: 학습 오차 수, 최대 모델 수)에 도달할 때까지 반복한다.

  • Adaptive Boosting (AdaBoost) - 가중치 조정

    • AdaBoost는 훈련 데이터에 대해 **순차적으로 약한 학습기(weak learner)**, 예를 들어 의사결정 트리를 학습합니다.

    • 각 반복 단계에서 AdaBoost는 훈련 데이터의 각 인스턴스에 가중치를 부여합니다.

    • 그리고 이전 학습기에 의해 잘못 분류된 인스턴스에 더 큰 가중치를 부여합니다.

    • 이를 통해 AdaBoost는 **이전 학습기의 오류를 점진적으로 보정해 나가면서 강력한 최종 모델을 만들어 냅니다**.

  • Gradient Boosting (GB) - 손실 함수 최적화

    • GB는 **약한 학습기(weak learner)들의 앙상**블을 구축합니다.

    • 새로운 학습기는 이전 앙상블의 **잔여 오류를 최소화하도록 학습**됩니다.

    • AdaBoost와 달리 GB는 데이터 샘플의 가중치를 조정하는 대신, 각 **반복 단계에서 손실 함수를 최적화**합니다.

    • 이 결과 **가장 최근에 학습된 모델이 항상 가장 우수한 성능**을 보입니다.

    • GB는 분류 문제와 회귀 문제 모두에 적용할 수 있는 강력한 알고리즘입니다.

  • Extreme Gradient Boosting (XGBoost)

    • CPU의 여러 코어를 활용하여 **병렬 학습을 수행**합니다.

    • 병렬화, 분산 컴퓨팅, 캐시 최적화, 디스크 기반 처리 기능을 제공합니다.

    • 이러한 성능 향상 기술들로 인해 XGBoost는 **대용량 데이터셋 및 빅데이터 애플리케이션에 적합**합니다.

Bagging

  • **다양한 데이터셋으로 학습된 모델들의 출력을 결합**

  • 과적합 방지 및 예측 정확도 향상

    1. 훈련 데이터셋을 부트스트래핑(bootstrapping)을 이용하여 **여러 개의 부분집합**으로 나눕니다.

    2. 각각의 **부트스트랩 부분집합을** 사용하여 **별도의 모델들을 학습**시킵니다.

  • Random forests bagging algorithm

    • 랜덤 포레스트는 **훈련 데이터셋을 무작위 샘플링**하여 **다수의 의사결정 트리 모델을 학습**합니다.

    • 각 의사결정 트리 모델 학습 시, 노드 분할을 위해 무작위로 선택된 특성 부분집합을 사용합니다.

    • 이는 배깅 기법과 랜덤 특성 선택을 결합한 방식으로, 과적합을 방지하고 안정적인 예측 성능을 제공합니다.

Stacking

  • 다수의 기본 모델(level-0 모델)의 예측 결과를 메타 모델(level-1 모델)에 입력하여 최종 예측 생성

  • **복잡한 패턴을 포착하기 위해 다양한 모델을 결합**

    1. 베이스 모델 선택: 의사결정 트리, 랜덤 포레스트 등 다양한 기계 학습 알고리즘을 level-0 모델로 선택한다.

    2. level-0 모델 학습: 각각의 level-0 모델을 훈련 데이터로 학습시킨다.

    3. 메타 모델 입력 데이터 생성: 검증 데이터셋 또는 다른 별도의 데이터를 사용하여 trained level-0 모델의 예측 결과를 생성한다. 이 예측 결과를 메타 모델의 입력 특성으로 사용한다.

    4. 메타 모델 학습: 3단계에서 생성한 입력 데이터를 사용하여 level-1 모델, 즉 메타 모델 또는 메타 학습기를 학습시킨다.

    5. 최종 모델 성능 평가: 테스트 데이터를 사용하여 앙상블 모델의 성능을 검증한다.

Hyperparameter Tuning

하이퍼파라미터 튜닝은 기계 학습 모델의 성능을 최적화하는 중요한 단계입니다.

하이퍼파라미터는 모델 학습 전 조정할 수 있는 설정값으로, 이를 체계적으로 튜닝하여 가장 좋은 성능의 모델을 찾아낼 수 있습니다.

하이퍼파라미터가 미치는 영향

  1. 하이퍼파라미터는 **모델의 특성을 정**의합니다. 예를 들어 신경망의 층 수, 랜덤 포레스트의 트리 수 등을 결정합니다.

  2. 하이퍼파라미터는 훈련 작업의 효율성과 성능을 최적화하여 균형 잡힌 모델 학습을 가능하게 합니다. 예를 들어 학습률, 배치 크기, 정규화 매개변수 등이 있습니다.

경사하강법 (Gradient descent)

  • 반복적으로 모델 매개변수를 업데이트하여 손실 함수를 최소화합니다.

  • 각 반복 단계에서 현재 매개변수 값에 대한 손실 함수의 기울기(gradient)를 계산합니다.

  • 이 기울기 방향으로 매개변수 값을 업데이트하여 손실 함수를 줄여나갑니다.

Learning Rate

  • 학습률은 각 반복 단계에서 **알고리즘이 취하는 단계 크기**를 결정합니다.

  • 이를 통해 모델 **매개변수 업데이트 속도를 제어**할 수 있습니다.

  • 학습률이 너무 낮으면, 알고리즘이 최적 솔루션에 도달하는 데 너무 오랜 시간이 걸릴 수 있습니다.

  • 반대로 학습률이 **너무 높으면, 알고리즘이 최적 솔루션을 지나쳐 수렴하지 못할 수 있습니다**.

Batch Size

  • 배치 크기는 모델 매개변수를 업데이트하기 전에 각 반복에 사용되는 예제의 수를 결정합니다.

  • 배치 크기가 **크면 더 빠른 수렴 속도**를 얻을 수 있습니다.

  • 그러나 이 경우 더 많은 컴퓨팅 자원이 필요할 수 있습니다.

Epochs

  • 에포크는 훈련 작업이 **전체 훈련 데이터셋을 통과해야 하는 횟수**를 나타냅니다.

  • 충분한 에포크 수를 설정하면 모델이 데이터의 근본적인 관계를 capture할 수 있어 과소적합을 방지할 수 있습니다.

  • 그러나 **에포크 수가 너무 많으면 오히려 과적합이 발생**할 수 있습니다.

  • 에포크 수가 증가함에 따라 다음과 같은 효과를 볼 수 있습니다:

    1. 모델의 수렴 도달: 초기에는 모델 학습이 빠르게 진행되지만, 에포크가 늘어날수록 점진적으로 수렴해 나갑니다.

    2. 과적합 방지: 초기에는 과적합 위험이 높지만, 적절한 수의 에포크를 거치면 모델이 일반화 성능을 높일 수 있습니다.

    3. 복잡한 패턴 학습: 에포크가 늘어나면 모델이 데이터의 더 복잡하고 미묘한 패턴까지 포착할 수 있게 됩니다.

신경망

  • Connections

    • 가중치(weights)와 편향(biases)이 뉴런 출력의 영향력과 효과를 결정함

    • 이를 통해 신경망 내에서 정보가 어떻게 흐르는지가 결정됨

    • 가중치는 한 뉴런의 출력이 다른 뉴런에 미치는 영향력을 결정

    • 편향은 뉴런의 활성화 임계값을 조절하여 출력에 영향을 줌

    • 이러한 연결 강도를 나타내는 가중치와 편향이 신경망의 동작 및 학습 능력을 결정하는 핵심 요소

  • Neuron

    • 다른 뉴런들로부터 전달받은 입력값에 대해 수학적 함수를 적용합니다.

    • 이 함수를 통해 계산된 값을 출력값으로 내보냅니다.

  • Activation Functions

    • 뉴런으로 전달되는 데이터 입력값에 대해 특정 수학적 함수를 적용합니다.

    • 이 함수는 입력 데이터를 처리하여 뉴런의 출력값을 결정합니다.

    • 이러한 활성화 함수의 선택은 신경망 모델링에서 중요한 하이퍼파라미터 중 하나입니다.

  • Input Layer

    • 신경망의 가장 첫 번째 층으로, 외부 입력 데이터를 받아들입니다.

    • 이 층의 뉴런 수는 입력 데이터의 특성(feature) 수와 동일합니다.

    • 입력층은 데이터를 다음 은닉층으로 전달하는 역할을 합니다.

    • 신경망 모델링에서 입력층은 데이터를 네트워크에 공급하는 중요한 부분입니다.

  • Hidden Layer

    • 입력층과 출력층 사이에 위치한 중간 층들을 의미합니다.

    • 실제 데이터 분석 및 특성 추출이 이루어지는 부분입니다.

    • 은닉층은 입력 데이터나 최종 출력에 직접적으로 노출되지 않습니다.

    • 신경망의 심도(depth)를 결정하는 중요한 구성 요소입니다.

    • 은닉층의 수와 각 층의 뉴런 수 등은 신경망 모델링의 핵심 하이퍼파라미터입니다.

  • Output Layer

    • 신경망의 최종 출력을 제공하는 층입니다.

    • 사용되는 활성화 함수와 기계 학습 과제에 따라 출력층의 동작이 결정됩니다.

      • 분류 문제라면 소프트맥스 함수가 주로 사용됩니다.

      • 회귀 문제라면 선형 함수가 사용될 수 있습니다.

    • 출력층의 뉴런 수는 문제에 따른 목표 변수의 차원 수와 관련됩니다.

Number of Layers

  • 신경망의 층 수가 늘어날수록 모델이 더 복잡해진다.

  • 복잡한 모델일수록 입력과 출력 간의 복잡한 관계를 더 잘 모델링할 수 있다.

  • 하지만 신경망의 깊이(layer 수)를 지나치게 늘리면 과적합 위험이 증가한다.

Number of Neurons in Each Layer

  • 각 층의 뉴런 수가 많을수록 입력 데이터를 포착하고 해석할 수 있는 처리 능력이 높아진다.

  • 하지만 뉴런 수를 지나치게 늘리면 과적합 위험이 증가한다.

  • 과도한 뉴런 수는 모델을 데이터의 노이즈에 더 취약하게 만들 수 있다.

Choice of Activation Functions

  • 활성화 함수는 신경망에 비선형성을 도입하여 **복잡한 비선형 관계를 모델링**할 수 있게 해줍니다.

  • 활성화 함수의 선택은 층의 종류와 원하는 출력 결과에 따라 달라집니다.

  • 시그모이드 함수(Sigmoid)

  • 렐루(ReLU, Rectified Linear Unit)

  • 하이퍼볼릭 탄젠트(Tanh)

  • 소프트맥스 함수(Softmax)

Regulation Techniques

  • **정규화는 모델의 복잡도에 대한 제약이나 페널티를 도입하여 과적합을 방지**합니다.

  • L1 정규화와 L2 정규화

  • Dropout

  • 조기 중지(Early stopping)

의사결정 트리

  • Root node

    • 의사결정 나무는 일련의 의사결정 노드(decision node)로 구성되어 있습니다.

    • 모델은 데이터 처리를 루트 노드(root node)에서 시작합니다.

  • Subnode

    • 각 의사결정 노드는 데이터셋의 특정 특성(feature)에 반응합니다.

    • 그리고 조건문을 사용하여 다음에 어떤 하위 노드(subnode)로 갈지 결정합니다.

    • 이와 같이 상위 노드에서 하위 노드로 내려가면서 세분화된 의사결정 규칙을 적용하게 됩니다.

  • Leaf node

    • 의사결정 나무는 최종적으로 리프 노드(leaf node)에서 예측 결과를 출력합니다.

    • 데이터가 상위 노드에서 하위 노드로 내려오면서 조건문을 거쳐 최종적으로 도달하는 리프 노드가 예측 결과가 됩니다.

Maximum Depth of the Tree

  • 이 하이퍼파라미터는 의사결정 나무의 최대 레벨 수를 제한합니다.

  • 이를 통해 모델의 **복잡도를 관리하고 과적합을 방지**할 수 있습니다.

  • 트리의 깊이가 너무 깊어지면 모델이 과도하게 복잡해져 훈련 데이터에 과적합될 수 있습니다.

  • 따라서 적절한 최대 깊이 값을 선택하는 것이 중요한 하이퍼파라미터 튜닝 작업입니다.

Minimum Samples required to split a Node

  • 이 하이퍼파라미터는 노드를 분할하기 위한 최소 데이터 샘플 수 임계값을 설정합니다.

  • 이를 통해 트리가 **지나치게 많은 분기를 생성하는 것을 방지**할 수 있습니다.

  • 또한 이는 과적합 문제를 해결하는 데에도 도움이 됩니다.

Criterion

  1. 지니 불순도(Gini Impurity):

    • 데이터의 **순수도와 오분류 가능성을 측정**하는 지표

    • 동질적/이질적 데이터 분포 여부를 나타냄

    • 하이퍼파라미터 튜닝 시, **부모 노드와 자식 노드의 불순도를 비교하여 노드 분할 여부 결정**

  2. 엔트로피(Entropy):

    • 데이터의 **무작위성을 평가**하는 지표

    • 각 노드의 엔트로피와 후보 자식 노드의 엔트로피 변화량을 측정

    • **엔트로피 감소가 가장 큰 분할을 선택**

Hyperparameter Tuning Techniques

수동 선택(Manual Selection)

  • 직관, 도메인 지식, 과거 경험을 바탕으로 하이퍼파라미터 값을 선택

  • 간단하지만 시간이 많이 걸리고 최적의 결과를 보장하기 어려움

그리드 서치(Grid Search)

  • 모든 하이퍼파라미터 조합을 평가하는 체계적이고 exhaustive한 접근

  • **정확하지만 계산 비용이 매우 높음**

랜덤 서치(Random Search)

  • 랜덤으로 하이퍼파라미터 조합을 선택

  • 그리드 서치보다 **효율적이지만 최적값을 찾지 못할 위험이 있음**

베이지안 최적화(Bayesian Optimization)

  • **이전 결과를 바탕으로 다음 하이퍼파라미터 조합을 예측**

  • **속도가 빠르지만 구현이 복잡함**

하이퍼밴드(Hyperband)

  • 성능이 좋은 구성을 더 많은 자원으로 학습, 나쁜 구성은 조기 중단

  • **병렬 처리에 적합하며 효율적인 리소스 활용이 가능**

Hyperparameter Tuning Using Amazon SageMaker AMT (Automatic Model Tuning)

  • AMT를 사용하면 지정한 범위의 하이퍼파라미터 조합으로 다수의 모델 학습 작업을 실행하고, 최적의 성능을 보이는 모델을 찾을 수 있습니다.

  • 데모에서 ML 엔지니어가 다음과 같은 작업을 수행했습니다:

    • 환경과 리소스(출력 버킷, 학습/검증 데이터셋) 정의

    • 튜닝할 하이퍼파라미터와 값 범위 지정 (alpha, eta, max_depth 등)

    • 목표 평가 지표(AUC) 설정

    • AMT 튜닝 작업 구성 및 실행

    • 최적의 모델과 사용된 하이퍼파라미터 식별

    • 하이퍼파라미터와 평가 지표 간 상관관계 분석

  • 이를 통해 AMT가 효과적으로 하이퍼파라미터 최적화를 수행하여 우수한 모델을 찾아낼 수 있음을 보여주고 있습니다.

  1. 환경 설정:

    • 필요한 라이브러리 설치(AWS SDK, NumPy, Pandas 등)

    • 학습/검증 데이터셋, 출력 버킷 등 리소스 정의

  2. 추정기(Estimator) 구성:

    • XGBoost 알고리즘, 컴퓨팅 리소스, 학습 스크립트 등 정의

  3. AMT 하이퍼파라미터 설정:

    • 튜닝할 하이퍼파라미터와 값 범위 지정

    • alpha, eta, max_depth, min_child_weight, num_round 등

  4. 목표 평가 지표 설정:

    • 검증 데이터셋 AUC 최대화를 목표 지표로 선택

  5. AMT 작업 시작 및 결과 분석:

    • 가장 우수한 성능의 모델과 해당 하이퍼파라미터 값 식별

    • 하이퍼파라미터와 평가 지표 간 상관관계 분석

  6. 모델 아티팩트 저장 및 활용:

    • S3에서 최적 모델 아티팩트 찾아 추가 테스트 또는 배포에 활용

Model Size

Factors

  • Input Data and Features

  • Architecture

  • Problem Domain

  • Desired Accuracy

모델 크기

장점

  • 더 작은 모델

    • 학습 시간이 빠르고, 메모리 사용량이 낮으며, 계산 비용이 낮음

    • 실시간 또는 리소스 제한 환경에 적합

  • 더 큰 모델

    • 데이터에서 더 많은 관계를 학습할 수 있어 성능이 더 좋을 수 있음

단점

  • 더 작은 모델

    • 학습 데이터에 존재하는 복잡한 패턴을 충분히 포착하지 못할 수 있음

  • 더 큰 모델

    • 배포 시간과 예측 지연 시간이 더 길며, 더 많은 계산 자원이 필요함

모델 성능 요구 사항

  • 모델 성능 요구 사항과 문제 도메인 복잡성이 모델 크기 평가의 주요 고려 사항

  • 추가적으로 고려해야 할 사항:

    • 리소스 요구 사항: 모델 크기에 따라 계산 및 저장 자원 요구량이 달라짐

    • 로드 시간: 모델 크기가 클수록 배포 시간이 늘어남

    • 예측 지연 시간: 더 큰 모델은 계산 복잡도가 높아 실시간 예측에 부적합할 수 있음

    • 비용: 추가적인 저장 및 계산 자원 요구로 인해 비용이 증가함

Model Size Reduction Techniques

가지치기(Pruning)

  • 모델에서 가장 중요하지 않은 **매개변수나 노드를 제거**하는 기법

  • 모델 크기를 줄이면서도 정확도를 유지할 수 있음

양자화(Quantization)

  • 모델 내 가중치의 **데이터 표현을 가장 공간 효율적인 형태로 변경**하는 기법

  • 예를 들어 32비트 부동 소수점 표현 대신 8비트 정수 표현을 사용

지식 증류(Knowledge Distillation)

  • 더 큰 **교사 모델의 지식을 더 작은 학생 모델로 전달**하는 기법

  • 학생 모델은 동일한 데이터셋으로 훈련되지만, 교사 모델의 지식도 활용하여 훈련

모델 가지치기(Iterative Model Pruning) 6단계

  • 모델 초기화:

    • 모델의 가중치를 초기화하여 학습을 시작합니다.

  • 모델 학습:

    • 학습 데이터와 손실 함수를 사용하여 모델을 학습시킵니다.

    • 각 학습 반복(iteration)마다 가중치가 조정됩니다.

  • 중요도 평가:

    • 학습된 모델에서 각 가중치의 중요도를 평가합니다.

    • 중요도가 낮은 가중치를 식별합니다.

  • 가지치기:

    • 중요도가 낮은 가중치를 제거(가지치기)합니다.

    • 이를 통해 모델 크기를 줄일 수 있습니다.

  • 모델 재학습:

    • 가지치기된 모델을 다시 학습시킵니다.

    • 모델 성능을 유지하기 위해 재학습이 필요합니다.

  • 반복:

    • 2-5단계를 반복하여 모델 크기를 점진적으로 줄여나갑니다.

    • 성능 저하 없이 모델 크기를 최소화할 수 있습니다.

Fine-Tuning Pre-trained Models

모델 사전 학습 및 미세조정(Fine-tuning)

  • 사전 학습(Pre-training): 모델이 일반 데이터 v1.0으로 학습

  • 미세조정(Fine-tuning): 사전 학습된 모델을 특정 도메인 데이터로 추가 학습

  • 전이 학습(Transfer Learning): 사전 학습된 모델을 다른 작업에 적용

미세조정이 유용한 이유

  • 특정 비즈니스 요구사항에 맞춰 모델을 맞춤화할 수 있음

  • 도메인 특화 언어, 전문 용어 등에 효과적으로 대응할 수 있음

  • 특정 작업에 대한 성능 향상이 가능

  • 더 사실적이고 유해하지 않은 응답을 얻을 수 있음

미세조정 접근법

  • 도메인 적응(Domain Adaptation) 미세조정

    • 제한된 도메인 데이터를 사용하여 기초 모델을 특정 작업에 적응시킴

    • 도메인 적응 미세조정은 제한된 **도메인 특화 데이터를 사용하여 기초 모델을 특정 작업에 적응시키는 기법**입니다.

    • 이 방법은 모델이 산업 용어, 기술 용어 또는 기타 전문화된 데이터를 다룰 때 유용합니다.

    • 기초 모델이 일반적인 데이터로 사전 학습되어 있을 때, 도메인 적응 미세조정을 통해 해당 도메인에 특화된 성능을 달성할 수 있습니다.

    https://docs.aws.amazon.com/sagemaker/latest/dg/jumpstart-foundation-models-fine-tuning-domain-adaptation.html

  • 명령어 기반(Instruction-based) 미세조정

    • 명령어를 사용하여 기초 모델을 특정 작업에 미세조정

    • 명령어 기반 미세조정은 사전 학습된 기초 모델의 성능을 특정 작업에 맞춰 향상시키는 기법입니다.

    • **레이블링된 예제 데이터를 프롬프트-응답 쌍의 형태로 제공**하며, 이를 **명령어 형식으로 구성**합니다.

    • 추가적인 데이터와 미세조정을 통해, 사전 학습 시 고려되지 않았던 더 구체적인 작업에 대해서도 모델을 적응시킬 수 있습니다.

    https://docs.aws.amazon.com/sagemaker/latest/dg/jumpstart-foundation-models-fine-tuning-instruction-based.html

Catastrophic Forgetting Prevention

재앙적 망각

  • 새로운 작업이나 데이터로 모델을 학습할 때 이전에 학습했던 지식을 잊어버리는 현상

재앙적 망각의 사례

  • 질문 답변 시스템에서 질문 주제의 분포가 변화하는 경우

  • 분류 모델에서 새로운 데이터로 인해 특정 클래스가 잊혀지는 경우

  • 순차 데이터 모델에서 초기 패턴을 잊어버리는 경우

재앙적 망각 감지 방법

  • 모델 성능을 시간에 따라 관찰하여 감소 추세 확인

  • 과거 데이터로 모델을 평가하여 낮은 성능 확인

재앙적 망각 방지 방법

Elastic Weight Consolidation (EWC)

  • 이전 작업에 **중요했던 가중치를 보호하는 정규화** 기법

  • 새로운 작업 학습 시 이전 지식의 손실을 최소화

Rehearsal

  • 새로운 학습 과정에서 **기존 학습 데이터의 샘플을 포함시켜 학습**

  • 이를 통해 이전에 학습한 지식을 유지

모델 설계

  • 데이터의 다양한 패턴을 충분히 학습할 수 있도록 **모델 복잡도를 적절히 설계**

  • 층과 노드 수, 특징 수 등을 고려

Renate

  • 신경망 모델의 자동 재학습을 지원하는 오픈소스 Python 라이브러리

  • 고정된 학습 데이터 세트가 아닌 **증분 학습 알고리즘** 제공

Amazon SageMaker Model Registry

  1. 모델 **카탈로그 관리**

    • 프로덕션에 사용할 **모델을 등록 및 관리**

  2. 모델 **버전 관리**

    • 모델을 **학습/미세조정할 때마다 새로운 버전을 생성하여 추적**

    1. 모델 승인 상태 제어

      • ML 파이프라인 내에서 **모델의 승인 상태를 관리**

  1. 등록(Registration):

    • 모델 아티팩트(모델 파일, 메타데이터 등)를 제공하여 모델 버전을 등록

    • SageMaker가 고유한 버전 번호를 부여

  2. 승인(Approval):

    • 등록된 모델 버전의 승인 상태를 관리

    • 철저히 테스트되고 검증된 모델만 프로덕션에 배포

  3. 그룹(Groups):

    • 모델 그룹을 사용하여 특정 문제를 해결하기 위한 모델들을 함께 관리

    • 버전 관리를 위한 세부적인 단위

  4. 컬렉션(Collections):

    • 모델 그룹을 포함하는 상위 조직 단위

    • 모델 카탈로그를 계층적으로 관리

Registering and Deploying Models with SageMaker Model Registry

  1. 새로운 모델 버전 등록

    • 모델 아티팩트, 추론 코드, 컨테이너 정보 제공

    • 승인 상태 설정

  2. 기존 모델 버전의 상태 변경
