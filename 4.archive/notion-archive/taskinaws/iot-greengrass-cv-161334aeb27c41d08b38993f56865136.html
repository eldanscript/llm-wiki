GStreamer 동작 확인

  • Start container with bash shell

  • Run gst-launch with multifilesrc

    • multifilesrc location : input source로 container shared volume에 저장한 sequece image를 사용

    • multifiesync location : output image로 sequence file이 순차적으로 frame.jpg로 출력 됨
