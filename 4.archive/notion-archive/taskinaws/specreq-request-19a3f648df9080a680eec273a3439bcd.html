For your SpecReq to be properly routed, and not get stuck, please SET THE PRIMARY TOPIC TO A DATABASE ENGINE (e.g. DynamoDB), you can specify other objectives as secondary topics (e.g. Cost Optimization). Doing the reverse will get your request stuck in pending assignment, because the Database SMEs are organized by database engine, and routing occurs by database engine. If you say primary topic is ‘Cost Optimization’ or anything like that the system won’t know what specialty you need, and won’t be able to route your request
