Start From AWS Console

  • Find FreeRTOS service

  • Access from IoT console

    • FreeRTOS Device Software → Configure download

  • Go to FreeRTOS console

  • Use Predefined configuration

    • Input ‘stm32’ at find box

    • select ‘Connect to AWS IoT-STM32 …’

  • Select Hardware platform

    • STM32L4 Discovery kit IoT node

    • Development tools

      • IDE : System Workbench for STM32 (default)

      • Compiler : GCC

  • Select Libraries

    • Wi-Fi Management (default)

    • MQTT : Selectable

    • If need more, click ‘Add another library’

  • Select Demo projects and Create

  • After creation, you can find it on ‘My configuration’ tab

  • Download from Select Configuration

  • Extract to workspace folder

Run Demo Project

Open WorkbenchProject

  • Run System Workbench for STM32

  • File → Open Projects from File System

  • Browse Demo Extraction Folder

  • Project Imported

Build and Run Demo

  • Project → Build All (Command + B)

  • Run → Run

    • Select Ac6 STM32 C/C++ Application

  • Launching

  • Run as log

Register STM32 board with AWS IoT

💡

Reference Link

Create AWS IoT policy

  • Secure → Policy → Create a policy

  • Input policy name

  • Select Advanced mode

  • Input policy

    • aws-region : any region you will use

    • aws-account-id : created IAM user for FreeRTOS

    • Resource : “arn:aws:iot:aws-region:aws-account-id:*”

    • allow actions of STM32 to all IoT resouces of aws-account in aws-region

    • action : Connect, Publish, Subscribe, Receive

Create an IoT thing

  • IoT thing, private key, certificate for STM32

  • Manage → Things → Register a thing

  • Create a single thing

  • Input thing name

  • Create a device type

  • Apply this type to a thing

  • Add a certificate for a thing

  • Create a certificate

  • Download certificate, public key, private key, rootCA

  • Activate certificate

  • Attach a policy

  • Done Register thing
