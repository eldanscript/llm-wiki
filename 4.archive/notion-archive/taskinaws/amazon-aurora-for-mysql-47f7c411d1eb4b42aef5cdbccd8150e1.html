Connect to Session Manager Workstation

  • Start Session에 연결 가능한 EC2 instance가 표시된다.

  • EC2 Instance에 SSM Role이 설정 되어 있어야 한다.

  • Workstation instance에 대해 start session을 실행한다.

  • 연결된 session에서 user account를 변경한다.

    • ssm-user : Session Manager가 연결하는 계정

    • ubuntu 계정으로 변경 : switch user

  • Log 확인

    • debug.log의 마지막 줄을 확인

Create Aurora Database Cluster

Retrieve the DB cluster endpoints

  • DB Cluster

  • Cluster Endpoint

    • auroralab-mysql-cluster-instance-1

      • auroralab-mysql-cluster.cluster-ce0b3wdrkb06.us-west-2.rds.amazonaws.com

    • always point to the writer DB instance

    • used for both write and read

  • Reader Endpoint

    • auroralab-mysql-cluster-instance-1-us-west-2b

      • auroralab-mysql-cluster.cluster-**[ro](-ce0b3wdrkb06.us-west-2.rds.amazonaws.com

    • resolve to one of the reader DB instance

    • used to offload read operations to read replicas

Assign an IAM role to the DB cluster

  • auroralab-integrate-[region]

  • S3 access role

Create a replica auto scaling policy

  • Allow the DB cluster to scale # of reader DB instances at any point in time based on the load

  • create policy
