Manual Install

AMI

  • Region에 맞춰 아래 AMI ID에 해당하는 Image 사용 필요

Management Portal (bootcamp-aes-mgmt-portal.json)

  1. ManagementPortalSecurityGroup

    • Inbound

      • 모든 소스에 대한 SSH port (22) allow

  2. ManagementPortalInstance

    • AMI (us-east-1 region) : ami-0947d2ba12ee1ff75 (amzn2-ami-hvm-2.0.20200917.0-x86_64-gp2)

    • Amazon Linux 2 AMI (HVM), SSD Volume Type

    • Instance Type : t3.small

    • Subnet : X.X.1.0/24 (Public)

    • Public IP Auto Assignment

    • Security Group : aes-portal-securitygroup

  3. key pair file ManagementPortalInstance에 복사

  4. SSH로 ManagementPortalInstance 접속

  5. Script 실행

    • management_portal.txt

    • ElasticsearchEndpoint : CloudFormation으로 생성된 ElasticSearch Endpoint 값 사용 (vpc-aes-domain-6nlglphnl643kprqjgmrchhqqq.us-east-1.es.amazonaws.com)

Logstash Server (bootcamp-aes-logstash.json)

  1. LogStashInstanceSecurityGroup

    • Inbound

      • 스택 생성시 적용한 IP 대역에 대한 SSH port Allow : X.X.0.0/21

  2. LogStashInstance 생성

    • AMI (us-east-1 region) : ami-0947d2ba12ee1ff75 (amzn2-ami-hvm-2.0.20200917.0-x86_64-gp2)

    • Amazon Linux 2 AMI (HVM), SSD Volume Type

    • Instance Type : t3.small

    • Subnet : X.X.2.0/24 (Private)

    • Public IP Auto Assignment

    • Security Group : 1단게의 logstash securitygroup

  3. SSH로 LogStash Instance 접속

    • SSH로 Management portal 접속

    • Management portal에서 SSH로 LogStash Instance 접속

  4. Script 실행

    • logstash_server.txt

    • CloudFormation으로 생성된 Redis Endpoint 사용 (aes-network-cache.lzgt4m.0001.use1.cache.amazonaws.com)

    • CloudFormation으로 생성된 ElasticSearch Endpoint 값 사용 (vpc-aes-domain-6nlglphnl643kprqjgmrchhqqq.us-east-1.es.amazonaws.com)

Application Server (bootcamp-aes-servers.json)

  1. WebServerSecurityGroup

    • Inbound

      • 모든 소스에 대한 SSH port (22) allow

  2. ALBSecurityGroup

    • Inbound

      • 모든 소스에 대한 HTTP port (80) allow

  3. WebServerInstanceSecurityGroup

    • Inbound

      • 2번에서 생성한 ALBSecurityGroup을 소스로 하여 80 port Allow

      • 스택 생성시 적용한 IP 대역에 대한 SSH port Allow : X.X.0.0/21

  4. WebServer Instance 설치

    • AMI (us-east-1 region) : ami-0947d2ba12ee1ff75 (amzn2-ami-hvm-2.0.20200917.0-x86_64-gp2)

    • Instance Type : t3.small

    • Subnet : X.X.3.0/24 (Private)

    • Security Group : 3번의 WebServerInstanceSecurityGroup 적용

  5. SSH로 WebServer Instance 접속

    • SSH로 Management portal 접속

    • Management portal에서 SSH로 WebServer Instance 접속

  6. Script 실행

    • application_server.txt

  7. Filebeat, Metricbeat 설정 파일 추가

    • filebeat.yml 설정에 CloudFormation으로 생성된 Redis Endpoint 사용 (aes-network-cache.lzgt4m.0001.use1.cache.amazonaws.com)

    • metricbeat.ym 설정에 CloudFormation으로 생성된 ElasticSearch Endpoint 값 사용 (vpc-aes-domain-6nlglphnl643kprqjgmrchhqqq.us-east-1.es.amazonaws.com)

  8. IMDB 파일 추가 & Start Service

  9. ALBTargetGroup 생성

    • Target type : Instances

    • Protocol version : HTTP1

    • Health checks

    • Instance : Webserver Instance

  10. ApplicationLoadBalancer 생성

    • AZ : Pub0, Pub1

    • Listener : HTTP 80 port

    • Security Group : 2단계의 ALBSecurityGroup

    • Target Group : 9번에서 생성한 ALBTargetGroup
