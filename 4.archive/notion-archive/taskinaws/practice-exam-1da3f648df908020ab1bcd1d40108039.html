Q1

A financial planning company is using the Amazon SageMaker endpoint with an Auto Scaling policy to serve its forecasting model to the company’s customers to help them plan for retirement. The team wants to update the endpoint with its latest forecasting model, which has been trained using Amazon SageMaker training jobs. The team wants to do this without any downtime and with minimal change to the code.

What steps should the team take to update this endpoint?

  • Use a new endpoint configuration with the latest model Amazon S3 path in the UpdateEndpoint API

  • De-register the endpoint as a scalable target. Update the endpoint using a new endpoint configuration with the latest model Amazon S3 path. Finally register the endpoint as a scalable target again

  • UpdateEndpoint API 사용한 model 변경 방법

    1. 새로운 모델을 배포할 EndpointConfig를 생성합니다. CreateEndpointConfig API를 사용하여 새로운 엔드포인트 구성을 정의합니다.

    2. UpdateEndpoint API를 호출하여 기존 엔드포인트를 업데이트합니다. 요청에 다음 파라미터를 포함시킵니다:

      • EndpointName: 업데이트할 기존 엔드포인트의 이름

      • EndpointConfigName: 새로운 EndpointConfig의 이름

    3. UpdateEndpoint API는 새로운 엔드포인트 구성을 배포하고, 트래픽을 새 인스턴스로 점진적으로 전환합니다. 이 과정에서 기존 엔드포인트 인스턴스는 점차 제거됩니다.

    4. 엔드포인트의 상태를 모니터링하여 업데이트가 성공적으로 완료되었는지 확인합니다. DescribeEndpoint API를 사용하면 엔드포인트의 상태를 확인할 수 있습니다.

    이렇게 UpdateEndpoint API를 활용하면 중단없이 기존 엔드포인트를 새로운 모델로 업데이트할 수 있습니다. 업데이트 중에도 엔드포인트가 계속 작동하며, 트래픽 전환 및 인스턴스 제거가 자동으로 진행됩니다.

Q2

An ML Engineer at a real estate startup wants to use a new quantitative feature for an existing ML model that predicts housing prices. Before adding the feature to the cleaned dataset, the Engineer wants to visualize the feature in order to check for outliers and overall distribution and skewness of the feature.What visualization technique should the ML Engineer use? (Select TWO.)

  • Heatmap

  • Scatterplot

  • Histogram

  • T-SNE

  • Box Plot

이 문제에서 ML 엔지니어가 새로운 정량적 특징을 시각화하기 위해 사용해야 하는 가장 적절한 두 가지 기술은 히스토그램과 박스플롯입니다.

  1. 히스토그램:

    • 히스토그램은 특징의 분포를 이해하는 데 유용한 시각화 기술입니다.

    • 히스토그램은 특징의 다양한 값 범위(bin)에 속하는 데이터 포인트의 빈도나 개수를 보여줍니다.

    • 이를 통해 특징의 전반적인 분포 모양, 왜도(skewness) 및 잠재적인 이상치를 파악할 수 있습니다.

  2. 박스플롯:

    • 박스플롯(box plot)은 분포를 탐색하고 이상치를 식별하는 데 효과적인 또 다른 시각화 기술입니다.

    • 박스플롯은 특징의 최소값, 1사분위수, 중앙값, 3사분위수, 최대값을 요약하여 보여줍니다.

    • 박스플롯을 통해 수염(whisker)을 벗어나는 이상치를 쉽게 파악할 수 있습니다.

히스토그램과 박스플롯은 서로 보완적인 시각화 기술입니다. 히스토그램은 전체적인 분포를 보여주고, 박스플롯은 잠재적인 이상치를 명확하게 식별할 수 있습니다.

다른 시각화 옵션, 예를 들어 산점도(scatter plot) 또는 쌍체 플롯(pair plot)도 유용할 수 있지만, 단일 정량적 특징의 분포와 이상치를 탐색하는 데는 가장 적합하지 않습니다.

산점도(Scatter Plot)는 다음과 같은 경우에 유용하게 사용될 수 있습니다:

  1. 두 변수 간의 관계 분석: 산점도는 두 개의 연속형 변수 간의 관계를 시각화하는 데 가장 널리 쓰이는 기법입니다. 이를 통해 변수 간의 선형/비선형 상관관계, 군집화 등을 파악할 수 있습니다.

  2. 다변량 데이터 탐색: 여러 개의 변수로 구성된 데이터셋에서 변수 간의 관계를 파악하기 위해 산점도 행렬(Scatter Plot Matrix)을 활용할 수 있습니다.

  3. 이상치 탐지: 산점도를 통해 데이터 포인트의 분포를 시각적으로 확인할 수 있어 이상치를 식별하기 용이합니다.

  4. 특징 엔지니어링: 새로운 특징을 생성할 때 두 변수 간의 관계를 이해하기 위해 산점도를 사용할 수 있습니다.

  5. 모델 평가: 예측 모델의 성능을 평가할 때 실제값과 예측값의 산점도를 살펴볼 수 있습니다.

즉, 산점도는 주로 두 변수 간의 관계를 파악하고 데이터의 전반적인 구조를 이해하는 데 유용합니다. 이상치 탐지와 특징 엔지니어링, 모델 평가 등 다양한 목적으로 활용될 수 있습니다.

T-SNE(t-Distributed Stochastic Neighbor Embedding)는 고차원 데이터를 저차원 공간에 효과적으로 투영하는 차원 축소 기법입니다. 주로 다음과 같은 경우에 유용하게 활용됩니다:

  1. 데이터 시각화: T-SNE는 고차원 데이터를 2D 또는 3D 공간에 효과적으로 투영하여 데이터 분포와 군집을 시각화할 수 있습니다. 이를 통해 데이터의 내재적 구조를 직관적으로 파악할 수 있습니다.

  2. 데이터 탐색 및 군집 분석: T-SNE를 통해 얻은 저차원 표현은 데이터 간의 근접성을 잘 보존하므로, 데이터 군집을 쉽게 식별할 수 있습니다. 이는 군집 분석, 이상치 탐지 등에 도움이 됩니다.

  3. 고차원 데이터 처리: 고차원 데이터를 T-SNE를 통해 저차원으로 축소하면 계산 복잡도를 크게 낮출 수 있어, 고차원 데이터를 효율적으로 처리할 수 있습니다.

  4. 데이터 압축 및 전처리: T-SNE는 데이터의 본질적인 구조를 잘 보존하면서 차원을 축소할 수 있어, 데이터 압축 및 전처리에 유용합니다.

T-SNE는 특히 비선형 복잡한 구조의 고차원 데이터에 대해 효과적으로 작동하며, 데이터 시각화와 탐색, 전처리 등 다양한 데이터 마이닝 작업에 활용될 수 있습니다. 다만 최적의 하이퍼파라미터 설정이 중요하며, 계산 복잡도가 높은 단점이 있습니다.

Q3

A Data Scientist wants to include “month” as a categorical column in a training dataset for an ML model that is being built. However, the ML algorithm gives an error when the column is added to the training data.What should the Data Scientist do to add this column?

  • Map the “month” column data to the numbers 1 to 12 and use this new numerical mapped column.

  • Scale the months using StandardScaler.

  • Use pandas fillna() to convert the column to numerical data.

  • Convert the “month” column to 12 different columns, one for each month, by using one-hot encoding.

이 문제에서 데이터 과학자가 “월” 열을 훈련 데이터에 추가하려고 할 때 발생하는 문제를 해결하기 위한 가장 적절한 방법은 원-핫 인코딩(One-Hot Encoding)입니다.

  1. 원-핫 인코딩:

    • 이것이 “월” 범주형 특징을 다루는 올바른 접근 방식입니다.

    • 원-핫 인코딩은 각 고유한 월 값에 대해 이진 열(0 또는 1)을 생성하여, ML 알고리즘이 각 월을 고유한 범주로 처리할 수 있게 합니다.

    • 이 기술을 통해 범주형 정보가 적절하게 훈련 데이터에 표현되어, 알고리즘이 비숫자 값을 처리할 수 없어 발생하는 오류를 방지할 수 있습니다.

  2. 라벨 인코딩:

    • 라벨 인코딩은 범주형 특징을 다루는 또 다른 방법으로, 각 고유한 월 값에 숫자 레이블(예: 1월 = 1, 2월 = 2 등)을 할당합니다.

    • 그러나 이 접근 방식은 “월” 특징에 적합하지 않을 수 있는데, ML 알고리즘이 숫자 레이블 간의 내재적인 순서나 관계를 해석할 수 있기 때문입니다.

    • 라벨 인코딩은 때때로 ML 알고리즘이 월 간의 잘못된 순서나 관계를 학습하게 하는 등의 의도치 않은 결과를 초래할 수 있습니다.

  3. “월” 열 제거:

    • 훈련 데이터에서 “월” 열을 제거하는 것은 바람직하지 않습니다. 이렇게 하면 모델 성능 향상에 도움이 될 수 있는 잠재적으로 유용한 정보가 손실됩니다.

    • “월” 특징은 ML 모델이 학습할 수 있는 중요한 패턴이나 계절적 추세를 포함할 수 있습니다.

  4. “월” 열을 숫자 특징으로 변환:

    • “월” 열을 월 번호(1월 = 1, 2월 = 2 등)와 같은 숫자 특징으로 변환하는 것은 최선의 방법이 아닙니다.

    • 이 접근 방식은 월 간의 내재적인 순서나 관계가 있다고 가정하지만, 이는 정확하지 않을 수 있으며 ML 알고리즘이 잘못된 가정을 하도록 할 수 있습니다.

요약하면, 데이터 과학자가 “월” 범주형 특징을 처리하는 가장 적절한 방법은 원-핫 인코딩을 사용하는 것입니다. 이를 통해 범주형 정보가 훈련 데이터에 적절히 표현되어, ML 알고리즘이 비숫자 값을 처리하지 못해 발생하는 오류를 방지할 수 있습니다.

Q4

A financial organization uses multiple ML models to detect irregular patterns in its data to combat fraudulent activity such as money laundering. They use a TensorFlow-based Docker container on GPU-enabled Amazon EC2 instances to concurrently train the multiple models for this workload.However, they want to automate the batch data preprocessing and ML training aspects of this pipeline, scheduling them to take place automatically every 24 hours.What AWS service can they use to do this?

  • AWS Glue

  • Amazon EMR

  • AWS Batch

  • Kinesis Data Analytics

이 문제에서 금융 기관이 자동으로 배치 데이터 전처리 및 ML 모델 학습을 수행하고자 하는 경우, AWS Batch 서비스가 적절한 선택이 될 수 있습니다.

AWS Batch는 다음과 같은 이유로 이 사용 사례에 적합합니다:

  1. 배치 작업 실행: AWS Batch는 대규모 배치 처리 작업을 자동화하고 관리하는 데 최적화되어 있습니다. 매일 실행되는 데이터 전처리 및 ML 모델 학습 작업에 적합합니다.

  2. 다양한 컴퓨팅 리소스 활용: AWS Batch를 통해 GPU 지원 Amazon EC2 인스턴스와 같은 다양한 컴퓨팅 리소스를 활용할 수 있습니다. 이는 TensorFlow 기반 Docker 컨테이너를 사용하는 ML 모델 학습 워크로드에 적합합니다.

  3. 자동화된 작업 스케줄링: AWS Batch는 작업을 자동으로 예약하고 실행할 수 있는 기능을 제공합니다. 이를 통해 매일 정기적으로 데이터 전처리 및 모델 학습을 수행할 수 있습니다.

반면, AWS Glue는 이 사용 사례에 적합하지 않습니다. AWS Glue는 주로 데이터 추출, 변환 및 로딩(ETL) 작업에 사용되며, 머신 러닝 모델 학습을 자동화하기에는 적합하지 않습니다.

AWS Glue는 스파크 기반 ETL 파이프라인 구축에 초점을 맞추고 있으며, 배치 처리 작업보다는 실시간 데이터 처리에 더 적합합니다. 따라서 이 문제에서 요구하는 정기적인 배치 데이터 전처리 및 ML 모델 학습 자동화 요구사항에는 AWS Batch가 더 적절한 선택이 될 수 있습니다.

Q5

A security and networking company wants to use ML to flag certain IP addresses that have been known to send spam and phishing information. The company wants to build an ML model based on previous user feedback indicating whether specific IP addresses have been connected to a website designed for spam and phishing.What is the simplest solution that the company can implement?

  • Regression

  • Natural language processing (NLP)

  • Classification

  • A rule-based solution should be used instead of ML

이 문제에서 보안 및 네트워킹 회사가 구현할 수 있는 가장 단순한 솔루션은 규칙 기반 솔루션(rule-based solution)입니다. 분류(Classification) 모델을 사용하는 것보다 규칙 기반 솔루션이 더 적절한 이유는 다음과 같습니다:

  1. 명확한 문제 정의: 이 문제는 특정 IP 주소가 스팸 및 피싱 정보를 전송했는지 여부를 식별하는 것입니다. 이는 명확한 규칙 세트로 구현할 수 있는 문제 정의입니다.

  2. 사용 가능한 데이터: 회사는 이전 사용자 피드백을 기반으로 특정 IP 주소가 스팸 및 피싱 웹사이트와 관련되어 있는지 알고 있습니다. 이러한 명확한 레이블링된 데이터를 사용하면 규칙 기반 솔루션을 구현하기 쉽습니다.

  3. 단순성 및 투명성: 규칙 기반 솔루션은 분류 모델보다 구현이 더 단순하고 결과에 대한 설명이 쉽습니다. 이는 보안 및 네트워킹 분야에서 중요한 요구 사항입니다.

  4. 빠른 구현 및 배포: 규칙 기반 솔루션은 분류 모델을 개발, 학습, 배포하는 것보다 훨씬 더 빠르게 구현하고 배포할 수 있습니다.

반면, 분류 모델을 사용하는 것은 이 문제에 최적화된 솔루션이 아닙니다. 분류 모델을 사용하려면 더 많은 데이터 수집, 모델 훈련 및 튜닝이 필요할 수 있습니다. 이는 시간이 더 많이 소요되고 복잡성이 증가할 수 있습니다.

따라서 이 문제의 경우 규칙 기반 솔루션이 가장 단순하고 효과적인 접근 방식입니다. 명확한 문제 정의, 사용 가능한 레이블링된 데이터, 그리고 보안 및 네트워킹 분야의 요구 사항을 고려할 때 규칙 기반 솔루션이 가장 적합한 선택이 될 수 있습니다.

Q6

A real estate startup wants to use ML to predict the value of homes in various cities. To do so, the startup’s data science team is joining real estate price data with other variables such as weather, demographic, and standard of living data.However, the team is having problems with slow model convergence. Additionally, the model includes large weights for some features, which is causing degradation in model performance.What kind of data preprocessing technique should the team use to more effectively prepare this data?

  • Max absolute scaler

  • Normalizer

  • One hot encoder

  • Standard scaler

이 문제에서 부동산 스타트업의 데이터 과학 팀이 겪고 있는 느린 모델 수렴 속도 및 일부 특징의 큰 가중치로 인한 모델 성능 저하 문제를 해결하기 위해 가장 적절한 데이터 전처리 기술은 **feature scaling (특징 스케일링)**입니다.

특징 스케일링은 다음과 같은 이점을 제공합니다:

  1. 모델 수렴 속도 향상: 특징 값의 범위가 다양할 경우, 일부 특징이 모델 학습에 더 큰 영향을 미칠 수 있습니다. 특징 스케일링은 모든 특징을 유사한 범위로 변환하여 모델 수렴 속도를 높일 수 있습니다.

  2. 과적합 방지: 일부 특징의 가중치가 지나치게 커지면 모델이 과적합될 수 있습니다. 특징 스케일링은 특징 간 가중치 균형을 맞추어 과적합을 방지할 수 있습니다.

  3. 성능 향상: 특징 스케일링은 모델의 전반적인 성능을 향상시킬 수 있습니다. 특징 간 스케일의 균형이 맞춰지면 모델이 데이터를 더 효과적으로 학습할 수 있습니다.

다른 데이터 전처리 기술인 scaler나 normalizer는 특징 스케일링 기법의 일종이지만, 이 문제에서는 특징 스케일링이 가장 적절한 선택입니다.

Scaler는 특징을 0과 1 사이의 값으로 변환하는 반면, Normalizer는 특징을 단위 길이의 벡터로 변환합니다. 이 문제의 경우 특징 간 스케일 차이로 인한 문제를 해결하는 것이 중요하므로, 0과 1 사이의 값으로 변환하는 Scaler 기법이 가장 적절합니다.

따라서 이 문제의 가장 적절한 해결책은 특징 스케일링(feature scaling)을 사용하여 데이터를 전처리하는 것입니다.

Robust Scaler는 각 특성에 대해 중앙값을 빼고 지정된 사분위수 범위에 따라 데이터를 조정합니다. 이 스케일러는 **이상치에 강인**

Standard Scaler (정규 분포 사용) 각 특성에 대해 **평균을 빼고 표준편차로 나누어 정규화**합니다. 이 방식은 **이상치에 큰 영향**

Min Max Scaler: 각 특성에 대해 최솟값과 최댓값 사이로 값을 조정합니다. 이상치가 존재하면 대부분의 데이터가 좁은 범위로 압축되어 전체 분포가 왜곡될 수 있습니다.

Max Absolute Scaler: 각 특성에 대해 최대 절대값으로 나누어 조정합니다. **이상치가 스케일 계수에 과도한 영**향을 미치므로 적절한 조정이 어렵습니다.

Q7

A Data Scientist is using stochastic gradient descent (SGD) as the gradient optimizer to train a machine learning model. However, the model training error is taking longer to converge to the optimal solution than desired.What optimizer can the Data Scientist use to improve training performance? (Select THREE.)

  • Xavier

  • Gradient Descent

  • Mini-batch gradient descent

  • Adagrad

  • RMSProp

  • Adam

이 문제에서 SGD를 사용하여 모델 학습 시 수렴 속도가 느린 경우, 데이터 과학자가 선택할 수 있는 세 가지 최적화기는 다음과 같습니다:

  1. Momentum:

    • 정답: Momentum은 SGD의 성능을 높일 수 있는 좋은 선택입니다.

    • Momentum은 현재 gradient와 이전 gradient를 결합하여 최적화 방향을 안정화시킵니다. 이를 통해 수렴 속도를 높일 수 있습니다.

  2. Adam (Adaptive Moment Estimation):

    • 정답: Adam은 적응형 학습률과 모멘텀을 결합한 최적화기로, SGD보다 뛰어난 성능을 보입니다.

    • Adam은 개별 특징에 대한 학습률을 동적으로 조절하여 수렴 속도를 높일 수 있습니다.

  3. RMSProp (Root Mean Square Propagation):

    • 정답: RMSProp은 적응형 학습률을 사용하여 SGD의 성능을 개선할 수 있습니다.

    • RMSProp은 각 특징에 대한 과거 gradient의 제곱 평균을 사용하여 학습률을 조절합니다.

    AdaGrad(Adaptive Gradient Algorithm)는 적응형 학습률을 사용하는 최적화 알고리즘의 하나입니다. AdaGrad의 특징은 다음과 같습니다:

    1. 적응형 학습률: AdaGrad는 각 매개변수에 대해 개별적인 학습률을 적용합니다. 매개변수별로 과거 gradient의 제곱 합을 사용하여 학습률을 동적으로 조절합니다.

    2. 희소 데이터에 효과적: 희소 데이터(sparse data)에서 특히 효과적입니다. 희소 데이터의 경우 중요한 매개변수에 큰 gradient가 발생하므로, AdaGrad는 이 부분에 더 큰 학습률을 적용할 수 있습니다.

    3. 수렴 속도 향상: AdaGrad는 SGD에 비해 수렴 속도가 빠른 편입니다. 매개변수별 학습률 조절을 통해 효율적으로 최적화 과정을 수행할 수 있기 때문입니다.

    4. 단점: 시간이 지날수록 학습률이 계속 감소하는 문제가 있습니다. 이는 과도한 학습률 감소로 인해 수렴에 문제가 발생할 수 있습니다.

    요약하면, AdaGrad는 매개변수별 적응형 학습률을 사용하여 SGD의 수렴 속도를 향상시킬 수 있는 대표적인 최적화 알고리즘입니다. 특히 희소 데이터 환경에서 효과적이지만, 지속적인 학습률 감소로 인한 단점도 존재합니다.

오답 선택지:

  1. Scaler:

    • Scaler는 데이터 전처리 기법으로, 최적화기가 아닙니다. 따라서 이 문제의 정답은 아닙니다.

  2. Normalizer:

    • Normalizer 역시 데이터 전처리 기법으로, 최적화기가 아닙니다. 따라서 이 문제의 정답이 될 수 없습니다.

요약하면, 데이터 과학자가 SGD의 성능을 향상시키기 위해 선택할 수 있는 세 가지 최적화기는 Momentum, Adam, RMSProp입니다. 이 세 가지 방법은 SGD의 수렴 속도를 개선할 수 있는 대표적인 기법입니다.

A Data Scientist at a credit card company trained a classification model to predict fraud at the time of a transaction.   • 52.6%; Precision

  • 52.6%; Recall

  • 80%; Precision

  • 80%; Recall

이 문제에서 데이터 과학자가 신용카드 거래 데이터를 사용하여 훈련한 분류 모델의 성능을 평가하기 위해 사용한 혼동행렬(Confusion Matrix)을 보면, 정답인 “52.6%; Recall”을 선택해야 합니다.

“52.6%; Recall”이 정답인 이유는 다음과 같습니다:

  1. Recall(재현율): Recall은 실제 긍정 사례 중 모델이 정확하게 분류한 비율을 나타내는 지표입니다. 즉, 실제 사기 거래 중 모델이 정확하게 탐지한 비율을 의미합니다.

  2. 계산: 혼동행렬에서 “True Positive(TP)“는 실제 사기 거래를 모델이 정확하게 분류한 경우입니다. “False Negative(FN)“는 실제 사기 거래를 모델이 정상 거래로 잘못 분류한 경우입니다.
    Recall = TP / (TP + FN) = 100 / (100 + 90) = 52.6%

  3. 선택지 분석:

    • “52.6%; Precision”: 정확성(Precision)은 모델이 긍정으로 분류한 것 중 실제 긍정인 비율을 나타내므로, 이 문제에서는 정답이 아닙니다.

    • “80%; Precision” 및 “80%; Recall”: 이 수치는 혼동행렬에 나와 있지 않으므로 정답이 될 수 없습니다.

따라서 이 문제의 정답은 “52.6%; Recall”입니다.

이 문제에서 광고 및 분석 회사가 자사의 XGBoost 모델을 Amazon SageMaker로 마이그레이션하여 ML 파이프라인을 개선하고자 하는 경우, 가장 적절한 접근 방식은 다음과 같습니다:

정답:
“Use the Amazon pre-built R container option and port the existing code over to the container. Register the container in Amazon Elastic Container Registry (Amazon ECR). Finally, run the training and inference jobs using this container.”

이 접근 방식이 적절한 이유는 다음과 같습니다:

  1. Amazon 제공 R 컨테이너 사용:

    • Amazon SageMaker는 사전 구축된 R 컨테이너 옵션을 제공합니다.

    • 기존 R 코드를 이 컨테이너에 포팅할 수 있어, 코드 변경을 최소화할 수 있습니다.

  2. 컨테이너 Amazon ECR에 등록:

    • 포팅된 R 코드가 포함된 컨테이너를 Amazon Elastic Container Registry(ECR)에 등록합니다.

    • 이를 통해 SageMaker에서 컨테이너를 쉽게 사용할 수 있습니다.

  3. 컨테이너를 사용하여 학습 및 추론 실행:

    • 마지막으로 ECR에 등록된 컨테이너를 사용하여 SageMaker에서 학습 및 추론 작업을 실행합니다.

오답 선택지:

  1. “Use Amazon in-built algorithms to run their training and inference jobs.”:

    • 이 접근 방식은 기존 R 코드를 마이그레이션하기 어렵습니다. Amazon 제공 알고리즘을 사용하려면 코드를 상당히 변경해야 합니다.

  2. “Use the Build Your Own Container (BYOC) Amazon SageMaker option. Create a new Docker container with the existing code. Register the container in Amazon Elastic Container Registry (ECR). Finally, run the training and inference jobs using this container.”:

    • 이 방법은 정답과 유사하지만, 기존 R 코드를 직접 Docker 컨테이너로 만들어야 합니다. Amazon 제공 R 컨테이너를 사용하는 것이 더 편리합니다.

  3. “Create a new Amazon SageMaker notebook instance. Copy the existing code into an Amazon SageMaker notebook. Then, run the pipeline from this notebook.”:

    • SageMaker 노트북을 사용하는 것은 편리할 수 있지만, 기존 R 코드를 노트북에 복사하는 것은 코드 변경이 필요할 수 있습니다. 컨테이너 기반 접근 방식이 더 바람직합니다.

따라서 이 문제의 정답은 두 번째 선택지입니다.

Q13

A Data Scientist wants to create a linear regression model to train on a housing dataset to predict home prices. As part of that process, the Data Scientist created a correlation matrix between the dataset’s features and the target variable. The correlations between the target and two of the features, feature 3 and feature 7, are 0.64 and -0.85, respectively.Which feature has a stronger correlation with the target variable?

  • Feature 3

  • Feature 7

  • Feature 7 and feature 3 both have weak correlations to the target

  • There is not sufficient enough data to determine which variable has a stronger correlation to the target

이 문제에서 데이터 과학자가 주택 데이터셋을 사용하여 선형 회귀 모델을 만들 때, 특징 3과 특징 7의 상관관계를 확인한 결과는 다음과 같습니다:

  • 특징 3과 타겟 변수의 상관관계: 0.64

  • 특징 7과 타겟 변수의 상관관계: -0.85

따라서 이 문제의 정답은 Feature 7입니다.

정답 설명:

  • 특징 7의 상관관계 절댓값인 0.85가 특징 3의 상관관계 절댓값인 0.64보다 크므로, 특징 7이 타겟 변수와 더 강한 상관관계를 가집니다.

  • 상관관계의 크기는 변수 간 선형 관계의 강도를 나타내며, 절댓값이 클수록 상관관계가 강합니다.

  • 특징 7의 상관관계가 음수이므로 타겟 변수와 반비례 관계에 있습니다.

오답 설명:

  1. “Feature 3”: 특징 3의 상관관계가 더 약하므로 정답이 아닙니다.

  2. “Feature 7 and feature 3 both have weak correlations to the target”: 특징 7의 상관관계는 -0.85로 강한 편이므로 정답이 아닙니다.

  3. “There is not sufficient enough data to determine which variable has a stronger correlation to the target”: 문제에 제시된 상관관계 값으로 특징 7이 더 강한 상관관계를 가지는 것을 알 수 있으므로 정답이 아닙니다.

따라서 이 문제의 정답은 Feature 7입니다.

Q14

A ride-share company wants to create intelligent conversational chatbots that will serve as first responders to customers who call to report an issue with their ride. The company wants these chatbot-customer calls to mimic natural conversations that provide personalized experiences for the customers.What combination of AWS services can the company use to create this workflow without a lot of ongoing management?

  • Amazon Transcribe to parse the utterances and intent of customer comments, Amazon Lex to reply to the customers

  • Amazon Polly to parse the utterances and intent of customer comments, Amazon Lex to reply to the customers

  • Amazon Transcribe to parse the utterances and intent of customer comments, Amazon Polly to reply to the customers

  • Amazon Lex to parse the utterances and intent of customer comments, Amazon Polly to reply to the customers

이 문제에서 라이드 셰어 회사가 고객과의 자연스러운 대화를 제공하는 지능형 대화형 채팅봇을 만들기 위해 사용할 수 있는 AWS 서비스 조합은 다음과 같습니다:

정답:
“Amazon Transcribe to parse the utterances and intent of customer comments, Amazon Lex to reply to the customers”

이 접근법이 적절한 이유는 다음과 같습니다:

  1. Amazon Transcribe:

    • Transcribe는 음성을 텍스트로 변환하여 고객의 발언 내용과 의도를 파악할 수 있습니다.

  2. Amazon Lex:

    • Lex는 대화형 인터페이스를 구축하고 자연어 처리 기능을 제공하여 고객의 요청에 대한 응답을 생성할 수 있습니다.

이 조합을 사용하면 고객의 음성 입력을 텍스트로 변환하고, 텍스트를 바탕으로 고객의 의도를 파악하여 맞춤형 응답을 제공할 수 있습니다. 이를 통해 자연스러운 대화 환경을 구축할 수 있습니다.

오답 선택지:

  1. “Amazon Polly to parse the utterances and intent of customer comments, Amazon Lex to reply to the customers”:

    • Polly는 텍스트를 음성으로 변환하는 기능만 제공하므로, 고객 의도 파악에는 적합하지 않습니다.

  2. “Amazon Transcribe to parse the utterances and intent of customer comments, Amazon Polly to reply to the customers”:

    • Polly는 음성 출력에만 사용되므로, 전체 대화 워크플로를 구현하기에는 부족합니다.

  3. “Amazon Lex to parse the utterances and intent of customer comments, Amazon Polly to reply to the customers”:

    • Lex는 대화형 인터페이스 구축에 사용되지만, 고객의 음성을 텍스트로 변환하는 기능은 없습니다.

따라서 이 문제의 정답은 첫 번째 선택지인 “Amazon Transcribe to parse the utterances and intent of customer comments, Amazon Lex to reply to the customers”입니다.

Q15

A healthcare organization has an application that takes in sensitive user data. This data is encrypted at rest and stored in an Amazon S3 bucket using customer-managed encryption with AWS Key Management Service (AWS KMS). A Data Scientist in the organization wants to use this encrypted data as features in a Amazon SageMaker training job. However, the following error continues to occur: “Data download failed.”What should the Data Scientist do to fix this issue?

  • Make sure the AWS Identity and Access Management (IAM) role used for Amazon S3 access has permissions to encrypt and decrypt the data with the AWS KMS key.

  • Add “S3:*” to the IAM role that is attached to the Amazon SageMaker training job.

  • Specify the “VolumeKmsKeyId” in the Amazon SageMaker training job.

  • Add “EnableKMS” to the Amazon SageMaker training job. Then, specify the Amazon S3 bucket that includes the data.

이 문제에서 의료 기관의 데이터 과학자가 Amazon SageMaker 학습 작업에서 Amazon S3 버킷의 암호화된 데이터를 사용하다 “Data download failed” 오류가 발생하는 경우, 다음과 같은 해결책이 필요합니다:

정답:
“Make sure the AWS Identity and Access Management (IAM) role used for Amazon S3 access has permissions to encrypt and decrypt the data with the AWS KMS key.”

이 방법이 정답인 이유는 다음과 같습니다:

  1. IAM 역할의 권한 확인:

    • Amazon S3 액세스에 사용되는 IAM 역할에는 AWS KMS 키로 데이터를 암호화하고 복호화할 수 있는 권한이 필요합니다.

    • 이 권한이 없으면 SageMaker에서 데이터를 다운로드하지 못하게 되어 “Data download failed” 오류가 발생합니다.

오답 선택지:

  1. “Add “S3:*” to the IAM role that is attached to the Amazon SageMaker training job.”:

    • S3에 대한 모든 권한을 부여하는 것은 보안상 바람직하지 않습니다.

    • 대신 필요한 최소한의 권한만 부여하는 것이 좋습니다.

  2. “Specify the “VolumeKmsKeyId” in the Amazon SageMaker training job.”:

    • “VolumeKmsKeyId”는 Amazon EBS 볼륨 암호화에 사용되는 KMS 키 ID를 지정하는 것입니다.

    • 이 문제에서는 Amazon S3의 암호화된 데이터에 대한 액세스 권한이 문제이므로, 이 설정은 해결책이 아닙니다.

  3. “Add “EnableKMS” to the Amazon SageMaker training job. Then, specify the Amazon S3 bucket that includes the data.”:

    • “EnableKMS”는 EBS 볼륨 암호화를 활성화하는 옵션이며, 이 문제에서는 관련이 없습니다.

    • Amazon S3 버킷 지정만으로는 데이터 다운로드 문제를 해결할 수 없습니다.

따라서 이 문제의 정답은 첫 번째 선택지입니다.
