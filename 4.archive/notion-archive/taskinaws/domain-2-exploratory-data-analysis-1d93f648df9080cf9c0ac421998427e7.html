Domain 2. Exploratory Data Analysis

Objectives

  • Sanitizing and preparing data for modeling

  • Performing feature engineering

  • Analyzing and visualizing data for ML

Domain 2.1: Sanitize and prepare data for modeling

데이터 모델링을 위한 데이터 정제 및 준비 단계에 대해 자세히 살펴보겠습니다.

  1. 데이터에 대한 이해 높이기

    • 데이터를 정제하기 전에 먼저 데이터에 대한 이해도를 높여야 합니다.

    • 기술 통계를 사용하여 데이터의 다양한 속성을 파악할 수 있습니다.

    • 변수 간 상관관계 분석, 산점도 분석, 상관 행렬 등이 도움이 됩니다.

    데이터셋에 대한 전반적인 통계 정보는 기계 학습 모델링에 매우 중요합니다. 이러한 통계 정보는 크게 다음과 같은 세 가지 범주로 구분할 수 있습니다.

    1. 전체 통계:

      • 데이터셋의 **행(인스턴스) 수와 열(특성) 수**를 나타냅니다.

      • 이 정보를 통해 **데이터셋의 크기와 차원성**을 파악할 수 있습니다.

      • 차원성이 너무 높으면 모델 성능 저하를 야기할 수 있습니다.

    2. 속성 통계(Attribute statistics) :

      • **숫자형 속성**에 대한 통계 정보입니다.

      • **평균, 표준편차, 분산, 최솟값, 최댓값** 등의 정보를 제공합니다.

      • 이를 통해 각 **속성의 분포 및 모양을 이해**할 수 있습니다.

    3. 다변량 통계(Multivariate statistics):

      • 데이터셋의 **다양한 속성 간 상관관계와 관계**를 나타냅니다.

      • 속성 간 상관관계를 파악하는 것은 모델 성능에 중요한 영향을 미칠 수 있습니다.

      • 예를 들어 높은 상관관계를 보이는 속성들은 모델 성능에 부정적인 영향을 줄 수 있습니다.

    이와 같은 전반적인 통계 정보를 활용하면 데이터셋의 특성을 깊이 있게 이해할 수 있습니다. 이는 데이터 정제, 전처리, 모델 설계 등 후속 작업에 매우 유용한 정보를 제공합니다. 따라서 데이터 분석 초기 단계에서 이러한 통계 정보를 충분히 살펴보는 것이 중요합니다.

    데이터셋에 여러 변수나 특성이 포함된 경우, 이들 간의 상관관계를 분석하는 것이 중요합니다.

    1. 상관관계 파악의 중요성

      • 두 특성 간 높은 상관관계는 모델 성능 저하를 초래할 수 있습니다.

      • **서로 강하게 상관된 특성들을 모델에 모두 사용하면 모델 수렴 문제 등이 발생**할 수 있습니다.

        • 문제 내용

          서로 강하게 상관된 특성(feature)들을 모델에 모두 사용하면 발생할 수 있는 문제는 다음과 같습니다:

          1. 다중 공선성(Multicollinearity) 문제:

            • 서로 강하게 상관된 특성들이 모델에 포함되면 **데이터 간 선형 종속성이 발생**합니다.

            • 이로 인해 모델의 계수 추정이 불안정해지고, 모델의 성능이 저하됩니다.

          2. 모델 수렴 문제:

            • 다중 공선성으로 인해 모델 파라미터 학습 과정에서 **수렴이 어려워질 수 있습니다**.

            • 경사 하강법과 같은 최적화 알고리즘이 최적해를 찾기 어려워지거나, 매우 느리게 수렴할 수 있습니다.

          3. **과적합(Overfitting)** 문제:

            • 상관된 특성들이 모델에 과도하게 반영되어 학습 데이터에는 잘 맞지만, 새로운 데이터에는 **일반화가 어려워질 수 있습니다**.

          이러한 문제를 해결하기 위해서는 다음과 같은 접근이 필요합니다:

          • 상관관계가 높은 특성들을 식별하고, 중복되는 정보를 제거하는 특성 선택 및 차원 축소 기법 적용

          • **정규화(Regularization) 기법을 사용하여 모델의 복잡도를 조절**

          • **교차 검증(Cross-Validation)을 통해 모델 평가 및 일반화 성능 향상**

          결과적으로 상관된 특성들을 모델에 과도하게 포함하면 모델 학습 과정에서 문제가 발생할 수 있으므로, 이를 해결하기 위한 노력이 필요합니다.

      • 따라서 데이터셋 내 높은 상관관계를 가진 특성들을 파악하는 것이 중요합니다.

    2. 산점도를 통한 관계 파악

      • **2개 이상의 수치형 특성 간 관계를 이해하기 위해 산점도를 활용**할 수 있습니다.

      • 산점도를 통해 특성 **간 선형 관계의 강도를 시각적으로 확인**할 수 있습니다.

      • 일부 특성 간에는 강한 선형 관계가 관찰되지만, 다른 특성 간에는 그렇지 않음을 알 수 있습니다.

    3. 상관 행렬을 통한 정량화

      • 특성 간 선형 관계의 강도를 정량적으로 파악하기 위해 상관 행렬을 사용할 수 있습니다.

      • 상관 계수는 -1에서 1 사이의 값을 가집니다.

      • 상관 계수가 1이면 완벽한 양의 선형 관계, -1이면 완벽한 음의 선형 관계를 나타냅니다.

      • 상관 계수가 0이라면 선형 관계가 없다는 것을 의미하지만, 비선형 관계가 존재할 수 있습니다.

    요약하면, 데이터셋 내 특성 간 상관관계를 파악하는 것은 모델 성능에 중요한 영향을 미칠 수 있습니다. 산점도와 상관 행렬 분석을 통해 이러한 상관관계를 체계적으로 분석할 수 있습니다.

  2. 데이터 표준화

    • 데이터의 **언어와 문법을 표준화**해야 합니다.

    • 예를 들어 모든 텍스트를 소문자로 변환하는 등의 전처리가 필요합니다.

    • 서로 다른 단위의 데이터도 통일해야 합니다. (same scale)

      • Scaling vs Normalization

        네, 서로 다른 단위의 데이터를 통일하는 것은 scaling 및 normalization 작업과 관련됩니다.

        1. Scaling (스케일링):

          • 서로 다른 범위의 값을 가진 특성들을 **동일한 범위로 변환**하는 과정입니다.

          • 예를 들어 길이(meter), 무게(kg), 온도(°C) 등의 데이터를 모두 **0~1 사이의 값으로 변환**하는 것이 대표적인 스케일링 기법입니다.

          • 이를 통해 모델 학습 과정에서 **특성들 간 균형을 유지**할 수 있습니다.

        2. Normalization (정규화):

          • 스케일링과 유사하지만, 특성의 **분포 형태를 변환**하는 것에 초점을 맞춘 기법입니다.

          • 예를 들어 평균을 0, 표준편차를 1로 만드는 **z-score 정규화**가 대표적입니다.

          • 정규화를 통해 특성 간 **스케일 차이뿐만 아니라 분포 차이도 해소**할 수 있습니다.

        데이터 전처리 과정에서 서로 다른 단위의 데이터를 통일하는 것은 주로 스케일링 기법을 사용합니다. 하지만 경우에 따라 정규화 기법을 함께 적용하여 특성 간 균형을 더 잘 맞출 수 있습니다.

        이러한 스케일링과 정규화 작업을 통해 모델 학습 과정에서 수치적 안정성을 확보하고, 모델 성능 향상을 기대할 수 있습니다.

      • Scaling 기법

        데이터 스케일링(Scaling)을 위해 사용되는 대표적인 기법들은 다음과 같습니다:

        1. Min-Max 스케일링 (Normalization):

          • 데이터를 최소값 0, 최대값 1 사이의 범위로 변환합니다.

          • 공식: x_scaled = (x - min(x)) / (max(x) - min(x))

        2. Z-score 정규화 (Standardization):

          • 데이터를 평균 0, 표준편차 1의 정규 분포 형태로 변환합니다.

          • 공식: x_scaled = (x - mean(x)) / std(x)

        3. Robust 스케일링:

          • 평균과 표준편차 대신 중앙값과 IQR(사분범위)를 사용하여 이상치에 강인한 스케일링을 수행합니다.

          • 공식: x_scaled = (x - median(x)) / IQR(x)

        4. MaxAbs 스케일링:

          • 데이터를 절대값 최대값 1 사이의 범위로 변환합니다.

          • 공식: x_scaled = x / max(|x|)

        5. Unit 벡터 스케일링:

          • 데이터 벡터의 L2 norm(유클리드 거리)이 1이 되도록 스케일링합니다.

          • 공식: x_scaled = x / ||x||

        각 스케일링 기법은 데이터의 분포, 이상치 존재 여부, 모델 요구사항 등에 따라 적절히 선택되어야 합니다. 스케일링을 통해 모델 학습의 효율성과 안정성을 높일 수 있습니다.

      • Robust Scaling 기법

        Robust 스케일링 기법은 이상치에 강인한 특성을 지닌 스케일링 방법입니다. 대표적인 Robust 스케일링 기법인 Robust Scaler의 처리 과정은 다음과 같습니다:

        1. 중앙값(Median) 계산

          • 데이터의 중앙값을 계산합니다.

          • 중앙값은 이상치의 영향을 받지 않는 중심 경향성 지표입니다.

        2. 사분범위(IQR) 계산

          • 25th 백분위수(Q1)와 75th 백분위수(Q3)의 차이를 계산합니다.

          • 이는 데이터 분포의 산포도를 나타내는 지표입니다.

        3. 스케일링 수식 적용

          • 다음 수식을 사용하여 데이터를 스케일링합니다:

          • x_scaled = (x - median(x)) / IQR(x)

        이 과정에서 중앙값과 사분범위를 사용함으로써 이상치의 영향을 최소화할 수 있습니다.

        Robust Scaler의 특징:

        • 평균과 표준편차에 민감한 표준 정규화 기법에 비해 이상치에 강인합니다.

        • 데이터의 상대적인 크기 관계를 잘 유지할 수 있습니다.

        • 데이터가 정규 분포를 따르지 않아도 적용할 수 있습니다.

        따라서 데이터에 이상치가 포함되어 있거나 정규 분포를 가정하기 어려운 경우, Robust 스케일링 기법을 사용하면 효과적으로 데이터를 정규화할 수 있습니다.

      • Unit Vector Scaling 기법

        네, Unit 벡터 스케일링 방법에 대해 구체적인 예시와 함께 자세히 설명하겠습니다.

        Unit 벡터 스케일링은 데이터의 L2 norm(유클리드 노름)이 1이 되도록 변환하는 방식입니다. 수식은 다음과 같습니다:

        x_scaled = x / ||x||

        여기서 ||x||는 데이터 벡터 x의 L2 norm을 의미합니다.

        예를 들어, 다음과 같은 데이터 벡터 x가 있다고 가정해 봅시다:

        x = [2, 3, 4]

        1. L2 norm (벡터나 행렬의 크기) 계산

          • ||x|| = sqrt(2^2 + 3^2 + 4^2) = sqrt(13) ≈ 3.6056

        2. Unit 벡터 스케일링 적용

          • x_scaled = x / ||x|| = [2/3.6056, 3/3.6056, 4/3.6056] ≈ [0.5547, 0.8321, 1.1094]

        결과적으로 원래 데이터 벡터 x = [2, 3, 4]는 Unit 벡터 스케일링을 거쳐 x_scaled = [0.5547, 0.8321, 1.1094]로 변환됩니다.

        Unit 벡터 스케일링의 특징은 다음과 같습니다:

        1. 방향 보존:

          • 데이터 벡터의 방향성은 그대로 유지되지만, 크기는 1로 변환됩니다.

          • 따라서 데이터 간 각도 관계는 보존됩니다.

        2. 거리 척도 변경:

          • 데이터 간 거리는 상대적으로 변경됩니다.

          • 하지만 각도 관계는 유지되므로, 데이터의 방향성에 초점을 맞추는 모델에 유용합니다.

        3. 균일한 scale:

          • 모든 데이터가 L2 norm 1로 정규화되므로, 특성 간 scale이 균일해집니다.

          • 이는 거리 기반 모델(kNN, SVM 등)에 도움이 될 수 있습니다.

        이처럼 Unit 벡터 스케일링은 데이터의 방향성을 유지하면서도 균일한 크기로 변환하는 특성이 있습니다. 따라서 각도 정보가 중요한 모델에 효과적으로 활용될 수 있습니다.

      • Normalizer 기법

        네, Normalizer는 데이터 스케일링 기법 중 하나입니다.

        Normalizer는 각 데이터 샘플을 L2 Norm이 1이 되도록 정규화합니다. 수식은 다음과 같습니다:

        x_normalized = x / ||x||2

        여기서 ||x||2는 벡터 x의 L2 Norm을 의미합니다. L2 Norm은 다음과 같이 계산됩니다:

        ||x||2 = sqrt(x1^2 + x2^2 + … + xn

        Normalizer의 특징은 다음과 같습니다:

        1. 데이터 방향 보존:

          • Normalizer는 데이터의 방향성을 유지하면서 크기만 조정합니다.

          • 따라서 데이터 간 각도 관계가 보존됩니다.

        2. 균일한 스케일:

          • 모든 데이터 샘플이 L2 Norm 1로 정규화되므로, 특성 간 스케일이 균일해집니다.

        3. 거리 척도 변경:

          • 데이터 간 거리 척도는 변경되지만, 방향성은 유지됩니다.

          • 이는 거리 기반 모델(kNN, SVM 등)에 유용할 수 있습니다.

        Normalizer는 특히 문서 분류, 추천 시스템 등의 분야에서 널리 사용됩니다. 이러한 분야에서는 데이터의 방향성이 중요하기 때문입니다.

        또한 Normalizer는 Unit Vector Scaling과 유사한 효과를 가지지만, 계산 복잡도가 낮아 효율적입니다.

        따라서 Normalizer는 데이터의 방향성을 유지하면서도 균일한 스케일을 얻을 수 있는 효과적인 스케일링 기법입니다.

      • Unit Vector vs Normalizer

        Unit Vector Scaling은 다음과 같은 수식으로 데이터를 변환합니다:

        x_scaled = x / ||x||2 (모든 데이터 샘플의 L2 Norm이 1)

        여기서 ||x||2는 벡터 x의 L2 Norm을 의미합니다.

        반면, Normalizer는 다음과 같은 수식으로 데이터를 정규화합니다:

        x_normalized = x / ||x||2 (각 데이터 샘플의 L2 Norm이 서로 다름)

        두 기법의 차이점은 다음과 같습니다:

        1. 결과 값의 차이:

          • Unit Vector Scaling: 결과 벡터의 L2 Norm이 1

          • Normalizer: 결과 벡터의 L2 Norm이 각각 다름

        2. 목적의 차이:

          • Unit Vector Scaling: **데이터 벡터의 방향성을 유지하면서 크기를 조절**

          • Normalizer: **각 데이터 벡터의 크기를 정규화하여 균일한 크기** 확보

        즉, Unit Vector Scaling은 데이터의 방향성을 보존하는 것이 목적이지만, Normalizer는 데이터의 크기를 균일하게 하는 것이 목적입니다.

        따라서 Unit Vector Scaling과 Normalizer는 서로 다른 스케일링 기법이며, 각각 상황에 따라 적절히 사용되어야 합니다.

      • Scaling 활용 예

        네, 각 스케일링 기법이 주로 사용되는 대표적인 예를 소개하겠습니다.

        1. Min-Max 스케일링 (Normalization)

          • 전통적인 데이터 정규화 기법

          • 범위 제한이 필요한 모델(SVM, KNN 등)에 적합

          • 이미지 픽셀값, 금융 데이터 등에 활용

        2. Z-score 정규화 (Standardization)

          • 평균 0, 표준편차 1의 정규 분포로 변환

          • 선형 모델(선형 회귀, 로지스틱 회귀 등)에 효과적

          • 다양한 도메인의 데이터에 널리 사용

        3. Robust 스케일링

          • 중앙값과 사분범위를 사용하여 이상치에 강인

          • 비정규 분포를 가진 데이터에 유용

          • 금융, 의료 데이터 등의 이상치가 많은 경우에 활용

        4. Unit Vector Scaling

          • 문서 분류, 추천 시스템 등 방향성이 중요한 모델에 활용

          • 자연어 처리 분야의 언어 모델(BERT, GPT 등)에 널리 사용

        5. Normalizer

          • 문서 분류, 추천 시스템 등 거리 기반 모델에 효과적

          • 자연어 처리, 이미지 처리 등 다양한 분야에서 활용

        이처럼 데이터와 모델의 특성에 따라 적절한 스케일링 기법을 선택하는 것이 중요합니다. 상황에 맞는 기법을 적용하여 모델 성능을 극대화할 수 있습니다.

  3. 데이터 구조 정리

    • **하나의 열에 여러 특성이 섞여 있는 경우 각 특성을 별도의 열로 분리**해야 합니다.

    • 이를 통해 데이터의 이해도를 높이고 모델링 성능을 향상시킬 수 있습니다.

  4. 이상치(Outlier) 처리

    • 데이터셋에 포함된 이상치는 모델 성능에 부정적인 영향을 줄 수 있습니다.

    • 이상치 식별 및 제거, 또는 적절한 대체 방법을 사용해야 합니다.

      • 이상치 제거 방법

        이상치(outlier) 처리는 데이터 전처리 과정에서 매우 중요합니다. 이상치를 적절히 다루지 않으면 모델 성능에 부정적인 영향을 줄 수 있습니다. 이상치 식별 및 제거, 그리고 대체 방법에 대해 자세히 살펴보겠습니다.

        1. 이상치 식별

          • 산점도, 히스토그램 등의 시각화 도구를 이용하여 이상치를 식별할 수 있습니다.

          • Z-score, IQR(사분범위), Isolation Forest 등의 통계적 방법을 사용하여 이상치를 탐지할 수 있습니다.

          • 이상치 기준은 데이터의 특성과 목적에 따라 달리 설정해야 합니다.

        2. 이상치 제거

          • 식별된 이상치는 데이터셋에서 완전히 제거할 수 있습니다.

          • 이 방법은 데이터 손실이 발생할 수 있지만, 모델 성능 향상에 도움이 될 수 있습니다.

          • 다만 이상치가 많거나 데이터가 부족한 경우에는 적절하지 않을 수 있습니다.

        3. 이상치 대체

          • 이상치를 완전히 제거하는 것이 적절하지 않다면, 이를 적절한 값으로 대체할 수 있습니다.

          • 결측값 대체 기법(평균, 중앙값, 최빈값 등)을 활용하여 이상치를 대체할 수 있습니다.

          • 또한 보간법, 모델 기반 예측 등의 방법으로 이상치를 대체할 수 있습니다.

        4. 모델 기반 대체

          • 이상치를 단순히 제거하거나 대체하는 것 외에, 모델을 활용하여 이상치를 다룰 수 있습니다.

          • 강건 회귀, 이상치 탐지 모델 등을 통해 이상치의 영향을 최소화할 수 있습니다.

          • 이 방법은 이상치를 제거하지 않고도 모델 성능을 향상시킬 수 있습니다.

        이상치 처리 방법을 선택할 때는 데이터의 특성, 모델 요구사항, 그리고 전체 워크플로우를 고려해야 합니다. 상황에 맞는 최적의 접근법을 선택하는 것이 중요합니다.

  5. 결측값 처리

    • 데이터셋에 누락된 값이 있는 경우 이를 적절히 처리해야 합니다.

    • 결측값이 있는 행이나 열을 삭제하거나, 평균값 또는 다른 대체값으로 채우는 등의 방법을 사용할 수 있습니다.

이와 같은 데이터 정제 및 준비 과정을 통해 ML 모델링을 위한 최적의 데이터셋을 만들 수 있습니다. 특히 데이터에 대한 충분한 이해와 분석이 중요하며, 이를 바탕으로 적절한 데이터 정제 전략을 수립해야 합니다.

Domain 2.2: Perform feature engineering

데이터 형식으로 인해 추가적인 특성 엔지니어링이 필요할 수 있습니다.

ML 알고리즘에 사용되려면 **범주형 데이터를 수치형 데이터로 변환**해야 하는 경우가 많습니다. 이때 데이터의 특성에 따라 다른 접근법을 사용해야 합니다:

  1. **순서형(Ordinal) 범주형** 데이터:

    • 범주 간 순서가 정의된 데이터입니다.

    • 예: 매우 나쁨, 나쁨, 보통, 좋음, 매우 좋음

    • 각 범주에 대응하는 **숫자 값을 부여하여 수치형으로 변환**할 수 있습니다.

    • **순서 정보를 유지**하는 것이 중요합니다.

  2. **명목형(Nominal) 범주형** 데이터:

    • 범주 간 **순서가 정의되지 않은 데이터**입니다.

    • 예: 남성, 여성, 기타

    • 범주를 숫자로 인코딩할 때는 범주 간 의미 있는 순서가 없도록 주의해야 합니다.

    • One-Hot Encoding → norminal

    • Label Encoding → ordinal

범주형 데이터를 어떻게 처리하느냐에 따라 모델의 성능이 크게 달라질 수 있습니다. 따라서 데이터의 특성을 정확히 파악하고, 적절한 인코딩 기법을 선택하는 것이 중요합니다.

예를 들어, 순서형 데이터에 One-Hot Encoding을 적용하면 순서 정보가 손실될 수 있습니다. 반면 **명목형 데이터에 Label Encoding을 적용하면 범주 간 의미 있는 순서가 부여**될 수 있습니다.

이처럼 데이터의 특성에 맞는 적절한 인코딩 기법을 선택하여 적용하는 것이 특성 엔지니어링의 핵심입니다. 이를 통해 모델의 성능을 향상시킬 수 있습니다.

Domain 2.3: Analyze and visualize data for ML

데이터 시각화는 특성과 특성 간 관계를 더 잘 이해할 수 있게 해줍니다.

ML 파이프라인의 탐색적 데이터 분석 단계에서, 데이터를 분석하고 시각화하는 것은 매우 중요합니다. 이를 통해 특성(feature)과 특성 간 관계를 더 잘 파악할 수 있습니다. 데이터 정제와 특성 엔지니어링 작업에서 시각화 기법은 핵심 도구입니다.

시각화 기법에는 꺾은선 그래프, 히스토그램, 다양한 맞춤형 시각화 등이 포함됩니다. 이 부분에서는 이러한 기법을 이해하고 분석하는 능력을 평가합니다.

시각화를 통해 새로운 특성을 도출할 수도 있습니다:

  • 데이터의 범위는 어떠한가?

  • 데이터의 최빈값은 어디인가?

  • 이상치는 있는가?

  • 데이터에 어떤 흥미로운 패턴이 있는가?

이러한 질문에 대한 답을 통해 데이터 전처리 및 모델 학습에 필요한 작업을 결정할 수 있습니다.

대표적인 시각화 기법으로는 산점도와 히스토그램이 있습니다:

  1. 산점도:

    • 두 개의 수치형 변수 간 관계를 보여줍니다.

    • 데이터 포인트들이 어떻게 퍼져 있는지 확인할 수 있습니다.

    • 두 변수 간 상관관계의 강도와 방향을 파악할 수 있습니다.

  2. 히스토그램:

    • 개별 특성의 분포 특성을 보여줍니다.

    • 데이터의 전체적인 모양, 왜도, 첨도 등을 확인할 수 있습니다.

    • 각 관측치에 대한 전반적인 정보를 얻을 수 있습니다.

이처럼 데이터 시각화는 특성과 특성 간 관계를 깊이 있게 이해하는 데 도움이 되며, 이는 데이터 정제와 특성 공학에 필수적입니다.

  1. AWS Glue의 feature_tokenizer 기능은 없으므로 이 선택지는 제외할 수 있습니다.

  2. 클러스터링은 차원 축소에 도움이 되지 않는 비지도 학습 기법이므로 제외할 수 있습니다.

  3. 나머지 선택지 A, B, D 중 B와 D가 특성 엔지니어링 및 차원 축소 기법으로 보입니다.

  4. A의 Dropout은 정규화 기법이지만 특성 선택 기법은 아닙니다.

  5. 따라서 가장 적절한 답변은 B와 D입니다.

이 문제에서 가장 적절한 기술은 다음 두 가지입니다:

  1. Principal Component Analysis (PCA) 알고리즘 사용

  2. 특성 선택 및 차원 축소 기법 활용

PCA는 데이터의 차원을 감소시키는 대표적인 알고리즘이므로, 이를 활용하여 가장 관련성 있는 특성들을 추출할 수 있습니다.

또한 특성 선택 및 차원 축소 기법을 사용하면, 불필요한 특성들을 제거하고 모델 성능에 가장 중요한 특성들만 유지할 수 있습니다.

반면, 드롭아웃은 정규화 기법이지만 차원 축소에는 도움이 되지 않습니다. 클러스터링 역시 차원 축소에 적합하지 않은 비지도 학습 알고리즘입니다.

AWS Glue의 feature_tokenizer 기능은 실제로 존재하지 않습니다.

따라서 가장 적절한 답변은 “PCA 알고리즘 사용”과 “특성 선택 및 차원 축소 기법 활용”입니다.

  • t-SNE

    t-SNE(t-Distributed Stochastic Neighbor Embedding)는 고차원 데이터를 저차원 공간에 효과적으로 시각화하는 차원 축소 기법입니다. 이를 보다 자세히 설명하겠습니다.

    t-SNE의 기본 원리는 다음과 같습니다:

    1. 고차원 데이터에서 인접한 데이터 포인트들은 저차원 공간에서도 가까이 배치되어야 합니다.

    2. 고차원 데이터에서 멀리 떨어진 데이터 포인트들은 저차원 공간에서도 멀리 배치되어야 합니다.

    이를 위해 t-SNE는 다음과 같은 과정을 거칩니다:

    1. 고차원 데이터의 유클리드 거리를 계산하여 유사도 행렬을 만듭니다.

    2. 이 유사도 행렬을 바탕으로 저차원 공간에 데이터 포인트를 배치합니다.

    3. 저차원 공간에서의 유클리드 거리와 고차원 공간에서의 유사도 사이의 차이를 최소화하는 방향으로 데이터 포인트를 반복적으로 업데이트합니다.

    예를 들어, 고차원의 이미지 데이터를 2D 평면에 효과적으로 시각화할 수 있습니다. t-SNE를 통해 유사한 이미지들이 서로 가까이 배치되고, 다른 유형의 이미지들은 멀리 배치되는 것을 볼 수 있습니다.

    이처럼 t-SNE는 고차원 데이터의 복잡한 구조를 잘 보존하면서도 저차원 공간에 효과적으로 표현할 수 있어, 데이터 탐색과 시각화에 유용하게 사용됩니다.

    다만 t-SNE는 비지도 학습 알고리즘이므로 차원 축소를 위한 목적으로는 적합하지 않습니다. 대신 PCA와 같은 지도 학습 기반 차원 축소 기법이 더 효과적일 수 있습니다.
