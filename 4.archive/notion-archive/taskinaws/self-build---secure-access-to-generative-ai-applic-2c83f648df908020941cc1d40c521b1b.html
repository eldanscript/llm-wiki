관리 계정 (AWS Organizations)

  • 권한 세트 생성 및 관리

  • 위임 관리자 계정 설정

위임 계정 (optional)

  • 사용자와 그룹 생성, 수정, 삭제

  • 사용자와 그룹에 대한 권한 세트 할당

  • 관리 계정에서 생성된 권한 세트는 수정할 수 없음

  • 관리 계정에 대한 접근 권한이 있는 사용자 수를 최소화

  • 관리 계정에 대한 접근을 제한하여 보안을 향상

Activate IAM Identity Center

  • Enable IAM Identity Center

  • AWS Workshop event에서는 AWS Organizations 사용 권한이 없음

  • Single AWS account로 활성화

    • 제한 사항

      • Users, groups, AWS managed applications are isolated to this account instance : IAM Identity Center에서 생성한 사용자, 그룹, 애플리케이션은 해당 single account에만 적용되며 다른 AWS 계정에서는 사용 불가

      • This account instance doesn’t support granting users and groups access to AWS accounts in an AWS organization : AWS Organization 내의 다른 계정에 대한 액세스 관리가 불가능

      • This account instance can’t be upgraded to become an organization instance : 단일 계정 기반의 Identity Center에서는 조직 전체에 걸친 사용자 및 권한 관리 불가

  • Identity Center Instance name 설정

    1. Single Account Instance:

      • AWS 계정 하나에 IAM Identity Center의 인스턴스가 생성됩니다.

      • 이 인스턴스는 해당 계정 내에서만 사용자, 그룹, 애플리케이션 관리 등이 가능합니다.

    2. Organization Instance:

      • AWS Organization 내의 멤버 계정들에 대해 하나의 공유 IAM Identity Center 인스턴스가 생성됩니다.

      • 조직 전체에 걸쳐 사용자, 그룹, 애플리케이션 등을 통합적으로 관리할 수 있습니다.

IAM Identity Center - External Identity Provider

  • Identity provider를 external IdP로 선택

  • SAML 2.0 metadata : IAM Identity Center certificate & metadata (SAML Service Provider 정보)
<?xml version="1.0" encoding="UTF-8"?>
<md:EntityDescriptor xmlns:md="urn:oasis:names:tc:SAML:2.0:metadata" entityID="https://us-east-1.signin.aws.amazon.com/platform/saml/d-9067c2bf1a">
	<md:SPSSODescriptor AuthnRequestsSigned="false" WantAssertionsSigned="true" protocolSupportEnumeration="urn:oasis:names:tc:SAML:2.0:protocol">
		<md:NameIDFormat>urn:oasis:names:tc:SAML:1.1:nameid-format:emailAddress</md:NameIDFormat>
		<md:AssertionConsumerService Binding="urn:oasis:names:tc:SAML:2.0:bindings:HTTP-POST" Location="https://us-east-1.signin.aws.amazon.com/platform/saml/acs/a08f95a3-cb58-420a-9916-71315861eb3e" index="0" isDefault="true"/>
	</md:SPSSODescriptor>
</md:EntityDescriptor>

이 XML 문서는 SAML(Security Assertion Markup Language) 메타데이터 파일로, SAML 서비스 제공자(Service Provider, SP)의 구성을 설명합니다.

주요 내용은 다음과 같습니다:

  1. <md:EntityDescriptor>: SAML 엔티티의 메타데이터를 포함하는 루트 요소입니다.

    • entityID="<https://us-east-1.signin.aws.amazon.com/platform/saml/d-9067c2bf1a>": SAML 엔티티의 고유 식별자로, 이 경우 AWS 플랫폼의 us-east-1 리전 SAML 엔드포인트입니다.

  2. <md:SPSSODescriptor>: SP의 SAML Single Sign-On(SSO) 기능을 설명합니다.

    • AuthnRequestsSigned="false": SP가 보내는 SAML 인증 요청이 서명되지 않음을 의미합니다.

    • WantAssertionsSigned="true": SP가 Identity Provider(IdP)에서 보내는 SAML 어설션(응답)이 서명되기를 요구합니다.

    • protocolSupportEnumeration="urn:oasis:names:tc:SAML:2.0:protocol": SP가 SAML 2.0 프로토콜을 지원함을 나타냅니다.

  3. <md:NameIDFormat>: SP가 지원하는 이름 식별자 형식을 지정합니다. 이 경우 “urn:oasis:names:tc:SAML:1.1:nameid-format:emailAddress”입니다.

  4. <md:AssertionConsumerService>: SP가 IdP로부터 SAML 어설션(응답)을 받는 엔드포인트를 설명합니다.

    • Binding="urn:oasis:names:tc:SAML:2.0:bindings:HTTP-POST": SAML 어설션이 HTTP POST 바인딩을 사용하여 전송됨을 나타냅니다.

    • Location="<https://us-east-1.signin.aws.amazon.com/platform/saml/acs/a08f95a3-cb58-420a-9916-71315861eb3e>": SAML 어설션을 받는 URL입니다.

    • index="0": 이 엔드포인트가 기본 어설션 소비자 서비스 엔드포인트임을 나타냅니다.

    • isDefault="true": 이 엔드포인트가 기본 어설션 소비자 서비스 엔드포인트임을 확인합니다.

요약하면, 이 SAML 메타데이터 파일은 us-east-1 리전의 AWS SAML 서비스 제공자(SP)의 구성을 설명합니다. 여기에는 지원되는 SAML 프로토콜, 어설션 소비자 서비스 엔드포인트, 그리고 기타 설정이 포함됩니다.
