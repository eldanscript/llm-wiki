SageMaker Setup and Navigation

Introduction to SageMaker Studio

Amazon SageMaker와 SageMaker Studio:

  • Amazon SageMaker는 기계 학습(ML) 서비스로, 데이터 과학자와 개발자들이 ML 모델을 빠르고 자신감 있게 구축, 학습, 배포할 수 있도록 도와줌

  • 전통적인 ML 파이프라인은 복잡하고 반복적인 작업으로, 여러 도구와 시스템을 오가며 수작업으로 진행해야 하는 문제점 존재

  • Amazon SageMaker는 **ML 개발에 필요한 모든 구성 요소를 하나의 통합된 서비스로 제공**하여 **ML 모델의 프로덕션 배포를 더 빠르고 쉽게 할 수 있도록 지원**

SageMaker Studio의 주요 특징:

  • 웹 기반 시각적 인터페이스를 제공하여 **ML 워크플로우의 모든 단계를 단일 환경에서 수행**할 수 있음

  • 데이터 준비, 레이블링, 특성 엔지니어링, 통계적 편향 감지, 학습, 튜닝, 호스팅, 모니터링 등의 목적 기반 도구 제공

  • 실험 추적, 코드 작성, 디버깅, 데이터 시각화 등을 단일 환경에서 수행할 수 있어 생산성 향상

  • 2023년 11월 30일 새로운 웹 기반 UI가 도입되었고, 기존 SageMaker Studio는 SageMaker Studio Classic으로 이름 변경

새로운 SageMaker Studio 환경의 특징:

  • JupyterLab, RStudio, Code Editor(Visual Studio Code 기반) 등 다양한 관리형 IDE를 선택할 수 있음

  • 이번 과정에서는 주로 SageMaker Studio Classic 인터페이스를 사용하지만, 일부 데모에서 새로운 UI도 경험해 볼 수 있음

2024년 12월에 SageMaker Studio에 추가된 새로운 기능

  • SageMaker Studio 환경에 **Studio Lab** 추가:

    • Jupyter Notebook과 유사한 환경을 제공하지만 **완전한 관리형 서비스**

    • 사용자가 직접 서버 및 인프라를 관리할 필요 없이 ML 실험 및 모델 개발 수행 가능

    • 다양한 프레임워크와 라이브러리를 사용할 수 있는 사전 구성된 커널 지원

  • SageMaker Notebooks 개선:

    • 사용자 경험 향상을 위한 새로운 UI 도입

    • 노트북 실행 속도 향상 및 안정성 개선

    • **실시간 협업 기능 추가 - 다른 사용자와 노트북을 공동으로 편집** 가능

  • SageMaker Studio 보안 강화:

    • **IAM 역할 기반 액세스 제어 기능** 추가

    • **VPC 내부에서만 SageMaker Studio 사용** 가능

    • 고객 관리형 키를 사용한 데이터 암호화 지원

SageMaker Studio Classic Notebook Architecture

SageMaker Studio Classic Notebook 아키텍처:

  • 단일 호스트 아키텍처로 구성됨

    • Jupyter 노트북은 기본적으로 단일 Amazon EC2 인스턴스에 호스팅되며, 웹 브라우저를 통해 액세스 가능

    • 브라우저에서 Jupyter 서버 URL을 입력하면 HTTPS 또는 WSS 호출을 통해 Jupyter 서버가 실행 중인 인스턴스에 연결

SageMaker Studio 도메인:

  • 도메인은 다음 요소들의 논리적 집합체:

    • Amazon Elastic File System(Amazon EFS) 볼륨

    • 도메인 액세스 권한이 부여된 사용자 목록

    • 보안 및 네트워킹 관련 구성

  • 도메인을 통해 사용자 간 노트북 및 기타 아티팩트 공유가 가능

  • 계정당 리전 별로 1개의 도메인만 생성 가능

앱 및 커널:

  • SageMaker Studio는 두 가지 유형의 앱을 지원:

    • JupyterServer 앱: Jupyter 서버를 실행

    • KernelGateway 앱: SageMaker 이미지를 실행하여 커널에 대한 액세스 제공

  • KernelGateway 아키텍처를 통해 노트북 서버가 원격 호스트의 커널과 통신 가능

터미널 액세스:

  • JupyterServer 앱의 시스템 터미널: 노트북 서버 확장 설치, 파일 시스템 작업 수행

  • KernelGateway 앱의 이미지 터미널: 특정 라이브러리 설치, 스크립트 실행

사용자 정의:

  • Lifecycle Configurations를 통해 환경 사용자 정의 가능

    • 패키지 설치, 네트워킹/보안 구성, 데이터셋 로딩, 소스 코드 리포지토리 설정 등

인스턴스:

  • SageMaker Studio는 완전 관리형 EC2 인스턴스 제공

  • 각 사용자는 특정 인스턴스 유형(예: ml.t3.medium)을 1개만 실행 가능

컨테이너 및 이미지:

  • 각 앱은 자체 컴퓨팅 환경(컨테이너)에서 실행

  • 컨테이너 이미지에는 필수 라이브러리, 바이너리, 프레임워크, 인터프리터 등이 포함

  • SageMaker Studio는 사전 구축된 이미지를 제공하며, 사용자 정의 이미지도 사용 가능

  • 인스턴스당 최대 4개의 앱 할당 가능

콘솔:

  • 노트북 및 터미널 외에도 대화형 Python 셸(콘솔) 실행 가능

이와 같은 아키텍처에서 핵심 요소는 SageMaker Studio 도메인입니다. 도메인은 EFS 볼륨, 사용자 권한, 보안/애플리케이션/네트워킹 구성을 논리적으로 통합합니다.

SageMaker Stuido Architecture

SageMaker Studio 아키텍처

새로운 사용자 인터페이스 경험

  • SageMaker Studio의 새로운 웹 기반 UI는 빠른 성능을 제공하며 작업 및 엔드포인트를 포함한 모든 SageMaker 리소스에 대한 액세스를 제공합니다.

  • Amazon SageMaker Studio는 다음과 같은 애플리케이션을 지원합니다:

    • Code Editor

    • Amazon SageMaker Studio Classic

    • JupyterLab

    • Amazon SageMaker Canvas

    • RStudio

노트북 아키텍처

  • 새로운 SageMaker Studio 아키텍처는 Jupyter 서버와 커널 프로세스가 동일한 ML 컴퓨팅 인스턴스에서 Docker 컨테이너 내에서 함께 작동하는 더 로컬화된 아키텍처를 제공합니다.

  • 업데이트된 Jupyter Lab 아키텍처는 모든 커널 작업을 로컬 인스턴스에서 직접 실행합니다.

  • 이 설계는 지연 시간과 네트워크 복잡성을 최소화하고, 디버깅 및 유지 관리를 더 쉽게 만들며, 리소스 활용을 향상시킵니다.

  • SageMaker Studio의 최신 업데이트에서는 **Amazon EFS 기반 스토리지에서 Amazon EBS 기반 솔루션으로 전환**되었습니다.

  • SageMaker Studio 공간에 프로비저닝된 Amazon EBS 볼륨은 볼륨 크기에 관계없이 **일관된 기준 성능 3,000 IOPS를 제공하는 GP3 볼륨**입니다.

  • 이 새로운 EBS 스토리지는 모델 교육, 데이터 처리, 고성능 컴퓨팅, 데이터 시각화와 같은 I/O 집약적 작업에 대해 높은 성능을 제공합니다.

공간(Spaces)

  • 공간은 SageMaker Studio 애플리케이션의 스토리지 및 리소스 요구 사항을 관리하는 데 사용됩니다.

  • 공간은 컴퓨팅 인스턴스, 스토리지 및 기타 런타임 구성의 조합을 나타냅니다.

  • 각 공간은 애플리케이션의 인스턴스와 1:1 관계를 가집니다. 모든 지원되는 애플리케이션에는 자체 공간이 있습니다.

  • 공간은 프라이빗 또는 공유될 수 있습니다.

  • 공간이 생성될 때 Amazon EBS 볼륨으로 구성되며, 사용자 파일, 데이터 캐시 및 기타 아티팩트를 저장하는 데 사용됩니다.

  • EBS 볼륨은 공간이 실행되는 ML 컴퓨팅 인스턴스에 연결됩니다.

  • EBS 볼륨은 공간이 중지되고 재시작될 때마다 사용자 파일, 데이터, 캐시 및 세션 상태가 일관되게 복원되도록 합니다.

  • 공간이 실행 중이거나 중지된 상태인지 여부와 관계없이 이 EBS 볼륨은 지속적으로 유지됩니다. 공간이 삭제될 때까지 계속 유지됩니다.

Notebook Architecture

업데이트된 SageMaker Studio 아키텍처에서는 다음과 같은 변화가 있습니다:

  1. 더 지역화된 아키텍처: Jupyter 서버와 커널 프로세스가 동일한 Docker 컨테이너 내에서 같은 ML 컴퓨팅 인스턴스에서 작동합니다. 이를 통해 지연 시간과 네트워크 복잡성이 감소하고, 디버깅과 유지 관리가 더 쉬워지며, 리소스 활용이 향상됩니다.

  2. Amazon EFS에서 Amazon EBS로 전환: SageMaker Studio 공간에 프로비저닝된 Amazon EBS 볼륨은 GP3 볼륨으로, 볼륨 크기와 무관하게 기본 성능 3,000 IOPS를 제공합니다.

요약하면, 이번 업데이트를 통해 SageMaker Studio의 아키텍처가 단순화되고 성능이 향상되었다고 할 수 있습니다.

Spaces

SageMaker Studio에서 Spaces는 다음과 같은 요소들의 조합을 의미합니다:

  1. 컴퓨팅 인스턴스

  2. 스토리지

  3. 다양한 애플리케이션의 스토리지 및 리소스 요구사항을 관리하기 위한 런타임 구성

각 Space는 1:1 관계로 애플리케이션의 인스턴스를 나타냅니다. 지원되는 모든 애플리케이션은 자신만의 Space를 가집니다.

Space는 개인 공간(private) 또는 공유 공간(shared)으로 구분됩니다. Space가 생성될 때 Amazon Elastic Block Store(EBS) 볼륨이 함께 프로비저닝됩니다. 이 EBS 볼륨은 사용자 파일, 데이터 캐시, 기타 아티팩트를 저장하는 데 사용됩니다. EBS 볼륨은 Space가 실행되는 ML 컴퓨팅 인스턴스에 연결됩니다.

EBS 볼륨을 사용하면 Space가 중지되었다가 다시 시작될 때 사용자 파일, 데이터, 캐시, 세션 상태가 일관되게 복원됩니다. 중요한 점은 EBS 볼륨이 Space의 실행 상태와 무관하게 지속된다는 것입니다. Space가 삭제될 때까지 볼륨이 지속됩니다.

SageMaker Studio vs SageMaker AI

SageMaker AI와 SageMaker Unified Studio 비교 분석:

  1. 주요 목적과 사용 대상

  • SageMaker AI

    • AI/ML 모델 개발에 특화된 플랫폼

    • 데이터 사이언티스트와 ML 엔지니어를 위한 도구

    • 모델 학습과 배포에 중점

  • SageMaker Unified Studio

    • 데이터, 분석, AI를 통합한 개발 환경

    • 데이터 사이언티스트, 분석가, 개발자, 비즈니스 사용자 모두를 위한 플랫폼

    • **종합적인 데이터 처리와 AI 개발** 가능

  1. 핵심 기능

  • SageMaker AI

    • **250개 이상의 사전 학습된 기초 모델** 제공

    • 분산 학습 지원

Data Processing Introduction

비디오 트랜스크립트:

  • 이 모듈에서는 데이터를 준비하고 처리하는 4가지 옵션을 살펴볼 것입니다.

  • 데이터 준비 과정은 모델 학습 및 생성을 위해 데이터를 준비하는 단계입니다.

  • 데이터 분석, 품질 확인, 변수 타입 확인 등의 작업이 이 단계에 포함됩니다.

  • Amazon SageMaker Data Wrangler를 사용하여 데이터 분석 및 준비를 수행할 수 있습니다.

  • Apache Spark on Amazon EMR, AWS Glue 대화형 세션, Amazon SageMaker Processing 등 다양한 도구를 사용할 수 있습니다.

  • 최종적으로 Amazon SageMaker Feature Store에 변환된 특징을 저장할 수 있습니다.

데이터 처리 도구:

  • SageMaker Data Wrangler: 저코드 시각화 및 변환 기능 제공

  • SageMaker Processing: 사용자 정의 스크립트 및 컨테이너 사용

  • Amazon EMR: 기존 Spark 스크립트 재사용

  • AWS Glue 대화형 세션: 서버리스 Spark 세션 제공

Amazon SageMaker Data Wrangler:

  • 데이터 정제, 탐색, 시각화를 가속화하기 위한 시각적 인터페이스를 제공합니다.

  • 코드 작성 없이 기본 제공되는 변환 기능을 적용할 수 있는 “무코드” 워크플로를 제공합니다.

  • PySpark, Pandas, SQL을 사용하여 사용자 정의 변환을 작성할 수 있는 옵션이 있습니다.

Amazon SageMaker Processing:

  • 전처리, 후처리, 모델 평가 작업을 완전 관리형 인프라에서 쉽게 실행할 수 있습니다.

  • Apache Spark, Scikit-learn 등을 위한 사전 구축된 컨테이너를 포함하고 있습니다.

  • R 등의 다양한 프레임워크와 언어를 위한 사용자 정의 컨테이너 통합을 지원합니다.

  • SageMaker Processing 작업을 반복 가능한 워크플로의 일부로 통합할 수 있습니다.

Amazon EMR:

  • 조직에서 Apache Spark를 사용하는 경우 SageMaker Studio에서 Amazon EMR에 연결하는 것이 좋습니다.

  • 지속적인 연결이 필요한 경우 Amazon EMR을 사용하여 지속적인 클러스터를 프로비저닝할 수 있습니다.

  • SageMaker Studio의 내장 SparkMagic 커널을 사용하여 Amazon EMR과 시각화를 수행할 수 있습니다.

AWS Glue 대화형 세션:

  • 서버리스 Apache Spark 옵션을 제공합니다.

  • 내장된 SparkAnalytics 이미지와 노트북 셀 매직을 사용하여 대화형 세션을 사용자 정의하고 확장 가능한 데이터 준비 워크로드를 실행할 수 있습니다.

Using SageMaker Data Wrangler

데이터 소스 연결:

  • S3, Athena, Redshift, Databricks (JDBC), Snowflake, Amazon EMR, SaaS platform 등 다양한 데이터 소스를 지원함

  • CSV, Parquet, JSON, JSON Lines, ORC 등 다양한 데이터 형식을 지원함

데이터 흐름 (Data Flow):

  • 데이터 소스 선택부터 데이터 변환, 분석, 내보내기까지의 과정을 시각적으로 표현

  • 데이터 소스, 데이터 변환 단계, 분석 및 시각화 기능, 데이터 내보내기 등을 포함

아마존 SageMaker Data Wrangler에서의 데이터셋 및 데이터 변환 과정은 다음과 같습니다:

First dataset:

  • 데이터셋을 가져오면 원본 데이터셋은 “Source”라는 이름으로 데이터 흐름에 나타남

  • 데이터 가져올 때 샘플링을 활성화하면 “Source - sampled”라는 이름의 샘플링된 데이터셋이 나타남

Second dataset:

  • SageMaker Data Wrangler는 데이터셋의 각 열 데이터 유형을 자동으로 추론하고 “Data types”이라는 새로운 데이터프레임을 생성함

  • 이 “Data types” 데이터프레임을 선택하면 추론된 데이터 유형을 업데이트할 수 있음

Data transformations:

  • 변환 단계를 추가할 때마다 새로운 데이터프레임이 생성됨

  • 동일한 데이터셋에 여러 변환 단계(Join 또는 Concatenate 제외)를 추가하면 이 단계들이 쌓여서 표시됨

Joined dataset:

  • Join과 Concatenate는 새로 조인되거나 연결된 데이터셋을 포함하는 독립적인 단계를 생성함

Add step:

  • 이전에 추가한 단계 옆의 + 버튼을 선택하면 다음 작업을 수행할 수 있음:

    • 데이터 정리를 위한 변환 단계 추가

    • 데이터 시각화를 위한 분석 단계 추가

    • 두 개의 데이터셋을 조인하여 새 데이터셋 추가

    • 두 개의 데이터셋을 연결하여 새 데이터셋 추가

내장 분석 기능:

  • 데이터 품질 및 통찰력 보고서

  • 히스토그램, 산점도, 편향 탐지, 타깃 누출 분석, 시계열 분석 등

    아마존 SageMaker Data Wrangler의 내장 분석 기능은 다음과 같습니다:

    히스토그램:

    • 하나 이상의 특성에 대한 데이터 행의 수를 비교할 수 있는 시각화

    • “색상별로” 옵션을 사용하면 누적 막대 차트를 만들 수 있음

    산점도:

    • **두 변수 간의 관계를 시각화**하는 데 사용

    편향 탐지:

    • 다음과 같은 편향 측정 항목을 제공:

      • 클래스 불균형(CI)

      • 레이블의 긍정적 비율 차이(DPL)

      • 레이블 분포 발산(Jensen-Shannon Divergence, JS)

      • 레이블의 조건부 인구통계학적 격차(CDDL)

    타깃 누출 분석:

    • 원시 특성의 예측 능력을 확인하여 **과도한 상관관계를 검사**

    • AUC-ROC 곡선을 기반으로 함

    시계열 분석:

    • 시계열 데이터의 이상치와 계절적 패턴을 분석할 수 있음

    Feature Correlation:

    • 특성 간 선형 또는 비선형 상관관계 값을 계산

    Multicollinearity:

    • Variance Inflation Factor(VIF) 및 주성분 분석(PCA)을 통해 다중 공선성을 측정

    • Lasso 특성 선택을 사용하여 특성 중요도 분석

    이 외에도 사용자가 직접 코드로 커스텀 분석을 추가할 수 있습니다.

  • 사용자 정의 분석도 가능

데이터 변환:

  • 결측치 처리, 범주형 변수 인코딩, 텍스트 전처리 등 300여 가지 내장 변환 기능

    데이터셋 균형화(Balancing a dataset):

    • 데이터셋의 클래스 불균형을 해결하기 위한 기능

    • 과대 또는 과소 표현된 클래스의 샘플 수를 조정

    범주형 데이터 인코딩(Encoding categorical data):

    • 범주형 변수를 수치형 변수로 변환

    • One-hot 인코딩, 라벨 인코딩 등의 기법 지원

    텍스트 피처화(Featurizing text):

    • 텍스트 데이터를 수치형 특성으로 변환

    • 단어 빈도, TF-IDF, 임베딩 등의 기법 제공

    문자 통계 생성(Generating character statistics):

    • 텍스트 데이터의 문자 수, 단어 수, 문장 수 등의 통계량 생성

    텍스트 토큰화(Tokenizing text):

    • 텍스트를 토큰으로 분할하는 기능

    • 공백, 구두점 등을 기준으로 토큰화

    시계열 데이터 그룹화(Grouping time series data):

    • 시계열 데이터를 시간 단위로 그룹화하는 기능

    • 일별, 월별, 연도별 등으로 그룹화 가능

    시계열 데이터 리샘플링(Resampling time series data):

    • 시계열 데이터의 시간 주기를 변경하는 기능

    • 일별 데이터를 월별로 리샘플링 등

    이상치 처리(Clipping, removing, or invalidating outliers):

    • 이상치를 제거, 무효화 또는 클리핑하는 기능

    결측값 처리(Filling, imputing, or dropping missing values):

    • 결측값을 채우거나 제거하는 기능

    • 평균, 중앙값, 최빈값 등으로 대체 가능

    JSON 데이터 중첩 해제(Unnesting JSON data):

    • 중첩된 JSON 데이터를 펼치는 기능

    데이터 배열 확장(Exploding data arrays):

    • 행 내 배열 데이터를 개별 행으로 확장하는 기능

    이 외에도 300여 개의 다양한 내장 변환 기능을 제공하며, 사용자 정의 변환도 가능합니다.

  • 사용자 정의 변환도 가능 (PySpark, Python UDF, Pandas, PySpark SQL)

데이터 준비 위젯:

  • Jupyter Notebook 내에서 데이터 탐색, 변환, 품질 이슈 해결 가능

  • Pandas 데이터프레임 활용 가능

종합적으로 SageMaker Data Wrangler는 데이터 준비 과정을 시각적이고 효율적으로 수행할 수 있게 해주는 도구입니다. 다양한 데이터 소스와 형식을 지원하고, 내장 분석 및 변환 기능을 제공하여 ML 모델 구축을 위한 데이터 준비 작업을 간소화합니다.

Data Wrangler 작업 예

  1. 데이터셋에서 층화 샘플링(Stratified Sampling)을 수행하여 데이터를 가져오기:

    • 데이터셋의 특정 특성(예: 성별, 연령 등)을 기반으로 층화(stratification)하여 대표성 있는 샘플을 추출

  2. 여러 개의 데이터프레임을 병합(Join)하기:

    • 다양한 데이터 소스에서 가져온 데이터프레임을 하나의 통합된 데이터프레임으로 결합

  3. Seasonal-Trend 분해(Seasonal-Trend Decomposition) 수행하기:

    • 시계열 데이터에서 계절성(Seasonal), 추세(Trend), 잔차(Residual) 성분을 분리하여 분석

    • 이를 통해 데이터의 패턴과 변동 요인을 파악할 수 있음

이 작업은 데이터 전처리, 데이터 병합, 시계열 분석 등 데이터 분석 과정에서 매우 유용하게 사용됩니다. 층화 샘플링을 통해 데이터의 대표성을 확보하고, 여러 데이터 소스를 하나로 통합하며, 시계열 데이터의 구성 요소를 분해하여 분석할 수 있습니다.

Using Amazon EMR

Amazon EMR 사용하기:

  • Amazon EMR은 클라우드 기반의 Big Data 솔루션으로, 수페타바이트 규모의 데이터 처리와 분석, 기계 학습을 지원합니다.

  • 다양한 Big Data 프레임워크(Apache Spark, Hadoop, Apache Hive, Presto 등)를 사용할 수 있으며, SageMaker Studio에서 이를 연결하여 대규모 데이터 준비 작업을 수행할 수 있습니다.

Amazon EMR 사용 단계:

  1. SageMaker Studio에서 Amazon EMR 클러스터를 찾아 연결하기

  2. SageMaker Studio 노트북에서 PySpark(SparkMagic) 커널을 사용하여 Amazon EMR 클러스터에 액세스하고 데이터 탐색 및 쿼리하기

  3. Spark 작업을 실행하여 데이터 준비하기

  4. SageMaker Studio에서 Amazon EMR 클러스터 중지하기 (SageMaker Studio에서 생성한 클러스터만 중지 가능)

PySpark Magic 명령어:

  • %%local: 로컬에서 Python 코드 실행

  • %%sql: Hive SQL 쿼리 실행, -o 옵션으로 결과를 Pandas DataFrame에 저장

  • %%help: 사용 가능한 Magic 명령어 목록 확인

AWS Glue Interactive Sessions

AWS Glue 인터랙티브 세션 요약:

  • AWS Glue 인터랙티브 세션은 온디맨드 제공되는 Apache Spark 런타임 환경을 통해 데이터 준비 및 분석 애플리케이션을 빠르게 구축, 테스트, 실행할 수 있습니다.

  • AWS Glue가 서버리스 Spark 환경을 투명하게 관리하므로 Spark 워크로드를 위한 클러스터를 직접 생성하고 관리할 필요가 없습니다.

  • AWS는 Jupyter 커널을 오픈소스로 제공하여, 로컬 환경에서 코딩한 내용을 인터랙티브 세션 백엔드에서 실행할 수 있습니다.

  • SageMaker Studio에서도 인터랙티브 세션을 사용할 수 있으며, SparkAnalytics 이미지와 Glue Python 또는 Glue Spark 커널을 선택하면 됩니다.

  • Jupyter 노트북에서 Glue 인터랙티브 세션을 활용하려면 매직 명령어를 사용하여 세션 ID 접두사, Glue 버전, 작업자 수, 유휴 시간 제한 등을 구성할 수 있습니다.

  • 인터랙티브 세션에서 실행되는 모든 Spark 명령어와 작업은 AWS Glue API를 통해 관리됩니다.

Using SageMaker Processing with Custom Scripts

SageMaker Processing의 주요 기능 및 사용 방법:

  • 데이터 전처리, 특성 엔지니어링, 데이터 검증 등 ML 생명 주기의 다양한 단계에서 활용 가능

  • 컨테이너 기반으로 작동하며, Amazon SageMaker가 제공하는 사전 구축된 Docker 이미지 또는 사용자 정의 이미지 사용 가능

  • Amazon S3, Amazon Redshift, Amazon Athena 등 다양한 입력 소스로부터 데이터를 처리하고 Amazon S3에 출력 데이터 저장

  • SageMaker Python SDK를 사용하면 편리하고 일관된 프로그래밍 API로 처리 작업 생성 가능

  • CloudWatch 로그를 통해 처리 컨테이너의 표준 출력 및 표준 오류 확인 가능

  • 실험 단계에서도 SageMaker Processing API를 활용하여 사후 처리 작업 및 모델 성능 평가 수행 가능

이 모듈에서는 다음과 같은 기능을 다룸:

  • 데이터 전처리

  • 특성 엔지니어링

  • 데이터 검증

이후 모듈에서는 다음과 같은 기능을 다룰 예정:

  • 모델 평가

  • 모델 해석

  • 실험

  • 모델 성능 평가

SageMaker Feature Store

SageMaker Feature Store에 대해 다음과 같이 설명드리겠습니다:

  1. SageMaker Feature Store의 개념과 기능:

    • 반복적인 데이터 처리 및 큐레이션 작업을 자동화하여 ML 개발 프로세스를 가속화하는 서비스

    • **특징(feature)을 저장, 발견, 공유하는 중앙 저장소 역할**을 수행

    • 특징은 ML 모델 학습 및 예측에 사용되는 입력 데이터의 속성을 의미

  2. Feature Store를 사용한 특징 데이터 공유:

    • 사용자 간 특징 데이터 공유를 통해 **데이터 처리 및 큐레이션 작업의 중복 수행을 방지**

    • 특징 그룹(feature group)에 특징 데이터를 저장하여 다른 사용자들이 발견하고 사용할 수 있도록 함

  3. Feature Store의 온라인 스토어와 오프라인 스토어:

    • **온라인** 스토어: **실시간 낮은 지연 시간 요구사항**을 충족하는 경우 사용(예: **추론 엔드포인트**)

    • **오프라인** 스토어: **지연 시간 요구사항이 낮은 경우** 사용(예: **일괄 추론, 모델 학습**)

  4. Feature Store로 데이터 인제스트:

    • Boto3 또는 SageMaker Python SDK의 API를 사용하여 데이터 인제스트 가능

    • Amazon EMR, AWS Glue, SageMaker Processing 등 다양한 도구에서 데이터 인제스트 가능

  5. SageMaker Data Wrangler에서 Feature Store 연동:

    • Data Wrangler 내에서 Feature Store에서 데이터를 가져오고, 처리된 데이터를 Feature Store로 내보낼 수 있음

    • 두 가지 방법으로 Feature Store와 연동 가능: **1) 데이터 흐름에서 직접** 연동, **2) Jupyter 노트북**에서 연동

  6. Feature Store의 이점:

    • 특징 데이터의 표준화와 재사용을 통한 ML 개발 생산성 향상

    • 팀 간 특징 데이터 공유와 협업 지원

    • 안전하고 통합된 특징 데이터 저장소 제공
