Prompting Engineering Guide Hands-On

LLM Settings

Temperature

  • The lower → the deterministic : highest probable next token is always picked

  • The higher → more random : more diverse or creative

Top P

  • Nucleus sampling

  • Top_P probability mass를 구성하는 토큰을 응답으로 간주

  • Low value : most confident response

  • High value : more diverse output, less likely ones

  • Temperature와 Top_P를 함께 쓰는 것을 권장하지 않음

Max Length

  • Control long or irrelavant response and cost

Stop Sequence

  • String that stops the model from generating token

  • Control the length and structure of the model’s response

Frequency Penality

  • 토큰의 반복을 제어

Presence Penalty

  • 토큰의 반복을 제어

  • 반복 회수와 관계없이 penalty는 동일

  • Higher penalty → creative or diverse text

  • Lower penalty → stay focused

  • Frequency penalty와 Presence penalty를 같이 쓰지 않는 것을 권장

General Tips

Instruction

  • More specific and relevant the context → Better perform

  • Prompt 시작에 배치하는 것이 좋음

  • 명확한 구분자(#)를 사용하여 instruction과 context를 분리

Specificity

  • The more descriptive and detailed : 설명적이고 상세할 수록 → Better perform

  • 불 필요한 상세화는 피해야 함 → 적절하고 관련 있는(relevant) 정보 제공이 필요

Reasoning

Zero-shot Prompting

  • the prompt used to interact with the model won’t contain examples or demonstrations

Few-shot Prompting

  • Few-shot prompting can be used as a technique to enable in-context learning where we provide demonstrations in the prompt to steer the model to better performance.

  • “the label space and the distribution of the input text specified by the demonstrations are both important (regardless of whether the labels are correct for individual inputs)”

  • the format you use also plays a key role in performance, even if you just use random labels, this is much better than no labels at all

  • additional results show that selecting random labels from a true distribution of labels (instead of a uniform distribution) also helps

Chain-of-Thought (CoT) Prompting

  • Address more complex arithmetic, commonsense, and symbolic reasoning tasks

Zero-shot CoT Prompting

  • Let’s think step by step

Automatic CoT

  • Question clustering : partition questions of a given dataset into a few clusters

  • Demonstration sampling : select a representative question from each cluster and generate its reasoning chain using Zero-Shot-CoT with simple heuristics

Self-Consistency

  • Replace the naive greedy decoding used in chain-of-thought prompting

  • Sample multiple, diverse reasoning paths through few-shot CoT → use the generations to select the most consistent answer

  • Apply self-consistency

Generated Knowledge Prompting

  • incorporate knowledge or information to help the model make more accurate predictions

Prompt Chaining

  • Break tasks into its subtasks

  • LLM is prompted with a subtask and then its response is used as input to another prompt → Useful to accomplish complex tasks

  • Chain prompts perform transformations or additional processes on the generated responses before reaching a final desired state

Tree of Thoughts

  • Generalize over chain-of-thought prompting and encourages exploration over thoughts

  • Thoughts represent coherent language sequences that serve as intermediate steps toward solving a problem

  • Define the number of candidates and the number of thoughts/step

  • Combined with search algorithms - BFS (Breadth-first search) & DFS (Depth-first search)

  • https://github.com/dave1010/tree-of-thought-prompting
  • https://github.com/holarissun/PanelGPT

RAG - Retrieval Augmented Generation

  • Meta AI researchers introduced a method called Retrieval Augmented Generation (RAG) to address such knowledge-intensive tasks.

Automatic Reasoning and Tool-use (ART)

  • Strong and robust approach to address many tasks with LLMs

  • Encourages the model to generalize from demonstrations to decompose a new task and use tools in appropriate places, in a zero-shot fashion

  • Extensible as it also enables humans to fix mistakes in the reasoning steps or add new tools by simply updating the task and tool libraries

Automatic Prompt Engineer (APE)

  • Framework for automatic instruction generation and selection

Active-Prompt

  • Query the LLM with or without a few CoT examples. k possible answers are generated for a set of training questions.

  • An uncertainty metric is calculated based on the k answers (disagreement used)

  • The most uncertain questions are selected for annotation by humans. The new annotated exemplars are then used to infer each question.

Directional Stimulus Prompting

  • A tuneable policy LM is trained to generate the stimulus/hint
