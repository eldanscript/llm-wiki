Demo5. Evaluation and Optimization

https://github.com/ACloudGuru-Resources/Course_AWS_Certified_Machine_Learning/blob/master/Chapter8/ufo-evaluation-optimization-lab.ipynb

Goal

  • Use the Linear Learner model for identifying the legitimacy of a reported UFO sighting

  • Plan to send out reported sighting predcited probable or unexplained

  • Optimize model, Improve performance in training and accuracy

Questions

  • Tune model to find the most optimized model

  • Determine if the model is less accurate, more accurate, or about the same

  • What objective metric to monitor to ensure and plan on measuring success

  • Which hyperparameters need to be tuned? What combination of hyperprarameters need to be used?

  • How much faster was training time improved?

Results

  • Best training job hyperparameters

  • Difference in time between baseline model and optimized model

  • Difference in accuracy between models

Work

  • Find the best configuration to minimize the validation : objective_loss metric → Best training job hyperparameters

  • Use optimized hyperparameters to rerun training job

  • Compare the results of time to complete and accuracy to the baseline model → Difference in time and in accuracy between baseline and optimized model

Hyperparameter Tuning

Linear Learner Hyperparameter

  • https://docs.aws.amazon.com/sagemaker/latest/dg/ll_hyperparameters.html

  • num_classes

    • 응답 값의 class 수

    • 3 ~ 1,000,000

  • predictor_type

    • binary classification

    • multiclass classification

    • regression

  • accuracy_top_k

    • multiclass classification

      • top-k accuracy

      • 확률이 높은 순서대로 k 개 안에 정답이 있으면 그 데이터에 대해서는 맞은 것으로 세는 방식. 일반적인 정확도는 Top-1이라고 생각

    • default 3

  • beta_1, beta_2

    • exponential deacy rate for first and second moment estimates

  • bias_lr_mult, bias_wd_mult

    • bias term의 learning rate, different regularization

  • binary_classifier_model_selection_criteria

    • predictor_type이 binary classification인 경우

    • accuracy, F1 score, highest precision, highest recall, loss function

  • early_stopping_patience

    • 관련 메트릭에서 개선이 없으면 훈련을 끝내기 전에 기다릴 수있는 epoch의 수

    • default : 3

  • early_stopping_tolerance

    • 이전의 최상 손실로 나눈 손실의 개선 비율이 이 값보다 작으면 early stopping은 개선을 0으로 간주

    • default : 0.001

  • epochs

    • 훈련 데이터를 통과하는(학습하는) 최대 수

    • default 15

Create tunning job

  1. Tunning Job Config

    1. Early stopping

    2. Tunning Strategy

      1. Bayesian

        1. 어느 입력값(x)를 받는 미지의 목적 함수(f(x))를 상정한 후 해당 함숫값(f(x))을 최대로 만드는 최적해를 찾는 것이 목적

        2. 목적 함수(탐색대상함수)와 하이퍼파라미터 쌍(pair)을 대상으로 Surrogate Model(대체 모델) 을 만들고

        3. 순차적으로 하이퍼 파라미터를 업데이트해 가면서 평가를 통해 최적의 하이퍼파라미터 조합을 탐색

      2. Random

        1. 탐색 대상 구간 내의 후보 hyperparameter 값들을 랜덤 샘플링(sampling)을 통해 선정

        2. Grid Search에 비해 불필요한 반복 수행 횟수를 대폭 줄이면서, 동시에 정해진 간격(grid) 사이에 위치한 값들에 대해서도 확률적으로 탐색이 가능하므로, 최적 hyperparameter 값을 더 빨리 찾을 수 있음

        3. 매 회 새로운 hyperparameter 값에 대한 조사를 수행할 시 ‘사전 지식’을 충분히 반영하면서, 동시에 전체적인 탐색 과정을 체계적으로 수행할 수 있는 방법론 → Bayesian Optimization을

    1. Algorithm source

    2. Training data input mode

      1. Pipe

        1. Training 인스턴스로 직접 스트리밍

        2. 디스크 I/O를 사용하지 않고 알고리즘 컨테이너에 데이터를 즉시 입력
