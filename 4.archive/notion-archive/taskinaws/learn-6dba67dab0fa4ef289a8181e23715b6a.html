1.2 What is ML?

  • AI - Perform activities using human-like intelligence

  • ML - automatically learn and improve from experience without explictly programmed to do so

  • supervised learning,

    • every training sample from the dataset has a corresponding label or output value associated with it. As a result, the algorithm learns to predict labels or output values.

  • reinforcement learning,

    • the algorithm figures out which actions to take in a situation to maximize a reward (in the form of a number) on the way to reaching a specific goal.

  • unsupervised learning,

    • there are no labels for the training data. A machine learning algorithm tries to learn the underlying patterns or distributions that govern the data

1.3 Components of ML

  • A model

    • an extremely generic program (or block of code)

    • made specific by the data used to train it

    • used to solve different problems

  • Training Algorithm

    • Think about the changes that need to be made

      • uses the model to process data and then compares the results against some end goal

    • Make those changes

      • gently nudges specific parts of the model in a direction that brings the model closer to achieving the goal

    • Repeat

      • iterating these steps over and over

      • until you determine that you’re close enough and then you can stop

  • Inference Algorithm

    • the trained model is used to generate predictions

2.1 Five. ML Steps

  • Clustering is an **unsupervised learning task** that helps to determine if there are any naturally occurring groupings in the data.

  • Discrete is a term taken from **statistics referring to an outcome** that takes only a finite number of values (such as days of the week).

  • A categorical label has a discrete set of possible values, such as “is a cat” and “is not a cat.”

  • A continuous (regression) label does not have a discrete set of possible values, which means there are potentially an unlimited number of possibilities.

  • A label refers to data that already contains the solution.

  • Using unlabeled data means you don’t need to provide the model with any kind of label or solution while the model is being trained

2.2 Define the problem

  • Define a very specific task

    • Question: Does adding a $1.00 charge for sprinkles on a hot fudge sundae increase the sales of hot fudge sundaes?

    • Question: Does adding a $0.50 charge for organic flavors in your snow cone increase the sales of snow cones?

  • Identify the used ML task to solve this problem

  • Supervised Tasks

    • using labeled data

    • labeled to refer to data that already contains the solutions, called labels

    • Categorical label

      • discrete set of possible values

    • Continous (Regression) label

      • does not have a discrete set of possible values, often working with numerical data

  • Unsupervised Tasks

    • using unlabeled data

    • don’t need to provide the model with any kind of label or solution while the model is being trained

    • **Clustering** helps to determine if there are any naturally occurring groupings in the data

2.3 Build a dataset

  • check that your data is in line with the underlying assumptions of the machine learning model that you chose

  • Impute (대체) is a common term referring to different statistical tools that can be used to calculate missing values from your dataset.

  • Outliers are data points that are significantly different from other date in the same sample.

2.4 Model training

💡

The model training algorithm iteratively updates a model’s parameters to minimize some loss function.

  • Split Dataset

    • Training dataset: The data on which the model will be trained. Most of your data will be here. Many developers estimate about 80%.

    • Test dataset: The data withheld from the model during training, which is used to test how well your model will generalize to new data

  • Model parameter

    • settings or configurations that the training algorithm can update to change how the model behaves

  • Loss function

    • codify the model’s distance from a goal

  • Training process

    • Feed the training data into the model

    • Compute the loss function on the results

    • Update the model parameters in a direction that reduces loss

    • continue to cycle until you reach a predefined stop condition - training time, the number of training cycles, or an even more intelligent or application-aware mechanism

  • Use machine learning frameworks that already have working implementations of models and model training algorithms

  • Use a process called model selection to determine which model or models to use.

  • Hyperparameters are settings on the model

    • not changed during training

    • can affect how quickly or how reliably the model trains

  • Be prepared to iterate

  • Foster a habit of trying new things, measuring success, and comparing results across iterations

Linear model

  • Most common model

  • Simply describe the relationship between a set of input numbers and a set of output numbers through a linear function

    • y = mx + b

  • Fast to train and give a great baseline against which to compare more complex model

Tree-based model

  • 2nd most common model

  • Learn to categorize or regress by building an extremely large structure of nested if/else blocks, splitting the world into different regions at each if/else block

  • Training determeines exactly where these splits happen and what value is assigned at each leaf region

  • XGBoost is commonly used as an off-the-shelf implementation

  • Get a baseline before moving on to more complex models

Deep learning model

  • Conceptual model of how the human brain functions - composed of collections of neurons

  • The training process finds values for each weight

  • FFNN (Feed Forward Neural Network)

    • Most straightforward way of structuring a NN

    • Structures neurons in a series of layers - each neuron containing weights to all neurons in the previous layer

  • CNN (Convolutional Neural Networks)

    • Represent nested (중첩) filters over grid-organized data

    • Most commonly used for processing images

  • RNN/LSTN (Recurrent Neural Networks / Long Short-Term Memory)

    • Effectively represent for loops in traditional computing, collecting state while iterating over some object

    • Processing sequences of data

  • Transformer

    • More modern replacement for RNN/LSTMs

    • Enables training over large datasets involving sequences of data

  • ML Library

    • Classical model (linear, tree-based) : scikit-learn

    • Deep Learning : MXNet, TensorFlow, PyTorch

2.5 Model evaluation

  • Model Accuracy : the fraction of predictions (예측 비율) a model gets right

Log Loss

  • Log loss could be used to understand your **model's uncertainty** about a given prediction

  • Log loss enables to measure how strongly the model believes that its prediction is accurate

  • trying to predict how likely a customer is to buy either a jacket or t-shirt

    • In an instance, model predicts with 5% certainty that customer will buy a t-shirt

    • In another instance, model predicts with 80% certainty that customer will buy a t-shirt

    • In above, model predicts that a customer will buy a t-shirt, but the model’s certainty about that prediction can change

2.6 Model Inference

  • Once you have trained your model, have evaluated its effectiveness, and are satisfied with the results, you’re ready to generate predictions on real-world problems using unseen data in the field.

  • In machine learning, this process is often called inference.

  • Even after you deploy your model, you’re always monitoring to make sure your model is producing the kinds of results that you expect.

  • There may be times where you reinvestigate the data, modify some of the parameters in your model training algorithm, or even change the model type used for training.

2.7 Summary

  1. Solving problems using machine learning is an evolving and iterative process.

  2. To solve a problem successfully in machine learning finding high quality data is essential.

  3. To evaluate models, you often use statistical metrics. The metrics you choose are tailored to a specific use case.

3.1 Example - Linear Model

💡

Predicting home prices - estimate the price of a house based on lot size or the number of bedrooms

Problem define

  • Access the sale prices for recently sold homes or have them appraised → this is a supervised learning task

  • Want to predict a continuous numeric value → a regression task

Build the dataset

  • Data Collection

  • Data exploration (탐색)

    • confirm that all of your data is numerical because most machine learning models operate on sequences of numbers

    • If there is textual data, you need to transform it into numbers

  • Data cleaning

    • missing information or outliers, such as the 10-room mansion

    • use several techniques to handle outliers, but you can also just remove them from your dataset

  • Data Visualization

    • want to look for trends in your data

  • Data Split

    • The standard practice is to put 80% of your dataset into a training dataset and 20% into a test dataset

Model Training

  • As you see in the preceding chart, when lot size increases, home values increase too. This relationship is simple enough that a linear model can be used to represent this relationship → Linear Model selection

  • Using a Python scikit-learn library

Model Evalutaion

  • One of the most common evaluation metrics in a regression scenario is called root mean square or RMS

  • RMS can be thought of roughly as the “average error” across your test dataset

  • Many machine learning engineers manually count how many predictions were off by a threshold (for example, $50,000 in this house pricing problem) to help determine and verify the model’s accuracy

Model Inference

  • seeing how well it predicts with new data not seen during model training

  • Hyperplane: A mathematical term for a surface that contains more than two planes

3.2 Example - ML Model

💡

how the machine learning process can be applied to an unsupervised machine learning task that uses book description text to identify different micro-genres

Problem Define

  • believe that a trend called “micro-genres” exists, and you have confidence that you can use the book description text to identify these micro-genres

  • unsupervised machine learning technique → clustering

Build the dataset

  • Data cleaning and exploration

    • capitalization and verb tense will not matter

    • remove capitals and convert all verbs to the same tense

    • remove punctuation and words you don’t think have useful meaning

  • Data preprocessing

    • Vectorization : process whereby words are converted into numbers

    • transform this book description text into what is called a bag of words representation → understandable by machine learning models

Model Training

  • pick a common cluster-finding model called k-means

  • a model parameter, k, to be equal to how many clusters the model will try to find in your dataset

Model Evaluation

  • In this use case, the silhouette coefficient is a good choice

  • This metric describes how well your data was clustered by the model

  • plot the silhouette coefficient : k = 19

  • if every cluster is going to be as cohesive as this, but you decide to use this model to see if you can find anything interesting about which to write an article

Model Inference

Terminology

  • Bag of words (BOW)

    • A technique used to extract features from text.

    • It counts how many times a word appears in a document (corpus), and then transforms that information into a dataset.

  • Data vectorization

    • A process that converts non-numeric data into a numerical format so that it can be used by a machine learning model.

  • Silhouette coefficients

    • A score from -1 to 1 describing the clusters found during modeling.

    • A score near zero indicates overlapping clusters

    • scores less than zero indicate data points assigned to incorrect clusters

    • A score approaching 1 indicates successful identification of discrete non-overlapping clusters.

  • Stop words (불용어)

    • A list of words removed by natural language processing tools when building your dataset.

    • There is no single universal list of stop words used by all-natural language processing tools

3.3 Example - ML Model

💡

offers specialized on-site janitorial services - classical methods like linear models and k-means to solve machine learning tasks

Problem Define

  • predict if each image belongs to one of the following classes

    • Contains spill or Does not contain spill

Build the dataset

  • Data Collecting

    • Using historical data, as well as safely staged spills

    • quickly build a collection of images

      • contain both spills and non-spills

      • in multiple lighting conditions and environments

  • Data Exploring and Cleaning

    • Go through all of the photos to ensure that the spill is clearly in the shot

    • Python tools and other techniques available to improve image quality

  • Data Verctorization

    • require numerical data → Python tools can help you do this automatically

Model Training

  • CNN

Model Evaluation

  • accuracy might not be the best evaluation mechanism

  • The model will see the does not contain spill’ class almost all the time → any model that just predicts no spill most of the time will seem pretty accurate

  • What you really care about is an evaluation tool that rarely misses a real spill

  • precision (정밀도) : Of all predictions of a spill, how many were right?

  • recall (재현률) : Of all actual spills, how many did we detect?

Model Inference

  • The model can be deployed on a system that enables you to run machine learning workloads such as AWS Panorama

  • when the class contains spill’ is detected, a simple paging system could alert the team to respond

Summary

  1. For some applications of machine learning, you need to use more complicated techniques to solve the problem. While
    modern neural networks are a powerful tool, don’t forget their cost in terms of being easily explained.

  2. High quality data once again was very important to the success of this application, to the point where even staging some fake data was required. Once again, the process of data vectorization was required so it was important to convert the images into numbers so that they could be used by the neural network.

  3. During model inference you continued to inspect the predictions for accuracy. It is especially important in this case because you created some fake data to use when training your model.

Evaluation Metric

  • Accuracy

  • Confusion matrix

    • False positive rate (Type I error) : 틀렸음 → 아닌것을 맞다고 함 (Predict True, Actual False / 거짓 양성)

    • False negative rate (Type II error) : 틀렸음 → 맞는것을 틀리다고 함 (Predict False, Actual True / 거짓 음성)

  • F1 score

    • Precession (정밀도) : 맞다고 한 것 중 실제 맞는 것은 얼마인가 (Actual True / Predict True)

    • Recall (재현율) : 실제 맞는것을 얼마나 맞다고 했는가 (Predict True / Actual True)

  • ROC Curve

  • Log loss

    • Model’s uncertainity

    • Score using Binary Cross Entropy

  • Negative predictive value

  • Sensitivity → Recall (TPR, 민감도)

    • 질병에 양성 진단, 실제도 양성

  • Specificity → True negative rate (TNR, 특이도)

    • 질병에 음성 진단, 실제도 음성
