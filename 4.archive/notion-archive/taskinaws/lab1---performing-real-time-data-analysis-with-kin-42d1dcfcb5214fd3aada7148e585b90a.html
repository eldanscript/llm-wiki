Real-time analysis : Averaging rating values

Create SQL Code

  • Output Stream 생성

    • CREATE OR REPLACE STREAM “CAPTAIN_SCORES”

  • Output Stream Column 지정

    • (“favoritecaptain” varchar(32), “average_rating” DOUBLE, “total_rating” INTEGER)

  • Output Stream을 생성하기 위한 Pump Stream

    • CREATE OR REPLACE PUMP “STREAM_PUMP” as INSERT INTO “CAPTAIN_SCORES”

  • Input Stream을 Pump Stream으로 변형

    • SELECT STREAM “favoritecaptain”, avg(“rating”), sum(“rating”) FROM SOURCE_SQL_STREAM_001

    • favoritecaptain → favoritecaptain

    • avg(‘rating’) → average_rating

    • sum(‘rating’) → total_rating

  • Input Stream의 Data Record 처리 단위 지정

    • GROUP BY “favoritecaptain”, STEP (“SOURCE_SQL_STREAM_001”.ROWTIME BY INTERVAL ‘1’ MINUTE)

    • 1분 동안 수집된 record를 favoritecaptain 값으로 group (1분 간격의 window 설정)

      • ROWTIME 사용

      • ROWTIME BY INTERVAL ‘1’ MINUTE : group the records based on ROWTIME in a one-minute window

    • ORDER BY STEP(“SOURCE_SQL_STREAM_001”.ROWTIME BY INTERVAL ‘1’ MINUTE), avg(“rating”) desc → 1분 간격의 평균값을 내림차순으로 정렬

Real-time Analysis - Anomaly detection of rating

Create SQL Code

  • Output Stream 생성

    • CREATE OR REPLACE STREAM “RAW_ANOMALIES”

  • Output Stream Column 지정

    • (“favoritecaptain” varchar(32), “rating” INTEGER, “ANOMALY_SCORE” DOUBLE)

  • Anomaly 함수로 Anomaly Pump Stream을 생성

    • SOURCE_SQL_STREAM_001 → RAW_ANOMALTIES, RAW_PUMP

    • CREATE OR REPLACE PUMP “RAW_PUMP” as INSERT INTO “RAW_ANOMALIES”

  • RANDOM_CUT_FOREST

    • SELECT “favoritecaptain”, “rating”, “ANOMALY_SCORE” FROM TABLE(RANDOM_CUT_FOREST(CURSOR(SELECT STREAM “favoritecaptain”, “rating” FROM “SOURCE_SQL_STREAM_001”)))

    • inputStream

      • CURSOR 함수 사용 (CURSOR(SELECT STREAM * FROM InputStream))

      • InputStream의 데이터에 pointer 설정

  • Anomaly Pump Stream을 정렬하는 Stream 생성

    • CREATE OR REPLACE STREAM “ORDERED_ANOMALIES” (“favoritecaptain” varchar(32), “rating” INTEGER, “ANOMALY_SCORE” DOUBLE);

  • RCF로 생성된 RAW_ANOMALTIES stream을 입력으로 사용

    • CREATE OR REPLACE PUMP “ORDERED_PUMP” as INSERT INTO “ORDERED_ANOMALIES” SELECT STREAM * FROM RAW_ANOMALIES

  • Anomaly Score 값을 Stream 정렬 기준 설정

    • ORDER BY FLOOR(“RAW_ANOMALIES”.ROWTIME TO SECOND), “ANOMALY_SCORE” desc

    • 1초 마다 ANOMALY_SCORE를 기준으로 내림차순 정리
