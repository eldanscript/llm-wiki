Demo1 - Data Preparation

Use Case

  • Which percentage of users are male vs female?

  • What are the ages of most of the users?

  • Of the users, how many are in their 20s, 30s, 40s, etc?

  • Convert data from JSON to CSV and store it in S3

  • Transform ‘gender’ feature to binary value (e.g. male to 1, female to 0)

User Data

  • Key/Value → Stored in S3 as CSV format

  • First Name : first

  • Last Name : last

  • Age : age

  • Gender (male : 1, female : 0) : gender

  • Latitude : latitude

  • Longitude : longitude

Method

  • Amazon Athena to query the data collected to answer business question

  • Setup an AWS Glue job to run Apache Spark code to transform data and convert to CSV format

AWS Glue & Athena

Process

  1. Upload user data to S3 as raw data

  2. Run AWS Crawler

  3. Create Data Catalog

  4. Create Database Table

  5. Create Ahtena query

AWS Crawler

What is

  • 완전 관리형 ETL(데이터 추출, 변환, 적재) 서버리스 서비스

  • 사용이 간단하며 비용 효율적으로 데이터를 분류(categorize), 정제(clean) 및 보강(enrich)하고 다양한 데이터 소스와 데이터 스트림 간의 안정적인 데이터 이동을 수행

  • 반정형 데이터를 처리하도록 설계

    • Dynamic Frame을 사용하여 스키마 없이 데이터를 행과 열로 조직(organize)하고 추상화

    • Apache Spark dataframe과 유사

구성

  • AWS Glue Data Catalog : 중앙 메타데이터 저장소 (central metadata repository)

  • ETL engine : 자동으로 Python 또는 Scala 코드 생성

  • Job System : 종속성 확인(dependency resolution), 작업 모니터링 및 재시도를 관리

Use Case

  • 데이터 웨어하우스나 데이터 레이크의 스토리지 데이터를 조직(organize), 정제(clean), 인증(validate) 및 형식(format) 구성

  • S3 데이터 레이크에 대해 서버리스 쿼리 실행

  • ETL 파이프라인 생성

  • 데이터 자산 이해

Transform Data - Glue ETL Job

  • Job : AWS Glue 작업을 추출, 변환 및 로드(ETL)하는 데 필요한 비즈니스 로직

  • 스크립트 실행 : 소스에서 데이터 추출 → 데이터 변환 → 대상으로 로드

Create Job

  1. Select Add job

  1. Select Type

    1. Spark → PySpark 사용

    2. Python Shell

      1. Python script를 shell에서 실행 : v2.7, v3.6 호환 script

      2. Support library : Boto3, collections, CSV, gzip, multiprocessing, NumPy, Pandas, Pickle, PyGreSQL, SciPy, Sklearn

      3. Apache Spark 작업에 사용할 수 있는 대부분의 기능은 Python 셸 작업에서도 사용 가능 : 작업 북마크 사용 안됨 (작업 북마크는 상태 정보를 유지하고 이전 데이터의 재처리를 방지하는 기능)

  • Advanced Option

  1. IAM Role

    1. Check S3 bucket access permission : include job related bucket

    2. 앞단계에서 설정한 role을 수정하여 사용

  1. Data Source

  1. Transform type

  1. Target

    1. Data Catalog에서 생성한 table을 사용할 경우

    b. 새로운 table을 생성 하도록 진행 → Target format : CSV

  1. Create Transform Code

    1. Schema 확인 후 다음 단계를 진행하면 기본 python script을 제공

    2. Gender 값을 변환하는 script 추가

  2. Save and Run Job

  3. S3 bucket에 output target 생성 확인

  • CSV format과 gender 값이 0, 1로 변경
