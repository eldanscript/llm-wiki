Ch2. Data Collection

Data Terminology

DataSet

  • A Collection of Data : 데이터 모음

  • Dataset = Input data = training/testing data

  • Column = Attribute = Feature (Describe data)

  • Row = Observation = Sample = Data Point

Structured Data (정형 데이터)

  • Has a defined schema : 스키마 정의를 가지고 있는 데이터

  • Schema is the information neede to interpret the data, including attribute names and their assigned data types : 스키마는 데이터를 해석하기 위한 정보이다. 속성과 형식을 가지고 있다.

  • ERD (Entity Relationship Diagram) , Traditional database

  • Database

Unstructured Data (비정형 데이터)

  • Has no defined schema or structural properties : 정의된 스키마가 없거나 구조화된 속성이 없는 데이터

  • Makes up majority of data collected : 수집되는 데이터들의 대부분을 차지한다

  • Audio Files, Log Files, Social Media Stream

Semi-structured Data (반정형 데이터)

  • Unstructured for relational data, but has some organizational structure : 관계형 데이터 수준으로 구조화 되어 있지는 않지만 어느 정도는 조직적인 구조를 가지고 있는 데이터

  • CSV(Comma-separated values), JSON(JavaScript Object Notation), XML(eXtensible Markup Language)

Databases

  • Relational data stored well : 관계형 데이터가 잘 저장될 수 있다

  • Defined as a single repository for applications or other services that are transactional : 데이터베이스는 트랜잭션 작업을 수행하는 서비스나 애플리케이션을 위한 단일 저장소(레퍼지토리)이다.

  • traditional relational databases are made up of two tables with rows and columns : 전통적인 데이터베이스는 로우와 컬럼으로 구성된다.

  • Transaction

    • 데이터베이스의 연산을 모아 놓은 논리적인 작업의 단위로 Commit이나 Rollback을 수행한다

    • 데이터베이스의 상태를 변경하는 작업 또는 한번에 수행되어야 하는 연산들을 의미

    • ACID 속성을 가지고 있음

      • Atomicity (원자성) : 트랙잭션 내의 작업들은 하나의 단위로 처리. 성공하거나 실패

      • Consistency (일관성) : 트랜잭션은 일관성 있는 데이터의 상태를 유지

      • Isolation (격리성) : 동시에 실행되는 트랙잭션들이 서로 영향을 주지 않도록 격리

      • Durability (영속성) : 트랙잭션이 성공되면 결과가 항상 저장

Data Warehouse

  • Collect data from many different sources in many different formats : 많은 다양한 소스에서 많은 다양한 형식의 데이터를 수집

  • Congregate them all together : 모두 모아 두는 곳

  • Used to store petabytes or exabytes of data

  • Give the ability to analyze more easily

  • Before the data lands into the data warehouse, usually some type of processing or cleaning of that data : 데이터를 데이터 웨어하우스에 저장하기 전에 데이터 정제나 데이터 처리를 수행 하였음.

  • Able to run analytics use BI tools and find out important information about our data : Business Intelligent 툴을 사용하여 분석하거나 데이터에 대한 중요한 정보를 찾아내기 위해서 였음.

Data Lakes

  • Store massive amounts of unstructured data that are dumped into a single repository or a data lake : 단일 저장소에 대규모의 비정형 데이터를 덤프하기 위해 사용

  • No processing done before we dump the data into a data lake : 데이터를 덤프하기 전에 별도의 처리 작업이 없음

  • Used to store many different sources and many different formats : 많은 다양한 소스에서 많은 다양한 형식의 데이터를 저장하기 위해 사용

  • Usually the data is in raw format, and it’s really not ready to use : 대부분 데이터는 가공되지 않은 형식이며 사용할 수 있는 상태가 아님

  • Must process on export : 데이터를 내보내면서 처리를 해야 함

  • Store historical data, data we’re not really sure what to do with yet but we know that it’s important : 히스토릭 데이터나 무엇을 해야 할지는 모르지만 중요한 데이터를 저장하기 위해 사용

Machine Learning Terminology

Labeled Data

  • Know what the target attribute is : 타겟 속성이 무엇인지 아는 데이터

  • Has the correctly predicted value assigned to it : 올바르게 예측된 값이 할당됨

Unlabeled Data

  • Collected with no target attribute : 타겟 속성 없이 수집된 데이터

  • Customer information, News article, Surveilance Videos, Apache Logs, Tweets, Blog posts, Web traffic access, Stock market prices

Categorical

  • Values are associated with a group : 그룹화 할 수 있는 값 들

  • Qualitive : 질적인 속성

  • Discrete, Finite : 이산성을 가지며 유한

  • Qualtive data : l for categorical

  • Attribute falls into a group or category

Continuous

  • Values are expressed as measurable number : 측정 가능한 수치로 표현

  • Quantitative : 양적인 속성

  • Infinitive : 무한

  • Quantitative data : n for continuous

  • Place the attribute value on a number line

Text Data (Corpus Data)

  • Datasets collected from text

  • Used in NLP, speech recognition, text to speech

GroundTruth

  • Factual data that has been observed or measured

  • Successfully labeled and trusted as ‘truth’ data

Image Data

  • Datasets with tagged images

  • https://image-net.org/

Time Series Data

  • Datasets that capture chages over time

AWS Data Stores

Amazon S3

  • Unlimited data storage that provides object based storage for any type of data

Aamzon RDS

  • Amazon Relational Database Services

Amazon DynamoDB

  • NoSQL datastore for non-relational databases that is used to store key value pairs

Amazon RedShift

  • Fully managed, clustered petabyte data warehousing solution that congregates data from other data sources like S3, Dynamo DB, and more

  • Redshift spectrum : allows to query Redshift cluster that has sources of S3 data

Amazon TimeStream

  • Fully-managed time series database service

Amazon DocumentDB

  • Place to migrate Mongo DB data

  • Provides better performance and scalability than your traditional Mongo DB instances that are running on something like EC2 or on premises

AWS Migration Tools

Amazon Data Pipeline

  • Allow to process and move data between different AWS compute and storage services

  • Allow to transfer data from on-premise data sources onto AWS

  • DynamoDB, RedShift, RDS → Pipeline → S3

  • Offers several built-in activity objects

    • SqlActivity : specify SQL queries

    • RedshiftCopyActivity

    • EmrActivity

    • HadoopActivity

    • HiveActivity

AWS DMS (Data Migration Service)

  • Allow to migrate data between two different database platforms

  • Used for transferring data between two different relational databases

  • Able to output the result onto S3

  • Support homogeneous and heterogeneous migration

    • Homogeneous : MySQL to MySQL

    • Heterogeneous : SQL Server to S3, SQL Server to MySQL

  • On-prem Database, Database on EC2, Database on RDS → DMS → S3

Data Pipeline vs DMS

  • DMS handles all the heavy lifting when it comes to resources that are required to transfer the data : 데이터 변경 없이 대규모 전송을 위해

  • Data Piepline allow to set up resources as needed and handles the transferring of data in more of a custom way : 데이터를 처리하여 전송 가능

AWS Glue

  • Fully managed ETL service : Extract, Transform, Load

    • Load data from one data source to another

    • Change the output format for Machine Learning model : argo, csv, ion, grokLog, json, orc, parquet, xml

  • Creates tables within a data catalog that are, kind of, like a skeleton for dataset : 데이터셋의 뼈대 같은 데이터 카탈로그 내에 테이블을 생성

    • metadata of dataset

    • data types of dataset

    • attribute types of dataset

  • Set up a crawler that essentially goes out, looks at the data and it determines the schema associated with that data : 데이터 크롤러를 설정하여 데이터를 살피보고 관련된 스키마를 결정한다

    • Within these crawlers, there are several different classifiers that work at a hierarchy level and go down the line to try to infer what type of data it is or what type of schema it is : 데이터 크롤러에는 계층 레벨에서 동작하는 여러개의 다른 분류기가 있고 어떤 종류의 데이터인지, 어떤 스키마를 가지고 있는지 추론한다

    • If some unstructured data or possibly schema-less data, the built in classifiers help build a skeleton of some type of schema associated with data : 비정형 데이터 이거나 스키마가 없는 데이터여도, 분류기는 데이터와 관련된 스키마들로 뼈대를 만들 수 있게 도움

    • Similar to a regular expression that can, kind of, go along and try to find some type of schema or some type of structure in data : 분류기는 정규식과 유사

  • S3, DynamoDB, RDS, RedShift, Database on EC2 → Glue → Athena, EMR, S3, RedShift

    • Take data from input data source

    • Set up a crawler

    • Clasffiers try to define the schema if possible

    • Output the data into other AWS services

AWS Helper Tools

  • Help to get data into AWS and also to store data within AWS.

Amazon EMR (Elastic Map Reduce)

  • Fully managed Hadoop cluster eco-system that runs on multiple EC2 instances : 완전 관리형 하둡 클러스터 에코 시스템

    • Eco-system : PIG, Presto, MXNet, Hadoop. HIve, Spark, OOZiE, TensorFlow, Sqoop, Flume, Jupyter, Apache Zookeeper, MAHOUT, Apache HBASE

    • Assemble all or some of these open source to do different things

  • Allows to pick and choose different frameworks that want to include within the cluster : 클러스터에 포함하고자 하는 다른 종류의 프레임워크를 선택

    • Apache Spark

      • ETL and ML Lbrary

    • Presto

      • SQL Query Engine

    • Mahout

      • ML Framework

    • Hive

      • ETL Service

    • Jupyter Notebooks

      • Code Sharing

    • TensorFlow

      • ML Framework

    • Hadoop Distributed File System

      • Persistant Datastore

    • MXNet

      • ML Framework

  • Allows to run distributed workloads over many EC2 instances for petabytes and petabytes worth of data : EC2 인스턴스에 페타바이크 규모의 데이터를 위한 분산 워크로드 구동

Amazon Athena

  • Serverless platform that allows you to run SQL queries on S3 data : S3 데이터에 대해 SQL 쿼리를 수행하는 서버리스 플랫폼

Athena vs Redshift Spectrum

  • Redshift Spectrum

    • Must have Redshift Cluster

    • Made for existing Redshift customer

  • Athena

    • No need for Redshift Cluster

    • New customer quickly want to query S3 data
