KNet - Generative AI

What is Gen AI?

  • Gen AI : 대화, 스토리, 이미지, 동영상, 음악 등 새로운 콘텐츠와 아이디어를 만들 수 있는 AI (인공 지능)의 일종

  • Foundation Model : 방대한 양의 데이터를 기반으로 사전 훈련된 초대형 모델

    • Transformer-based Neural Network Architecture를 기반으로 수십억 개의 파라미터 또는 변수를 포함하는 모델 등장

    • 크기와 범용성의 특성 때문에 텍스트에 내포된 감정 분석, 이미지 분류, 추세 예측과 같은 특정 작업을 일반적으로 수행하는 기존 기계 학습 모델과 차별

    • 복잡한 개념을 학습할 수 있는 파라미터가 매우 많기 때문에 여러 작업을 수행할 수 있으며 다양한 형태와 무수히 많은 패턴의 대규모 인터넷 데이터에 사전 훈련으로 노출됨

    • 다양한 맥락에서 지식을 적용하는 방법을 학습

What is Bedrock?

💡

Managed Service to build and scale generative AI applications with FMs

  • API를 통해 AI21 Labs, Anthropic, Stability AI, Amazon FM (Titan)에 엑세스할 수 있도록 하는 서비스

    • Makes FMs from leading AI startups and Amazon available via an API

  • 고객이 FM을 통해 생성형 AI 기반 애플리케이션을 구축 및 확장하여 모든 빌더의 액세스를 공용화 할 수 있는 쉬운 방법을 제공

    • Find the right model : Choose from a wide range of FMs to find the model that’s best suited for customer use case

    • Privately customize FMs : Get started quickly, privately customize FMs with customer own data

    • Integrate to application : Easily integrate and deploy into customer applications without having to manage any infrastructure

  • Amazon Titan FM을 포함하여 여러 강력한 텍스트 및 이미지용 FM에 액세스할 수 있는 기능을 제공

  • Available FMs

    • Multilingual LLMs : Jurassic-2 family (AI21 Labs)

    • Philanthropics LLM : Claude Anthropic’s LLM (정직하고 책임감 있는 AI 시스템을 훈련하기 위한 Anthropic의 연구를 기반)

    • Text to Image FM : Stabile Diffusion (고유하고 사실적인 고품질 이미지, 아트, 로그 및 디자인을 생성하는 Stable AI)

  • Fine-tune

    • 대용량 데이터에 주석을 달지 않고도 특정 작업에 맞게 모델을 미세 조정

    • 20 examples is enough

Titan FM

  • First Model - Generative LLM

    • 요약, 텍스트 생성, 분류, 개방형 (open-ended) Q&A, 정보 추출 (요약, 블로그 게시물 작성 등)

  • Second Model - Embeddings LLM

    • 텍스트 입력, 단어, 구 또는 대규모 텍스트 단위를 텍스트의 의미론적 뜻이 포함된 숫자 표현인 임베딩으로 변환

    • 텍스트를 생성하지는 않지만 임베딩을 비교하여 단어 일치보다 관련성이 높고 상황에 맞는 응답을 생성

    • 개인화 및 검색과 같은 응용 분야에 유용

  • 책임감 있는 AI

    • 데이터 내 유해한 콘텐츠를감지하여 제거하고, 사용자 입력에서 부적절한 콘텐츠를 거부

    • 혐오성 발언, 욕설, 폭력 등 부적절한 콘텐츠가 포함된 모델 출력을 필터링 하도록 구축

CodeWhisper

  • Productivity Boost

    • 문자열을 구문 분석하고 지정된 대로 목록을 반환하는 전체 함수를 생성

  • 편향되거나 불공정 하다고 간주될 수 있는 코드 제안을 필터링

  • 고객이 참조하거나 사용 허가를 원하는 오픈 소스 코드와 유사한 코드 제안을 필터링하고 플래그 지정

  • 개인 사용자에게 무료로 제공하며 AWS 계정을 필요로 하지 않음

  • 비지니스 사용자의 경우 IAM과 통합을 통한 SSO와 같은 관리 기능과 더 강력한 보안 스캔 제한 기능 등의 전문가 tier를 제공

Energy

  • Generative AI application that could scan for potential safety risks, such as faulty values resulting in gas leaks, The application could generate recommendations for Personal Protective Equipment and tools/equipment for remedial work. This would help to eliminate an initial trip to the field to identify issues, minimize operational downtime, and also reduce health and safety exposure

  • Generative AI can be used to create synthetic data, which is a class of data that is generated rather than obtained from direct observations of the real world. This ensures the privacy of the original sources of the data that was used to train the model. In the energy industry, synthetic image data creation can be used for creating images of equipment (e.g. compressors, turbines) with rust or cracks. These images can be used for training vision-based ML models for predictive maintenance, which can play a key role in reducing costs and minimizing operational downtime

  • Generative AI models can be used for reservoir modeling by generating synthetic reservoir models that can be used to simulate reservoir behavior. GANs are a popular generative AI technique that can be used to generate synthetic reservoir models. The generator network of the GAN is trained to produce synthetic reservoir models that are similar to real-world reservoirs, while the discriminator network is trained to distinguish between real and synthetic reservoir models. Once the generative model is trained, it can be used to generate a large number of synthetic reservoir models that can be used for reservoir simulation and optimization, reducing uncertainty and improving hydrocarbon production forecasting. These reservoir models can also be used for other energy applications where subsurface understanding is critical, such as geothermal and carbon and storage (CCS), and wind farm development
