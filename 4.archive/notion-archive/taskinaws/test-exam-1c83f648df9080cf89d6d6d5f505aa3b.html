Q1

Key Q) similar scale for optimal performance - outliers

A) Robust Scaler - Robust for outliers

Robust Scaler는 각 특성에 대해 중앙값을 빼고 지정된 사분위수 범위에 따라 데이터를 조정합니다.

이 스케일러는 **이상치에 강인**하므로, Property_Price에 존재하는 여러 이상치로 인해 다른 스케일러들이 제대로 작동하지 않는 상황에서 가장 적합합니다.

오답:

  1. Standard Scaler (정규 분포 사용)
    각 특성에 대해 **평균을 빼고 표준편차로 나누어 정규화**합니다. 이 방식은 **이상치에 큰 영향**을 받기 때문에 Property_Price의 이상치로 인해 잘못된 조정이 이루어집니다.

  2. Min Max Scaler:
    각 특성에 대해 최솟값과 최댓값 사이로 값을 조정합니다. 이상치가 존재하면 대부분의 데이터가 좁은 범위로 압축되어 전체 분포가 왜곡될 수 있습니다.

  3. Max Absolute Scaler:
    각 특성에 대해 최대 절대값으로 나누어 조정합니다. **이상치가 스케일 계수에 과도한 영**향을 미치므로 Property_Price의 이상치로 인해 적절한 조정이 어렵습니다.

Q2

Key Q) under-fitting (not capturing the underlying relationship)

  • 모델이 제품의 결함 유무를 정확하게 식별하지 못하고 있다는 것을 의미합니다.

  • 이는 모델이 **트레이닝 데이터셋에 내재된 입력 데이터와 타깃 값 간의 관계를 제대로 학습하지 못했다는 것**을 나타냅니다.

  • 즉, 모델이 **언더피팅** 문제를 겪고 있다는 것을 의미합니다. 모델이 **트레이닝 데이터셋의 특징을 충분히 학습하지 못했기 때문에** 평가 데이터에 대해서도 정확한 예측을 하지 못하고 있습니다.

A)

정답:
A. 트레이닝 데이터셋에서 **도메인 특화 특징을 늘리는 것** (Increase the amount of **domain-specific features** in the training dataset)

  • 모델이 트레이닝 데이터셋의 근본적인 관계를 정확하게 포착하지 못하는 것은 언더피팅 문제입니다.

  • 이를 해결하기 위해서는 모델이 데이터의 관계를 더 잘 포착할 수 있도록 트레이닝 데이터셋의 도메인 특화 특징을 늘려주는 것이 효과적입니다.

오답:
B. L2 regularization 강화

  • L2 규제는 **모델 계수(weight)의 극단적인 가중치를 줄이는데 사용**됩니다.

  • 하지만 이 경우는 언더피팅 문제이므로, L2 규제 강화는 도움이 되지 않습니다.

C. L1 regularization 강화

  • L1 규제는 모델 **계수 가중치를 0**으로 줄여 **노이즈를 제거**하는데 사용됩니다.

  • 그러나 이 경우는 언더피팅 문제이므로, L1 규제 강화 역시 도움이 되지 않습니다.

D. 트레이닝 데이터 통과 횟수 감소 (decrease the number of passes on the training data)

  • **트레이닝 데이터가 부족해서 언더피팅이 발생**한다면, 트레이닝 데이터 통과 횟수를 늘리는 것이 도움이 됩니다.

  • 따라서 이 경우 트레이닝 데이터 통과 횟수를 줄이는 것은 올바른 방법이 아닙니다.

      • L2 regularization reduces the weights of the model coefficients

      • L1 regularization is used to reduce the noise in the models, reducing some model coefficient weights to 0

    • Ensembling

A)

정답:
D. 정밀도(Precision)
이메일이 스팸이 아님에도 불구하고 스팸으로 잘못 분류되는 것**(거짓 양성)을 최소화**하려면 정밀도 지표를 사용하는 것이 가장 적합합니다. **정밀도는 모델이 예측한 양성 결과 중 실제 양성인 비율**을 나타냅니다.

오답:
A. 재현율(Recall)
재현율은 **실제 양성 중 모델이 정확하게 예측한 비율**을 나타냅니다. 이메일이 스팸으로 잘못 분류되는 것을 방지하는 데에는 적합하지 않습니다.

→ 실제 참인 값을 정확히 찾아내는 정도 (암 환자 예측)

B. 정확도(Accuracy)
정확도는 전체 예측 중 정확한 예측의 비율을 나타냅니다. 이메일이 스팸으로 잘못 분류되는 것을 방지하는 데에는 적합하지 않습니다.

C. F1 점수
F1 점수는 정밀도와 재현율의 조화 평균입니다. 이메일이 스팸으로 잘못 분류되는 것을 방지하는 데에는 적합하지 않습니다.

Key Q) Scaling - Cool Down (intermittent spike)

A)

  • 도서 추천 시스템이 Amazon SageMaker 엔드포인트에 배포되었습니다.

  • 엔드포인트에는 호출 수 메트릭을 기반으로 자동 확장하는 대상 추적 스케일링 정책이 적용되어 있습니다.

  • 시스템 배포 후 간헐적인 트래픽 급증이 발생하여 과도한 확장이 일어났습니다.

  • ML 엔지니어는 트래픽 급증을 처리할 수 있는 솔루션을 구현해야 합니다.

이 중 운영 오버헤드가 가장 적은 솔루션은 다음과 같습니다:

정답: C. 대상 추적 스케일링 정책에 쿨다운 기간을 지정합니다.

쿨다운 기간을 설정하면 **용량 증가 또는 감소 이후 다음 스케일링 활동이 발생할 때까지 일정 시간 동안 기다리게 됩니다**. 따라서 **간헐적인 트래픽 급증에 효과적으로 대응**할 수 있습니다.

A. 스케일링 인스턴스의 지표 값을 늘리는 것은 문제를 해결할 수 없습니다. 대상 추적 스케일링 정책은 지정된 목표값에 맞춰 자동으로 인스턴스를 추가/제거하기 때문에, 지표 값을 올리더라도 트래픽 급증 시 과도한 확장이 지속될 수 있습니다.

B. 스케일링 인스턴스의 지표 값을 줄이는 것도 문제를 해결할 수 없습니다. 대상 추적 스케일링 정책은 지정된 목표값에 맞춰 자동으로 인스턴스를 추가/제거하기 때문에, 지표 값을 낮춰도 트래픽 급증 시 과도한 확장이 지속될 수 있습니다.

D. 단계별 스케일링 정책(**step scaling policy**)으로 변경하는 것은 적절하지 않습니다. 단계별 정책은 CPU 사용률 등의 지표를 기반으로 확장/축소 규칙을 정의하며, **트래픽 급증과 같은 상황에 효과적이지 않습니다**.

Key Q) ROC - 임계값 기반 평가

A)

정답:
C. 수신자 동작 특성(ROC) 곡선
ROC 곡선은 모델의 성능을 모든 분류 임계값에서 비교할 수 있는 그래프입니다. 따라서 엔지니어가 원하는 임계값 기반 성능 평가 요구사항을 만족합니다.

오답:
A. 루트 평균 제곱 오차(RMSE)
RMSE는 회귀 모델의 예측 오류와 이상치를 측정하는 데 사용되는 지표입니다. 임계값 기반 성능 평가에는 적합하지 않습니다.

B. F1 점수
F1 점수는 모델의 성능을 평가하는 지표입니다. 하지만 이 지표는 임계값이 아닌 모델 성능 자체를 나타내므로 요구사항을 충족하지 않습니다.

D. 정확도
정확도는 모델의 예측 정확성을 측정하는 지표입니다. 그러나 이 지표는 임계값이 아닌 모델의 정확도를 나타내므로 요구사항을 충족하지 않습니다.

Key Q) Data Wrangler Split Data - Data Leakage가 발생하지 않도록 설정

A)

정답:
B. 정렬된 분할(Ordered split)이 정답입니다. **데이터가 날짜순으로 정렬**되어 있는 경우, **정렬된 분할을 사용**하면 훈련 데이터에 나중에 발생한 데이터가 포함되어 데이터 누출(data leakage)이 발생하는 것을 방지할 수 있습니다. 이를 통해 예측 편향을 줄이고 향후 새로운 데이터에 대해서도 모델의 일반화 성능을 높일 수 있습니다.

오답:
A. 무작위 분할(Randomized split)은 데이터 순서가 섞여 데이터 누출이 발생할 수 있어 적절하지 않습니다.
C. 층화 분할(Stratified split)은 **데이터 카테고리의 비율을 유지**하지만, 데이터 순서 문제로 인해 데이터 누출이 발생할 수 있습니다.
D. 키 기반 분할(Split by key)은 동일한 키가 훈련 데이터와 테스트 데이터에 중복되지 않도록 하지만, 데이터 순서 문제로 인해 데이터 누출이 발생할 수 있습니다.

Reference

  • Data Wrangler Split Data : https://docs.aws.amazon.com/sagemaker/latest/dg/data-wrangler-transform.html#data-wrangler-transform-split-data

  • Split Data Type

    • Randomized Split

      • 데이터를 무작위로 분할하여 학습/테스트 데이터셋을 생성합니다.

      • 데이터 순서와 상관없이 분할하므로, 데이터 누출 문제가 발생할 수 있습니다.

      • **데이터 분포가 비교적 안정적일 때 사용**하면 적합합니다.

    • Ordered Split

      • 데이터를 순서대로 분할하여 학습/테스트 데이터셋을 생성합니다.

      • 시간 순서에 따라 데이터를 분할하므로, 데이터 누출 문제를 방지할 수 있습니다.

      • **시계열 데이터나 날짜 순서가 중요한 경우** 적합합니다.

    • Starfield Split

      • 데이터의 **target 변수 분포를 유지하며 분할**합니다.

      • 타겟 변수의 **비율을 보존하여 학습/테스트 데이터셋의 대표성을 높일 수 있습니다**.

      • **타겟 변수의 불균형 문제가 있는 데이터셋**에 적합합니다.

    • Split by Key

      • 특정 키 값을 기준으로 데이터를 분할합니다.

      • 같은 키 값을 가진 데이터가 학습/테스트 데이터셋에 중복되지 않도록 합니다.

      • **고객 ID, 제품 ID 등의 키 값이 있는 데이터셋에 적합**합니다.

  • 데이터 누출(data leakage)

    • 모델 평가 시 실제 배포 환경과 다른 정보가 모델에 포함되어 있는 상황을 말합니다. 예를 들어, 이 문제에서 날짜순으로 정렬된 데이터셋에서 무작위 분할을 하면, 훈련 데이터에 나중에 발생한 데이터가 포함될 수 있습니다. 그러면 테스트 데이터로 모델을 평가할 때, 실제 배포 환경과 다른 미래 데이터에 대한 정보가 포함되어 있기 때문에 모델 성능이 과대 추정될 수 있습니다. 이렇게 데이터 누출이 발생하면 모델의 실제 일반화 성능을 정확하게 평가할 수 없습니다. 그래서 데이터 누출을 방지하기 위해 정렬된 분할을 사용하는 것이 중요합니다.

    • Object2Vec: 고차원 객체의 저차원 임베딩을 학습하는 알고리즘. 특징 엔지니어링에 활용 가능.

    • DeepAR Forecasting: 시계열 데이터 예측을 위한 순환 신경망 기반의 알고리즘.

  2. **비지도** 학습 알고리즘 (Unsupervised Learning Algorithms):

    • Principal Component Analysis (**PCA**): 차원 축소를 위한 알고리즘.

    • **K-Means**: 데이터 클러스터링을 위한 알고리즘.

    • **IP Insights**: IPv4 주소의 사용 패턴을 학습하여 이상치를 탐지하는 알고리즘.

    • **Random Cut Forest (RCF)**: 이상치 탐지를 위한 알고리즘.

  3. 텍스트 분석 알고리즘:

    • BlazingText: Word2Vec, 텍스트 분류를 위한 고성능 알고리즘.

    • Sequence-to-Sequence: 기계 번역, 텍스트 요약 등에 사용되는 알고리즘.

    • Latent Dirichlet Allocation (LDA): 문서의 토픽 모델링을 위한 비지도 학습 알고리즘.

    • Neural Topic Model (NTM): 신경망 기반의 토픽 모델링 알고리즘.

    • Text Classification (TensorFlow): 전이 학습을 지원하는 텍스트 분류 알고리즘.

  4. 이미지 처리 알고리즘:

    • Image Classification (MXNet, TensorFlow): 이미지 분류를 위한 지도 학습 알고리즘.

    • Semantic Segmentation: 픽셀 단위의 이미지 분할 알고리즘.

    • Object Detection (MXNet, TensorFlow): 객체 탐지 및 분류를 위한 지도 학습 알고리즘.

각 알고리즘의 주요 사용 사례는 다음과 같습니다:

  • AutoGluon-Tabular, CatBoost, LightGBM 등: 분류 및 회귀 문제 해결

  • Factorization Machines: 고차원 희소 데이터 모델링

  • K-NN: 데이터 유사성 기반 분류 및 회귀

  • Linear Learner: 선형 모델 활용 분류 및 회귀

  • TabTransformer: 구조화된 데이터 모델링

  • Object2Vec: 고차원 객체의 저차원 임베딩 학습

  • DeepAR Forecasting: 시계열 데이터 예측

  • PCA, K-Means, RCF: 차원 축소, 클러스터링, 이상치 탐지

  • BlazingText, Seq2Seq: 자연어 처리 작업 (분류, 번역, 요약 등)

  • Image Classification, Object Detection: 컴퓨터 비전 작업
