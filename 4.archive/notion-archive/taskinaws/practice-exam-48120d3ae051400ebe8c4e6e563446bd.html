Example Question

Q1) You are working for a hot new startup that calculates different metrics about their customers depending on how much money they spend on a weekly, quarterly, and yearly basis. These metrics are classified as elite, novice, and beginner. Depending on their ranking they get more/less discounts and placed in higher/lower priority for customer support. The algorithm you have chosen expects all numerical inputs. What can be done to handle these classification values so that ordering is taken into account for the required numerical inputs?

  • 조건

    • 주별, 쿼터별, 년간 소비 금액에 대해 각종 지표를 계산 → 지표는 elite, novice, beginner로 분류 → 고객의 랭킹(지표)에 따라 할인과 고객 지원이 결정

    • 알고리즘 입력은 모두 수치값을 사용

    • 순서가 고려 되도록 분류 값을 처리

  • 지문

    1. 분류 값 (elite, novice, beginner)에 임의 수치 값을 적용하고 Gradient descent를 사용하여 값들이 예상치에 수렴 하도록 함 → 임의 수치 값이 아니라 범위 (scale)를 지정하여 매핑이 필요

    2. **각 상태에 대해 다른 값을 매핑하여 실험하고 가장 잘 동작하는 것을 찾음**

    3. one-hot encoding을 사용하여 값을 매핑

    4. one-hot encoding을 사용하여 값을 매핑하고 원 분류 속성은 drop

  • 해석

    • 수치값을 변경할 때 가장 먼저 고려할 점은 Ordinal 인지 Nominal 인지 확인 해야 한다.

    • Ordinal (순서 데이터)는 값의 순서가 중요하고 Nominal (명목 데이터)는 순서가 정해지지 않는다

      • Ordinal 예 : 좋다, 보통이다, 나쁘다와 같이 값이 크고 작음이 의미를 가지게 된다

      • Nominal : 남자/여자, 청팀/홍팀/백팀 처럼 순서를 정할 수 없고 count만 가능

    • **One-hot encoding은 nominal category에 적용 가능**한 기능이다

      • 조건의 지표는 elite, novice, begineer로 등급의 높고 낮음이 있으므로 ordinal 값 이다

    • Ordinal 값은 어떤 범위(scale)에 맵핑 하거나 다른 인코딩 방법들을 모델에 적용해 보고 가장 잘 동작하는 것을 찾는 방법을 사용한다

Q2) A machine learning model is being created using Amazon’s Factorization Machines algorithm to help make click predictions and item recommendations for new customers. Which of the following would be candidates during the training process?

  • 조건

    • Factorization Machine 알고리즘 사용하여 새로운 사용자에 대한 클릭 예측 및 아이템 추천

    • Training 과정에서 추천할 수 있는 것들

  • 지문 및 해석

    1. **Binary classification 모델**을 사용하고 test는 Binary Cross Entroy, Accuracy, F1 score 를 사용하여 스코어링

      1. test dataset is scored using **Binary Cross Entropy (Log Loss), Accuracy (at threshold=0.5) and F1 Score (at thresh**old =0.5)

    2. Multi classification 모델을 사용하고 test는 AUC를 사용하고 스코어링

    3. CSV 형식의 Sparce 데이터를 훈련 데이터로 사용

    4. **Regression 모델**을 생성하고 test는 RMSE로 스코어링

      1. testing dataset is scored using **Root Mean Square Error (RMSE)**

    5. 모델 추론은 application/csv 형식으로 함

      1. For **inference**, factorization machines support the application/json and x-recordio-protobuf formats

    6. Sparce data는 Float32 tensor의 recordIO-protobuf 형식으로 함

      1. supports only the **recordIO-protobuf format** with Float32 tensors

It has been deployed for a few weeks now and the results are not accurate and sometimes the inference data is missing values. What are some techniques you can review to help solve this problem?

  • 해석

    • 이러한 데이터 세트를 생성하는 데 사용되는 추출 방법은 프로덕션 데이터와 동일한 것입니까? → 훈련 과정과 상품화 추론 서비스는 **동일한 데이터 추출 방법을 적용**해야 함. 입력 데이터의 구조 및 특성이 일치 하도록 유지

    • 모델이 예측하는 **대상 변수**가 ML 모델이 예측하려는 **실제 결과**를 나타내거나 **결과에 대한 프록시**가 되어야 함

    • 샘플 데이터가 **실제 데이터와 얼마나 비슷**한지? 테스트 가능한 사실에 의해 지원되는 **유사성에 대한 확신**은 어떻게 되는지?
