BigData 이해하기

BigData 개념

  • Volumes of Data/Information : 2020 64 Zeta byte (10^21) → 2025 181 Zeta byte

  • 80%는 비정형 데이터 (SNS, IoT, Image, Audio, Video, …) → BigData 분석 필요

  • BigData : 대규모 데이터 집합 → 기술, 분석, 통찰력 (Insight) 총칭

통상적인 데이터 수집, 관리, 처리를 하는 SW의 수용 한계를 넘어서는 크기의 데이터

일반적 DB SW로 저장, 관리, 분석할 수 있는 범위를 초과하는 규모의 데이터

대용량 데이터를 활용, 분석하여 가치 있는 정보를 추출, 생성된 지식을 바탕으로 능동적으로 대응하거나 변화하기 위한 기술

기존 방법으로는 데이터 수집, 저장, 검색, 분석 등이 어려운 데이터를 총칭해서 일컫는 용어

3V + 2V = 1V (Value) → 6V

  • Volume : 방대한 양의 데이터

  • Variety : 정형 + 비정형

  • Veloctiy : 실시간 생성, 빠른 속도로 데이터 처리, 분석

  • Veracity (정확성, 진실성) : 주요 의사 결정을 위한 데이터 품질, 신뢰성

  • Visualization : 복잡한 데이터를 시각적으로 표현

  • Value : 비지니스 효익을 실현하기 위해 궁극적 가치 창출

BigData Insight

  • 이해 : 대규모 데이터에서 통계량을 추출해 과거에 발생한 일에 대한 이해와 원인 파악

    • 시계열 회원 가입 추이, 서비스 평균 이용 시간, 신규 상품 관심도, 서비스 해지율

  • 발견 : 알지 못했던 데이터 패턴들을 발견하고 해석하여 무슨 일이 새롭게 발생하는지 파악

    • 고객(매출) 증가/감소 원인?, 회원 가입 중 Bounce 발생 원인?, 부정적 평판 점수 높아진 원인?

  • 예측 : 이해와 발견을 기반으로 예측 모형을 만들고 미래에 발생할 현상을 예측

    • 상품 가입/이탈 고객은?, 부정거래 가망 고객은?, 상품 구매력이 높은 고객은?

BigData 활용

  1. BigData Lake & Warehouse : 3V

  2. BigData Mart : Veracity

  3. Visualization : Insight (이해, 발견, 예측)

  4. Value : Business 가치 창출

유의점

  • BigData는 대규모 데이터에서 pattern과 trend를 발견하고 목적에 맞게 해석하는 행위

  • 일부 데이터의 문제가 발생하여도 사람이 데이터를 해석하는 결과가 크게 달라지지 않는 큰 수의 법칙이 적용
