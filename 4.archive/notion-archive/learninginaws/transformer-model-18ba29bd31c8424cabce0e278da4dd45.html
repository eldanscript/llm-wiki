Sequence Model

🖼️Coursera DeepLearning4 - Sequence Models

Sequence Data

  • 순서에 의미가 있는 데이터 : text, time-series data

  • 데이터 순서를 유지하며 신경망에 주입

  • 이전에 입력한 데이터를 기억

Feed Forward Neural Network (FFNN)

  • 입력 데이터의 흐름이 앞으로만 전달되는 신경망

  • 하나의 샘플을 사용하여 정방향 계산을 수행하고 나면 그 샘플은 버려지고 다음 샘플 처리할 때 재 사용하지 않음

  • FC (Fully Convolutional Neural Network), CNN (Convolutional Neural Network)

Recurrent Neural Network (RNN)

  • Neuran의 출력이 다시 자기 자신으로 전달 → 다음 timestep 에서 재 사용

  • Sample C, B, A가 neuran cell에 순차적으로 입력될 경우 A의 출력 Oa가 다시 입력으로 들어가고 다음 timestep에서 B가 입력될 때 Ob는 Oa를 포함하게 된다.

  • 다음 timestep에서 C가 입려되면 Ob가 포함되고 Oc는 B와 A의 정보를 가지고 있지만 B에 대한 정보가 더 많게 된다.

  • 이 때 자기 자신으로 전달되는 neuran cell을 hidden state라고 부른다.

  • 입력되는 sample은 하나의 sequence라고 지칭

    • sequence의 길이는 timestep의 길이

    • sample은 sequence 길이와 sample 표현의 2차원 배열

  • Layer 구조

    • Input Layer (입력층)

    • Recurrent Layer (순환층)

      • 순환층을 통과 후 출력은 neuron 개수로 결정

      • 마지막 timestep의 hidden state만 출력으로 전달 → sequence 길이를 모두 읽어 정보를 마지막 hidden state에 압축하여 전달

    • Output Layer (출력층)

      • 밀집층을 두어 class를 분류

      • 다중 분류의 경우 출력층에 class 수 만틈 neuron을 두고 softmax 활성화 함수를 사용

      • 이진 분류의 경우 출력층에 하나의 neuron을 두고 Sigmoid 활성화 함수를 사용

  • Model Parameter 수

    • 입력 특성 4개, 순환층 neuron 3개

    • Wx = 4 x 3 = 12 → 입력층과 순환층의 neuron이 모두 연결

    • Wb = 3 x 3 = 9 → 순환층의 모든 은닉 상태가 서로 다른 순환층 neuron에 전달

    • 총 Parameter = wx + b = 12 + 9 + 3 = 24

Background

  • Simple RNN의 경우 Sequence가 길수록 순환되는 은닉 상태의 정보가 점차 희석 (Vanishing Gradient) → 멀리 떨어져 있는 단어의 정보를 인식하는 게 어려워짐

LSTM (Long Short-Term Memory)

  • Forget Gate - 과거 정보를 잊기위한 게이트, 이전 상태의 값을 어느 정도 기억할지 결정 (0 ~ 1)

  • Input Gate - 현재 정보를 기억하기 위한 게이트, 현재 입력을 얼마나 기억할 것인지 결정

  • Output Gate - 최종 결과를 다음 상태의 은닉 상태로 보내기 위한 게이트, 다음 단계로 보낼 정도를 결정

GRU (Gated Recurrent Unit)

  • LSTM의 간소화 버전

  • Reset Gate(r) - 새로운 입력을 이전 메모리와 어떻게 합칠 것 인지 결정

  • Update Gate(z) - 이전 메모리를 어느 정도 기억할지 결정, LSTM의 Forget, Input Gate 역할

Natural Language Model

Embedding

  • 단어나 문장 각각을 vector로 변환해 vector space에 ‘끼워 넣는다 (embed)‘는 의미

  • 단어를 고정된 크기의 실수 vector (dense vector)로 변환 → one-hot encoding vector (sparse vector)보다 자연어 처리에서 더 좋은 성능을 보임

Transfer Learning

  • 특정 task를 학습한 모델을 다른 task 수행에 재사용하는 기법

  • 학습 속도가 빠르고 새로운 task를 더 잘 수행할 수 있음

Upstream Task

  • Pre-training 단계에서 진행하는 학습 task

  • GPT 계열 모델 - 다음 단어 맞추기 → Language Model

  • BERT 계열 모델 - 빈칸 채우기 → Masked Language Model

  • Self-supervised learning - 데이터 내에서 정답을 만들고 이를 바탕으로 모델을 학습

Downstream Task

  • Transfer learning시 적용하고자 하는 target task

    • 문서 분류 - 자연어 (문서, 문장) 입력에 대해 범주에 속하는 확률값 반환 (긍정, 중립, 부정 등)

    • 자연어 추론 - 2개의 문장을 입력 받아 두 문장 사이의 관계에 대한 범주를 확률값으로 반환 (entailment 참, contradiction 거짓, neutral 중립)

    • 개체명 인식 - 자연어 (문서, 문장) 입력에 대해 단어별로 개채명 범주에 속하는 확률값 반환

    • 질의응답 - 자연어 (질문, 지문)을 입력받아 단어가 정답의 시작일 확률값과 끝일 확률값을 반환

    • 문장 생성 - 자연어 (문장)을 입력받아 어휘 전체에 대한 확률값을 반환

  • Fine-tuning

    • Pretrained 된 모델을 downstream task에 맞게 업데이트

    • Downstream Task 데이터 전체를 사용

    • 모델 전체를 업데이트

  • Prompt tuning

    • Downstream Task 데이터 전체를 사용

    • 모델 일부만 업데이트

  • In-context learning

    • 모델 업데이트 하지 않음

    • Downstream Task 데이터 일부를 사용

    • Zero-shot learning - Downstream Task 데이터 사용하지 않고 모델이 바로 Downstream Task 수행

    • One-shot learning - Downstream Task 데이터를 1건만 사용. 모델은 1개 데이터 수행 결과를 참고한 후 Downstream Task 수행

    • Few-shot learning - Downstream Task 데이터를 몇 건만 사용. 모델은 데이터 수행 결과를 참고한 후 Downstream Task 수행

Token

  • 자연어 처리 모델의 입력으로 사용

  • 문장보다 작은 단위로 한 개의 문장은 여러 개의 token으로 구성

Tokenization

  • 문장을 token sequence로 분석하는 과정

Tokenizer

  • Tokenization을 수행하는 프로그램

  • Tokenization 방법

    • Word-based

      • Space로 분리, Vocbaulary가 커질 수 있음

    • Character-based

      • 한글로 표현할 수 있는 글자는 1만 1172개로 언어 모델 구성이 어렵지 않고 미등록 token 문제가 없음

      • 의미 있는 단위 생성이 어려움

      • Token sequence가 길어지면서 문장 학습이 어려워지고 성능이 떨어짐

    • Subword

      • 단어와 문자 단위의 중간 형태

      • Vocabulary 집합이 커지는 것을 막고 미등록 token 문제를 회피, sequence가 길어지는 것을 차단

  • 한국어 Tokenizer

    • 은전한닢 (mecab)

    • 꼬꼬마 (kkma)

Algorithm

  • BPE (Byte Pair Encoding) : GPT-2

    • 데이터에 가장 많이 등장한 문자열을 병합하여 데이터 압축하는 기법

    • 고빈도 bigram 쌍을 병합하는 방식으로 구축

    • aaabdaaabac → ZabdZabac (Z : aa) → ZYdZYac (Y : ab) → XdXac (X : ZY)

      • vocabulary : 4개 (a, b, c, d) → 7개 (X, Y, Z, a, b, c, d)

      • data length : 11 → 5

  • WordPieces : BERT

    • 말뭉치에 자주 등장한 문자열을 token으로 인식

    • 병합할 때 말뭉치의 likelihood (우도, 가능도)를 가장 높이는 쌍을 병합

  • SentencePiece, Unigram : 다국어 모델

Tokenization Process

  • 데이터 로더로 데이터를 batch 단위로 모델에 입력 → 문서와 레이블로 구성된 인스턴스들의 집합인 dataset 구성 : PyTorch

  • Batch의 모양 등을 정비해 모델의 최종 입력으로 생성하는 과정 - collate

  • 입력된 data에 대해 정수로 변환 - indexing

Model Training

  • 모델, 최적화 방법, 학습 과정 등의 정의 되어 있는 Task 구성

  • 모델 학습은 Batch 단위로 수행 → 학습 순환 과정을 step 이라고 함

  • Task는 하나의 step에서 수행할 일들을 정의

Optimization

  • Optimizer

  • Learning Rate Scheduler

Language Model

  • Word sequence에 확률을 부여하는 모델

  • 단어가 동시에 나타날 Join probability를 사용해 단어 시퀀스가 나타날 확률을 부여

Forward Language Model

  • 단어 sequence가 자연스러운 언어 모델 구축에 사용 가능

  • 문장 앞에서 뒤로, 사람이 이해하는 순서대로 계산하는 모델

  • GPT, ELMo (Embeddings from Language Models)

Backward Language Model

  • 방향만 바뀌는 것이며 단어 sequence가 나타날 확률을 계산

  • ELMo

Masked Language Model

  • 대상 문장에 빈칸을 만들고 빈칸에 올 적절한 단어가 무엇인지 분류하는 과정으로 학습

  • BERT → bidirectional

Skip-gram Model

  • 임의의 단어 앞뒤에 특정 범위를 정해 두고 범위 내에 올 단어를 분류하는 과정으로 학습

  • Word2Vec

Sequence-to-sequence

  • 특정 속성을 지닌 sequence를 다른 속성의 sequence로 변환하는 작업

  • Encoder와 Decoder로 구성

Encoder

  • Source sequence 정보를 압축해 decoder로 보내는 역할

Decoder

  • Encoder가 보내 준 source sequence 정보를 받아서 target sequence를 생성

Transformer Block

Encoder Block

  • Multi-head attention - Self attention

  • Feedforward Neural Network

  • Residual Connection

  • Layer Normalization

Decoder Block

  • Masked multi-head attention

Attention

  • Sequence 요소 가운데 중요한 요소에 집중하고 그렇지 않은 요소는 무시해 task 수행 성능을 끌어 올림

  • Source sequence 전체 단어들과 target sequence 단어 하나 사이를 연결

  • Target 언어의 단어를 1개 생성 시 Attention은 1회 수행

Convolutional Neural Network (CNN)

  • Sequence의 지역적인 특성을 잡아내는 모델

  • CNN 크기를 넘어서는 context는 읽어내기 어려운 단점이 있음

RNN

  • Sequence 길이가 길어질수록 정보 압축에 문제가 발생

  • 특정 정보를 과도하게 반영해 전체 정보를 왜곡하는 경우가 자주 발생

Self-attention

  • 자기 자신에게 수행하는 attention

  • Context 전체를 고려하여 attention 계산을 수행

  • 모든 경우의 수를 고려 - 모든 단어들을 1 대 1로 계산

  • 입력 sequence 전체 단어들 사이를 연결

  • Target 언어의 단어를 1개 생성 시 Attention은 encoder, decoder block 수 만큼 반복 수행

  • 구성 요소 : Query, Key, Value → 3개 vector에 대한 weighted sum 방식으로 계산
