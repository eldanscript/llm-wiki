Padding

💶Audio Description

_ca061732d8be6f7973cc810c23e5c3df_C4W1L04-Padding.pptx

  • f x f filter → Output : (n-f+1) x (n-f+1)

    • f is usually odd

    • f is even → need some asymmetric padding

  • Pad the image with an additional one border → Pad with zeros

  • If pad size p, output will be (n + 2p - f + 1 ) x (n + 2p - f + 1 )

  • Adjust f to get the same size as the input size

  • Same : 필터의 사이즈가 k이면 사방으로 k/2 만큼의 padding. Input 차원 유지

  • Valid : No padding. output 차원 축소

  • Zero padding helps keep more information at the image borders, and is helpful for building deeper networks

ResNets

⛳Audio Description

_f968ded494544a1de4b634edc2f61336_C4W2L03-ResNets.pptx

  • Very, very deep neural networks are difficult to train because of vanishing and exploding gradient types of problems

    • Learn about skip connections : take the activation from one layer and feed it to another layer even much deeper int the neural network

    • Build ResNet : enable to train very, very deep networks (over 100 layers)

  • ResNets are built out of something called a residual block

  • ReLU non-linearity g applied to z[l+2] as before, but now plus a[l].

  • So, the addition of this a[l] here, it makes this a residual block

  • Short cut : a[l] is being injected after the linear part but before the ReLU part

  • Skip connection : a[l] just skipping over a layer

  • Inventors found that using residual blocks allows to train much deeper neural networks

  • Build a ResNet by taking many of residual blocks and stacking them together to form a deep network → Residual Network

  • Without short cuts or skip connection (**Plain Network**)

    • Increase # of layers → tend to decrease training error → tend to go back up

  • With deeper neural network (**Residual Network**)

    • Better and better on the training set

    • Help with the vanishing and exploding gradient problems

    • maybe at some point, this will plateau, this will flatten out,

Convolutional Implementation of Sliding Windows

🎊Audio Description

_9bddadb2bdbfec97a350b58187921803_C4W3L04-ConvImpSlidingWindows.pptx

  • Sliding window object detection algorithm using a CONV is too slow

    → Implement algorithm convolutionally

  • Turn FC layers into CONV layers

    • 5x5x16 CONV → 400 FC → Softmax

    • 5x5x16 CONV : 16개의 filter에 대한 5x5 convolutional feature 값을 가지고 있는 것

    • 16개 filter 기준으로 배열한다면 output은 1x1x400 이 되는데 이것을 단순히 400개의 node로 보지 않고 1x1x400의 volume으로 본다

    • 이것은 이전 layer에서 16개의 activation function으로 얻은 5x5에 대한 filter 값이다.

  • Make all the predictions at the same time by one forward pass through CONV → convolutional implementation of sliding windows

  • Weakness

    • position of the bounding boxes is not going to be too accurate

Non-max Suppression

👟Audio Description

_e9e369378451599c3a64ba8d31be7352_C4W3L07-NonmaxSuppression.pptx

  • A way to detect each object only once

  • Non-max suppression → cleans up these detection → end up with just one detection per car

  • Discard all the boxes, all the predictions of the bounding boxes with probability less than threshold

  • Repeatedly pick the box with the highest probability

  • 다음으로 남은 상자를 모두 버립니다. 예측으로 출력하지 않았고 이전에 폐기되지 않은 상자입니다.
    따라서 겹치는 부분이 높은 나머지 상자는 모두 버리고 IoU가 높고 이전 단계에서 방금 출력 한 상자가 있습니다.
    while 루프의 두 번째 단계는 이전 슬라이드에서 방금 밝게 만든 경계 상자와 겹치는 나머지 경계 상자를 어둡게 만들 때였습니다.
    따라서 아직 처리하지 않은 나머지 상자가있는 동안 계속이 작업을 수행합니다. 각 상자를 가져 와서 예측으로 출력하거나 겹치는 부분이 너무 많아 버릴 때까지 감지 된 개체 중 하나에 대한 예측 위치로 방금 출력 한 상자 중 하나를 사용하여 IOU를 높입니다.

U-Net Architecture Intuition

🏀Audio Description

  • First Half Normal convolutions (sort of compress the image) : from a very large image to one where the heightened whiff of this activation is much smaller

    • lost a lot of spatial information because the dimension is much smaller

    • but it’s much deeper

  • Second Half Transpose convolution : blow the representation size up back to the size of the original input image

    • Turn this into the unit architecture

    • Earlier block of activation is copied directly to the later block

  • 2 type of information

    • High level spatial and High level contextual information : miss very detailed, fine grained spatial information

    • Skip connection allows to take very high resolution, low level feature information

  • Final layer has both the lower resolution but high level, spatial, high level contextual information as well as low level
