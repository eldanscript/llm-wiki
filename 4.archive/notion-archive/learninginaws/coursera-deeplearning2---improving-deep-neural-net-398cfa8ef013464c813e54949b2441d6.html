Bias / Variance

🎇Audio Description

_6be35b3b106383a2d98bd03a84935da7_C2W1L02.pptx

  • In Deep Learning there’s less about the bias-variance trade-off

    • Solve the bias

    • Solve the variance

  • High dimensional problem → can’t plot the data and visualize bias & variance → different metrics

  • train error 1%, dev error 11% : overfit train set → high variance

  • train error 15%, dev error 16% : underfit the data → high bias

  • train error 0.5%, dev error 1% → low variance, low bias

    • 시작점과 끝점의 거리를 직선 거리로 측정한 것

Regularizing Neural Network

Regularization

🏆Audio Description

_ff76ae8a7ee526eb18cc9b3acd0cbc3f_C2W1L03.pptx

💡

Overfit (high variance problem) → Regularization : 특정 weight 값에 의해 overfit이 발생하는 것을 조정한다 (지엽적인 데이터를 학습하여 새로운 데이터에 대해 잘 못 예측 하는 것)

  • Background

    • High variance → get more training data → Can’t always get or it could be expensive

    • Adding regularization help to prevent overfitting

  • Regularization (정칙화, 정규화, 일반화)

    • Add lambda to logistic regression : regularization parameter

    • Square Euclidean norm of prime to vector w : L2 regularization

  • L1 regularization (norm) = lambda/2m∗sum∣W∣lambda/2m * sum|W|lambda/2m∗sum∣W∣

    • w will end up being sparse : w vector will have a lot of zeros

    • cost function + W (가중치)의 절대값

    • 편미분시 L1 norm은 상수값이 되고 부호에 따라 +,- 가 결정

    • 가중치가 작은 경우 상수 값에 의해 W가 0이 되어 중요한 가중치 만 남음

  • Lasso regression

    • Linear regression에 L1 norm 적용

  • L2 regularization (norm) = W2=WT∗WW^2 = W

    • Help prevent over fitting → another parameter that have to tune

    • In Python, lambda is reserved keyword → use lambd

  • Squared norm = lambda/2m∗sum∣W2∣Flambda/2m * sum|W

  • F (Frobenius norm) : Sum of square of elements of a matrix

  • Back propagation

    • new dw[l] with respect to your parameters, now that you’ve added the extra regularization term at the end → L2 regularization is sometimes also called weight decay

    • 편미분시 가중치도 줄어드는 방식으로 학습을 함

    • 전체적으로 가중치를 작아지게 하여 overfit을 방지

  • Ridge regression

    • Linear regression에 L2 norm 적용

  • Weight decay

    • A regularization technique (such as L2 regularization) that results in gradient descent shrinking the weights on every iteration.

Dropout Regularization

🔮Audio Description

_427563a8bbe5ab22b581c1d84ed72bce_C2W1L04.pptx

  • Powerful regularization techniques → Dropout

    • Go through each of the layers of the network and set some probability of eliminating a node in neural network

    • End up with smaller, much diminished network

  • Inverted dropout

    • Common implementation of dropout

  • With the inverted dropout technique, at test time

    • You apply dropout (randomly eliminating units) and do not keep the 1/keep_prob factor in the calculations used in training

  • Increasing the parameter keep_prob from (say) 0.5 to 0.6 will likely cause the following

    • Reducing the regularization effect

    • Causing the neural network to end up with a lower training set error

Batch Normalization

💡

학습을 더 빠르게 / Local optimum에 빠질 가능성을 줄이기 위해

  • 학습의 불안정 발생 이유

    • internal covariance shift : network의 각 layer나 activation 마다 input의 분산이 달라지는 현상

  • Layer 입력 분산을 평균 0, 표준편차 1인 입력값으로 정규화 : Whitening

    • 입력값의 특징을 uncorrelated 하게 해 줌

    • 각각의 분산을 1로 만들어 줌

  • Whitening만 진행하면 back propagation과 무관하게 진행되어 특정 parameter가 계속 커지는 상태로 whitening이 진행될 가능성 있음

    • 최적화 과정이 진행되면서 특정 변수가 계속 커지는 현상 발생

  • batch normalization

    • Whitening의 문제점을 해결하는 방법으로 고안

    • 정규화 과정을 신경망 안에 포함되어 학습 시 평균과 분산을 조정

    • mini batch를 정규화 → scale 및 shift를 gamma, beta 값을 통해 실행 → 정규화 값을 활성화 함수의 입력으로 사용 → 최종 출력 값 → next layer input

    • Output = g( WX+b ) → g( BN(WX+b) )

  • 학습 할 때마다 활성화 함수 값과 출력값을 정규화 하여 가중치의 초기값 문제에서 자유로워 짐

  • Hidden layer에서 정규화를 하여 입력 분포가 일정하게 되면 learning rate를 크게 설정해도 괜찮아 짐 → 학습 속도가 빠르게 됨

Why does Batch Norm work

🌑Audio Description

_12792c39c974eca78050af35b4cf8717_C2W3L06.pptx

  • covariance shift

💡

covariance (여러 변수들이 공통적으로 함께 공유하고 있는 변량)가 고정된 분포를 가지지 않고 이리저리 움직인다

  • Weakens the coupling between what the early layers parameters has to do and what the later layers parameters have to do

  • Allows each layer of the network to learn by itself, a little bit more independently of other layers → Effect of speeding up of learning in the whole network

  • Slight regularization effect : noise added is quite small

  • Larger mini-batch size reduce noise and regularization effect → Using batch norm as a regularization is not the really the intent of batch norm

  • Extra intended or unintended effect on learning algorithm → Unintended side effect
