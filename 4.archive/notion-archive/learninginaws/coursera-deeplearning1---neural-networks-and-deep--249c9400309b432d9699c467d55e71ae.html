Structured vs Unstructured Data

  • Structured Data

    • Refers to things that has a defined meaning such as price, age

    • Categorized as quantitized data (정량적 데이터로 분류)

    • Exists in predefined format

    • Clearly defined and searchable types of data

    • Stored in data warehouse

  • Unstructured Data

    • Refers to thing like pixel, raw audio, text

    • Categorized as qualitative data (질적 데이터로 분류)

    • Difficult to deconstruct because it has no predefined data model

    • Usually stored in its native format

    • Stored in data lakes

Logistics Regression Cost Function

🧻Audio Description

Logistic_Regression_Cost_Function.pdf

💡

To **train the parameters w and b** of the logistic regression model, need to **define a cost function**

  • y hat

  • Loss (error) function

    • the square error or one half a square error → in logistics regression don’t usually do this

    • The optimization problem becomes non-convex → end up with multiple local optima

  • Loss function in logistics regression

    • Plays a similar role as squared error

    • Convex optimization problem

    • Sigmoid function < 1

    • If y = 1 : y hat should be as big as possible

    • If y = 0 : (1 - y hat) should be large → y hat should be as small as possible

  • Cost function (J)

    • The cost of parameters : measures on entire training set

    • Find parameters w and b that minimize the overall costs function

Activation Functions

📗Audio Description

NN and DL - 3rdWeek - ActivationFunctions.pptx

Sigmoid function

  • Goes within 0 and 1

  • Use sigmoid when use binary classification

  • If z is very small or very large → gradient or derivative is very small

Tangent function or Hyperbolic tangent function

  • tanh(z) : shifted version of the sigmoid function

  • Goes between -1 and 1

  • Center the data : mean 0 → makes learning a little bit easier

  • Strictly superior than sigmoid → 1 exception is for the output layer (y is either 0 or 1)

  • If z is very small or very large → gradient or derivative is very small

ReLU function

  • Rectified Linear Unit

  • z > 0 → derivative 1

  • z < 0 → derivative 0 : disadvantage → leaky ReLU

  • If not sure what to use for hidden layer → use the ReLU activation function

  • Learn much faster than tanh

  • Most commonly

Neural Network Hyperparameters

Most machine learning algorithms involve “hyperparameters” which are variables set before actually optimizing the model’s parameters. Setting the values of hyperparameters can be seen as model selection, i.e. choosing which model to use from the hypothesized set of possible models. Hyperparameters are often set by hand, selected by some search algorithm, or optimized by some “hyper-learner”.
