Recurrent Neural Networks

💡

Recurrent : 순환하는, 반복적인, Recurrent Neural Network (순환형 신경망) : 순차적 데이터 학습에 사용

  • RNN are effective for NLP (Natural Language Processing) and other sequence tasks : Why? → Have '**Memory**'

    • Read inputs x one at a time

    • Remember some contextual information through the hidden layer activations that get passed from one time step to the next

  • Unidirectional (one-way) : take information from the past to process later inputs

  • Bidirectional (two-way) : take context from both the past and the future

Notation

🌡️Audio Description

_ef9081bb8edeb90b65e757f6e30c2596_C5W1L02-Notation.pptx

  • Sequence model to automatically tell where are the peoples names in this sentence

    • Named-entity recognition

    • Used by search engines to index all the people mentioned in the news articles

  • 9 words → 9 sets of features and index into the positions and sequence

    • x<1>, x<2>, x<3>, …, x : index t to positions in the middle of the sequence

    • t implies that these are temporal sequences

    • output y : go back at y<1>, y<2>, y<3>, …, y<9>

  • **Tx** : 9 (the length of the input sequence), **Ty** : 9 (the length of the output sequence)

    • Tx and Ty can be different

  • **Tx(i)** : input sequence length for training example i

  • **Ty(i)** : output sequence length for training example i

  • **X(i)** : i th training example, **X(i)** : t-th element in the sequence of training example

  • Represent individual words in a sentence

    • Dictionary : making a list of the words

    • a, Aaron, and, Harry (4075 th), Potter (6830 th), …, Zulu (10,000 th) → Dictionary size 10K

    • Commercial application : Dictionary size 30 ~ 50K words

    • Large internet companies : Dictionary size 1M words

  • One hot representation : represent each of these words

    • Harry : a vector with all zeros except for a 1 in position 4075

  • x : one-hot vector (one is on and zero everywhere else)

Recurrent Neural Network Model

🛩️Audio Description

_98266faf944cb04b732b4e02bf4833fc_C5W1L03-RNNModel.pptx

  • Input : 9 words, 9 one-hot-vectors

  • A few hidden layers

  • Output : 9 values (0 or 1) tell each word is part of a person’s name

  • 2 main problems

    • Inputs and outputs can be different lengths and examples → pad or zero-pad every inputs up to maximum length but doesn’t seem like a good representation

    • Naive neural network architecture doesn’t share features learned across different positions of texts → better representation let reduce the # of parameters

  • At each time step, the RNN that passes on as activation to the next time step

  • RNN scans through the data from left to right. The parameters for each tiem step are shared → Wax

  • Deactivations will be governed by some set of parameters are shared → Waa

  • The sum governs the output predictions → Wya

  • Limitation : The prediction at a certain time uses inputs or uses information from the inputs earlier in the sequence but not information later in the sequence

  • Forward Propagation

    • a1 = g ( Waa * a<0> + Wax * x<1> + b )

      • activation function will often be a tonnage in the choice of RNN

      • could be different activation functions in each step

    • y^<1> = g ( Wya * a<1> + b )

  • a : 100 dimension, x : 10K dimension → Waa 100 x 100 dimension, Wax 100 x 10K dimension

  • Stacking these two matrices together : 100 dimension → Wa : 100 x 10100 dimension

Word Representation

🚔Audio Description

kaJAwn4WEeiC-BK3XY5K_A_91b553007e1611e8b2d56182efc9cb8e_C5W2L01-WordRepresentation.pptx

  • One of the features of AI revolutionized by deep learning is NLP (Natural Language Processing - 자연어 처리)

  • One of the key ideas is Word Embeddings - A way of representing words (단어를 표현하는 방법)

  • Represent words using a vocabulary of words → represent words using a one-hot vector

    • Treats each word as a thing unto itself

    • Doesn’t allow an algorihm to easily generalize the cross words

  • Instead of a one-hot presentation → Learn a featurized representation

  • Allow to generalized better across different words

    • Apple and orange are more similar

    • Man and woman tend to get grouped together

  • Common algorithm is the t-SNE algorithm

    • A non-linear dimensionality reduction technique

Properties of Word Embeddings

🏑Audio Description

yTkOmH4WEeiB7g5AGkIFQA_c949fe107e1611e898bd9305a8f8f25e_C5W2L03-PropertiesOfWordEmbeds.pptx

  • Reasonable analogies may not be the most important NLP application, but might also help convey a sense of what these word embeddings are doing

  • Man to woman vs King to queen : Is it possible to have an algorithm figure this out automatically?

  • Four dimensional embeddings

    • Man - Woman is similar King - Queen → that’s approximately the same thing

    • Royal, Age, Food differences are equally

    • Main difference is gender

  • Vector difference between man and woman is very similar to the vector difference between king and queen

  • s : high degree of a similarity between

  • Find the word w that maximize the similarity between

  • Ew compared to Eking - Eman + Ewoman

  • Every one-hot vector has the same Euclidean distance from any other one-hot vector → One-hot vectors don’t do a good job of capturing the level of similarity between words.

  • Parallelogram relationships in analogy pairs to hold true

  • A mapping through t-SAE → many of praralleogram analogy relationships will be broken by t-SAE

  • Commonly used similarity function : cosine similarity

  • Similarity = uT * v / inner product between u and v

    • if u and v are very similar → inner product will tend to be large

    • this is called cosine similarity

Word2Vec

ATo2s34XEeiqbAqxMNypOA_014cd4407e1711e8b2d56182efc9cb8e_C5W2L06-Word2Vec.pptx

  • A few context to target errors to create supervised learning problem

  • Randomly pick a word within some window to be the context word

  • Context c → Some target t

  • Take the embedding matrix E → multiply E by vector Oc → embedding vector for the input context word Ec = E * one hot vector → feed to a softmax unit

  • skip-gram model because is taking as input one word like orange and then trying to predict some words skipping a few words from the left or the right side

  • If using a vocabulary of size 100K or 1M, gets slow to sum up over this denominator every single time

  • One of solution is to use a hierarchical softmax classifier

    • Instead of trying to categorize something into all 10K carries on one go

    • Target word in the first 5K words or in the second 5K words in the vocabulary

    • Get down to classify exactly what word it is → leaf of tree → each of the retriever nodes of the tree can be just a binding classifier

    • Hierarchical softmax classifier

Beam Search

🛁Audio Description

_69c763f597722403da7f6d5300cca0a6_C5W3L03-BeamSearch.pptx

  • Want to output the best and the most likely text transcript → Beam search is most widely used

  • Greedy search will pick only the one most likely words and move on

  • Beam Search consider multiple alternatives

    • Parameter called B (beam width)

  • Beam width = 3

    • Evaculating probability over different choices

  • For each of these three choices consider what should be the second word

  • multiply them by this second probabilities to get the probability of the first and second words
