Key Glossary

Univariate vs Multivariate

  • Univariate (일변량) : 각 timestamp에서 측정된 변수가 하나만 있는 경우

    • CDG airport의 여행객 수 예측

  • Multivariate (다변량) : 각 timestamp에서 측정된 변수가 여러개 있는 경우

    • CDG airport의 여행객 수, 환승 시간, 수화물 무게 등 예측

    • 측정되는 여러 변수가 서로 연관되거나, 각각의 변수가 서로 시간 종속성을 가지는 시계열

    • Multivariate는 서로 다른 시계열을 vector 형태의 단일 관찰로 처리

    • Multiple : 서로 다른 시계열을 구분되는 관찰로 처리, Amazon.com의 여러 상품들에 대해 별도 시계열로 각각 예측

시계열 데이터로 재 구성

  • 문제에 맞는 형태로 데이터와 간격을 교정

  • 사전 관찰 (look-ahead)을 피해야 함

    • 가용 데이터를 생산하는 timestamp를 데이터에 사용하지 않도록

    • 아직 알아서는 안 되는 정보를 생산하는 timestamp를 데이터에 사용하지 않도록

  • 아무 일도 일어나지 않았더라도 관련된 모든 기간을 기록

데이터 정리

결측 데이터 (누락된 데이터)

  • 대치법 (imputation) : 데이터 전체 관측에 기반하여 누락 데이터를 채워 넣음

    • Forward fill, 이동 평균, 보간법

  • 보간법 (interpolation) : 대치법의 한 형태, 인접 데이터를 사용하여 누락 데이터를 추정

  • 영향 받은 기간 삭제 : 누락된 데이터 기간을 사용하지 않음

  • Forward fill

    • 누락된 값이 나타나기 직전의 값으로 채우는 방법

    • 계산이 단순하여 실시간 데이터 스트리밍에 쉽게 적용

  • Backward fill

    • 사전 관찰 이므로 미래를 예측하지 않거나 미래보다 과거를 채우는 것이 의미가 있는 경우에만 사용해야 함

  • Moving Average (이동 평균)

    • 과거의 값으로 미래의 값을 예측

    • 최근 과거의 여러 시간대를 입력한 내용을 사용 (Forward fill과 구분 되는 지점)

    • Noise가 많은 데이터는 forward fill 보다 적합

    • Rolling average 혹은 중앙값으로 데이터 대치

      • 데이터 세트의 분산 정도를 감소 시키지만 시계열 모델의 성능을 과대 평가할 수 있게 되므로 주의가 필요

    • 평균 산출

      • 산술 평균

      • 지수가중 이동 평균 (Exponentially weighted moving average) : 최근 데이터에 더 많은 가중치를 부여

      • 기하 평균 (geometric mean) : 일련의 데이터가 강한 상관 관계를 가지고 시간이 지나면서 복합적인 값을 가지는 시계열에 유용

  • Interpolation

    • 전체 데이터를 기하학적 행동에 제한하여 누락된 데이터 값을 결정

    • Linear interpolation (선형 보간법)

      • 시간에 따른 시스템 동작 방식을 이미 알고 있고 그 지식을 활용할 때 특히 유용

    • Spline interpolation
