Code 1

  • CountVectorizer

    • Convert a collection of text documents to a matrix of token counts

    • 단어들의 출현 빈도로 문서들을 vector화 : TDM (Term-Document Matrix)

    • lowercase로 변환하여 처리

  • Result : dem_bow (200, 1092)

    • 200개의 feature를 가진 1092개의 word에 대한 frequency count

  • array print option 조정

    • np.set_printoptions(threshold=784,linewidth=np.inf)

    • threshold=784개가 넘는 원소를 갖는경우 축약형으로 출력해주는 속성이고 linewidth는 한줄에 출력되는 원소 숫자

  • Add 1 and 0 vector using hstack and vstack

    • dem_bow(200, 1000), gop_bow(200, 1000)

    • vstack → (400, 1000) → make sparse

      • <400x1000 sparse matrix of type ‘<class ‘numpy.int64’>’ with 5388 stored elements in Compressed Sparse Row format>

    • ones(200, ), zeros(200, )

    • hstack → (200, ) ? : why (400, )

  • Split dataset as train and test
  • train with Bernouli Naive Bayes : predict 1 or 0
  • Train model을 통해 y 예측 값 확인 및 accuracy 측정 : 0.94

Using Apache Spark

Overall operation

  • 대규모 데이터를 사용하게 된다면 단일 머신에 데이터 저장하여 처리, 학습이 어려움 → 데이터셋 분산 저장 (Amazon S3)

  • Apache Spark를 이용하여 분산되어 저장된 데이터셋을 읽고, 분산 컴퓨팅을 수행 (Amazon EMR)

  • ML 알고리즘에서 데이터를 여러 단계를 거쳐 처리할 때 효율적으로 수행할 수 있도록 데이터셋을 메모리에 cache 하는 방법을 제공

  • Sparkmagic

    • Jupyter notebook에서 Livy(Spark REST service)를 통해 remote Spark cluster와 상호 작용하도록 하는 tool 집합

Distributed Deep Learning

DL AMI

https://docs.aws.amazon.com/ko_kr/dlami/latest/devguide/what-is-dlami.html

DL Instance

  • Accelerated Computing : GPU 기반

    • P family

      • p4 : A100 Tensor Core GPU / 400 Gbps networking

      • p3 : V100 Tensor Core GPU / 100 Gbps networking

      • p2 : K80 GPUs

    • G family

      • g4dn : T4 Tensor Core GPU / 100 Gbps networking

      • g4ad : AMD EPYC processor, AMD Radeon Pro V520 GPUs

      • g3 : Tesla M60 GPUs

  • Distribution 작업을 고려할 때는 GPU수와 Network performance가 중요

Amazon EIA (Elastic Inference Acceleration)

https://aws.amazon.com/ko/blogs/korea/amazon-elastic-inference-gpu-powered-deep-learning-inference-acceleration/

https://aws.amazon.com/blogs/machine-learning/reducing-deep-learning-inference-cost-with-mxnet-and-amazon-elastic-inference/

  • TensorFlow, Apache MXNet, ONNX 지원

  • AWS에 최적화된 빌드를 사용하여 인스턴스에 연결된 엑셀러레이터를 자동으로 검색하고, 인증된 액세스만 허용되는지 확인하고, 모든 로컬 CPU 리소스와 연결된 엑셀러레이터에 걸쳐 계산 부하를 분산

Data Parallelrization vs Model Parallelrization

  • Single Machine with Multi-GPU 혹은 Mutli Machine synchronization

  • Workload distribution → Data or Model parallelrization

Data Parallerization

  • 여러개의 Mini-batch를 병렬로 수행

  • 병렬 실행 결과 가중치 결합

    • 가중치 평균

    • AllReduce : 분산 방식으로 기울기들을 결합

    • 가중치 동기화를 위한 중앙 장소 역할을 하는 Parameter Server Hosting

Model Parallerization

  • Algorithm 작업을 여러 thread 혹은 machine에 분배

  • 빠른 속도의 bus를 공유하는 여러 GPU가 있는 machine에서 잘 동작

Distributed TensorFlow

  • AllReduce를 사용하여 둘 이상의 GPU가 있는 single machine에서 데이터 병렬화 지원

Apache Spark Distributed Learning

  • TensorFlow DL library와 결합

Data Parallerization

  • Mini-batch를 Spark executor 전체에 걸쳐 parallel 하게 실행 : map transformation

  • 가중치는 평균 : reduce computation

  • SparkFlow를 사용하여 간단하게 TensorFlow model 정의 가능하고 Spark driver가 Parameter server 역할 수행

    • Smart wrapper로 작동하는 pipeline abstraction (Estimator, Transformer)로 작업

  • BigDL

    • All-reduce SGD 구현을 사용하여 DL 훈련을 분산

Model Parallerization

  • MLPC (Multilayer Perception Classifier) : Apache Spark를 통해 모델 병렬화 구현

Distributed HyperParameter Tuning

  • HorovodRunner : Horovod를 사용하여 distributed DL training을 구동

Distributed Estimation at scale

  • Spark에 의해 분산된 데이터에 적용하여 병렬로 예측
