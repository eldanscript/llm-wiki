Claude Code 가이드 - OAuth 등록 방법

GCP OAuth 등록 전체 가이드 — Raingent

전제 조건

  • Gmail 계정 2개: eldanscript@gmail.com, rainbell72@gmail.com

  • 필요 scope: gmail.modify (읽기 + 라벨 쓰기 + 삭제)

  • credentials/client_secret.json → OAuth Client ID 파일 저장 위치

STEP 1 — Google Cloud 프로젝트 생성

  1. https://console.cloud.google.com 접속

  2. 상단 프로젝트 선택 → “새 프로젝트”

  • 이름: raingent (자유롭게)

  • 조직: 없음

  1. “만들기” 클릭 후 해당 프로젝트 선택

▎ 기존 프로젝트(project-316ffc27…)가 있다면 STEP 1 생략 가능

STEP 2 — Gmail API 활성화

  1. 좌측 메뉴 → “API 및 서비스” → “라이브러리”

  2. 검색창에 Gmail API 입력

  3. Gmail API 클릭 → “사용” 클릭

STEP 3 — OAuth 동의 화면 선택

1단계 — 브랜딩 설정

좌측 메뉴 → “브랜딩”

┌──────────────────────┬───────────────────────┐

│         필드         │        입력값         │

├──────────────────────┼───────────────────────┤

│ 앱 이름              │ Raingent              │

├──────────────────────┼───────────────────────┤

│ 사용자 지원 이메일   │ eldanscript@gmail.com │

├──────────────────────┼───────────────────────┤

│ 개발자 연락처 이메일 │ eldanscript@gmail.com │

└──────────────────────┴───────────────────────┘

→ “저장”

2단계 — 대상(Audience) 설정

좌측 메뉴 → “대상”

  • User Type: “외부(External)” 선택

  • 게시 상태: “테스트” 유지

  • 테스트 사용자 추가:

  • eldanscript@gmail.com

  • rainbell72@gmail.com

→ “저장”

3단계 — 데이터 액세스(Scope) 설정

좌측 메뉴 → “데이터 액세스”

  1. “범위 추가 또는 삭제” 클릭

  2. 검색창에 gmail 입력

  3. 아래 항목 체크:

  • https://www.googleapis.com/auth/gmail.modify
  1. “업데이트” → “저장”

4단계 — 클라이언트 ID 생성

좌측 메뉴 → “클라이언트”

  1. ”+ 클라이언트 만들기” (또는 “클라이언트 추가”)

  2. 설정:

| 필드              | 입력값           |

|-------------------|------------------|

| 애플리케이션 유형 | 데스크톱 앱      |

| 이름              | raingent-desktop |

  1. “만들기”

  2. 생성된 클라이언트 옆 다운로드 아이콘(⬇) 클릭 → JSON 저장

5단계 — 파일 배치

cp ~/Downloads/client_secret_*.json

/home/rainny/raingent/credentials/client_secret.json

STEP 4 — 범위(Scope) 추가

  1. “범위 추가 또는 삭제” 클릭

  2. 검색창에 gmail 입력 후 아래 항목 체크:

  • https://www.googleapis.com/auth/gmail.modify
  1. “업데이트” → “저장 후 계속”

STEP 5 — 테스트 사용자 추가

▎ 앱을 “테스트” 상태로 유지할 경우, 인증 가능한 계정을 등록해야 합니다.

  1. “테스트 사용자” → “사용자 추가”

  2. 두 계정 모두 입력:

  • eldanscript@gmail.com

  • rainbell72@gmail.com

  1. “저장 후 계속” → “대시보드로 돌아가기”

STEP 6 — OAuth 2.0 클라이언트 ID 생성

  1. 좌측 메뉴 → “API 및 서비스” → “사용자 인증 정보”

  2. 상단 ”+ 사용자 인증 정보 만들기” → “OAuth 클라이언트 ID”

  3. 설정:

| 필드              | 입력값           |

|-------------------|------------------|

| 애플리케이션 유형 | 데스크톱 앱      |

| 이름              | raingent-desktop |

  1. “만들기”

  2. “JSON 다운로드” 클릭 → 파일 저장

STEP 7 — client_secret.json 배치

다운로드한 파일을 프로젝트에 복사:

cp ~/Downloads/client_secret_*.json

/home/rainny/raingent/credentials/client_secret.json

파일 형태 확인 (정상이면 installed 키 포함):

cat /home/rainny/raingent/credentials/client_secret.json

STEP 8 — 계정별 OAuth 인증 (토큰 발급)

기존 만료 토큰 먼저 삭제:

rm -f /home/rainny/raingent/credentials/token.json

rm -f /home/rainny/raingent/credentials/eldanscript/token.json

eldanscript 계정 인증 (브라우저가cd /home/rainny/raingent

cd /home/rainny/raingent

source .venv/bin/activate

python auth_gmail.py eldanscript

실행하면 터미널에 아래와 같이 URL이 출력됩니다:

Please visit this URL to authorize this application:
https://accounts.google.com/o/oauth2/auth?…

그 URL을 Chrome에 붙여넣기 → eldanscript@gmail.com으로 로그인 → 허용
클릭하면 터미널에서 자동으로 완료됩니다.

  • auth_gmail.py

rainbell72 계정 인증:

python auth_gmail.py rainbell72

▎ 브라우저에서 각 계정으로 로그인 → “Raingent이(가) Gmail에 액세스하도록

▎ 허용” → “허용”

STEP 9 — 동작 확인

python3 check_gmail_auth.py

주의사항 — refresh token 만료 방지

Google Cloud Console — OAuth 앱 프로덕션 전환 가이드

1단계: OAuth consent screen 이동

  1. https://console.cloud.google.com 접속

  2. 상단 프로젝트 선택기에서 raingent 프로젝트 선택

  3. 좌측 메뉴 → APIs & Services → OAuth consent screen

2단계: 현재 상태 확인

페이지 상단에 Publishing status가 표시됩니다.

Publishing status: Testing

Test users 목록에 계정이 등록되어 있을 것입니다.

3단계: 프로덕션 전환

  1. “PUBLISH APP” 버튼 클릭

  2. 확인 다이얼로그가 뜨면 “CONFIRM” 클릭

전환 후 상태:

Publishing status: In production

▎ 주의: gmail.modify는 민감한 스코프이므로 Google 검수를 받지 않으면 로그인 시 “이 앱은 Google에서 확인하지 않았습니다” 경고가 표시됩니다. 본인 계정만 사용하는 개인

▎ 프로젝트이므로 “고급” → “raingent(으)로 이동(안전하지 않음)” 을 클릭하면 정상 인증됩니다.

4단계: 두 계정 재인증

프로덕션 전환 후 새 Refresh Token을 발급받기 위해 각 계정을 재인증합니다.

cd /home/rainny/raingent

eldanscript 계정

python3 auth_gmail.py eldanscript

rainbell72 계정

python3 auth_gmail.py rainbell72

각 명령 실행 시 터미널에 URL이 출력됩니다. 브라우저에서 해당 URL을 열어 Google 계정으로 로그인하고 권한을 허용하면 credentials/{account}/token.json이 갱신됩니다.

5단계: 재인증 확인

python3 check_gmail_auth.py

두 계정 모두 정상 출력되면 완료입니다.
