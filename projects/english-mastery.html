English Mastery — Leo Live English Coach

Vertex AI gemini-3.8-live 기반 실시간 양방향(Full-Duplex) 영어 스피킹 코칭 웹 애플리케이션.

핵심 내용

  • 프로덕션 URL: Cloud Run Gen2 (us-central1) 배포. https://leo-live-english-coach-115089868668.us-central1.run.app
  • 타깃 모델: gemini-3.8-live (gemini-live-2.5-flash-native-audio) + 콘텐츠 분석용 gemini-2.5-flash
  • 4인 AI 튜터 페르소나:
    • Lucas 🇺🇸 — 시애틀 비즈니스·테크 피칭 코치, Voice: Puck, TTS: en-US-Neural2-D (-110c / 1.00x)
    • Victoria 🇺🇸 — 뉴욕 이그제큐티브 뉘앙스 코치, Voice: Kore, TTS: en-US-Neural2-F (+135c / 0.98x)
    • Hailey 🇺🇸 — 실리콘밸리 프로덕트·실전 회화 코치, Voice: Aoede, TTS: en-US-Neural2-C (+230c / 1.05x)
    • Sebastian 🇬🇧 — 런던 글로벌 리더십·스몰토크 멘토, Voice: Charon, TTS: en-GB-Neural2-B (-240c / 0.95x)
  • 프라이버시 보호 데모 모드 (Alex): 미인증 방문자는 가명 Alex (Demo) 고정, 일반 비즈니스 표현 커리큘럼(GEN-01~GEN-20)만 로드, GCS 상태 미기록 무상태(Stateless) 운영
  • Full-Duplex 오디오 아키텍처: 브라우저 AudioWorklet 16kHz PCM 캡처 → 서버 160ms 버스트 코얼레싱(5,120B) → session.send_realtime_input() → 24kHz 네이티브 오디오 하향 스트리밍. 기존 STT→LLM→TTS 직렬 파이프라인(2.5~4.5초) 대비 대폭 지연 개선
  • 세션 안정성: ContextWindowCompressionConfig (16K→8K SlidingWindow) + SessionResumptionConfig 무중단 세션 복구
  • 5종 실시간 Function Calling: evaluate_queue_turn, provide_expression_hint, write_on_blackboard, save_new_study_card, customize_avatar_3d
  • 60fps WebGL 2.5D 아바타 립싱크: GLSL 상·하순 분리 워핑, 절차적 구강(윗니·아랫니·3D 혀 uTongueUp) 렌더링. LipsyncEn 15종 Oculus 비젬(68%) + WebAudio 256-bin FFT 3대역 포먼트 에너지(32%) 하이브리드 융합
  • 학습 큐 관리: 2-Streak 연속 성공 게이트(score ≥ 85, 2회 연속 통과 시 마스터 승급) + Leitner 5-Box 간격 반복, Google Drive 오디오(.m4a/.mp3) 자동 분석 및 온디맨드 +5 AI 학습 카드 생성
  • BigQuery 텔레메트리: 매 대화 턴의 TTFA·Turn Latency·WS RTT·오디오 토큰(32 tok/s)·TPS·추정 클라우드 원가를 english_coach_telemetry.turn_metrics 파티션 테이블에 실시간 적재. Looker Studio 대시보드(/looker-embed) 연동
  • 고객 실습 가이드 (GEAP-LIVE-L400): Lab 0~5 총 120분 구성. Lab 0 GCP 환경 준비 → Lab 1 Live 오디오 브리지 → Lab 2 WebAudio VAD → Lab 3 WebGL 아바타 → Lab 4 Function Calling → Lab 5 BigQuery·Cloud Run 배포

기술 스택

레이어기술
AI 코어Vertex AI gemini-3.8-live (Native Audio), gemini-2.5-flash
백엔드FastAPI, Python 3.12, google-genai SDK, WebSocket (/ws/live)
오디오브라우저 AudioWorklet 16kHz → 서버 코얼레싱 → 24kHz PCM
프론트엔드WebGL 2.5D 아바타, WebAudio API, VAD 바지인
TTS (온디맨드)Cloud TTS Neural2 → WebAudio → WebSpeech 3단 폴백, FFmpeg pitch/rate 변조
스토리지Google Cloud Storage (테넌트 상태), Google Drive (오디오 콘텐츠)
분석BigQuery 파티션 테이블, Looker Studio
배포Cloud Run Gen2 (us-central1), Cloud Build, Artifact Registry

GCP 아키텍처 흐름

  → FastAPI /ws/live (Cloud Run Gen2)

  → WebGL 아바타 립싱크 + 학습 큐 갱신
