Raingent Finance Agent

자산 모니터링·자동 매수를 위한 Multi-Agent 기반 금융 시스템. 2028년 1월부터 배당 ETF로 월 500만원 수령을 목표로 합니다.

시스템 아키텍처 (2026-06-08)

실행 파이프라인

cron (평일 08:00)
  → python -m src.finance_agent daily
      ├── kis_sync.py      — 한투 KIS API 잔고 자동 동기화
      ├── collector.py     — 주식·ETF·환율 현재가 수집 (yfinance)
      ├── calculator.py    — 평가액·수익률·22억 달성률 계산
      ├── reporter.py      — Telegram 메시지 생성
      └── notifier.py      — Telegram 발송 + 스냅샷 저장

cron (토요일 09:00)
  → python -m src.finance_agent strategy
      └── analyzer.py      — Gemini 2.5 Flash 전략 분석 → Telegram 2개 메시지

nohup (상시)
  → python -m src.finance_agent.dashboard
      └── FastAPI REST API (port 8080, Tailscale IP 100.122.69.43)
          + React SPA (frontend/dist/ 서빙)

AI 전략 분석 — Gemini 2.5 Flash (analyzer.py)

5섹션 프롬프트 구조:

  1. 목표 달성 가능성 평가 — 22억 합산 + 카테고리별, 배당 기여도
  2. 리스크 요인 — 집중도·섹터 편중·변동성
  3. 장기 전략 (6개월 이상) — 비중 조정, 리밸런싱, 배당 재투자
  4. 단기 전략 (1~3개월) — 추가 매수 우선순위, 비중 조정
  5. 이번 달 실행 액션 플랜 — 구체적 3가지

컨텍스트 포함 데이터:

  • 22억 합산 달성률·잔여액·기한
  • 카테고리별 달성률·월 필요수익률
  • 연간·월별 배당 내역 (dividends.json 로드)
  • 종목별 수익률·주간·월간 변동
  • 퇴직연금 펀드 현황
  • 최대 단일 종목 집중도
