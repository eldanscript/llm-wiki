Raingent Finance Agent

자산 모니터링·자동 매수를 위한 Multi-Agent 기반 금융 시스템. 2028년 1월부터 배당 ETF로 월 500만원 수령을 목표로 합니다.

시스템 아키텍처

Multi-Agent 구조

Orchestrator가 4개 에이전트를 조율하는 Pane 기반 병렬 실행:

  • Orchestrator (pane 0): 파이프라인 지휘, daily/weekly 모드 분기
  • Backend (pane 1): collector.py — 주식·ETF·코인·환율 현재가 수집
  • Frontend (pane 2): calculator.py, analyzer.py, reporter.py — 계산·분석·메시지 생성
  • Reviewer (pane 3): notifier.py — Telegram·Gmail 발송, Obsidian 저장

실행 파이프라인

일일 (09:00, 21:00 KST)

  1. collector.py: yfinance + 빗썸 API로 현재가 수집
  2. calculator.py: 평가액, 수익률, 전일/전주 변동 계산
  3. analyzer.py: Claude Haiku 4.5로 AI 분석
  4. reporter.py: Telegram 메시지 생성
  5. notifier.py: Telegram 발송 + 스냅샷 저장

주간 (월요일 09:00 KST)

  • 동일 파이프라인 + HTML 이메일 생성·발송 (차트 포함)
