Finance Agent

Python 기반 개인 자산 모니터링·보고·AI 전략 분석 에이전트. KIS API로 한투 잔고를 자동 동기화하고, Gemini 2.5 Flash로 22억 목표 달성 전략을 분석한다. Telegram 일일 알림, 주간 전략 리포트, FastAPI + React 대시보드로 구성된다.

시스템 아키텍처

cron (평일 08:00)
  → python -m src.finance_agent daily
      ├── kis_sync.py      — 한투 KIS API 잔고 자동 동기화
      ├── collector.py     — 주식·ETF·환율 현재가 수집 (yfinance)
      ├── calculator.py    — 평가액·수익률·22억 달성률 계산
      ├── reporter.py      — Telegram 메시지 생성
      └── notifier.py      — Telegram 발송 + 스냅샷 저장

cron (토요일 09:00)
  → python -m src.finance_agent strategy
      └── analyzer.py      — Gemini 2.5 Flash 전략 분석 → Telegram 2개 메시지

nohup (상시)
  → python -m src.finance_agent.dashboard
      └── FastAPI REST API (port 8080, Tailscale IP)
          + React SPA (frontend/dist/)

AI 전략 분석 (Gemini 2.5 Flash)

analyzer.py가 생성하는 전략 분석 — 5개 섹션:

  1. 목표 달성 가능성 평가 — 22억 합산 + 카테고리별 달성 가능성, 배당 기여도 포함
  2. 리스크 요인 — 집중도·섹터 편중·변동성
  3. 장기 전략 (6개월 이상) — 카테고리별 목표 비중, 리밸런싱, 배당 재투자
  4. 단기 전략 (1~3개월) — 추가 매수 우선순위, 비중 조정
  5. 이번 달 실행 액션 플랜 — 구체적 3가지 행동

컨텍스트에 포함되는 데이터: 22억 합산 달성률·잔여액, 카테고리별 달성률, 연간·월별 배당 내역, 종목별 수익률·주간·월간 변동, 퇴직연금 펀드 현황, 최대 종목 집중도

React 대시보드
